# Balatro 视觉语言 → 动态字幕组件

目标是 Balatro / 小丑牌 / 赌场纸牌 / 传奇卡牌启发的中文 UI 字幕。先读 style_reference 中已核验的图像类别和视觉提炼；附图是参考而非待复制素材。无附图时明确只取得观察文本，不声称亲自看图。不抄某张官方卡，不新画人物、动物、小丑头像或像素角色卡。

语法：深青灰厚外壳、近黑凹槽、清晰切角/阶梯圆角、奶白效果说明窗、向下实体阴影。红色表达 mult/倍率，蓝色表达 chips/筹码，紫色稀有度脚签；标签附着框边，正文是主角。纸牌白边/印刷套色、封签的压边、局部 foil 同心刻纹与低频循环虹彩反光可转译进框与关键词。中文用实际打包字形和压印/定向厚边，不靠英文口号撑版。像素是原作栅格特征之一，不是整个风格；中文可用清楚的厚实字形，局部切角与点阵保留游戏UI味道。

三候选时分别发展：A「小丑牌倍率封签」：浅色效果窗叠在厚灰卡框里，红倍率关键词签和蓝筹码角签扣在同一框上；套色纸边、字面压印；底板啪地就位→边框锁定→正文和倍率签后扣，退出先回扣标签再收牌。B「赌桌筹码压印框」：宽肩切角深绿牌匾、筹码齿纹侧边和铜色压线；浅色厚字与蓝筹码式关键词；上下框压合→正文压印→筹码边就位，退出齿边退回、整块刚性抽走。C「稀有卡贴纸 / 传奇封牌」：叠层银边封套、紫稀有度封签、局部虹彩刻纹，关键词为贴纸式封签；封套打开→正文锁定→角签贴合，阅读期间foil持续缓慢掠过边缘，退出贴签抽离→主体收入封套。结构、材质、关键词和动作都要不同，不能同条幅换色。单候选按需求选最适合方向；这些是语法，不要求复制固定布局。

必须在真实字幕比例看见背景轮廓、内外框关系、留白、正文加工、关键词层次和局部效果。无关键词的句子仍有完整主题框与字面；长句自然换行、短句自适应，不留角色窗占位。允许花色、筹码分段边、倍率标签、封签与版本贴纸；装饰依附字幕，不漂一张小卡在上方。

入场必须有“扣/贴/压/翻”的主题事件，不能仅根容器平移/透明度。build 内层次错峰，文字在窗口内完成可读；阅读期始终保留克制生命感：持续扫描、颗粒流动或局部foil循环，字框亚像素/小角度微动；主轮廓与中文可读性稳定；resolve从阶段0开始组织回扣与收牌，0.95前完成，不能误把0.96当整句95%。短cue缩行程和事件，保留稳定阅读，不压缩成硬闪现；极短cue遵循宿主稳定阅读策略。

禁止：抽象画/流体或印象涂抹、无依据几何块、普通像素小插图、角色卡压过字幕、黑条白字黄块、全画面霓虹/HUD飞线、大幅抖动或不停抢拍的正文、淡入淡出冒充完整动作。抽象概念表达指把主题转译成UI结构与材料关系，绝不等于抽象画；不要具象角色绝不等于取消背景框或细节。

当前优先组件version:5。转场语法参考视频过渡插件：BCC Damaged TV Dissolve的信号恢复/压线关机；Split Transitions的相反方向遮罩开合；快速转场的冲击—回弹—锁定。typeEffect与transition可独立组合crt/score/foil，作用范围限字幕框。阅读期MotionSpec v2的breathe用sustain:true+durationMs:1100..3500直到窗口结束，短cue不加速。来源见随包motion-reference.md。
