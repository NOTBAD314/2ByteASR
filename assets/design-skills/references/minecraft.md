# Minecraft主题展开（参考语汇，不是三模板）

统一像素格点、可信方块空间、可区分的草土/石/木/矿物材质以及游戏内的建造、信号、生态或空间机制，构成主题识别。不要只做平面棋盘格或一条棕色字幕条。可从具体世界活动展开三个美术方向，不强制草地/红石/传送门三件套。

同一表面的局部纹理要遵循像素尺度和朝向；顶面/正面/侧面的明暗应有统一光源，不均匀的像素颗粒增强材质，禁止纹理铺满画布。字体可选已打包Cubic11像素字体，保持真实中文字形和完整行宽。

动作应有游戏语义和因果：组装、信号传播、机械响应、碎屑落定、生长或空间变化都可以成为主动作。丰富来自多个相关部件参与同一次事件，不是全体抖动。中文可以参与建造空间、物件承载或像素排版；先估算正文的格点尺度和行数，再决定结构尺寸。
