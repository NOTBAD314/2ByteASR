# 初音主题展开（参考语汇，不是候选模板）

核心是虚拟歌姬与电子音乐演出的轻盈、清澈和精密感。青绿/葱青与黑、银白组成关系，少量洋红可以来自发饰、电子标记或节拍强调。明亮银白也可以主导；不要默认黑底加青色HUD，更不要棕金木箱。

从音乐、舞台、服饰和字体中挑选相互支持的一组：修长的双曲线节奏可呼应双马尾；褶裥、领带的纵向线和袖口电子细节可抽象为排版结构；半透明光学膜、银色拉丝、乐谱节奏、均衡器或演出屏幕可以组织空间。不是把所有符号堆在同一个盒子上。不要把几根数据线当成完整主题。

优先精致的非人物艺术方案，例如富有性格的演出字体与流动曲面、音乐驱动的光学装置、服饰语汇转译的精密图形；这些只是语汇范围，不是固定三稿。若要角色，必须具备完成度合格的形体和细节资源，不能用圆头+矩形裙+两根青线代替角色。

运动体现音乐结构：先有短促节拍触发，再有流线、层片或字形响应，稳定段保留相位不同的细微变化，结束以节奏收束。正文参与演出标题和空间层次，并给中文留完整阅读段。三稿自由选择完全不同的视觉中心与节奏，不复制Minecraft方块台座。
