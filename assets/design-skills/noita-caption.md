# Noita 字幕视觉语法 · 2026-09-26

参考为实际读取的 https://noitagame.com/ 、官方 screenshot_013.jpg（圣山暗石/金刻符/局部蓝绿光）、screenshot_010.jpg（炼金瓶/岩层/熔岩与离散火花），以及 https://noita.wiki.gg/wiki/Wands 的物品说明图。观察与作者转译分开；不复制Logo、符文原形、框图、法杖或药瓶素材。

色彩：大面积煤灰、暗土褐、灰橄榄；暖白实体字；局部旧金、药剂绿、余烬橙。饱和色是反应源，不是整框赛博发光。结构：稳定的短横字幕承托面，方阶切角、断续嵌边、稀疏刻符；阅读区安静，边沿和与框接触的小炼金物件体现主题。不要场景大石块、巨幅海报、恐怖血字、传统JRPG人物对话框。

四方向：秘法石板（分层石沿/刻文点亮）；炼金卷轴（焦纸/墨迹/封蜡失效）；炼金反应铭牌（暗石薄底/药剂液面/有限火星）；地牢警示符（烧蚀边/危险色/法印回收）。优先反应铭牌用于反复播放与长句，方向必须有结构与动作差异，不能只换配色。

字先读清：只保留一套实心主字，可用已打包Cubic 11或清晰中文与像素描边。主体笔画不透明、不漏视频；重点词仅局部药剂色，不让整句跳动或被纹理穿透。44–88px参考字号，66px像素字为基线，长句换行而非无限缩字。

动作：150–450ms法印点亮召唤，首段即有正文；无中心横展。常驻正文和框面稳定，药液/边符/少数火星以真实毫秒低频变化；短cue减少次要事件。退场印记先熄、带字面阶梯回收，在末个编码帧前清空；不只整组淡出。MotionSpec为唯一时钟，steps缓动只用于装饰/边界，避免昂贵filter/turbulence/无限粒子。

HTML和MotionSpec是编辑真源，透明PNG帧代理只是可丢弃缓存；草稿关闭粒子与纹理，标准保留炼金主体和刻符，完整保留所有局部细节。三档均保持框、正文、主进退场与阅读尺寸。保存/导出用原完整源码，不把草稿烘进工程。不为未经确认的候选自动生成整条时间轴代理。
