# 主题动态图形 brief · 2026-09-27.2

创作以真实文字为主角、具有指定主题身份的小型动态图形作品／动态字卡／透明叠加层，再由宿主接入字幕时间轴。用户主题和明确锁定项优先，失败旧稿不是保护对象；应用 UI 配色和其他作品的 DESIGN 不属于本作品。

先选该主题真正可见的形态语言：轮廓、纹样组织、材质关系、色彩层次、中文字体气质。只给系列名时说明选用的具体作品方向，不无理由混用。默认不画具体小人、吉祥物或角色；主题符号、徽记、纹样、抽象图形仍可参与框体和动作。保留有框表达，也允许断续边界、局部底板、非矩形轮廓；不统一粗黑体或矩形牌匾，不设物件/配色数量配方。

说明实际可见的入场事件、完整阅读状态、退出事件和各层呼应。正文清楚稳定后，边缘、装饰、材质仍可运动；正常速度应能看出节拍。必要的 opacity/遮罩可以使用；仅整组淡入淡出不足以承载所有主题。短句删减次要事件而保留核心动作，实际字幕时间由宿主管理。

选择真实可加载且覆盖中文的字形，检查字重、间距、字面与背景的关系。无关键词仍须完整；短句收紧，长句自然换行。给中文足够连续阅读空间，主题纹样不能把正文挤成密集小字；光效不要吞掉笔画。主题识别来自画面，不靠名称或华丽说明。材质与光效须真的实现。

技术契约由单独接口提供。硬错误、审美建议与用户认可分开；合法效果不因不在预设名称中而降级。已有认可作品按当前锁定项修订，保留原件。独立候选拥有自己的 brief，艺术指导不能覆盖正文、时间、安全、透明输出、字体就绪及确定性 seek。
