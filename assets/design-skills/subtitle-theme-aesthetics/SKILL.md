# 主题先行的字幕动效作品 · 2026-09-27

把字幕当作承载真实正文的短时动效作品。用户主题和当前要求优先，字幕只约束正文准确、实际画面可读、时间和位置可控，不限定必须是长矩形、粗字、厚框或抽象UI。先想一个主题事件和可辨识构图，再适配长短句。简洁、抽象、具象、角色和装置都是可选手法，不能把某次失败或旧偏好升级为全局禁令。

主题名称允许采用与之有关的符号、纹样、器物、角色和空间关系，不需要用户另写造型授权。选少量最有识别度的元素并与字/支撑结构共同构图；不靠随意小图标、换色或标题声称像某游戏。用户明确“不要人物/无框/保留角色”等要求只作用于本次任务。无要求时不强塞人物，也不预先禁止人物。设计底板是否存在、厚薄、非矩形轮廓、开放边界和比例由可读性与主题决定。

规划说明须简述：可见主题依据、正文/支撑/标志的关系、入场事件、阅读期活动、退出事件。主题识别检验：去掉名字和说明，仍能从轮廓、纹样或动作识别方向吗？把颜色换成灰阶后，是否仍有专属形态？普通石板/绿金套边/粗白字只算基线，不能用“神庙/古代”命名替代设计。

动作按因果编排：触发物先行动→结构回应→字面形成→局部生命力→撤销/转化/回收。每个作品选择合适事件，不统一套旋转、扫光、像素或淡入。opacity可以辅助显隐；仅全组opacity或轻微平移不构成主题动作。入场与出场各有可见主体变化，出场可不同于入场倒放。阅读段正文清楚，外围允许有意义的活动；短cue减少次要事件和行程，保留主题识别，不把整场加速塞满。

字面设计服从主题：选真实中文字体，考虑笔画气质、层次、材质和字距，不强制每稿重描边/浮雕。没有重点词仍是完整作品。短句自适应收紧、长句自然换行，不改正文，不用额外英文假标语填空。

使用宿主已声明的HTML/SVG/CSS静态图层与MotionSpec单一时钟；安全、文本绑定、字体加载、可重复seek与导出一致性是技术硬边界。不要把这些技术边界理解成审美限额；自由源码是正常创作路径，组件只是可选的快速材料，不把不适合主题的预设当失败退路。

新作自由构思；已有作品修订先明确本次锁定项。保留用户认可的结构与动作，用户已否定的失败稿只作反例，不自动冻结，也不自动覆盖已采用作品。技术通过可预览/保存/采用；美感建议不触发无授权收费重做。实际检查正常比例、细节与完整正常速度动画、6秒和1.5秒、换句、正反seek、首尾清场；技术通过、作者审查与用户满意分开记录。

# 项目协作与生效路径

新作按当前要求自由创作；增强仅保护用户实际认可/明确锁定项，失败稿不是满意基线。严格材质修订不改结构动作，明确重构可以协同修改；不把两种任务混淆。将旧稿、模型首稿、本地精修分开保存和标识。

实际生成加载 assets/design-skills/abstract-caption.md、material-caption.md 和命中主题指导，由 design_guidance 返回版本及每份文件SHA。项目 skill 与随包副本同步；修改后检查普通规划、实现和修订的实际提示，不只编辑本文件。安全/字体/绑定/时钟边界以代码能力契约为准，不重复累加旧限制。
