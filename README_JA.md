# 2ByteASR · 兔白字幕

**正確な字幕で、動画編集をもっと手軽に。**

無料の字幕作成・動画編集ツール。ローカル環境で利用できます。<br/>
文字起こしから校正、字幕エフェクト、動画の書き出しまで、ひとつのアプリで。

## ひとつの字幕を、3つの役割で仕上げる

対応状況：Windows はデスクトップ作業に対応し、公開インストーラーはまだありません。[macOS ネイティブデスクトップ実験版](docs/deployment/macos-experimental.zh-CN.md)は開発中で、最初の対象は Apple Silicon arm64 です。実際のビルド・検証状況はリンク先の中国語ガイドをご覧ください。

文字起こしで話し言葉をテキストにし、タイミング調整で文字や単語を映像に合わせ、照合で同じ発話の認識結果を比較します。素材と機器に合わせてモデルを組み合わせ、必要に応じて AI による文の分割も利用できます。

| 役割 | できること | 主な選択肢 |
| --- | --- | --- |
| メインの文字起こし | 音声をテキスト化。話者識別に対応したモデルでは、話者別トラックの整理にも活用 | MOSS、SenseVoice、Whisper |
| 文字・単語のタイミング | 境界を捉え、映像に合った位置で字幕を分割 | FireRedASR2-AED、Paraformer。既存テキストには独立したアライナーも利用可能 |
| テキストの照合 | 別の認識結果と比較し、聞き取りにくい言葉や食い違いを確認 | Qwen3-ASR などのローカル／オンラインモデル |

![話者 A の2つの発話と話者 B の返答が、それぞれの字幕トラックに入る](docs/assets/readme/speaker-tracks.gif)

*A → B → A。発話ごとに文字起こしし、話者別のトラックに配置。*

## 単語の境界で切り、字幕のテンポを整える

長い文の切りたい位置を選び、分割ツールで切ると、タイムラインにも字幕クリップが反映されます。区切りを変えたいときは、元に戻すか結合して調整できます。

![長い文の切り位置を選んで3つに分割し、タイムラインと連動させながら順番に元に戻す](docs/assets/readme/word-split.gif)

## 同じ発話の候補を比べて採用する

「人物」「任务（任務）」「战术（戦術）」のどれか。同じ字幕の候補を並べて、文言の違いと認識元を確認できます。候補を選んで採用すると、現在の字幕が更新されます。

![候補を比較し、任务を採用して現在の字幕を更新する](docs/assets/readme/candidate-review.gif)

## ゲーム用語集：一度整理すれば、次の動画にも

キャラクター名、別名、よくある誤認識をゲームごとに管理。参考用語と出典を確認してから、認識に使用できます。次の素材でも、整理した用語集をそのまま活用できます。

![用語集のゲーム分類、出典、確認状態、一括管理の画面](docs/assets/readme/glossary.png)

## 配信の切り抜きと字幕エフェクト

**まず、切り抜きたい場面を見つける。** 配信コメントの XML と字幕から、瀕死からの逆転、思わず笑う失敗、コメントが集中した場面などを探します。左側で候補を選ぶと、右側の選定理由とタイムラインの選択範囲が連動。気に入った場面を編集に追加できます。

![配信の切り抜き候補を切り替え、理由と選択範囲を確認して編集に追加する](docs/assets/readme/live-clips.gif)

**ひと言に、表情を添える。** フォント、質感、登場と退場の動きを組み合わせて字幕をデザイン。既存のスタイルを再利用したり、AI デザインサービスを設定して生成・修正したりできます。字幕デザインと切り抜き機能は、それぞれ単独でも使えます。

![木版画風と CRT スコアボード風の字幕が登場し、表示を保ってから退場する](docs/assets/readme/caption-effects.gif)

*木版画風：木の板が合わさり、刻まれた文字が現れ、折りたたまれて退場。CRT スコアボード風：電源が入り、文字が発光し、画面が消えて退場。*

## ダウンロードとクイックスタート

**Windows x64** 向けです。本リポジトリで提供するのは限定されたソースです。**公開インストーラーはまだありません**。内部テスト候補は公開ダウンロード版ではありません。この範囲は既存 Setup の完全な対応ソースではなく、このツリーだけでの完全なビルドは未検証です。[ソースの範囲とビルド条件](SOURCE_ONLY_SCOPE.md)をご確認ください。

1. **ソースを準備。** [ソースの範囲とビルド条件](SOURCE_ONLY_SCOPE.md)を読み、独立した開発環境で利用権限のある外部依存関係を準備します。以降は依存関係の準備後の製品利用手順です。
2. **認識の準備。** モデル工房でローカルモデルを準備するか、利用するオンラインサービスを設定します。
3. **素材を読み込み、文字起こし。** 素材、コンテンツ設定、用語集を選び、認識テキスト、単語のタイミング、話者の結果を確認します。
4. **字幕ワークスペースを開く。** 校正、分割・結合、字幕と映像の調整を行い、字幕ファイル、原稿、字幕を焼き込んだ動画を書き出します。

既定のテーマは**ディープグレープ**。外観設定から好みの配色に変更できます。

### 動作条件

- **OS：** Windows 10 22H2（19045）以降の x64 システム。
- **ローカル認識：** モデル工房から必要なモデルの重みをダウンロードします。SenseVoice は CPU に対応。MOSS などは NVIDIA CUDA を使用します。各モデルの要件はモデル工房で確認できます。
- **オンラインサービス：** 自分のアカウントまたは API キーを使用します。料金は各サービスの規定に従います。
- **出力：** SRT、ASS、TXT、JSON、話者別トラック、MP4・MKV・MOV 動画。
