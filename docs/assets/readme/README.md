# README 素材说明

2026-10-29 更新：首页四种语言的 README 改成“字幕剪辑翻译工作台”，主图和“能做什么”的六张图全部换成 **0.8.7** 的真实窗口截图（`workbench*.png`、`feature-*.png`），示例画面从测试卡换成项目自绘的小游戏画面。旧的 `hero*.png` 已删除；“界面一览”（`docs/product-demo.*.md`）仍用下面列出的 0.7.1 / 0.7.2 素材，这次没有重拍。

## 读者需要知道的

- **截图是真的**：全部来自 tag `v0.8.7` 的程序源码（与 0.8.7 安装包同一提交），在隔离的 Windows 私有桌面上启动正常主窗口截取。用户数据、缓存、工程都写在临时测试文件夹里，只读取本机已登记的运行环境（`TWOBYTEASR_DEVELOPER_RUNTIMES=1`，登记表只读）和模型，并阻止对外网络连接。没有用安装版 EXE 截图；界面代码与安装包相同。
- **素材是自制的**：示例视频是用 PIL 绘制的横版小游戏画面（“林间小径”，`build_demo_media.py forest`），配合 Windows 自带中文语音合成的两人对话（男声 Kangkang、女声 Yaoyao）。没有使用游戏实录、直播录像、私人媒体、用户配置或密钥。
- **识别是真的跑过的**：34 秒示例在本机用 MOSS + FireRedASR2-AED + Qwen3-ASR 识别（NVIDIA RTX 5070 Ti，约 3 分钟，含模型加载），关闭 AI 断句与 AI 校对，得到 14 条字幕、两位说话人。“他／它”一处三个模型写法不同，就是审核图里的那一句。
- **在工作台里做过的操作**：在说话人管理里改名（主播／队友，英文 Host／Teammate，日文 配信者／相方，韩文 스트리머／팀원）；用合并工具和剃刀修了 4 处断得不好的句子；审核里采用 Qwen 的“它”；译文用工作台的手动补译逐条写入（与在译文轨双击输入是同一条代码路径，没有用 AI）：中文界面配英文译文，英、日、韩界面配各自语言的译文；打开双语显示（原文在上）。
- **只做了这些处理**：裁切、缩放、圆角和调色板压缩。六张功能图从同一个窗口里裁出 16:10 的区域（裁切框由截图时记录的控件位置算出，见 `build_assets_087.py`）；说话人管理窗口和链接下载窗口截图前把窗口调成 16:10 的大小。没有修改界面文字、按钮或识别结果。
- **窗口大小**：中文 1440×900，英日韩 1600×1000（标签较长），都按 2 倍缩放截取。
- **不是基准**：耗时和结果只代表这一段示例，不说明模型速度或准确率。

## 录制时看到、尚未修复的界面问题（0.8.7）

截图取景避开了它们，但没有修改画面：

- 时间轴面板较高时（中文 1440×900 窗口里约 425 像素以上），译文轨的字幕块画得比轨道高，下半截被视频轨挡住。截图把时间轴固定在 400 像素高。
- 工具面板“动效”页在 1440×900 窗口里，“持续时间”和“强度”两行文字叠在一起。样式图因此用“样式”页。
- 英文、日文、韩文界面里还有一部分文字是中文：工作台标题栏的“双语 / 翻译”、审核条的说明；韩语界面的说话人管理也有好几处。英文界面在 1440 宽时说话人轨名和列表标签会被截断（所以英日韩用 1600 宽）。
- 链接下载窗口只有简体中文、繁體中文、英语和日语界面；韩语界面下它大部分显示英文。日语界面在 848×530 时底部状态栏的说明被截断、右侧出现滚动条。
- 用过剃刀后出现的快捷键提示条，截图前手动关掉了。
