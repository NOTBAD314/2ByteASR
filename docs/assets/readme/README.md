# README 素材说明

2026-10-29 更新：GitHub 首页默认改成英文（`README.md`），中文移到 `README_ZH.md`。四种语言 README 的主图和“能做什么”六格全部换成 **0.8.7** 的应用内真实截图和真实操作录制（`workbench*.png`、`feature-*.webp`、`feature-link*.png`），示例影片是开放授权电影 *Tears of Steel*。“界面一览”（`docs/product-demo.*.md`）仍用下面列出的 0.7.1 / 0.7.2 素材，这次没有重拍。

## 读者需要知道的

- **示例影片**：[Tears of Steel](https://mango.blender.org/)，© Blender Foundation，[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。用的是开头 0:22–2:10 的片段（桥上 Celia 和 Thom 的对话，以及之后的实验室），从官方 720p 文件裁出，没有改画面。
- **截图和录制是真的**：全部来自 tag `v0.8.7` 的程序源码（与 0.8.7 安装包同一提交），在隔离的 Windows 私有桌面上启动正常主窗口截取。用户数据、缓存、工程都写在临时测试文件夹里，只读取本机已登记的运行环境（`TWOBYTEASR_DEVELOPER_RUNTIMES=1`，登记表只读）和模型，阻止对外网络连接。
- **识别是真的跑过的**：108 秒片段在本机用 MOSS + Qwen3-ForcedAligner + Qwen3-ASR 识别（NVIDIA RTX 5070 Ti，约 3 分钟，含模型加载，识别语言设为英语），关闭 AI 断句与 AI 校对，得到 12 条字幕。MOSS 把 Thom 写成 “Tom”、把 “claws of death” 写成 “class of death”，画面里保留原样。
- **在工作台里做过的操作**：在说话人管理里输入 Celia、Thom（录制中可以看到逐字输入）；用剃刀在 “I'm having nightmares” 之后切开一句；译文用工作台的手动补译逐条写入（与在译文轨双击输入同一条代码路径，没有用 AI），英文和中文 README 配中文译文，日、韩 README 配日语、韩语译文；打开双语显示（原文在上）；样式录制里给全部字幕依次换了几套预设，再给一句加“柔和弹入”入场动效并播放。
- **审核候选用的是中文示例**：0.8.7 的审核模式只给中文字幕列出多模型候选，这段英语影片没有候选可看。所以 `feature-review*.webp` 用的是 2026-10-29 同一天、同一版本录的中文示例（自绘小游戏画面 + 合成语音，MOSS／FireRed 写“他”、Qwen 写“它”），只截候选条，不含画面。
- **只做了这些处理**：裁切、缩放、圆角、调色板 PNG 与 WebP 编码；审核候选条放在应用自己背景色的底板上居中成 16:10。动图每一帧都是同一个窗口的原生截图，按截图时记录的控件位置用同一个框裁切，帧间隔保持录制时的实际间隔（录制时窗口截图约每秒 3–4 张，所以播放画面不是 30 帧流畅视频）。没有修改界面文字、按钮或识别结果。
- **窗口大小**：中文 1440×900，英日韩 1600×1000（标签较长），都按 2 倍缩放截取。
- **不是基准**：耗时和结果只代表这一段示例，不说明模型速度或准确率。

## 录制时看到、尚未修复的界面问题（0.8.7）

截图取景避开了它们，但没有修改画面：

- 时间轴自动分配高度时给译文轨只留 44 像素，画的时候却和说话人轨一样高（最多 74 像素），译文轨的字幕块下半截被视频轨挡住。截图前把字幕轨高度固定为 48 像素（等同于在应用里拖动轨道高度）。
- 审核模式不给英语字幕列出多模型候选（这段影片里 Qwen 听成了正确的 “claws”，MOSS 是 “class”，但没有候选卡片）。
- 工具面板“动效”页在 1440×900 窗口里，“持续时间”和“强度”两行文字叠在一起。
- 英文、日文、韩文界面里还有一部分文字是中文：工作台标题栏的“双语 / 翻译”、审核条的说明、说话人管理的“在字幕前显示说话人名称”“声纹比对”等。英文界面在 1440 宽时说话人轨名和列表标签会被截断（所以英日韩用 1600 宽）。
- 链接下载窗口只有简体中文、繁體中文、英语和日语界面；韩语界面下它大部分显示英文。日语界面在 848×530 时底部状态栏的说明被截断、右侧出现滚动条。
- 用过剃刀后出现的快捷键提示条，截图前手动关掉了。
