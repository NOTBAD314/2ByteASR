# 2026-11-01：独立 MCP 制作工具沿用原生功能与权限

## 背景与决定

用户明确要求 MCP 能直接修改字幕并调用更多软件功能。保留原有 18 个工具的参数与批准计划，新增 13 个独立制作工具按现有 MCP 开关、工程范围、编辑、导出和词库权限直接执行；不增加逐功能授权、批次令牌或新的迁移确认。此决定扩展 ADR 0106 的新工具行为，旧 `preview_* / apply_plan` 的批准流程保持。

运行中的 GUI 仍是唯一工程写入方。stdio 只做协议转换，桥接层只分派有限操作；识别、断句、校对、保存、剪切、撤销与渲染继续由原生服务负责。新增工具不接受 shell、任意代码或整份工程 JSON 写入。

## 结果与边界

- `current` 范围不切换工程；新建和打开库内其他工程需 `library` 范围。
- 异步回执绑定工程、revision、内容指纹及路径；取消或撤权阻止迟到结果采用，不自动重发收费请求。
- 工程内容指纹不能代替媒体来源身份。停顿剪切采用前重新捕获原生输入指纹，核对音频图及来源文件大小/修改时间；不符、丢失或缺少原始身份时拒绝，工程和撤销栈保持。
- 独立词库权限与工程范围分开。口吃整理在有关联词库时，预览及采用均复核词库权限；识别按保存配置使用关联或全局词库时也需该权限。撤权取消在途校对、口吃整理和识别。
- 工程格式、settings schema 与普通 GUI 调用的默认行为不变。显式数据根可隔离 Qt 设置，默认启动沿用原位置。

实现说明与接口见[独立制作工具](../mcp-production.md)。源文件身份的校验沿用原生大小/修改时间指纹，不宣称对故意保留这些属性的字节替换进行了全文件散列。物理输入、其他硬件、Mac 与耐久依各次实际验收记录。
