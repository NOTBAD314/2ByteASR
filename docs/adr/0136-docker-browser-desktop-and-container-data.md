# ADR 0136：Docker 保留原桌面，配置与模型独立持久化

日期：2026-10-19。状态：采纳。适用：独立 codex/docker-0.8.1 分支。

## 问题

用户需要 0.8.1 的 Docker 包，并要求字级时间戳模型与云端默认推荐。桌面依赖 Qt、mpv、音频输出和本地工程；只暴露识别命令无法覆盖编辑与导出，重写 Web UI 又会改变产品范围。

## 决定

以固定摘要的 Selkies 镜像承载原 Qt 桌面，linux/amd64 CPU 为首个受验证平台。通过 `TWOBYTEASR_CONTAINER=1` 启用最小 Linux 适配；保留原识别结果、工程与设置 schema。基线固定 v0.8.1，不从共享工作区混入后续日常修改。

首次启动种入 MOSS Pro API + Qwen3 本地对齐，保留已有设置。只展示能用当前 CPU 环境准备的模型；未完成 NVIDIA/MLX 运行适配的模型不作为可用项。云端仍要求用户自己的 API Key 与正常上传确认。

程序进入镜像，设置与工程放 /config，权重放 /models，媒体走显式 /media 挂载。API Key 用配置卷内 0600 密钥加密；密文和密钥作为一个备份单元，不承诺能防御已获得宿主机或卷权限的访问者。默认网络绑定 127.0.0.1；远程连接由部署者配置访问控制。

## 代价与证据

保留原有编辑能力，但浏览器看到的是远程桌面画面，CPU 长视频速度依赖主机。已验真实 SenseVoice + Qwen3、音画播放、编辑与导出；云端仅协议回环，CTC 仅推理冒烟，其余模型不因此成为已验。最终交付包含镜像归档、对应源码、配置、校验和及检查证据。
