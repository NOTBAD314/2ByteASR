| Apple シリコン（M1 以降）の Mac、macOS 15 以降 | [`2ByteASR-0.7.2-macos-arm64-Setup.dmg`](https://github.com/NOTBAD314/2ByteASR/releases/download/v0.7.2/2ByteASR-0.7.2-macos-arm64-Setup.dmg)（約 0.5 GB） | 実験版、Intel Mac は非対応 |

## Windows へのインストール

1. `2ByteASR-Setup-0.7.2.exe` をダウンロードします。確認したい場合は、ダウンロードしたフォルダーで PowerShell を開き、`certutil -hashfile 2ByteASR-Setup-0.7.2.exe SHA256` を実行して `SHA256SUMS.txt` の値と比べてください。
2. インストーラーを実行します。既定のインストール先は `%LOCALAPPDATA%\Programs\2ByteASR` で、管理者権限は不要です。別のドライブにも変更できます。インストール後は約 1.9 GB です。
3. インストーラーには**コード署名がありません**。そのため「不明な発行元」や「Windows によって PC が保護されました」と表示されることがあります。本リポジトリの Releases から入手したものでハッシュ値が一致していれば、「詳細情報」→「実行」を選んでください。**SmartScreen やウイルス対策ソフトなどのセキュリティ機能を無効にする必要はなく、無効にすべきではありません。**
4. スタートメニューかデスクトップのショートカットから起動します。

**以前のバージョンを使っている場合：** 0.6.5 / 0.7.0 / 0.7.2 はアプリ右上の「更新を確認」から、変わった部分だけをダウンロードできます（0.7.2 からは約 50 MB）。0.6.0 以前は、アプリを閉じてから新しいインストーラーで**アンインストールせずに上書き**してください。設定、用語集、プロジェクト、ダウンロード済みのモデルと実行環境は残ります。

**ファイルの保存場所：** 設定、用語集、プロジェクト、ログは `%LOCALAPPDATA%\2ByteASR` にあります。新規インストールでは、モデルはプログラムのあるフォルダーの `models` にダウンロードされます（D ドライブにインストールすればモデルも D ドライブ）。以前ダウンロードしたモデルはその場所のまま使います。

## Mac へのインストール（実験版）

**対応環境：** Apple シリコン（M シリーズ）、macOS 14 以降（0.8.5 から。0.8.4 以前は macOS 15 が必要）。**Intel Mac には対応していません。** メモリは 16 GB 以上を推奨し、8 GB の Mac は未確認です。このバージョンは GitHub の仮想 Mac（仮想 M1、メモリ 7 GB）でのみ確認しており、実機の Mac では確認していません。

1. DMG をダウンロードします。確認したい場合は「ターミナル」で `shasum -a 256 2ByteASR-0.7.2-macos-arm64-Setup.dmg` を実行し、`SHA256SUMS.txt` と比べてください。
2. DMG を開き、`2ByteASR` を「アプリケーション」へドラッグします。
3. アプリには **Developer ID 署名がなく、Apple の公証も受けていません**。初回は Finder で Control キーを押しながらアプリをクリックし、「開く」を選び、確認で再度「開く」を選びます。それでも開けない場合は「システム設定 → プライバシーとセキュリティ」の下のほうにある「このまま開く」をクリックします。**Gatekeeper などのセキュリティ設定を無効にする必要はなく、無効にすべきではありません。**
4. 次からは通常どおり開けます。

モデル、実行環境、設定、プロジェクト、ログは `~/Library/Application Support/2ByteASR` に、API キーは macOS のキーチェーンに保存されます。Mac 版の既知の制限（速度、ウィンドウが狭いと上部ツールバーが重なる、テキストレビューなしでは状態が「部分降级成功」（一部縮退での成功）と表示される、など）は [Mac 版の説明](deployment/macos-experimental.zh-CN.md)（中国語）にあります。

## 初回起動

新規インストール後の初回起動時に、認識方法を選ぶ画面が出ます（1 回だけ。あとからホーム画面の案内やヘルプメニューから開き直せます）。

| 選択肢 | 使うもの | 最初のダウンロード | 向いている場合 |
| --- | --- | --- | --- |
| **この PC で認識**（Windows） | MOSS + FireRedASR2-AED + Qwen3-ASR | モデル約 11 GB と実行環境（CUDA 版 PyTorch を含む） | NVIDIA GPU があり、話者分離、1 文字ずつの時刻、モデル比較を使いたい |
| **クラウド認識** | MOSS Pro クラウド（MOSI）、Alibaba Cloud 百炼、Qwen Cloud など | モデルは不要 | GPU がなく、すぐに字幕を作りたい。API キーが必要で従量課金 |
| **軽量（この PC）** | SenseVoice（CPU） | 約 0.9 GB と実行環境 | GPU がなく、アップロードしたくない。遅く、話者は分けない |
| **この Mac で認識**（Apple シリコン） | MLX 版 Qwen3-ASR とアライナー | 約 2.3 GB と実行環境 | Mac でアップロードしたくない。コミュニティ実装で実機では未確認 |

ローカルの選択肢ではモデルワークショップが開いてダウンロードが始まり、クラウドを選ぶと「API の申請と設定」が開いて、申請とキーの入力を案内します。NVIDIA GPU がない PC では、「この PC で認識」のカードに使える NVIDIA GPU がないと表示され、選べません。

まず画面に慣れたい場合は「ヘルプ → はじめてのチュートリアル」を開いてください。31 ステップのアニメーション付きチュートリアルで、サンプルプロジェクトを使ってホーム画面と字幕スタジオを案内します。自分で操作しても、「代わりにやる」を押してもかまいません。モデル不要で、アップロードも費用もありません。

## 認識方法の選び方

| お使いのコンピューター | おすすめ | 話者分離 | 1 文字ずつの時刻 | モデル候補 |
| --- | --- | --- | --- | --- |
| Windows、NVIDIA GPU あり | ローカルの MOSS + FireRedASR2-AED + Qwen3-ASR | あり（MOSS） | あり（FireRed が実測） | 3 つ |
| Windows、NVIDIA GPU なし | クラウド認識 | MOSS Pro クラウドと Qwen-Audio 3.1 はあり、ほかのサービスはなし | 百炼 / Qwen Cloud はあり、文単位の時刻だけのサービスは「推定」 | なし |
| Windows、NVIDIA GPU なし、アップロードしたくない | 軽量（SenseVoice） | なし | ローカルの Qwen3 アライナー（CPU 可）を加えればあり | なし |
| クラウド + ローカル整列 | クラウドで文字起こし、ローカルの Qwen3 アライナーで時刻を付ける | サービスによる | あり（ローカルで整列、アップロードなし） | なし |
| Apple シリコンの Mac | この Mac で認識（MLX）、モデルワークショップで準備した Apple GPU の MOSS + FireRed、またはクラウド | MOSS ならあり | あり | MOSS + FireRed で 2 つ |

補足：

- **Windows で NVIDIA GPU が必要なコンポーネント：** MOSS、FireRedASR2-AED、Qwen3-ASR 1.7B、FireRedASR2-LLM。役割カード、ホーム画面の案内、開始前の確認でその旨が表示され、「この PC で使える方法に変える」を選べます。
- **CPU で動くコンポーネント：** SenseVoice、Qwen3-ForcedAligner（整列、遅め）。Whisper、Paraformer、Fun-ASR も GPU がなければ CPU で動きますが、CPU での完全なテストはしていません。
- **クラウドサービスの違い**（詳しくは [API の申請と設定](api-setup/README.md)、中国語）：MOSS Pro クラウドはキー 1 つで話者を分けられますが、時刻は文単位です。百炼 / Qwen Cloud の録音ファイル認識は単語単位の時刻を返し、Qwen-Audio 3.1 は話者も分けます。通常の利用にはご自身の OSS プライベートストレージが必要です。認識を始める前に、使うエンジン、時刻の出どころ、アップロード先、おおよその費用が表示され、黙って有料サービスに切り替えることはありません。
- **Mac：** MOSS + FireRed は仮想 Mac で実時間の約 3〜4 倍の時間がかかりました。NVIDIA 専用のコンポーネントは、その PC では使えないと表示されます。

## 費用とプライバシー

- **アプリ自体は無料**で、有料機能、登録、サブスクリプションはありません。
- **ローカル認識：** モデルをダウンロードしたあとはオフラインで使え、映像や音声は PC の外に出ません。
- **クラウド認識：** 音声は選んだサービスにアップロードされ、料金はサービス側の規定に従います（料金はサービスのページで確認してください）。アプリが代わりに契約や支払いをすることはありません。
- **テキスト AI**（DeepSeek、Alibaba Cloud 百炼、OpenAI、Gemini、xAI、互換サービス。いずれもご自身のキー）：送るのは字幕の文字だけです。使う機能は、AI による文分割、AI 校正、AI 用語集校正の AI モード、字幕の翻訳（中国語・日本語・英語の字幕を簡体字・繁体字中国語、英語、日本語、韓国語へ）、AI による用語作成と用語集のオンライン更新、切り抜き候補の AI 順位付け、AI 字幕デザインです。設定しない場合、これらの機能は使えないかローカルの規則で動き、認識、編集、書き出しは通常どおり使えます。
- **外部 AI（MCP）：** 初期設定はオフです。オンにすると、AI クライアントが現在のプロジェクトの字幕テキストを読み、そのクライアントが使う AI サービスへ送ります。

## 認識プランとモデル

1 回の認識で、最大 3 つの役割を組み合わせます。

| 役割 | 内容 | 主な選択肢 |
| --- | --- | --- |
| メイン転写 | 文字に起こします。MOSS と一部のクラウドサービスは話者も分けます | MOSS、SenseVoice、Whisper、Qwen3-ASR、クラウドサービス |
| 字幕タイムライン | 1 文字ずつ開始・終了時刻を付け、区切りと分割を文字の境界に合わせます | FireRedASR2-AED、Qwen3-ForcedAligner、Paraformer |
| テキストレビュー | 別のモデルでもう一度聞き、違いを一覧にして字幕スタジオで比べられるようにします | Qwen3-ASR などのローカル／オンライン方式 |

- ホーム画面の「認識プラン」では、目的別（品質優先、軽量・高速、オンライン、日本語おすすめ、英語おすすめなど）の組み合わせを選ぶことも、役割ごとに変えることもできます。
- モデルはモデルワークショップでダウンロードします。カードにはサイズ、動作方法、「参考指数」（1〜100 の相対的な目安で、**認識精度ではありません**）が表示されます。
- ダウンロード元は ModelScope（固定バージョン）→ Hugging Face 公式 → hf-mirror.com の順で、すべてのファイルが固定された SHA-256 と一致する必要があります。中断しても再開できます。
- ローカルモデル：MOSS-Transcribe-Diarize、FireRedASR2-AED、Qwen3-ASR 1.7B、SenseVoice Small、Paraformer Large、Whisper large-v3-turbo、Fun-ASR Nano、FireRedASR2-LLM、GLM-ASR-Nano、Canary-Qwen-2.5B（英語）、Qwen3-ForcedAligner 0.6B、日本語 CTC アライナー、Mac 用の MLX 版 Qwen3-ASR とアライナー。ライセンスは[モデルライセンス一覧](../licenses/MODELS.md)を参照してください。

## 字幕スタジオのよく使う操作

| したいこと | 操作 |
| --- | --- |
| 字幕を分割する | C キーの分割ツール（表示は「レーザーツール」）：動かしてプレビュー、クリックで分割。吸着（S）がオンなら文字と文字の間で止まります |
| 字幕を結合する | B キーの結合ツール、または Ctrl+Shift+M で次の行と結合 |
| 元に戻す／やり直す | Ctrl+Z / Ctrl+Y |
| 候補を比べて別の読みを採用する | R でレビューモード。1〜4 で採用して次の行へ |
| 話者の名前、色、標準スタイルを変える | 話者管理。または字幕を別の話者のトラックへドラッグ |
| 動画の一部をカットする | 映像クリップを選んで Q / W でリップルカット、または右クリックで削除。クリップアシスタントで話の間を検出することもできます |
| 切り抜き候補を探す | クリップアシスタントで字幕とコメント XML を分析し、「クリップを生成」 |
| 用語集で校正する | 字幕スタジオ左上の「AI 校正」、または完了画面の「AI 用語集校正…」 |
| 既存の原稿に時刻を付ける | 字幕スタジオの「原稿を合わせる」。プレビューしてから置き換え |
| ショートカットを変える | 設定 → ショートカット |

ここに書いたのは既定のショートカットで、すべて変更できます。

**AI字幕デザイン（上級者向け、AI サービスが必要）：** 字幕スタジオの「AI デザイン」タブでは、説明文から編集可能な字幕の見た目と動きの候補を 3 つ作ります。設定した AI サービスが必要です。フォント、縁取り、位置、登場・退場アニメーションの通常のプリセットに AI は不要です。[画面紹介](product-demo.ja.md#ai-字幕デザインの作例)の木版画風と CRT 風は、AI 字幕デザインで作った作例で、内蔵プリセットではありません。

## よくある質問

**インストール時に「不明な発行元」や「Windows によって PC が保護されました」と出る。** インストーラーにコード署名がないためです。本リポジトリの Releases から入手し、ハッシュ値が一致していることを確認したら、「詳細情報」→「実行」を選んでください。ウイルス対策ソフトや SmartScreen は無効にしないでください。

**ホーム画面に NVIDIA GPU が必要と表示される。** 現在の組み合わせに NVIDIA GPU でしか動かないコンポーネントが含まれています。「この PC で使える方法に変える」を押すか、[認識方法の選び方](#認識方法の選び方)を参考にクラウド認識か軽量方式に切り替えてください。

**モデルのダウンロードが遅い、止まる。** ダウンロードは再開でき、ModelScope、Hugging Face、hf-mirror.com を順に試します。ダウンロード画面に現在のダウンロード元と切り替えた理由が表示されます。使う前にすべてのファイルを SHA-256 で確認します。

**認識が終わったのに「要確認」がある。** 認識が完了したことは、すべての行が確認済みという意味ではありません。字幕スタジオのレビューモード（R）で、確認を勧める項目を順に見てください。

**字幕の時刻に「推定」と付いている。** その行には実測の 1 文字ずつの時刻がありません（クラウドサービスが文単位の時刻しか返さない場合など）。分割位置は文字数の割合で推定されます。ローカルの Qwen3 アライナーを加えるか、単語単位の時刻を返すサービスを使うと実測の時刻になります。

**アンインストールするとデータは消える？** 消えません。アンインストールで削除されるのはインストーラーが入れたプログラムファイルだけで、あとからダウンロードしたモデル、プロジェクト、設定、用語集は残ります。更新や上書きインストールでも同じです。すべて削除したい場合は、`%LOCALAPPDATA%\2ByteASR` とプログラムフォルダー内の `models` を手動で削除してください（Mac は `~/Library/Application Support/2ByteASR`）。

## ソースからの実行

```powershell
git clone https://github.com/NOTBAD314/2ByteASR.git
cd 2ByteASR
.\setup_environment.bat
.\.venv-main\Scripts\python.exe quick_start.py
```

- `main` ブランチがアプリのソースです。0.7.2 のインストーラーに対応するビルド元はタグ `v0.7.2` で、完全なビルド入力はリリースの `2ByteASR-Source-0.7.2.zip` にあります。[0.7.2 リリースノート](releases/0.7.2.md#ソースと検証)の「ソースと検証」を参照してください。
- 開発とテストの約束事は [CONTRIBUTING.md](../CONTRIBUTING.md) にあります。
