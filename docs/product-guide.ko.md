| 파일 | 용도 |
| --- | --- |
| `2ByteASR-Source-0.7.2.zip` | 설치 프로그램을 살펴보거나 다시 빌드하려는 분용: Windows 설치 프로그램에 해당하는 전체 빌드 입력 |

| `2ByteASR-update.json(.sig)`, `2ByteASR-0.7.2-<구성 요소>-<해시>.zip` | 앱 안 업데이트가 자동으로 사용합니다. 직접 받을 필요가 없습니다 |
| `SHA256SUMS.txt(.sig)` | 받은 파일이 온전한지, 이 프로젝트가 배포한 파일인지 확인할 때 사용합니다 |

## Windows에 설치하기

1. `2ByteASR-Setup-0.7.2.exe`를 받습니다. 파일을 확인하려면 다운로드 폴더에서 PowerShell을 열고 `certutil -hashfile 2ByteASR-Setup-0.7.2.exe SHA256`을 실행한 뒤, 릴리스의 `SHA256SUMS.txt`에 있는 값과 비교하세요.
2. 설치 프로그램을 실행합니다. 기본 설치 위치는 `%LOCALAPPDATA%\Programs\2ByteASR`이고 관리자 권한이 필요 없으며, 다른 드라이브로 바꿀 수도 있습니다. 설치 후 약 1.9 GB를 차지합니다.
3. 설치 프로그램은 **코드 서명이 되어 있지 않아서** Windows가 "알 수 없는 게시자"나 "Windows의 PC 보호" 화면을 띄울 수 있습니다. 이 저장소의 Releases에서 받은 파일이고 체크섬이 일치하는지 확인했다면 "추가 정보" → "실행"을 누르세요. **SmartScreen, 백신 등 보안 기능을 끌 필요가 없으며, 꺼서도 안 됩니다.**
4. 시작 메뉴나 바탕 화면의 바로 가기로 앱을 실행합니다.

**이전 버전을 이미 설치했다면:** 0.6.5, 0.7.0, 0.7.1은 앱 오른쪽 위의 "업데이트 확인"을 누르세요. 바뀐 부분만 내려받습니다. 0.6.0 이하는 앱을 닫고 새 설치 프로그램을 **먼저 제거하지 말고 그대로 덮어 설치**하세요. 설정, 용어 라이브러리, 프로젝트, 이미 받은 모델과 실행 환경은 그대로 남습니다.

**파일 위치:** 설정, 용어 라이브러리, 프로젝트, 로그는 `%LOCALAPPDATA%\2ByteASR`에 있습니다. 새로 설치한 경우 모델은 프로그램 폴더 안의 `models` 폴더로 내려받습니다(D 드라이브에 설치하면 모델도 D 드라이브에 저장됩니다). 예전에 받은 모델은 옮기지 않고 원래 위치에서 그대로 사용합니다.

## Mac에 설치하기(실험판)

**지원 환경:** Apple 실리콘(M 시리즈), macOS 14 이상(0.8.5부터, 0.8.4 이하는 macOS 15 필요). **Intel Mac은 지원하지 않습니다.** 메모리는 16 GB 이상을 권장하며, 8 GB Mac에서는 테스트하지 않았습니다. 이 버전은 GitHub가 제공하는 가상 Mac(가상 M1, 메모리 7 GB)에서만 확인했고, 실제 Mac에서는 확인하지 않았습니다.

1. DMG를 받습니다. 파일을 확인하려면 "터미널"에서 `shasum -a 256 2ByteASR-0.7.2-macos-arm64-Setup.dmg`를 실행하고 `SHA256SUMS.txt`와 비교하세요.
2. DMG를 열고 `2ByteASR`를 "응용 프로그램" 폴더로 끌어다 놓습니다.
3. 앱은 **Developer ID 서명이 없고 Apple 공증도 받지 않았습니다**. 처음 열 때는 Finder에서 Control 키를 누른 채 앱을 클릭해 "열기"를 고르고, 확인 창에서 다시 "열기"를 누르세요. 그래도 막히면 "시스템 설정 → 개인정보 보호 및 보안"으로 가서 아래쪽의 "그래도 열기"를 클릭합니다. **Gatekeeper 등 시스템 보안 설정을 끌 필요가 없으며, 꺼서도 안 됩니다.**
4. 그다음부터는 평소처럼 열면 됩니다.

모델, 실행 환경, 설정, 프로젝트, 로그는 `~/Library/Application Support/2ByteASR`에 있고, API Key는 macOS 키체인에 저장됩니다. Mac 버전의 알려진 제한(속도, 창이 좁을 때 위쪽 도구 막대가 겹치는 문제, 텍스트 검토 없이 실행하면 결과가 부분 성공(部分降级成功)으로 표시되는 점 등)은 [Mac 실험판 안내](deployment/macos-experimental.zh-CN.md)(중국어)를 참고하세요.

## 처음 실행하기

새로 설치한 뒤 처음 실행하면 먼저 인식 방식을 고르는 창이 나옵니다(한 번만 나오며, 나중에 홈 화면 안내나 "도움말" 메뉴에서 다시 열 수 있습니다).

| 선택지 | 인식에 쓰는 것 | 처음 받을 것 | 이런 경우에 알맞습니다 |
| --- | --- | --- | --- |
| **이 컴퓨터에서 인식**(Windows) | MOSS + FireRedASR2-AED + Qwen3-ASR | 모델 약 11 GB와 실행 환경(CUDA 버전 PyTorch 포함) | NVIDIA 그래픽 카드가 있고 화자 구분, 글자별 시간, 여러 모델 비교가 필요할 때 |
| **클라우드 인식** | MOSS Pro 클라우드(MOSI), Alibaba Cloud Bailian, Qwen Cloud 등 | 모델을 받지 않음 | 그래픽 카드가 없고 자막을 빨리 만들고 싶을 때. API Key가 필요하며 사용한 만큼 요금이 붙습니다 |
| **경량 로컬** | SenseVoice(CPU) | 약 0.9 GB와 실행 환경 | 그래픽 카드가 없고 업로드하고 싶지 않을 때. 느린 편이며 화자를 구분하지 않습니다 |
| **이 Mac에서 인식**(Apple 실리콘) | MLX 버전 Qwen3-ASR + 정렬 모델 | 약 2.3 GB와 실행 환경 | Mac에서 업로드 없이 쓰고 싶을 때. 커뮤니티 구현이며 실제 Mac에서는 아직 확인하지 않았습니다 |

로컬 선택지를 고르면 "모델 워크숍"이 열리고 다운로드가 시작됩니다. 클라우드를 고르면 "API 신청 및 설정"이 열려 가입하고 키를 입력하는 과정을 안내합니다. NVIDIA 그래픽 카드가 없으면 "이 컴퓨터에서 인식" 카드에 "이 컴퓨터에 사용 가능한 NVIDIA 그래픽 카드가 없습니다"라고 표시되며 선택할 수 없습니다.

화면부터 익히고 싶다면 오른쪽 위의 "도움말" → "초보자 튜토리얼"을 여세요. 31단계로 된 애니메이션 튜토리얼이 예제 프로젝트로 홈 화면과 "자막 스튜디오"를 안내합니다. 직접 따라 해도 되고 "대신 하기"를 눌러도 됩니다. 모델이 필요 없고, 아무것도 업로드하지 않으며, 비용도 들지 않습니다.

**인터페이스 언어와 테마:** 인터페이스 언어는 简体中文, 繁體中文, English, 日本語, 한국어 가운데서 고를 수 있으며, 첫 실행 창이나 홈 화면 위쪽의 언어 선택 상자에서 바꿉니다. 인터페이스 테마는 라이트, 다크, 고대비 계열로 모두 15가지가 있고, "앱 설정 → 모양"에서 카드를 클릭하면 바로 미리 볼 수 있습니다.

## 인식 방식 고르기

| 사용하는 컴퓨터 | 추천 | 화자 구분 | 글자별 시간 | 여러 모델 후보 |
| --- | --- | --- | --- | --- |
| Windows + NVIDIA 그래픽 카드 | 로컬 MOSS + FireRedASR2-AED + Qwen3-ASR | 있음(MOSS) | 있음(FireRed 실측) | 3개 |
| Windows, NVIDIA 그래픽 카드 없음 | 클라우드 인식 | MOSS Pro 클라우드, Qwen-Audio 3.1은 있음. 다른 서비스는 없음 | Bailian / Qwen Cloud는 있음. 문장 단위 시간만 돌려주는 서비스는 추정값 | 없음 |
| Windows, NVIDIA 그래픽 카드 없음, 업로드를 원하지 않음 | 경량 로컬(SenseVoice) | 없음 | 로컬 Qwen3 정렬 모델(CPU 사용 가능)을 추가하면 있음 | 없음 |
| 클라우드 인식 + 로컬 정렬 | 클라우드가 텍스트를 만들고, 로컬 Qwen3 정렬 모델이 시간을 붙임 | 클라우드 서비스에 따라 다름 | 있음(로컬에서 정렬, 업로드 없음) | 없음 |
| Mac(Apple 실리콘) | 이 Mac에서 인식(MLX), 또는 모델 워크숍에서 준비한 MOSS + FireRed(Apple GPU), 또는 클라우드 | MOSS를 쓰면 있음 | 있음 | MOSS + FireRed로 2개 |

참고:

- **NVIDIA 그래픽 카드가 필요한 구성 요소**(Windows): MOSS, FireRedASR2-AED, Qwen3-ASR 1.7B, FireRedASR2-LLM. 홈 화면의 역할 카드와 안내, 인식 시작 전 확인 단계에서 이 점을 알려 주고 "사용할 수 있는 방식으로 변경"을 제안합니다.
- **CPU로 실행할 수 있는 구성 요소:** SenseVoice, Qwen3-ForcedAligner(정렬, 느린 편). Whisper, Paraformer, Fun-ASR도 그래픽 카드가 없으면 CPU로 실행되지만, CPU에서 충분히 테스트하지는 않았습니다.
- **클라우드 서비스의 차이**(자세한 내용은 [API 신청 및 설정 안내](api-setup/README.md), 중국어): MOSS Pro 클라우드는 키 하나로 화자를 구분할 수 있지만 문장 단위 시간만 돌려줍니다. Bailian / Qwen Cloud의 녹음 파일 인식은 단어 단위 시간을 돌려주고, 그중 Qwen-Audio 3.1은 화자도 구분합니다. 정식으로 사용하려면 본인 소유의 비공개 OSS 버킷이 필요합니다. 인식을 시작할 때마다 앱이 사용할 엔진, 시간 정보의 출처, 오디오 업로드 위치, 예상 비용을 먼저 보여 주며, 몰래 유료 서비스로 바꾸지 않습니다.
- **Mac:** 가상 Mac에서 MOSS + FireRed는 실제 재생 시간보다 약 3~4배 오래 걸렸습니다. NVIDIA에서만 실행되는 구성 요소는 그 컴퓨터에서 실행할 수 없다고 표시됩니다.

## 비용과 개인정보

- **앱 자체는 무료**이며 유료 기능, 회원 가입, 구독이 없습니다.
- **로컬 인식:** 모델을 받은 뒤에는 오프라인으로 쓸 수 있고, 영상과 음성이 컴퓨터 밖으로 나가지 않습니다.
- **클라우드 인식:** 오디오가 선택한 서비스 제공자에게 업로드되고, 요금은 해당 제공자의 규정에 따릅니다(가격은 제공자의 페이지에서 확인하세요). 앱이 대신 가입하거나 결제하지 않습니다.
- **텍스트 AI**(DeepSeek, Alibaba Cloud Bailian, OpenAI, Gemini, xAI 또는 호환되는 사용자 지정 서비스. 모두 본인의 키를 사용): 자막 텍스트만 보냅니다. 텍스트 AI를 쓰는 기능은 AI 줄 나누기, AI 교정, "AI 용어 라이브러리 교정"의 AI 모드, 자막 번역, AI 용어 만들기와 용어 라이브러리 온라인 업데이트, 방송 클립 후보의 AI 순위 매기기, AI 자막 디자인입니다. 자막 번역은 중국어, 일본어, 영어 자막을 중국어 간체, 중국어 번체, 영어, 일본어, 한국어 가운데 원문과 다른 언어로 옮기며, 이중 언어 자막으로 내보낼 수 있습니다. 텍스트 AI를 설정하지 않으면 이 기능들은 쓸 수 없거나 로컬 규칙으로 대신 처리되며, 인식, 편집, 내보내기는 평소처럼 사용할 수 있습니다.
- **외부 AI(MCP):** 기본적으로 꺼져 있습니다. 켜면 사용 중인 AI 클라이언트가 현재 프로젝트의 자막 텍스트를 읽고, 그 클라이언트가 쓰는 AI 서비스로 보냅니다.

## 인식 구성과 모델

한 번의 인식에는 최대 세 가지 역할이 있습니다.

| 역할 | 하는 일 | 자주 쓰는 선택지 |
| --- | --- | --- |
| 주 전사 | 말을 텍스트로 받아 적습니다. MOSS와 일부 클라우드 서비스는 화자도 구분합니다 | MOSS, SenseVoice, Whisper, Qwen3-ASR, 클라우드 서비스 |
| 자막 타임라인 | 글자마다 시작 시간과 끝 시간을 붙여, 줄 나누기와 분할이 글자 경계를 따르게 합니다 | FireRedASR2-AED, Qwen3-ForcedAligner, Paraformer |
| 텍스트 검토 | 다른 모델로 한 번 더 듣고 표기가 다른 곳을 목록으로 보여 줍니다. 자막 스튜디오에서 비교해 원하는 쪽을 적용합니다 | Qwen3-ASR 등 로컬 또는 온라인 선택지 |

- 홈 화면의 "인식 구성"에서 목적별(품질 우선, 빠르고 가벼운 구성, 온라인, 일본어 추천, 영어 추천 등)로 준비된 조합을 고르거나, 역할마다 직접 바꿀 수 있습니다.
- 모델은 "모델 워크숍"에서 받습니다. 카드에는 크기, 실행 방식, "2ByteASR 참고 지수"가 표시됩니다. 참고 지수는 고를 때 참고하는 1~100의 상대적인 값이며 **인식 정확도가 아닙니다**.
- 다운로드는 ModelScope(고정 리비전) → Hugging Face 공식 → hf-mirror.com 순서로 시도합니다. 모든 파일은 미리 고정된 SHA-256과 일치해야 하며, 중간에 끊겨도 이어서 받을 수 있습니다.
- 로컬 모델: MOSS-Transcribe-Diarize, FireRedASR2-AED, Qwen3-ASR 1.7B, SenseVoice Small, Paraformer Large, Whisper large-v3-turbo, Fun-ASR Nano, FireRedASR2-LLM, GLM-ASR-Nano, Canary-Qwen-2.5B(영어), Qwen3-ForcedAligner 0.6B, 일본어 CTC 정렬 모델, Mac용 MLX 버전 Qwen3-ASR과 정렬 모델. 각 모델의 라이선스는 [모델 라이선스 표](../licenses/MODELS.md)(중국어)를 참고하세요.

## 자막 스튜디오 기본 조작

| 하고 싶은 일 | 방법 |
| --- | --- |
| 자막 하나를 둘로 나누기 | 자르기 도구(C): 마우스를 움직여 미리 보고, 클릭해서 나눕니다. 스냅(S)을 켜 두면 글자와 글자 사이에서 멈춥니다 |
| 자막 합치기 | 병합 도구(B), 또는 Ctrl+Shift+M으로 다음 줄과 병합 |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 후보를 비교하고 다른 표기 적용하기 | R로 검토 모드에 들어가고, 1~4로 적용하면 다음 줄로 넘어갑니다 |
| 화자 이름, 색, 기본 스타일 바꾸기 | "화자 관리"를 엽니다. 또는 자막을 다른 화자의 트랙으로 끌어다 놓습니다 |
| 영상 일부 잘라 내기 | 영상 클립을 선택하고 Q / W로 리플 삭제하거나, 클립을 마우스 오른쪽 버튼으로 클릭해 삭제합니다. "클립 어시스턴트"로 말이 끊긴 구간을 찾을 수도 있습니다 |
| 방송 클립 후보 찾기 | "클립 어시스턴트"에서 자막과 탄막 XML을 분석하고, 후보를 고른 뒤 "클립 생성"을 누릅니다 |
| 용어 라이브러리로 교정하기 | 자막 스튜디오 왼쪽 위의 "AI 교정", 또는 완료 화면의 "AI 용어 라이브러리 교정…" |
| 기존 원고에 시간 맞추기 | 자막 스튜디오의 "원고 맞추기": 먼저 미리 본 뒤 바꿉니다 |
| 단축키 바꾸기 | "앱 설정 → 단축키" |

여기 적은 단축키는 기본값이며, 모두 바꿀 수 있습니다.

**AI 자막 디자인(고급, AI 서비스 필요):** 자막 스튜디오의 "AI 디자인" 탭에서 원하는 느낌을 설명하면, 설정해 둔 AI 서비스를 사용해 편집할 수 있는 자막 디자인과 모션 후보 3개를 만듭니다. 글꼴, 외곽선, 위치, 등장·퇴장 애니메이션 같은 일반 프리셋에는 AI가 필요 없습니다. [화면 둘러보기](product-demo.ko.md)에 나오는 목판화 효과와 CRT 효과는 AI 자막 디자인으로 만든 예시 작품이며, 기본 제공 프리셋이 아닙니다.

## 입력과 출력

| 용도 | 형식 |
| --- | --- |
| 영상 입력 | MP4, MOV, MKV, WebM, FLV, AVI |

## 업데이트

- **Windows 0.6.5 이상:** 앱 오른쪽 위의 "업데이트 확인"을 누릅니다. 바뀐 부분만 내려받아 파일마다 검증하고, 프로젝트를 저장하고 종료에 동의한 뒤에 파일을 교체합니다. 어느 단계에서든 실패하면 이전 버전으로 되돌립니다.
- **Windows 0.6.0 이하:** 새 설치 프로그램을 제거 없이 그대로 덮어 설치합니다.
- **Mac:** 새 DMG를 받아 "응용 프로그램" 폴더의 기존 앱 위에 끌어다 놓아 덮어씁니다.

자세한 내용은 [UPDATING.md](../UPDATING.md)(중국어)를 참고하세요.

## 자주 묻는 질문

**설치할 때 "알 수 없는 게시자"나 "Windows의 PC 보호"가 표시됩니다.** 설치 프로그램에 코드 서명이 없기 때문입니다. 이 저장소의 Releases에서 받았고 체크섬이 일치하는지 확인했다면 "추가 정보" → "실행"을 누르세요. 백신이나 SmartScreen은 끄지 마세요.

**홈 화면에 "NVIDIA 그래픽 카드가 필요합니다"라고 표시됩니다.** 현재 조합에 NVIDIA 그래픽 카드에서만 실행되는 구성 요소가 들어 있습니다. "사용할 수 있는 방식으로 변경"을 누르거나, [인식 방식 고르기](#인식-방식-고르기)를 참고해 클라우드 인식이나 경량 로컬로 바꾸세요.

**모델 다운로드가 느리거나 멈춥니다.** 다운로드는 이어 받기를 지원하며, ModelScope, Hugging Face, hf-mirror.com을 차례로 시도합니다. 다운로드 창에 현재 다운로드 위치와 위치를 바꾼 이유가 표시됩니다. 모든 파일은 SHA-256 검증을 통과해야 사용됩니다.

**인식이 끝났는데 "자막 완료, 검토할 항목 있음"으로 표시됩니다.** 인식이 끝났다고 해서 모든 줄이 확인된 것은 아닙니다. 자막 스튜디오에서 검토 모드(R)를 열고 "확인 권장" 항목을 하나씩 살펴보세요.

**자막 시간이 추정값으로 표시됩니다.** 그 자막에는 실측한 글자별 시간이 없습니다(예: 클라우드 서비스가 문장 단위 시간만 돌려준 경우). 그래서 나눌 때 글자 경계를 글자 수 비율로 추정합니다. 로컬 Qwen3 정렬 모델을 추가하거나 단어 단위 시간을 주는 서비스를 쓰면 실측 시간을 얻을 수 있습니다.

**앱을 제거하면 내 데이터도 지워지나요?** 아니요. 제거하면 설치 프로그램이 설치한 프로그램 파일만 지워지고, 나중에 받은 모델, 프로젝트, 설정, 용어 라이브러리는 남습니다. 업데이트하거나 덮어 설치할 때도 마찬가지입니다. 모두 지우려면 `%LOCALAPPDATA%\2ByteASR`와 프로그램 폴더 안의 `models` 폴더를 직접 삭제하세요(Mac은 `~/Library/Application Support/2ByteASR`).

## 소스에서 실행하기

git clone https://github.com/NOTBAD314/2ByteASR.git
cd 2ByteASR
.\setup_environment.bat
.\.venv-main\Scripts\python.exe quick_start.py
