功能特性

识别 / 编辑 / 输出

按角色选择识别模型，保留字级时间信息用于后期编辑；术语库与说话人字幕轨，服务于持续制作同一类内容。

多模型识别与字级对齐

分别选择主力转写、字幕时间轴和文字复核。转写确定文字内容，对齐补充每个字或词的时间位置，复核提供另一份文本依据。

AI 断句与文字复核

结合上下文整理错词和分句，再利用已有时间信息确定字幕边界。识别与分句结果仍可人工修改。

游戏术语库

手动录入或让 AI 搜索角色、技能和别名，保存词条与纠错关系供后续任务复用；已启用词库用于相关校对、匹配与纠错步骤。

说话人字幕轨

按方案区分说话人，人工命名、调整归属，在不同字幕轨上编辑，并合并或按说话人导出。短应答和重叠发言仍需检查。

Studio 字级字幕编辑

对照视频、波形和字幕修改文字与起止时间；有字级时间戳时，可按字拆分、裁剪与合并，减少手工寻找切点。

特效字幕与 AI 设计

直接套用已有样式，或描述字体、材质、框线和入退场动效，让 AI 生成字幕设计，预览后采用。

直播切片辅助

结合 B 站格式的弹幕 XML 与字幕分析片段，给出带时间范围的剪辑建议；可预览、调整后加入剪辑。建议不代替内容取舍。

多素材剪辑与输出

在多轨时间轴组织视频和音频，剪切、裁剪、调整片段；导出字幕文件，或把字幕及特效合成到视频。

识别与编辑工作流

这是从素材到输出的使用路径。字幕生成中的转写、对齐、复核与断句按方案组合，不要求所有模型依次运行。

音视频素材导入本地视频或音频
→
字幕生成主力转写 · 字级对齐
文字复核 · AI 断句
→
Studio 编辑字幕 · 片段 · 样式
→
文件与成片导出字幕 / 压制视频
术语库 → 相关校对、匹配与纠错（按需）B 站弹幕 XML + 字幕 → 片段分析 → Studio（可选）

Studio 字幕与视频编辑

识别后继续在同一工程中校对文字、调整切点和组织视频片段。已有字级时间戳可用于字幕拆分与裁剪，不必只凭句子级起止时间定位。

字级时间继续用于编辑。 已有逐字时间时，可按字拆分、裁剪和合并；普通 SRT／ASS 不自带逐字定位，需要手动调整或补充对齐。

特效先预览，再采用。 AI 设计流程使用已接入的 HyperFrames 设计资料作为参考，作品由 2ByteASR 的预览与导出流程处理。

模型与 AI 服务

按需准备

以下是已接入的代表选项，具体角色以应用中的方案选择为准。无需一次安装全部模型。

选项用途与条件
MOSS-Transcribe-Diarize主力转写及说话人区分；本版使用 NVIDIA CUDA。
FireRedASR2-AED字级时间轴，也可用于转写；本版使用 NVIDIA CUDA。
Qwen3-ASR 1.7B本地转写或文字复核；本版使用 NVIDIA CUDA。
Qwen3-ForcedAligner 0.6B根据已有文字补充字／词时间戳；本版使用 NVIDIA CUDA。
SenseVoice Small本地转写或文字复核，可使用 CPU；不提供 MOSS 的多人身份区分。
在线识别已接入阿里云 Qwen 音频、Groq Whisper、OpenAI 转写等渠道，需相应服务凭据；字级时间与说话人能力因接口而异。

本地识别和手动编辑不要求在线 API。AI 断句、文本校对、术语搜索、字幕设计与片段分析需要相应 AI 服务。 API 需密钥；已接入的 CLI 渠道需安装并登录。使用云端服务时，相关音频、文本或设计输入会发送给所选服务，并可能计费。

输入、输出与编码

文件格式
类型主要格式
音视频输入MP4、MKV、MOV、WebM、FLV、AVI；WAV、MP3、M4A、FLAC、AAC。具体编码需能被解码。
字幕及辅助输入SRT、ASS；B 站格式弹幕 XML。普通字幕文件不自带逐字时间。
字幕输出SRT、ASS、TXT、JSON；可输出合并字幕、说话人分轨，或两者。
视频输出MP4、MKV、MOV；按容器选择 H.264、HEVC 或 AV1（MOV 不提供 AV1）。

视频编码可使用软件编码，或经探测可用的 NVIDIA NVENC、Intel QSV、AMD AMF。这与 ASR 的 CUDA 需求不同；编码加速不等同于整段特效渲染耗时。完整字幕动效请以压制成片为准，SRT／ASS 不等同于完整 AI 特效作品。

安装条件

  • Windows x64
    Windows 10 22H2（19045）或更新版本。Setup 无需预先安装开发用 Python 或 Git。
  • 模型与运行库按需准备
    安装包不含模型权重。首次准备需要网络与额外空间，CPU／显卡需求由所选方案决定。
  • 核对来源，保留工程与媒体
    安装器未签名，请核对 SHA256SUMS。测试版先备份重要工程，源媒体另行保留。

已知问题：当前附件在自定义用户数据目录时，部分入口的工程路径可能不一致。原工程未显示时先核对路径，不要用空工程覆盖。

快速开始

  1. 下载 Setup 安装程序Release 附件：2ByteASR-Setup-0.2.6-test.2.exe；Source code 不是安装包。
  2. 准备识别方案选择所需本地模型并准备运行库，或填写在线服务凭据。
  3. 导入素材并编辑先用短素材生成字幕，进入 Studio 校对、剪辑，再导出字幕或视频。
