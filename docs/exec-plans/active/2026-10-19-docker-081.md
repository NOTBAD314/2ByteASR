# 0.8.1 Docker 浏览器桌面版

日期：2026-10-19。基线：`v0.8.1` / `83f928c1aa445fd17312ffbfb30c88cf5d5027b1`。分支：`codex/docker-0.8.1`。

## Goal

把 0.8.1 做成可构建、可启动和可保存数据的 Linux Docker 包，通过浏览器操作现有界面，支持播放与字幕导出，并实际验证至少一种本地识别路径。

## Non-goals

不合入 0.8.1 之后的日常修改，不改用户数据契约，不替换 Windows 日常程序，不自动公开发布镜像或调用付费 API。不重写整个 Web 前端。

## Acceptance criteria

- 构建来源可追溯到 0.8.1；Docker 上下文不含用户数据、模型、凭据或本机环境。
- 提供 Dockerfile、Compose、持久卷、使用说明及可携带的交付包。
- 容器实际构建、启动；浏览器显示应用，重启可恢复设置及工程。
- 容器内真实媒体预览、字幕编辑/保存与导出有检查证据。
- 至少一种本地识别完成真实音频→字幕；其他模型/GPU能力按已验与未验分别写明。
- 定向测试与文档目录检查通过；保留未解决问题，不能以构建成功代替完整功能验证。

## Verification strategy

在独立 Docker 容器和专用数据卷中验证，不挂载用户应用配置或已有工程。CPU 本地模型使用已锁定的下载与校验逻辑；云端服务不发送付费请求。记录镜像摘要、构建日志、检查结果和实际截图。测试在容器内完成，Qt 离屏测试与可见浏览器验收分别记录。

## Findings

- 原版 Linux 自动模型安装明确拒绝；需要接 Linux 下载入口。
- mpv 已有 Unix IPC，但 Linux 默认外置窗口；需针对 X11 容器验证嵌入或复用 Qt 视频适配器。
- Selkies 官方基础镜像提供浏览器画面、PulseAudio 音频和持久化 `/config`，比只提供画面的方案更适合字幕工作台。
- 终端沙箱调用无响应；只读检查切换到获准的沙箱外执行后恢复。Exa 未配置，官方文档由 Jina Reader 与可用网页搜索读取。

## Decisions

保留 0.8.1 原界面，以 Selkies 单应用容器交付；默认只绑定本机端口。应用设置与模型写入 Docker 数据卷，输入输出使用独立媒体挂载。容器平台为 linux/amd64；不暗示其他平台已验。

## Blockers

暂无不可绕过阻塞。Linux 首次运行兼容性和模型推理待实际验证。
