# 逐帧键盘入口与真实位置回执

2026-11-06：#11 的逐帧操作继续由既有 PlaybackClock 和时间映射拥有时间，不增设一个播放头或固定毫秒步长。

两条逐帧命令的重复资格在shortcut_registry。Qt/native共同派送并按原生消息时间去重；编辑、输入法、模态窗口、焦点和页面所有权仍先于命令。每次最多一个真实帧请求；忙定位最多保留一个初始按键，长按重复不积压，失焦/换页/其它输入会撤销等待。

播放器线程读取准确暂停位置后执行frame-step/back-step；逐帧暂停不附带旧位置seek。真实观测按epoch/generation验证后以显式位置变化接纳暂停回退，再沿原映射更新时钟、时间轴、时间码、字幕和跟随视口。

同源剪切片段的边界通过真实seek抵达保留段。候选位置使用源帧率与现有序列映射，真正落点仍取解码PTS；非整数落点不能被圆整的seek目标替代。其它用户输入会结束该边界确认范围。VFR、多素材和变速切点没有新增保证。
