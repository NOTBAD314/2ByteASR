## Mac 自定义临时目录过长

原生验收将 `TMPDIR` 指向较长的隔离目录时，Qt 的本地 socket 可能无法监听，被当前启动逻辑误报为已有实例；后续 Tk 提示窗与现有 Qt 应用冲突退出。原始中文场景的 socket 路径为112字节，尚未开始字幕操作。保持系统默认临时目录或使用较短路径可避免这次已复现的条件。

两套系统的原生长/短目录监听对照与同一DMG的完整短目录补验单独保留；没有改写原始失败回执。本版未修改该错误提示回退，也未承诺任意长度的自定义临时路径可用。
