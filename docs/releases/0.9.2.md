# 兔白字幕 2ByteASR 0.9.2

本版改善工程库与大工程切换，修订视频导出、旧工程导出入口和MOSS候选恢复。比较基准为上一正式版 **0.9.1**。

## 新增

- **MOSS候选恢复入口。** 当远端已有转写但未形成可用字幕时，分别展示候选、可用字幕与待恢复范围；核对后可复用候选或定向重新云端转写，减少整段重跑。纯音频任务也可使用真实WAV输入和精确PCM复用。
- **原生闪退伴随捕获。** 提供本地捕获助手，记录实际GUI进程的故障模块、原生调用栈和dump。dump默认仅留本地，不自动加入反馈ZIP。

## 改进

- **工程库首屏、返回与缓存重开。** 工程名称和封面不再反复完整加载工程，旧工程先显示摘要再后台补齐；同一文件版本合并读取，缓存按资源压力回收。日期变化、筛选、选择和滚动复用现有卡片。
- **大工程编辑与载入。** 大JSON在独立进程解码，读线程准备校验和初始状态；译文局部修改复用无关来源档案，减少复制。载入时减少整批控件启停，兔子动画复用资源并减少透明区域绘制，图像解码在后台、QPixmap和控件在GUI线程。
- **大量静态字幕导出。** 改为单稀疏图像流，降低FFmpeg内存和输入开销；显示真实阶段、视频时间和退出原因，预览异常不会堵住主编码，CPU编码及AAC重编码使用明确选择。
- 批量替换与载入页改版随本版纳入，原文/译文范围、应用后复核、一步撤销和异步建议保护继续保留。

## 修正

- 修订旧工程视频导出入口误依赖异步ASS预览缓存，以及初始化异常未提示的问题。尚无原反馈用户工程与日志，不能断言其现场只有这一原因。
- 修订MOSS真实英语恢复路径和手动源语言优先级，避免已手动选择的源语言被不相容的检测值覆盖；服务内部错语种原因仍未定案。
- 修订加载期间seek过早发送后一直等不到回执，以及旧媒体seek影响新媒体的问题；当前seek等待匹配的file-loaded。
- 移除图层缓存worker内的QPixmap边界操作，收紧快照对象与线程所有权。原两次访问冲突缺原生dump，不能据此宣称已找到根因或彻底解决闪退。

## 已知限制

- 首次反馈、部分加载/保存长尾和全程接近60fps尚未全部达成；主进程冷开RSS在拥有者匹配测量中约增加75MiB，缓存预算有界但不承诺长期无泄漏。
- 原访问冲突、原反馈工程/媒体及全部播放器卡死根因仍未确认。实体IME/音频、其它硬件、Mac、整片准确性和长时间耐久未验证。
- 强发光/大量动效绘制仍可能耗时。识别与AI质量依赖所选服务；本轮不新增付费整段识别，0.9.1记录的402恢复、译文失败与断句回退边界保留。
- Windows程序/安装器无Authenticode签名，提供SHA-256和既有发布者Ed25519签名，不需要关闭系统安全设置。
