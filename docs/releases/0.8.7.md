### 这一版有什么（相对 0.8.6）

这一版只有 Windows（Mac 版这次不更新，原因见下方“发布前实际检查了什么”），来自开发者日常使用的版本，0.8.6 之后一天的改动全部在内：链接下载支持 Bilibili 和其他视频网站；缺译文的地方可以在时间轴上双击直接补写；字幕之间不到 0.5 秒的空隙自动接上，不再一闪一闪；AI 清理可以顺便翻译，整批检查过才写入；预览和导出成片用同一套断行；云端分片识别留下的多个说话人编号，可以用本机声纹比对、试听后合并。还修了空工程点「识别字幕」没反应、只有一个说话人却提示「检测到多个说话人」、译文里保留技术名词被当成没翻译。设置和识别结果的格式没有变，旧工程可以直接打开。

这一版也带着几处还没完全解决的问题（打开 / 离开工作台时偶尔露出上一画面、AI 清理后闪退的原因还没找到、画中画 2× 播放），写在下面“已知限制”。

#### 新增

- **链接下载支持 Bilibili 与其他视频网站。** 完整的「链接下载」窗口和工作台 Ctrl+V 快贴卡都接受 BV / av 号、分 P、b23.tv 短链接，以及下载器（yt-dlp）支持的其他单个视频链接，并尝试抓取可用字幕；字幕抓不到时视频照样下载、放进工程。B 站未登录时字幕可能不全，可以选浏览器 Cookie 重试。
- **手动补译。** 双语工程里，译文轨道上缺译文的位置双击就能输入或粘贴：Enter 提交，Shift+Enter 换行，Esc 取消；右键可以添加、编辑、复制、粘贴、清空译文；选中译文层时 Ctrl+C / Ctrl+V / Delete 只作用于译文，多行文字留在同一条字幕里。保留 Markdown 局部格式和译文自己的样式；手动改过、清空过或撤销重做过的译文，晚到的 AI 翻译结果不会再覆盖。不需要 API Key。
- **说话人声纹比对。** 云端分片识别（如 MAI-Transcribe 2）会给每一段各自编号（`R001_S00`、`R002_S00`…），同一个人在不同段里成了不同编号。现在「说话人管理」里点「声纹比对」，程序在本机从每个编号取几段独立语音比较，列出可能是同一人的候选；卡片上的 ▶ 可以试听参与比对的样本，「查看声纹候选」确认后按组并入第一位，整个合并 Ctrl+Z 一次撤销，也可以再分开。相似度只用来挑需要试听的候选，不会自动合并；同一次请求里的不同编号、重叠说话、已手动确认或改名的身份不会被并掉。需要本机的主运行环境和说话人声纹模型。
- **AI 清理里可以翻译。** 选好目标语言后和校对一起处理；译文和自动双语显示一起撤销。

#### 改进

- **字幕短空隙自动衔接（防闪烁）。** 新识别的字幕，前后两句之间不超过 0.5 秒的空隙由前一句延长补上，字幕不会在两句之间闪一下。已有工程不会自动改：在时间轴选项里点「衔接 0.5 秒以内的字幕间隙（防闪烁）」，可以一次撤销。
- **预览和导出成片断行一致。** 工作台预览、ASS / 高级导出和改输出比例时，共用同一份断行、画布与字形位置，成片里的文字和预览看到的一样。
- **AI 清理整批检查过才写入。** 一批结果先完整检查，有问题时不会留下半批改动；应用、撤销、重做都是一步。AI 校对回答里个别条目不合格时，只退回那几条，其他照常采用；完成页写明是解析、格式、内容还是网络问题。
- **改了词只重新对齐改过的地方。** 英语字级对齐复用同一音频、同一说话人里已经实测过的词时间；改了词或证据不全的字幕，只在附近局部重跑。一个 460 条的真实工程里，421 条直接复用、39 条进 29 个局部窗口重跑。
- **进工作台一张加载卡到底。** 从打开工程到工作台可用，一直显示「准备工作台」和实际进度，中途可以取消返回。
- **播放更省。** 时间轴没开「跟随」时，播放中字幕切换复用已经画好的时间轴（同一工程 4× 播放时整条时间轴重画由 17 次降到 2 次）；内容相同的单条静态字幕共用一份图像缓存（测试工程约 133 MB 降到 66 MB，画面不变）。
- **全选几百条字幕不再卡一两秒**（隐藏着的变换面板不再逐条测量文字）。
- 自动选语言时不再提前启动 FireRed 字级模型，英语任务少加载一次模型；旧的英语配置按所选语言实际支持的时间轴模型处理。
- 英语断句不再把 set up、going to、color space 这类固定搭配拆开；MOSS 识别进程失败时写出具体原因。

#### 修正

- 空工程里点「识别字幕」按钮没有反应；连续点击不会重复启动，启动失败后按钮恢复可用。
- 只有一个匿名说话人时，误报「检测到多个持续说话人」。
- 译文里保留原文的技术名词（如 DaVinci Resolve、H.264）时，被当成「没翻译成目标语言」退回。
- 可选的术语搜索出错时，让没有绑定词库的识别任务也失败。
- 关闭程序时后台还在准备字幕图像，偶尔异常退出。
- 从首页回到工作台时，先露出上一段视频，再显示工作台。

### 已经装过旧版本

**macOS：这一版不发布**

0.8.7 没有 Mac 版，Mac 请继续用 [0.8.6](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.6)。发布前在 GitHub 的虚拟 Mac 上用同一个发布提交构建并检查了两次：构建、DMG 拖装与搬移、空白工程、模型工坊准备 SenseVoice、重启复用、Qt 真实帧、透明动效都通过，Mac 平台自动测试 365 项：361 项通过、4 项跳过；macOS 15 上同一个 DMG 的完整检查也通过。但在 macOS 14 上，有一次“首页识别完进入工作台”停在「准备播放器」，30 秒后报「准备超时」（另一次通过），之后的导出没有执行。原因是这一版新加的工作台载入检查：Mac 用的播放方式显示的是 0.67 秒处的画面，而播放位置在 0 秒，两者对不上就一直不放行。Windows 用另一种播放方式，不经过这段检查。修好以后 Mac 版随下一版发布。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases（或上面的 GitCode 镜像、gh-proxy 链接）下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **打开或离开工作台时**，视频区域偶尔会短暂露出上一画面或「准备工作台」字样，还没有完全消除。
- **AI 清理后闪退**：此前有用户遇到，原因还没找到；这一版加了整批提交和生命周期保护，检查中没有再出现，但不能保证不再发生。遇到时请保留工程和日志反馈。
- **画中画双轨 2× 播放**副画面约 57 张 / 秒，还没到 60。
- **声纹比对**：相似度只用来挑选试听候选，不能单凭数值判定是同一人；已剪成多段的时间线、或识别时选了独立音轨的工程暂不能自动取样，请试听后手动合并。
- **界面翻译没跟上**：声纹比对、导出时的「输出字幕排版」预览等约 30 条新文字还没有英语、日语、韩语等翻译，这些界面语言下会显示中文（繁體中文界面按字转换显示）。
- **链接下载**：不支持播放列表、批量；B 站需要登录才能看的字幕要用 Cookie；下载受网站与网络环境影响。它的界面只有简体中文、繁體中文、英语和日语，其他界面语言显示英文。中文、日语、韩语自动字幕只删标注、不重排。
- **Mac 这一版不更新**：在 macOS 14 虚拟 Mac 上，识别完进入工作台偶尔停在「准备播放器」，30 秒后报「准备超时」，修好后随下一版发布。Mac 请继续用 0.8.6。
- **Claude**：Anthropic 官方支持的地区不含中国大陆、香港、澳门。
- **Docker 版仍是 0.8.1**（[v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)），这一版没有更新 Docker 镜像。
- 0.8.6 及更早发布说明里的其他已知限制不变。

This release is Windows only (the Mac version is not updated this time; for the reason, see "What was checked before release" below). #### New

- **Link download supports Bilibili and other video sites.** Both the full "Import from link" window and the Ctrl+V quick-paste card in Studio accept BV / av numbers, single parts of multi-part videos, b23.tv short links, and links to other single videos supported by the downloader (yt-dlp), and try to fetch any available subtitles; when no subtitles can be fetched, the video is still downloaded and added to the project. - **リンクからのダウンロードが Bilibili とその他の動画サイトに対応。** 完全な「リンクから取り込む」画面と、字幕スタジオの Ctrl+V クイック貼り付けカードの両方で、BV / av 番号、複数パート動画の各パート、b23.tv の短縮リンク、およびダウンローダー（yt-dlp）が対応するその他の単一の動画のリンクを受け付け、利用できる字幕の取得も試みます。字幕を取得できないときも、動画はそのままダウンロードしてプロジェクトに入れます。Bilibili ではログインしていないと字幕が不完全なことがあり、ブラウザーの Cookie を選んで再試行できます。
- **訳文の手動入力。** 二言語のプロジェクトでは、訳文トラックで訳文が欠けている位置をダブルクリックすると、入力や貼り付けができます：Enter で確定、Shift+Enter で改行、Esc でキャンセル。右クリックで訳文の追加、編集、コピー、貼り付け、消去ができ、訳文のレイヤーを選んでいるときは Ctrl+C / Ctrl+V / Delete が訳文だけに作用し、複数行のテキストは同じ字幕の中に収まります。Markdown の部分的な書式と訳文独自のスタイルは保持されます。手動で変更・消去した訳文や、元に戻す / やり直しをした訳文は、あとから届いた AI 翻訳の結果で上書きされなくなりました。API キーは不要です。
- **話者の声紋比較。** 分割して認識するクラウド認識（MAI-Transcribe 2 など）は区間ごとに別々の番号を付けるため（`R001_S00`、`R002_S00`…）、同じ人が区間によって別の番号になります。今は「話者管理」で **声紋比較**（ボタン「声纹比对」。UI が未翻訳のため中国語で表示）を押すと、この PC で各番号から独立した発話をいくつか取り出して比較し、同一人物の可能性がある候補を一覧にします。カードの ▶ で比較に使ったサンプルを試聴でき、**声紋候補を表示**（「查看声纹候选」。同じく中国語で表示）で確認すると、グループごとに先頭の話者へ統合されます。統合全体は Ctrl+Z 1 回で元に戻せ、分け直すこともできます。類似度は試聴すべき候補を選ぶためだけに使い、自動では統合しません。同じリクエスト内の別の番号、重なった発話、手動で確認済みまたは名前を変えた話者は統合されません。この PC にメインの実行環境と話者の声紋モデルが必要です。
- **AI クリーンアップで翻訳も可能に。** 翻訳先の言語を選ぶと、校正と一緒に処理します。訳文と自動の二言語表示はまとめて元に戻ります。

#### 改善

- **字幕の短い隙間を自動でつなぐ（ちらつき防止）。** 新しく認識した字幕では、前後の 2 文の間にある 0.5 秒以下の隙間を前の文を延ばして埋めるので、2 文の間で字幕が一瞬消えることはありません。既存のプロジェクトは自動では変わりません：タイムラインのオプションで「0.5 秒以内の字幕の隙間を詰める（ちらつき防止）」を押してください。1 回で元に戻せます。
- **プレビューと書き出した動画の改行が一致。** 字幕スタジオのプレビュー、ASS / 高度な書き出し、出力の縦横比の変更で、同じ改行、キャンバス、字形の位置を共有するので、完成動画の文字はプレビューで見たものと同じです。
- **AI クリーンアップはバッチ全体を確認してから書き込みます。** 1 バッチの結果をまずすべて確認するので、問題があっても半分だけの変更が残ることはありません。適用、元に戻す、やり直しはそれぞれ 1 ステップです。AI 校正の回答の一部の項目が不適格なときは、その項目だけを差し戻し、ほかは通常どおり採用します。完了ページには、解析、形式、内容、ネットワークのどれが問題だったかを表示します。
- **単語を変えたときは、変えた箇所だけ合わせ直します。** 英語の単語単位の位置合わせは、同じ音声・同じ話者ですでに実測した単語のタイミングを再利用し、単語を変えた字幕や根拠が不十分な字幕だけを、その近くで部分的にやり直します。字幕 460 件の実際のプロジェクトで、421 件はそのまま再利用し、39 件を 29 の部分区間でやり直しました。
- **字幕スタジオに入るまで読み込みカードは 1 枚。** プロジェクトを開いてから字幕スタジオが使えるようになるまで、「ワークスペース準備中」と実際の進行状況を表示し続け、途中でキャンセルして戻れます。
- **再生がより軽く。** タイムラインの「追従」がオフのときは、再生中の字幕の切り替えで描画済みのタイムラインを再利用します（同じプロジェクトの 4× 再生で、タイムライン全体の再描画が 17 回から 2 回に）。内容が同じ静的な単一字幕は画像キャッシュを 1 つ共有します（テストプロジェクトで約 133 MB から 66 MB に。画面は同じ）。
- **数百件の字幕をすべて選択しても 1〜2 秒固まらなくなりました**（非表示の変形パネルが字幕ごとに文字を測らなくなりました）。
- 言語を自動で選ぶときに FireRed の文字単位モデルを先に起動しなくなり、英語のタスクではモデルの読み込みが 1 回減りました。古い英語の設定は、選んだ言語が実際に対応するタイムラインのモデルに合わせて扱います。
- 英語の文分割で set up、going to、color space のような決まった言い回しを分けなくなりました。MOSS の認識プロセスが失敗したときは、具体的な理由を書き出します。

#### 修正

- 空のプロジェクトで「字幕を認識」ボタンを押しても反応しない問題。連続で押しても二重に開始せず、開始に失敗したあとはボタンが再び使えるようになります。
- 匿名の話者が 1 人だけのときに「継続的に発話する複数の話者が検出されました」と誤って表示される問題。
- 訳文に原文の技術用語（DaVinci Resolve、H.264 など）を残すと「翻訳先の言語に翻訳されていない」として差し戻される問題。
- 任意の用語検索でエラーが起きると、用語辞書を結び付けていない認識タスクまで失敗する問題。
- バックグラウンドで字幕の画像を準備している間にアプリを閉じると、まれに異常終了する問題。
- ホームから字幕スタジオに戻るとき、前の動画が先に見えてから字幕スタジオが表示される問題。

### 既知の制限

- **コード署名はありません。** Windows では「不明な発行元」と表示されることがあり、Mac は Apple の公証を受けていません。このリポジトリの Releases（または上の GitCode ミラー、gh-proxy のリンク）からのみダウンロードし、`SHA256SUMS.txt` を確認してください。ウイルス対策やシステムのセキュリティをオフにする必要はなく、オフにすべきでもありません。
- **字幕スタジオを開くとき・離れるとき**、動画エリアにまれに前の画面や「ワークスペース準備中」の文字が一瞬見えることがあり、まだ完全にはなくせていません。
- **AI クリーンアップ後の強制終了**：以前にユーザーから報告がありましたが、原因はまだ分かっていません。このバージョンではバッチ単位の一括書き込みとライフサイクルの保護を加え、確認中には再発しませんでしたが、二度と起きないとは保証できません。起きたときはプロジェクトとログを残して報告してください。
- **ピクチャー・イン・ピクチャーの 2 トラック 2× 再生**では、サブ画面は約 57 枚 / 秒で、まだ 60 に届いていません。
- **声紋比較**：類似度は試聴する候補を選ぶためだけのもので、数値だけで同一人物とは判断できません。すでに複数に切り分けたタイムラインや、認識時に個別の音声トラックを選んだプロジェクトは、まだ自動でサンプルを取れません。試聴してから手動で統合してください。
- **UI の翻訳が追いついていません**：声紋比較や、書き出し時の「输出字幕排版」（出力字幕のレイアウト）プレビューなど、約 30 件の新しい文言にはまだ英語、日本語、韓国語などの翻訳がなく、これらの UI 言語では中国語で表示されます（中国語（繁体字）の UI では 1 文字ずつ変換して表示）。
- **リンクからのダウンロード**：再生リスト、一括には対応していません。Bilibili でログインが必要な字幕には Cookie が必要です。ダウンロードはサイトとネットワーク環境の影響を受けます。この画面は中国語（簡体字）、中国語（繁体字）、英語、日本語のみで、ほかの UI 言語では英語で表示されます。中国語・日本語・韓国語の自動字幕は表記を削除するだけで、区切り直しはしません。

### 이번 버전의 새로운 점(0.8.6과 비교)

이번 버전은 Windows 전용입니다(이번에는 Mac 버전을 업데이트하지 않으며, 이유는 아래 "출시 전에 실제로 확인한 것"을 참고하세요). 개발자가 날마다 쓰는 버전에서 나왔으며, 0.8.6 이후 하루 동안의 변경을 모두 담았습니다. 링크 다운로드가 Bilibili와 그 밖의 영상 사이트를 지원합니다. 번역문이 빠진 곳은 타임라인에서 더블클릭해 바로 써 넣을 수 있습니다. 자막 사이의 0.5초 미만 틈은 자동으로 이어져 자막이 더 이상 깜빡이지 않습니다. AI 정리에서 번역도 함께 할 수 있고, 묶음 전체를 검사한 뒤에만 반영합니다. 미리보기와 내보낸 영상이 같은 줄바꿈을 씁니다. 클라우드 분할 인식이 남긴 여러 화자 번호는 이 컴퓨터에서 성문(목소리 특징)을 비교하고 들어 본 뒤 합칠 수 있습니다. 또 빈 프로젝트에서 "자막 인식" 버튼을 눌러도 반응이 없던 문제, 화자가 한 명뿐인데 "지속적으로 발화하는 화자가 여러 명 감지" 경고가 뜨던 문제, 번역문에 기술 용어를 남기면 번역되지 않은 것으로 처리되던 문제를 고쳤습니다. 설정과 인식 결과 형식은 바뀌지 않았으므로 이전 프로젝트도 그대로 열 수 있습니다.

이번 버전에는 아직 완전히 해결하지 못한 문제도 몇 가지 남아 있습니다(자막 스튜디오를 열거나 떠날 때 가끔 이전 화면이 보임, AI 정리 후 강제 종료의 원인을 아직 찾지 못함, PIP 2× 재생). 아래 "알려진 제한"에 적었습니다.

#### 새 기능

- **링크 다운로드가 Bilibili와 다른 영상 사이트를 지원.** 전체 "Import from link" 창과 자막 스튜디오의 Ctrl+V 빠른 붙여넣기 카드 모두 BV / av 번호, 여러 파트로 된 영상의 개별 파트, b23.tv 단축 링크, 그리고 다운로더(yt-dlp)가 지원하는 다른 단일 영상 링크를 받으며, 쓸 수 있는 자막도 가져오려고 시도합니다. 자막을 가져오지 못해도 영상은 그대로 내려받아 프로젝트에 넣습니다. Bilibili에 로그인하지 않으면 자막이 불완전할 수 있으며, 브라우저 쿠키(Cookie)를 골라 다시 시도할 수 있습니다.
- **번역문 직접 입력.** 이중 언어 프로젝트에서 번역 트랙의 번역문이 빠진 위치를 더블클릭하면 입력하거나 붙여 넣을 수 있습니다. Enter로 확정, Shift+Enter로 줄바꿈, Esc로 취소합니다. 오른쪽 클릭으로 번역문을 추가, 편집, 복사, 붙여넣기, 비우기 할 수 있고, 번역문 레이어를 선택했을 때는 Ctrl+C / Ctrl+V / Delete가 번역문에만 작용하며 여러 줄 텍스트는 같은 자막 안에 남습니다. Markdown 부분 서식과 번역문 자체의 스타일은 유지됩니다. 직접 고치거나 비우거나 실행 취소 / 다시 실행한 번역문은 늦게 도착한 AI 번역 결과로 더 이상 덮어쓰이지 않습니다. API Key는 필요 없습니다.
- **화자 성문 비교.** 분할해서 인식하는 클라우드 인식(MAI-Transcribe 2 등)은 구간마다 따로 번호를 매기므로(`R001_S00`, `R002_S00`…), 같은 사람이 구간에 따라 다른 번호가 됩니다. 이제 "화자 관리"에서 **성문 비교**(버튼 「声纹比对」, 화면은 아직 번역되지 않아 중국어로 표시)를 누르면, 이 컴퓨터에서 번호마다 독립된 음성을 몇 구간씩 뽑아 비교하고 같은 사람일 수 있는 후보를 보여 줍니다. 카드의 ▶로 비교에 쓴 샘플을 들어 볼 수 있고, **성문 후보 보기**(「查看声纹候选」, 역시 중국어로 표시)에서 확인하면 그룹별로 첫 번째 화자에 합쳐집니다. 합치기 전체를 Ctrl+Z 한 번으로 되돌릴 수 있고, 다시 나눌 수도 있습니다. 유사도는 들어 볼 후보를 고르는 데만 쓰며 자동으로 합치지 않습니다. 같은 요청 안의 서로 다른 번호, 겹친 발화, 이미 직접 확인했거나 이름을 바꾼 화자는 합쳐지지 않습니다. 이 컴퓨터에 주 실행 환경과 화자 성문 모델이 필요합니다.
- **AI 정리에서 번역도 가능.** 대상 언어를 고르면 교정과 함께 처리합니다. 번역문과 자동 이중 언어 표시는 함께 실행 취소됩니다.

#### 개선

- **짧은 자막 틈 자동 잇기(깜빡임 방지).** 새로 인식한 자막에서 앞뒤 두 문장 사이 0.5초 이하의 틈은 앞 문장을 늘려 메우므로, 두 문장 사이에서 자막이 한 번 깜빡이지 않습니다. 기존 프로젝트는 자동으로 바뀌지 않습니다. 타임라인 옵션에서 "0.5초 이내 자막 간격 잇기(깜빡임 방지)"를 누르면 되며, 한 번에 실행 취소할 수 있습니다.
- **미리보기와 내보낸 영상의 줄바꿈 일치.** 자막 스튜디오 미리보기, ASS / 고급 내보내기, 출력 비율 변경이 같은 줄바꿈, 캔버스, 글리프 위치를 함께 쓰므로, 최종 영상의 글자가 미리보기에서 본 것과 같습니다.
- **AI 정리는 묶음 전체를 검사한 뒤에만 반영합니다.** 한 묶음의 결과를 먼저 모두 검사하므로 문제가 있어도 반쯤만 바뀐 상태로 남지 않습니다. 적용, 실행 취소, 다시 실행은 각각 한 단계입니다. AI 교정 답변 중 일부 항목이 부적합하면 그 항목만 돌려보내고 나머지는 평소처럼 씁니다. 완료 페이지에 문제가 파싱, 형식, 내용, 네트워크 중 어느 것이었는지 적어 줍니다.
- **단어를 고치면 고친 곳만 다시 맞춥니다.** 영어 단어 단위 정렬은 같은 오디오, 같은 화자에서 이미 측정한 단어 시간을 다시 쓰고, 단어를 고쳤거나 근거가 부족한 자막만 그 근처에서 부분적으로 다시 돌립니다. 자막 460개짜리 실제 프로젝트에서 421개는 그대로 다시 쓰고, 39개는 부분 구간 29개에서 다시 돌렸습니다.
- **자막 스튜디오에 들어갈 때까지 로딩 카드 하나.** 프로젝트를 열고 자막 스튜디오를 쓸 수 있을 때까지 "작업 공간 준비 중"과 실제 진행 상황을 계속 보여 주며, 도중에 취소하고 돌아갈 수 있습니다.
- **재생이 더 가벼워졌습니다.** 타임라인의 "따르기"가 꺼져 있으면 재생 중 자막이 바뀔 때 이미 그린 타임라인을 다시 씁니다(같은 프로젝트를 4×로 재생할 때 타임라인 전체 다시 그리기가 17번에서 2번으로 줄어듦). 내용이 같은 정적 단일 자막은 이미지 캐시 하나를 함께 씁니다(테스트 프로젝트에서 약 133 MB에서 66 MB로, 화면은 같음).
- **자막 수백 개를 모두 선택해도 1~2초씩 멈추지 않습니다**(숨겨진 변형 패널이 자막마다 글자를 재지 않음).
- 언어를 자동으로 고를 때 FireRed 글자 단위 모델을 미리 띄우지 않아, 영어 작업에서 모델을 한 번 덜 불러옵니다. 이전 영어 구성은 고른 언어가 실제로 지원하는 타임라인 모델에 맞춰 처리합니다.
- 영어 문장 나누기에서 set up, going to, color space 같은 고정 표현을 더 이상 나누지 않습니다. MOSS 인식 프로세스가 실패하면 구체적인 이유를 적어 줍니다.

#### 수정

- 빈 프로젝트에서 "자막 인식" 버튼을 눌러도 반응이 없던 문제. 연달아 눌러도 두 번 시작하지 않고, 시작에 실패한 뒤에는 버튼을 다시 쓸 수 있습니다.
- 익명 화자가 한 명뿐일 때 "지속적으로 발화하는 화자가 여러 명 감지되어 확인이 필요합니다"라고 잘못 표시되던 문제.
- 번역문에 원문의 기술 용어(DaVinci Resolve, H.264 등)를 남기면 "대상 언어로 번역되지 않음"으로 처리되어 되돌려지던 문제.
- 선택 사항인 용어 검색에서 오류가 나면, 용어집을 연결하지 않은 인식 작업까지 실패하던 문제.
- 백그라운드에서 자막 이미지를 준비하는 중에 프로그램을 닫으면 가끔 비정상 종료되던 문제.
- 홈에서 자막 스튜디오로 돌아갈 때 이전 영상이 먼저 보인 뒤 자막 스튜디오가 표시되던 문제.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 "알 수 없는 게시자"가 표시될 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러, gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`를 확인하세요. 백신이나 시스템 보안을 끌 필요도 없고 꺼서도 안 됩니다.
- **자막 스튜디오를 열거나 떠날 때** 영상 영역에 가끔 이전 화면이나 "작업 공간 준비 중" 글자가 잠깐 보이며, 아직 완전히 없애지 못했습니다.
- **AI 정리 후 강제 종료**: 이전에 이를 겪은 사용자가 있었지만 원인은 아직 찾지 못했습니다. 이번 버전에서 묶음 단위 반영과 수명 주기 보호를 더했고 확인 중에는 다시 나타나지 않았지만, 다시 일어나지 않는다고 보장할 수는 없습니다. 겪으면 프로젝트와 로그를 남겨 알려 주세요.
- **PIP 2트랙 2× 재생**에서는 보조 화면이 초당 약 57장으로, 아직 60에 이르지 못합니다.
- **성문 비교**: 유사도는 들어 볼 후보를 고르는 데만 쓰며, 수치만으로 같은 사람이라고 판정할 수 없습니다. 이미 여러 조각으로 자른 타임라인이나 인식할 때 개별 오디오 트랙을 고른 프로젝트는 아직 자동으로 샘플을 뽑지 못하므로, 들어 본 뒤 직접 합쳐 주세요.
- **화면 번역이 따라오지 못했습니다**: 성문 비교, 내보내기 때의 「输出字幕排版」(출력 자막 레이아웃) 미리보기 등 새 문구 약 30개에 아직 영어, 일본어, 한국어 등의 번역이 없어, 이 화면 언어들에서는 중국어로 표시됩니다(중국어(번체) 화면에서는 글자 단위로 변환해 표시).
- **링크 다운로드**: 재생목록과 일괄 다운로드는 지원하지 않습니다. Bilibili에서 로그인해야 볼 수 있는 자막은 쿠키가 필요합니다. 다운로드는 사이트와 네트워크 환경의 영향을 받습니다. 이 기능의 화면은 중국어(간체), 중국어(번체), 영어, 일본어만 있고, 다른 화면 언어에서는 영어로 표시됩니다. 중국어·일본어·한국어 자동 자막은 표기만 지우고 다시 나누지 않습니다.
- **이번에는 Mac 버전을 업데이트하지 않습니다**: macOS 14 가상 Mac에서 인식을 마치고 자막 스튜디오에 들어갈 때 가끔 "플레이어 준비 중"에서 멈추고, 30초 뒤 "준비 시간이 초과되었습니다. 미디어와 플레이어 상태를 확인하세요."라는 오류가 났습니다. 고친 뒤 다음 버전과 함께 출시합니다. Mac에서는 0.8.6을 계속 쓰세요.
