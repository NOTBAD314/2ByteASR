### 有什么变化（相对 1.1.1）

#### 新增

- **兔白个性与世界书。** 可以补充个性和背景设定，对话中增加害怕、和好等反应，并可设置玩梗间隔。
- **聊天粘贴与拖入图片。** 选择支持看图的模型后，在输入框粘贴或拖放图片一起提问。
- **兔白操作当前界面。** 按所选权限查看控件、点击按钮、修改选项和运行已有命令，也能打开历史识别结果与工程。
- **播放头持续居中。** 打开时间线上的居中开关，播放时持续跟随播放头；手动浏览或编辑时让位，继续播放后恢复，并记住开关状态。

#### 改进

- **首页随窗口更好地排布。** 完整显示时左右两栏底部对齐，大窗口适度放大模型名称、说明和图标，短窗口仍可滚动访问操作。
- **识别页面更清爽。** 移除顶部任务条，后台识别和逐视频交付继续工作，已完成的视频仍可先编辑。

#### 修正

- **切换代词要先选字、确认编辑要按多次。** Shift+F 自动锁定一处“他／她／它”并直接改入草稿；Shift+E、Enter 或确认按钮一次保存关闭。
- **点审核红字会整条确认或跳走。** 现在只在原位采纳对应文字，可撤销；最后一项仍保留导航、返回和关闭，同位置重复点击也不会误确认整条。
- **完整 Ultra 权重被误报损坏。** 启动预检按当前配置和模型目录校验。
- **教程的剪切示例停在等待中。** 现在先定位到示范字幕，再展示操作步骤。
- **Mac 聊天附件标签互相挤压。** 标签现在由两栏布局统一分配宽度，完整文件名仍可在提示中查看。

### 已经装过旧版本

- **Windows 1.1.1**：使用“检查更新”，约 **118 MB**；也可保存并退出后运行 Setup 覆盖安装。
- **Windows 0.6.5–1.1.0**：使用“检查更新”，按已装组件补齐差异，下载量随起始版本变化。
- **更早的 Windows 版本**：保存工程并退出，运行新 Setup 覆盖安装，不要先卸载。
- **Apple Silicon Mac**：保存工程并退出，将新应用拖入 Applications 覆盖旧应用。
- 覆盖安装保留工程、设置、词库、模型和运行环境；兔白读取与修改遵守所选权限。

### What changed (since 1.1.1)

#### New

- **Bunny personality and background settings.** Customize her personality and worldbook, emotional reactions and meme interval.
- **Paste or drop images into chat.** Ask about attached images using a vision-capable model.
- **Permission-controlled interface actions.** Bunny can inspect controls, press buttons, change options, run registered commands and open past results or projects.
- **Persistent playhead centering.** Playback follows the playhead, gives way to manual browsing and editing, resumes on playback and remembers the switch.

#### Improved

- Home columns align at the bottom when fully visible. Model names, descriptions and icons grow with available space; short windows retain scrolling and actions.
- A simpler recognition page removes the top task bar while keeping background recognition and access to completed videos.

#### Fixed

- Shift+F now changes one pronoun directly without requiring selection. Shift+E, Enter and Confirm save and close in one step.
- Red proofreading suggestions apply only the relevant text in place, with undo and navigation retained. Repeated clicks no longer confirm the whole cue.
- Ultra preflight no longer rejects complete weights because it checked a different configuration or model folder.
- The tutorial now reveals the example subtitle before showing the razor step, so persistent centering does not leave it waiting off screen.
- Mac chat attachment labels stay in their own columns, with full filenames available in tooltips.

### Upgrading

- **Windows 1.1.1:** use “Check for updates” (about **118 MB**) or save, quit and run Setup over the existing installation.
- **Windows 0.6.5–1.1.0:** update downloads depend on installed components. Earlier versions should use Setup without uninstalling first.
- **Apple silicon Mac:** save, quit and replace the app in Applications.
- Projects, settings, glossaries, models and runtimes remain available after an overlay installation.

### 변경 사항 (1.1.1 대비)

**추가:** 토끼의 성격과 세계관 설정, 채팅 이미지 붙여넣기와 드래그, 권한에 따른 화면 조작 및 이전 결과·프로젝트 열기, 재생 헤드를 계속 중앙에 표시하는 기능.
