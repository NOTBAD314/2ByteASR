# 1.0.1 实际检查与仍未覆盖的条件

2026-11-13。Windows 与 Apple Silicon Mac 的本次检查范围如下，详细原始回执随交付材料保留。

- Windows 源码470项中462项通过、8项旧断言失败，双语文件还有Qt退出异常；未改已验日常逐项同名复现。旧综合界面的固定100像素标题断言在原日常和本版同样失败，未执行的后续步骤不算通过；当前模型卡和工坊几何有独立同包检查。
- 真实1.0.0的签名核心升级、HTTP206续传、生产更新器与1.0.1正常重启确认通过。旧版整条“忙碌/保存/取消”界面驱动只查原生模态窗口，无法识别自绘弹窗，因此原始等待记录保留；没有把该驱动记为通过。核心验收使用旧安装附带且与公开来源逐字节相同的更新实现。
- 安装测试隔离profile内产生的Windows图标缓存、Start Menu desktop.ini及卸载临时日志已逐路径审核；原始严格断言失败保留，原资料与安装哨兵保持。
- Mac同一DMG实测系统为15.8.2、26.7.2；macOS14只做静态兼容核对。窗口验收使用隔离短临时根和系统实际提供的较大显示模式，不代表所有小屏、多屏或长自定义TMPDIR都已验证。
- 译文改词后仍按原错误词搜索，行可能移出列表；清空搜索可再查看。Mac原生回归保留该问题的严格预期失败。
- 早期候选的静态CI配置与同步状态测试夹具已修订，最终候选完整原生重验；原始失败与重新构建记录保留。
- 部分冷首开、放大比例和大词库仍有长帧，性能目标未全面达成。原音听审、内容准确率、跨语言数字校验、真实新云端质量、实体输入法、多屏和长期耐久没有新增保证。
- Windows无Authenticode签名，Mac采用ad-hoc签名、未做Apple公证，不支持Intel Mac。第三方精确重建与组合权利范围沿用随附许可材料，不新增合规保证。
