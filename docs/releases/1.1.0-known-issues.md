# 1.1.0 的实际检查与未验范围

2026-11-16。版本变化见 [1.1.0](1.1.0.md)，这里保留检查的覆盖范围、原始失败与尚未确认的条件。

## Windows

本版冻结 11 月 16 日已接纳的完整日常。正式生产构建来自干净提交；2351 项运行输入与公开候选干净检出逐字节一致，实际 EXE 的原始/编译输入来源检查通过。

候选 648 项累计窗口/字幕、21 项画面按压与链接检查，以及真实 1.0.2 升级后的安装目录 177 项检查通过。四份 327 秒 WAV/MP4 完整解码通过。检查使用隔离配置和临时工程，保留进程、截图、同一 GUI SHA 和正常退出码。全新安装、三次启动、卸载，真实旧更新器的签名、HTTP 206 续传、组件替换、健康重启，中文路径真实 Setup 覆盖与资料保留均通过。

源码 283 项通过，6 个断言在未改的直接日常逐项同败：3 项英语测试还要求已经退出内容审核的行长问题或旧提示措辞；3 项包布局测试仍未登记现有界面模块/包及已退役映射。没有把这些失败计为通过。画面字幕按压的旧综合驱动在候选和直接日常都停在已退役的数字快捷键断言；实际按压、拖动与撤销检查已通过，当前 F/A/D/E/S 操作由另一组正常窗口检查覆盖。使用已有兼容分支跳过旧数字绑定后，按压与链接综合检查通过。

首次工坊夹具直接复制了用户当前的 Ultra 选择，但检查要求从另一选择开始；只修订隔离夹具起点后，实际选择、状态与操作检查通过。用户真实模型选择未改。首次构建因版本号改变生成的渲染清单而被干净提交守门拒绝；提交生成输入后的新构建才用于本版。

原有工程 access violation 的唯一根因和工坊首次选择偶发超时仍未得到普遍证明。Windows 安装包没有 Authenticode 签名。

## Apple Silicon Mac

同一份 591012703 字节 DMG 在 macOS 15.8.2 和 26.7.2 完成安装、正常启动、编辑保存、波形、实际 CPU 模型准备/识别以及字幕/视频导出。原生回归 791 项通过、6 项跳过，无失败或错误；3643 份原生输入与对应源码逐 SHA 匹配。新增兔白、原译文操作、后台校对、动效、调音台、响度、任务和用量窗口有同包实际回执。

首候选的检查仍使用旧快捷键、旧英语长度和 Windows 浮窗坐标，抛掷单测又把 14 秒生产上限误限为 12 秒；这些失败保留。中文旧驱动还把模型 keep 错当成必须合并；修订为先验证保持原样，再明确请求合并，并核对译文、撤销、保存与导出。修订检查后完整重建，采用最终同包通过记录。响度补验先因过长临时路径超过原生 IPC 限长而未启动，短路径复验和原生边界探针确认条件；随后纠正对话框退场固定等待，最终在正常动效下完整复验。Mac 过长临时目录的既有边界仍保留，不把检查夹具修订说成产品已经修复所有启动异常。

Mac 仍是实验版、未公证。macOS 14 的最低版本声明来自二进制兼容性检查；本轮没有 macOS 14 实机运行保证。不支持 Intel Mac。
