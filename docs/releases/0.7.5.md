### 这一版的变化（相对 0.7.4）

#### 新增

- **线上词库。** 术语库页多了「线上词库」和「投稿」两个按钮。线上词库列出维护者审核后发布的社区词库，选一个先预览：哪些是只帮识别写对的热词、哪些是会改字的规则、哪些和你已有的词库重复或冲突，再安装。安装后就是你自己的词库；以后线上有新版本，按「预览更新」即可，你改过或删掉的词条保持原样。两字以内、普通词这类会改到别处的改字规则（例如把“落地”改成“跺地”，会连“落地窗”一起改掉）默认不勾，你可以逐条勾选，或一键勾选投稿人在实际直播里核对过的。中国大陆从 GitCode 下载、海外从 GitHub 下载，不用翻墙；程序只接受维护者签名的目录，每个文件都按哈希校验。首批有洛克王国：世界、原神、明日方舟：终末地、绝区零、瓦罗兰特（国服与台服两套名称）、我的世界、异环 7 个词库（[线上词库仓库](https://github.com/NOTBAD314/2ByteASR-glossaries)，CC0）。
- **投稿自己的词库。** 在术语库页选中你的词库，点「投稿」：程序先检查（冲突、太长的词、会改掉原话的规则），只导出词和分类，理由、来源、任务编号和日期留在你的电脑上；勾选同意以 CC0 公开后，程序存好文件、复制好标题和说明，并打开 GitHub 或 GitCode 的投稿页，把文件拖进去即可。
- **字幕里的数学公式。** 工作台「标点」菜单多了「数学公式」勾选项。打开后，`$…$` 写法的公式在预览、压制成片和所有字幕导出里显示成 `∫₀¹ x² dx = 1/3` 这样的符号。AI 校对、AI 清理、字幕翻译只把公式当作记号发给 AI，回来再换回原公式，AI 改动了公式的那一条不采用；AI 断句不会把公式切成两半。复杂的上下叠排（分数、矩阵）暂时只显示成一行文字。
- **术语库「给 AI 的说明」。** 每个术语库可以写一段给 AI 的说明（可以先插入“数学／理科科普”或“游戏实况”范例再改，最多 1000 字），AI 校对用这个术语库时会一起发给 AI。
- **本机 MCP（让 Claude 等外部 AI 操作兔白）。** Claude Desktop 运行时会把外部写进它配置文件的内容覆盖掉，所以「应用设置」里写入 Claude Desktop 配置前，会先要求完全退出 Claude（托盘图标 → 退出），写入后立即核对，之后被覆盖也会明说。Claude Code 可以一键写入。另外可以单独打开「允许查看和修改术语库」：外部 AI 能查询术语库、提出新增／修改／删除，你在兔白里点「批准并保存」才会写入。

#### 问题修复

- **中文的副词「十分」不再被改成「10分」**（`十分感谢`、`感到十分高兴`）。单独的「十分」只有前面是打分的词（`打了十分`、`扣十分`）、后面是钟／制／以上／以下／左右（`十分钟`），或单独成句时才当作数字。数字规则的版本号因此更新，已识别过的文件重跑时 AI 校对会重新调用一次。
- **识别热词先给角色名。** 送给识别模型的热词名额有限（MOSS 云端 20 个、Qwen3-ASR 64 个），以前按字符顺序截取，很多角色名排不进去；现在角色、人物、Boss、地点和记过误听写法的词排在前面。
- **术语库页「隐藏」的内置参考词，识别时真的不再使用**；隐藏的内置词的别名也不再替换字幕。
- **内置绝区零资料不再把「法厄同」换成「绳匠」**（3.0 起法厄同也是阵营名和首领名，「焚昼余火·法厄同」以前会被改坏）。
- **百炼录音文件识别不再因为一个太长的词整批失败。** 术语库里只要有一条不合它热词规则的词（含汉字超过 15 个字等），以前整次识别都会报错；现在跳过这类词并记下原因，其余照常送出。

### 已经装过旧版本

- **0.7.0–0.7.4**：主界面右上角“检查更新”，下载程序与许可材料两部分（约 78 MB；许可材料因为补了 pylatexenc 的许可原文而更新）。**0.6.5** 会多下载 Python 运行环境与渲染器。下载后校验，等你保存工程并同意退出后才替换；失败会自动恢复原版本。设置、词库、工程、已下载的模型与运行环境都保留。
- **0.6.0 及更早**：关闭兔白字幕，运行 0.7.5 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：还没有程序内更新。退出旧版，打开新的 DMG，把 App 拖进“应用程序”替换即可；设置、模型和工程存放在 App 以外的用户资料夹。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases（或上面的 GitCode 镜像、gh-proxy 链接）下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **Mac 是实验版**：只在 GitHub 虚拟 Mac 上验证过，实体 Mac 与 8 GB 内存的 Mac 没测；窗口很窄时工作台顶部工具栏会重叠。
- **线上词库**：GitCode 的条款写着未登录访客不能下载，目前可以下载；如果哪天限制了，大陆用户会改走 GitHub 代理，可能变慢。投稿需要 GitHub 或 GitCode 账号。
- **数学公式**：上下叠排的写法（分数、矩阵、根号下的长式子）还只显示成一行文字。
- **本机 MCP**：写入 Claude Desktop 配置需要先完全退出 Claude（会结束其中正在运行的 Code 会话），这是 Claude 自身的行为决定的。
- **热词**：内置资料超过 20 个词时（例如绝区零），MOSS 云端的 20 个名额仍全是内置词；MOSS 云端已识别过的素材因热词变化会重新识别一次（重新计费）。
- 长拖音正好拖在一个数字中间、中间停了 5 秒以上时，最后一步仍可能报“字幕保真检查未通过”。
- **不填 Key 时**，工作台里自己点的 AI 功能仍是原来的“缺少 API 密钥”报错。
- 英语、日语、韩语界面里仍有少数文字显示为中文。
- 4× 播放偶发整个窗口停住的原因仍未找到。
- **第三方许可**：Windows 随附的 gyan FFmpeg 9.0 仍缺构建脚本、可能的补丁与部分链接库的确切版本（gyan 没有公开这些材料）。本版补上数学公式用到的 pylatexenc 2.11（MIT）的许可原文。详见 `licenses/DISTRIBUTION-STATUS.md`。

### What changed (compared with 0.7.4)

#### New

- **Online glossary.** The term library page has two new buttons, "Online glossary" and "Submit". The online glossary lists community term libraries that the maintainer reviewed and published. Pick one to preview it first: which entries are hotwords that only help recognition, which are correction rules that change text, and which repeat or conflict with your own libraries. Then install it. It becomes your own library; when a newer version appears online, use "Preview update", and the entries you edited or deleted stay as they are. Correction rules of two characters or fewer, or whose source is an ordinary word (for example 落地 → 跺地, which would also change 落地窗), start unticked; tick them one by one, or tick all rules the contributor verified in real streams. Mainland China downloads from GitCode and everywhere else from GitHub, with no VPN needed; the app accepts only a catalog signed by the maintainer and checks every file's hash. The first seven libraries are Roco Kingdom: World, Genshin Impact, Arknights: Endfield, Zenless Zone Zero, VALORANT (mainland and Taiwan names), Minecraft and Neverness to Everness ([online glossary repository](https://github.com/NOTBAD314/2ByteASR-glossaries), CC0).
- **Submit your own library.** Select your library on the term library page and click "Submit". The app checks it first (conflicts, terms that are too long, rules that would change what was said) and exports only the terms and categories; reasons, sources, task IDs and dates stay on your computer. After you agree to release it under CC0, the app saves the file, copies a title and description, and opens the GitHub or GitCode submission page; drag the file in.
- **Math formulas in subtitles.** The Studio "Punctuation" menu has a new "Math formulas" option. When it is on, formulas written as `$…$` are shown as symbols such as `∫₀¹ x² dx = 1/3` in the preview, the burned-in video and every subtitle export. AI proofreading, AI cleanup and subtitle translation send formulas to the AI as placeholders and put the originals back afterwards; a result in which the AI changed a formula is not used; AI line breaking never splits a formula. Stacked layouts (fractions, matrices) are still shown on one line.
- **"Note for AI" in term libraries.** Each term library can have a note for the AI (start from the "math / science" or "game stream" example, up to 1000 characters); AI proofreading sends it along when it uses that library.
- **Local MCP (let Claude and other AI tools work with 2ByteASR).** While Claude Desktop is running it overwrites what other programs write into its configuration file, so Application settings now asks you to quit Claude completely (tray icon → Quit) before writing it, checks the file right after writing, and says so if Claude overwrote it later. Claude Code can be configured with one click. You can also turn on "Allow viewing and changing term libraries": an external AI can then look up term libraries and propose additions, changes or deletions, which are saved only after you click "Approve and save" in 2ByteASR.

#### Fixed

- **The Chinese adverb 十分 is no longer changed to 10分** (`十分感谢`, `感到十分高兴`). A standalone 十分 counts as a number only after a scoring word (`打了十分`, `扣十分`), before 钟/制/以上/以下/左右 (`十分钟`), or as a sentence on its own. Because the number rules changed, AI proofreading runs once more when an already recognised file is processed again.
- **Recognition hotwords now put character names first.** Recognition models take only a limited number of hotwords (20 for MOSS cloud, 64 for Qwen3-ASR). They used to be cut in character order, so many character names never made it; now characters, people, bosses, places and words with recorded mishearings come first.
- **Built-in reference terms you hide on the term library page are really no longer used in recognition**, and the aliases of a hidden built-in term no longer change subtitles.
- **The built-in Zenless Zone Zero data no longer replaces 法厄同 with 绳匠** (since 3.0, Phaethon is also a faction and a boss name, and 焚昼余火·法厄同 used to be broken).
- **Bailian recorded-file recognition no longer fails as a whole because of one long term.** If a term library contained one term outside its hotword rules (more than 15 Chinese characters, for example), the whole recognition used to stop with an error; now such terms are skipped with a recorded reason and the rest are sent as usual.

### 変更点（0.7.4 との比較）

#### 新機能

- **オンライン辞書。** 用語辞書のページに「オンライン辞書」と「投稿」の 2 つのボタンが増えました。オンライン辞書には、管理者が確認して公開したコミュニティの用語辞書が並びます。まずプレビューで、認識を助けるだけのホットワード、文字を書き換えるルール、手元の辞書と重複・競合するものを確認してから入れられます。入れた辞書はあなた自身の辞書になり、新しい版が出たら「更新をプレビュー」で更新できます。自分で編集・削除した項目はそのまま残ります。2 文字以内や一般語を書き換えるルール（例：「落地→跺地」は「落地窗」まで変えてしまう）は最初は未選択です。1 件ずつ選ぶか、投稿者が実際の配信で確認したルールをまとめて選べます。中国本土は GitCode、それ以外は GitHub からダウンロードし、VPN は不要です。アプリは管理者が署名した目録だけを受け付け、各ファイルをハッシュで確認します。最初の 7 件は、洛克王国：世界、原神、明日方舟：終末地、ゼンレスゾーンゼロ、VALORANT（中国本土版と台湾版の名称）、Minecraft、異環です（[オンライン辞書のリポジトリ](https://github.com/NOTBAD314/2ByteASR-glossaries)、CC0）。
- **自分の辞書を投稿。** 用語辞書のページで自分の辞書を選び「投稿」を押します。アプリはまず確認（競合、長すぎる語、話した内容を変えてしまうルール）を行い、語と分類だけを書き出します。理由・出典・タスク番号・日付はパソコンに残ります。CC0 での公開に同意すると、ファイルを保存し、タイトルと説明をコピーして、GitHub または GitCode の投稿ページを開きます。ファイルをドラッグして投稿してください。
- **字幕の数式。** 字幕スタジオの「句読点」メニューに「数式」が増えました。オンにすると、`$…$` で書いた数式がプレビュー・焼き込み動画・すべての字幕書き出しで `∫₀¹ x² dx = 1/3` のような記号で表示されます。AI 校正・AI クリーンアップ・字幕翻訳では数式を記号に置き換えて AI に送り、戻ってきたら元に戻します。AI が数式を変えた項目は採用しません。AI による区切りで数式が分かれることもありません。上下に重ねる書き方（分数、行列）はまだ 1 行の文字で表示されます。
- **用語辞書の「AI へのメモ」。** 用語辞書ごとに AI へのメモ（「数学・理科」「ゲーム実況」の例から始められます、最大 1000 文字）を書けます。AI 校正でその辞書を使うときに一緒に送ります。
- **ローカル MCP（Claude などの外部 AI から 2ByteASR を操作）。** Claude Desktop は動いている間、他のプログラムが設定ファイルに書いた内容を上書きします。そのため「アプリ設定」で Claude Desktop の設定を書き込む前に、Claude を完全に終了するよう求め（トレイアイコン → 終了）、書き込み後すぐに確認し、あとで上書きされた場合もそう表示します。Claude Code はワンクリックで設定できます。また「用語辞書の閲覧と変更を許可」をオンにすると、外部 AI が用語辞書を調べて追加・変更・削除を提案でき、2ByteASR で「承認して保存」を押したときだけ保存されます。

#### 修正

- **中国語の副詞「十分」が「10分」に変わらなくなりました**（`十分感谢`、`感到十分高兴`）。単独の「十分」は、前に点数の語がある（`打了十分`、`扣十分`）、後ろに 钟／制／以上／以下／左右 が続く（`十分钟`）、または単独の文のときだけ数字として扱います。数字の規則が変わったため、認識済みのファイルを再処理すると AI 校正がもう一度呼ばれます。
- **認識のホットワードでキャラクター名を優先。** 認識モデルに渡せるホットワードには上限があります（MOSS クラウド 20 件、Qwen3-ASR 64 件）。以前は文字順で切っていたため多くのキャラクター名が入りませんでしたが、今はキャラクター・人物・ボス・地名・聞き間違いを記録した語を先に渡します。
- **用語辞書のページで「非表示」にした内蔵の参考語は、認識で本当に使われなくなりました**。非表示にした内蔵語の別名も字幕を書き換えません。
- **内蔵のゼンレスゾーンゼロのデータが「法厄同」を「绳匠」に置き換えなくなりました**（3.0 以降、法厄同は勢力名やボス名でもあり、「焚昼余火·法厄同」が壊れていました）。
- **百煉の録音ファイル認識が、長い語 1 つのために全体で失敗しなくなりました。** ホットワードの規則に合わない語（漢字 15 文字超など）が 1 件でもあると、以前は認識全体がエラーで止まりました。今はその語を理由付きで記録して飛ばし、残りは通常どおり送ります。

- **コード署名はありません。** Windows では「不明な発行元」と表示されることがあり、Mac は Apple の公証を受けていません。このリポジトリの Releases（または上の GitCode ミラー・gh-proxy のリンク）からのみダウンロードし、`SHA256SUMS.txt` で確認してください。ウイルス対策やセキュリティ設定を切る必要はなく、切るべきでもありません。

### 바뀐 점(0.7.4와 비교)

#### 새 기능

- **온라인 용어집.** 용어집 페이지에 '온라인 용어집'과 '제출' 버튼이 생겼습니다. 온라인 용어집에는 관리자가 검토하고 공개한 커뮤니티 용어집이 나옵니다. 먼저 미리 보기로 인식만 돕는 핫워드, 글자를 바꾸는 규칙, 내 용어집과 겹치거나 충돌하는 항목을 확인한 뒤 설치합니다. 설치하면 내 용어집이 되고, 새 버전이 나오면 '업데이트 미리 보기'로 받을 수 있으며 내가 고치거나 지운 항목은 그대로 남습니다. 두 글자 이하이거나 일반 단어를 바꾸는 규칙(예: '落地→跺地'는 '落地窗'까지 바꿈)은 처음에 선택되지 않습니다. 하나씩 고르거나, 제출자가 실제 방송에서 확인한 규칙을 한 번에 고를 수 있습니다. 중국 본토는 GitCode, 그 밖의 지역은 GitHub에서 받으며 VPN이 필요 없습니다. 앱은 관리자가 서명한 목록만 받아들이고 모든 파일을 해시로 확인합니다. 첫 7개는 洛克王国：世界, 원신, 명일방주: 엔드필드, 젠레스 존 제로, VALORANT(중국 본토판과 대만판 이름), 마인크래프트, 이환입니다([온라인 용어집 저장소](https://github.com/NOTBAD314/2ByteASR-glossaries), CC0).
- **내 용어집 제출.** 용어집 페이지에서 내 용어집을 고르고 '제출'을 누르세요. 앱이 먼저 검사(충돌, 너무 긴 단어, 말한 내용을 바꾸는 규칙)를 하고 단어와 분류만 내보냅니다. 이유, 출처, 작업 번호, 날짜는 내 컴퓨터에 남습니다. CC0 공개에 동의하면 파일을 저장하고 제목과 설명을 복사한 뒤 GitHub 또는 GitCode 제출 페이지를 엽니다. 파일을 끌어다 놓으면 됩니다.
- **자막 속 수식.** 자막 스튜디오 '문장 부호' 메뉴에 '수식'이 생겼습니다. 켜면 `$…$`로 쓴 수식이 미리 보기, 입힌 영상, 모든 자막 내보내기에서 `∫₀¹ x² dx = 1/3` 같은 기호로 보입니다. AI 교정, AI 정리, 자막 번역은 수식을 기호로 바꿔 AI에 보내고 돌아오면 원래대로 되돌립니다. AI가 수식을 바꾼 항목은 쓰지 않으며, AI 줄 나누기가 수식을 나누지도 않습니다. 위아래로 쌓는 표기(분수, 행렬)는 아직 한 줄로 보입니다.
- **용어집의 'AI에게 주는 설명'.** 용어집마다 AI에게 주는 설명('수학·과학', '게임 방송' 예시에서 시작 가능, 최대 1000자)을 쓸 수 있고, AI 교정에서 그 용어집을 쓸 때 함께 보냅니다.
- **로컬 MCP(Claude 등 외부 AI가 2ByteASR를 다루게 하기).** Claude Desktop은 실행 중에 다른 프로그램이 설정 파일에 쓴 내용을 덮어씁니다. 그래서 '앱 설정'에서 Claude Desktop 설정을 쓰기 전에 Claude를 완전히 종료하라고 안내하고(트레이 아이콘 → 종료), 쓴 직후 확인하며, 나중에 덮어써지면 그렇게 알려 줍니다. Claude Code는 한 번에 설정할 수 있습니다. 또 '용어집 보기와 변경 허용'을 켜면 외부 AI가 용어집을 조회하고 추가·변경·삭제를 제안할 수 있으며, 2ByteASR에서 '승인하고 저장'을 눌러야 저장됩니다.

#### 수정

- **중국어 부사 '十分'이 더 이상 '10分'으로 바뀌지 않습니다**(`十分感谢`, `感到十分高兴`). 단독 '十分'은 앞에 점수 관련 단어가 있거나(`打了十分`, `扣十分`), 뒤에 钟/制/以上/以下/左右가 오거나(`十分钟`), 혼자 한 문장일 때만 숫자로 봅니다. 숫자 규칙이 바뀌어, 이미 인식한 파일을 다시 처리하면 AI 교정이 한 번 더 호출됩니다.
- **인식 핫워드에서 캐릭터 이름을 먼저.** 인식 모델에 줄 수 있는 핫워드는 수가 정해져 있습니다(MOSS 클라우드 20개, Qwen3-ASR 64개). 예전에는 글자 순서로 잘라 많은 캐릭터 이름이 빠졌는데, 이제 캐릭터, 인물, 보스, 장소, 오인식을 기록한 단어를 먼저 보냅니다.
- **용어집 페이지에서 '숨긴' 내장 참고어는 이제 인식에서 정말 쓰지 않습니다.** 숨긴 내장어의 별칭도 자막을 바꾸지 않습니다.
- **내장 젠레스 존 제로 데이터가 더 이상 '法厄同'을 '绳匠'으로 바꾸지 않습니다**(3.0부터 法厄同은 세력 이름과 보스 이름이기도 해서 '焚昼余火·法厄同'이 망가졌었습니다).
- **百炼 녹음 파일 인식이 긴 단어 하나 때문에 통째로 실패하지 않습니다.** 핫워드 규칙에 맞지 않는 단어(한자 15자 초과 등)가 하나라도 있으면 예전에는 인식 전체가 오류로 멈췄습니다. 이제 그런 단어는 이유를 기록하고 건너뛰며 나머지는 평소처럼 보냅니다.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 '알 수 없는 게시자'로 보일 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러·gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`로 확인하세요. 백신이나 보안 설정을 끌 필요는 없으며 꺼서도 안 됩니다.
- **Mac 판은 실험판입니다**: GitHub 가상 Mac에서만 확인했고 실제 Mac과 메모리 8 GB Mac에서는 확인하지 않았습니다. 창이 아주 좁으면 자막 스튜디오 도구 모음이 겹칩니다.
- **온라인 용어집**: GitCode 약관에는 로그인하지 않은 방문자는 내려받을 수 없다고 되어 있지만 지금은 내려받을 수 있습니다. 이를 실제로 막으면 중국 본토 사용자는 GitHub 프록시를 거치게 되어 느려질 수 있습니다. 제출에는 GitHub 또는 GitCode 계정이 필요합니다.
- **수식**: 위아래로 쌓는 표기(분수, 행렬, 근호 아래 긴 식)는 아직 한 줄로 보입니다.
- **로컬 MCP**: Claude Desktop 설정을 쓰려면 먼저 Claude를 완전히 종료해야 합니다(그 안에서 실행 중인 Code 세션도 끝납니다). Claude 자체의 동작 때문입니다.
- **핫워드**: 내장 데이터가 20개를 넘으면(예: 젠레스 존 제로) MOSS 클라우드의 20개 자리는 모두 내장어가 됩니다. MOSS 클라우드로 이미 인식한 소재는 핫워드가 바뀌어 한 번 다시 인식합니다(다시 과금).
- 길게 끄는 소리가 숫자 한가운데에 있고 5초 넘게 멈추면, 마지막 단계에서 여전히 '자막 충실도 검사 실패'가 날 수 있습니다.
- **API 키가 없으면** 자막 스튜디오에서 직접 실행하는 AI 기능은 예전처럼 'API 키 없음' 오류가 납니다.
- 영어, 일본어, 한국어 화면에 아직 중국어로 보이는 글자가 조금 있습니다.
- 4배속 재생 중 가끔 창 전체가 멈추는 원인은 아직 찾지 못했습니다.
- **서드파티 라이선스**: Windows에 포함된 gyan FFmpeg 9.0은 빌드 스크립트, 있을 수 있는 패치, 일부 링크 라이브러리의 정확한 버전이 아직 없습니다(gyan이 공개하지 않음). 이번에 수식에 쓰는 pylatexenc 2.11(MIT)의 라이선스 전문을 넣었습니다. 자세한 내용은 `licenses/DISTRIBUTION-STATUS.md`를 보세요.
