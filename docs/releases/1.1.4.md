### 有什么变化（相对 1.1.3）

#### 新增

- **首页可以查看「识别记录」。** 支持搜索、查看原始 JSON，并可另存脱敏副本以便反馈。
- **完成页可以把待核对项交给兔白。** 可先选处理类别，查看结果后逐条撤回或还原整次修正。
- **中文识别可将背景歌词放到单独的轨道。** 歌词轨默认隐藏，可按需打开。
- **影片压制支持 Windows Media Foundation。** 硬件编码可用时，多一个编码选项。

#### 改进

- **校对建议逐条确认后才写入字幕。** AI 校对和词库别名先提供建议，兔白处理若有改字会显示前后差异。
- **中文断句更注意停顿和词组。** 优先在句内停顿切分，减少拆开短语，也可按需开启额外的 AI 断句复查。
- **时间轴更容易分辨素材和切口。** 影音片段按来源着色，同源切点和不同素材的交界使用不同标记，相连影音共用轨道标头。
- **启动与工作台切换更连贯。** 启动时显示音波时间轴，切换侧面板时视频跟随移动。闲置缓存清理在后台运行。

#### 修正

- **重开停在工程末尾时可能没有正确画面。** 现在会在最后的有效片段内恢复预览。
- **仅安装 Ultra 时，旧对齐选项可能无法开始识别。** 所选旧官方兼容模型不在时，可切换到可用的 Ultra。
- **Qwen Audio 3.1 识别音频文件时遗漏语言选择。** 现在会传入所选语言。

### 已经装过旧版本

- **Windows 1.1.3** 可在程序内「检查更新」，约 **560 MB**，也可保存并退出后运行 Setup 覆盖安装。
- **Windows 0.6.5–1.1.2** 可在程序内更新，下载量取决于已安装的组件。
- **更早的 Windows 版本** 可在保存并退出后直接运行 Setup 覆盖安装。
- 覆盖安装会保留工程、设置、词库、模型和运行环境。

### What changed since 1.1.3

#### New

- **Recognition history on Home.** Search reports, inspect raw JSON and save redacted copies.
- **Review with Tubai.** Choose what to handle on the completion page, inspect changes and undo them individually or together.
- **Separate background lyrics in Chinese recognition.** The lyrics track is hidden by default.
- **Windows Media Foundation encoding.** Select hardware encoding for video exports where available.

#### Improved

- **Proofreading stays in review until you apply it.** Compare wording changes before committing them. Chinese line breaks pay closer attention to pauses and phrases.
- **Easier timeline editing.** Media is colored by source. Cut markers distinguish edits within a source from joins between sources.

#### Fixed

- **Projects saved at the end can recover their preview.** The workspace resumes inside the last playable clip.
- **Recognition uses Ultra when it is the only installed compatible aligner.** Qwen Audio 3.1 also receives the selected language for audio files.

### Upgrading

- **Windows 1.1.3** can use Check for updates (about **560 MB**) or run Setup after closing the app.
- **Windows 0.6.5–1.1.2** can update in the app. Download size varies by installed components.
- **Earlier Windows versions** can close the app and install over the existing copy.
- Installing over the existing copy preserves projects, settings, glossaries, models and the runtime.
