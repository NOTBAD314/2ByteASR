### 这一版有什么（相对 0.8.3）

这一版来自开发者日常使用的版本，0.8.3 之后一天多的改动全部在内：多音轨视频终于能选音轨，导出页和几个常用窗口重做，MOSS Pro 长素材快了很多，还修了两位用户回报的“最后一步失败”和“导出失败”。设置和识别结果的格式没有变，旧工程可以直接打开；**含多音轨素材的新工程，0.8.3 及更早的版本打不开**（见“已知限制”）。

#### 新增

- **多音轨视频：每条音轨都看得到，识别前先选音轨。** 含多条音轨的 MP4 / MKV（原音 + 配音、混音 + 麦克风等）拖进工作台后，每条音轨在视频轨下面各占一列（A1、A2…），写出名称、语言、声道，波形是各自那条的声音；一开始只有文件的默认音轨出声，其他列静音（成片声音和以前一样），要换配音就静音 A1、打开 A2。在工作台按「识别字幕」，或在首页拖入文件后按「开始生成字幕」，会先出「选择要识别的音轨」：每条一个勾选框，可以试听。只勾第二条，送进模型的就是第二条的声音；勾两条就各识别一次，字幕按音轨分成「中文原音 · S00」「第二配音 · S00」两组，两边的“说话人 1”不会被当成同一个人；某条失败时其他条照常完成，「重试失败项」只重跑那一条。晚开始的音轨（例如 3 秒后才有声音的配音）在波形、播放、导出和识别里都落在正确时间。单条立体声或 5.1 照旧是一条，不会出选择窗口。
- **导出剪辑后的工程声音。** 导出页「输出文件」标题行可以选「视频 / 音频」，选音频就直接导出剪辑后的工程声音（六种格式），不用先压视频。
- **字幕在「视频」分页移动。** 在时间轴或列表选中字幕，「视频」分页显示这条字幕的位置、缩放、旋转、锚点：原文 / 译文分开调，在小画面里拖圆点，一次拖动就是一步撤销；多选几条时一起改。选中视频片段时仍是原来的片段卡片，选字幕不再跳回样式分页。字幕位置与缩放可以全局联动（一处改、全部跟着改）。
- **AI 词库校对页可以隐藏或只看某位说话人**（旁白等）：隐藏的字幕不列出，原位置留一行“旁白 N 条已隐藏 · 显示”；采用全部、「在当前列表里」的替换和 AI 校对都跳过它们，「在整个工程里」才包括并写明含几处。

#### 改进

- **导出字幕视频页改版。** 左栏「输出文件」「画面与编码」两张卡，加「高级编码」「只导出字幕文件」两行折叠，默认不用滚动；前缀、文件名、后缀在一个框里；预设是一排标签；导出范围只在预览下面的时间条和入点出点上调；摘要是一排胶囊；右上角直接写「普通字幕：直接烧录」。
- **AI 词库校对页改版。** 查找和替换合成常驻的一条（不用再按 Ctrl+H）：「替换为」留空就是只查找，查找框显示第几处，「替换」只换带框的那一处，Enter 与「全部替换 N 处」一样；左栏收窄成词库 / 说话人 / 规范词三张卡片；字幕一条一行。
- **批量替换（Ctrl+H / Ctrl+F）改成精简窗口**：查找、替换两个框、范围选单、一排选项标签和勾选预览（删去 / 换上的字分别标色）；↓ 从查找跳到替换，Enter 替换勾选的，Esc 关闭。「AI 清理」移到字幕列表「AI 校对」旁边；「文本整理」不再提供（要去掉句尾空格，可以在批量替换里打开「正则表达式」，查找 `\s+$`、替换留空）。
- **首页和工作台换成同一套组件。** 按钮、下拉框、输入框、数值框改成没有描边的填色块，说明和单位写在框里，状态用胶囊（「● 在线 · 已配置」「✓ 字幕校对」）；首页「AI 文字处理」去掉框中框，「识别方案」一排上下居中。工作台顶栏按导航 / 视图 / 工具 / 导出分成四条色带，「回报问题」写出文字、用提醒色、放在「双语 / 翻译」右边，导出音视频永远是最后一个。动效、AI、视频、剪辑四个工具面板重排；动效点选即生效，底栏只有「范围」「语言层」。样式页最上面是「应用到」；动效预览、效果小卡和「更多预设」窗口的底色跟着主题（浅色主题不再是突兀的藏青底）。
- **Studio 里原文和译文可以分别移动、缩放、旋转**，画布拖动和角点缩放同步回填；动效默认对当前字幕双语一起应用。主轨锁定时有明确的说明和「解锁轨道」。
- **MOSS Pro 长素材快了很多。** 25 分钟以上的素材在安静处切成约 20 分钟一段，按顺序上传、最多 3 段同时在 MOSI 处理，先回来的先出临时字幕；一位用户 96 分钟的录播，整集从 1,139 秒降到 286 秒，字幕条数相同。已经交过的段不重复计费；MOSI 同时任务满了会等一会儿再交，不算失败。
- **MOSS Pro 失败时说明原因。** 报错、完成页、「重新提交云端识别？」确认框和排查报告都写「第 2 / 5 段（起–止）的 MOSI 任务（任务编号 …）执行失败，MOSI 返回的原因：…」；进度卡显示正在云端的是哪几段、本段已等多久，等得远超平常时提示可以继续等或安全取消（不会重新上传或重复计费）。报错详情不再贴一大段识别结果 JSON。
- **没填 API Key 时说清楚。** 「AI 文字服务设置 → 更多选项」里的「按意思断句」「字幕校对」显示关闭并写原因，原来的选择不变，填入 Key 就恢复。开始识别前，若没有 Key 或只有主力转写、没有字级时间戳，先问一次「确定要继续吗」（继续生成 / 去填 API Key / 取消 / 以后不再提醒）。
- **没填 Key 时本地断句少切在词中间**：句末 ？！ 不甩残字，副词、介词、连词不留行尾，“们、过、之间”不放行首。

#### 修正

- **单独一条语气词被省略后，最后一步整段重建甚至整份失败**（`字幕保真检查未通过`，用户回报：一个「哦」让 28 分钟没有字幕）。转写风格 clean 时会省略放不进相邻字幕的孤立语气词，最后的核对现在认得这些有记录的省略，不再把它们当漏字。
- **原视频里有个别坏数据包时，导出在「准备工程」失败**（`MEDIA_PREFLIGHT … avcodec_send_packet()`，用户导出 Twitch 录像时遇到）。现在像播放器一样跳过解码器拒收的包，那一两帧沿用前一帧；一帧都解不出的文件仍然报错。
- **关掉眼睛的字幕轨仍被烧进成片**，现在不烧录；全部隐藏时成片与没有字幕的导出逐位相同。
- **长 FLV 剪辑导出时逐段长停**（每段都从文件开头重新解码）：现在先建一份可定位的无损副本再导出，一个 3 分 51 秒、14 段的原工程有字幕导出约 132 秒、没有 5 秒以上的停顿。第一次导出这种素材要先等几分钟建副本。

### 已经装过旧版本

- **0.8.2、0.8.3**：主界面右上角“检查更新”。只下载约 60 MB（程序本身），其余部分沿用已装的。
- **0.7.0–0.8.1**：同样用“检查更新”。这些版本还要补上 0.8.2 换过的随附 FFmpeg、Python 运行库与离线安装包，共约 890 MB，和重新下载 Setup 差不多；**0.6.5** 还要多下载渲染器（共约 1.13 GB）。
- 这一版的更新清单仍把 GitCode 国内镜像排在 GitHub 前面：已安装的 0.6.5–0.8.2 会先从 GitCode 下载，在中国大陆比 GitHub 快得多，GitCode 下不了时再用 GitHub；0.8.3 从检查更新时先回应的来源下载，某个来源一直很慢时自动换来源续传。
- 下载可以断点续传；下载后校验，等你保存工程并同意退出后才替换；失败会自动恢复原版本。设置、词库、工程、已下载的模型与运行环境都保留，不需要重新准备。
- **0.6.0 及更早**：关闭兔白字幕，运行 0.8.4 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：还没有程序内更新。退出旧版，打开新的 DMG，把 App 拖进“应用程序”替换即可；设置、模型和工程存放在 App 以外的用户资料夹。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases（或上面的 GitCode 镜像、gh-proxy 链接）下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **含多音轨素材的新工程，0.8.3 及更早的版本打不开**（工程里多记了一个音轨编号）。没有多音轨素材的工程与之前完全相同，不受影响。
- **多音轨**：首页「匹配文稿」仍由 FFmpeg 自己挑音轨；首页勾选的音轨只在这次开着程序时记得；队列里有几个多音轨文件时逐个出选择窗口；多选合并后，完成页的「识别时 N 条」只算第一条音轨（「工程当前 N 条」才是合并后的总数）。
- **长 FLV 第一次导出**要先等几分钟建连续时间轴副本。
- **MOSS Pro 长素材**：分段更多，说话人编号按段标明，「只保留主播」在长素材上更容易误删（原有问题，跨段合并说话人还没做）。
- **AI 词库校对页**：设计稿上“替换时同时记进词库”的勾选没有做。
- **界面翻译**：新文字在 10 种界面语言都有译文，繁体中文按字转换；英文、俄文以外的语言没有在真实窗口里逐个看过。
- **Mac 是实验版**：这一版的新功能没有在 Mac 上单独检查；Mac 的最低系统仍是 macOS 15（macOS 14 的兼容版还在单独测试，没有放进这一版）。
- **Claude**：Anthropic 官方支持的地区不含中国大陆、香港、澳门。
- **Docker 版仍是 0.8.1**（[v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)），这一版没有更新 Docker 镜像。
- 0.8.3 及更早发布说明里的其他已知限制不变。

### What is new in this release (compared with 0.8.3)

This release comes from the version the developer uses every day and includes all changes from the little more than a day since 0.8.3: you can finally choose the audio track in videos with several audio tracks, the export page and several frequently used windows were redone, MOSS Pro is much faster on long media, and two problems reported by users were fixed, "failed at the last step" and "export failed". Settings and recognition-result formats are unchanged, so older projects open as they are; **new projects that contain multi-track media cannot be opened by 0.8.3 or earlier** (see "Known limitations").

#### New

- **Videos with several audio tracks: every track is visible, and you choose the track before recognition.** When you drag an MP4 / MKV with several audio tracks (original audio + dub, mix + microphone and so on) into Studio, each audio track gets its own row under the video track (A1, A2…) showing its name, language and channels, and each waveform shows the sound of that track. At first only the file's default track is audible and the other rows are muted (the finished video sounds the same as before); to switch to the dub, mute A1 and unmute A2. When you press "Transcribe captions" in Studio, or drag a file onto Home and press "Start subtitles", "Choose tracks to recognize" comes up first: one checkbox per track, and you can listen to each. Tick only the second track and the model gets the sound of the second track; tick two and each is recognized once, the subtitles are split by track into two groups, "Chinese original · S00" and "Second dub · S00", and "Speaker 1" on each side is not treated as the same person. If one track fails, the others still finish, and "Retry failed tasks" reruns only that one. A track that starts late (for example a dub with sound only after 3 seconds) lands at the right time in the waveform, playback, export and recognition. A single stereo or 5.1 track is still one track, and no selection window appears.
- **Export the project's edited audio.** In the "Output File" title row of the export page you can choose "Video / Audio"; choose Audio to export the project's sound after editing directly (six formats), without encoding a video first.
- **Move subtitles on the "Video" tab.** Select a subtitle on the timeline or in the list, and the "Video" tab shows its Position, Scale, Rotation and Anchor: the original and the translation are adjusted separately, you drag a dot in the small preview, and each drag is one undo step; with several subtitles selected, they change together. When a video clip is selected, you still get the same clip card as before, and selecting a subtitle no longer jumps back to the Style tab. Subtitle position and scale can be linked globally (change one place, and all follow).
- **The AI glossary proofreading page can hide a speaker or show only one speaker** (a narrator, for example): hidden subtitles are not listed, and in their place there is one line, "Narrator: N hidden · Show". "Adopt all", replacing "In current list" and AI proofreading all skip them; only "In whole project" includes them, and it says how many places that covers.

#### Improved

- **The "Export Subtitled Video" page was redesigned.** The left column has two cards, "Output File" and "Picture and Encoding", plus two collapsed rows, "Advanced Encoding" and "Subtitle Files Only", so by default you do not need to scroll; prefix, file name and suffix are in one box; presets are a row of tags; the export range is set only on the time bar and the in/out points below the preview; the summary is a row of pills; the top right corner simply says "Standard subtitles: burned in directly".
- **The AI glossary proofreading page was redesigned.** Find and replace are merged into one bar that is always shown (no more Ctrl+H): leaving "Replace with" empty means find only, the find box shows which match you are on, "Replace" replaces only the outlined match, and Enter does the same as "Replace all N"; the left column is narrowed to three cards, Term library / Speakers / Canonical terms; each subtitle takes one row.
- **Batch Replace (Ctrl+H / Ctrl+F) is now a compact window**: two boxes for find and replace, a scope menu, a row of option tags and a preview with checkboxes (removed and inserted text are marked in different colors); ↓ jumps from Find to Replace, Enter replaces the ticked items, Esc closes. "AI cleanup" moved next to "AI proofread" in the subtitle list; "Text tidy" is no longer offered (to remove trailing spaces, turn on "Regular expression" in Batch Replace, find `\s+$` and leave Replace empty).
- **Home and Studio now use the same set of components.** Buttons, drop-down lists, text boxes and number boxes are now filled blocks without outlines, with hints and units written inside the box, and status is shown as pills ("● Online · configured", "✓ Subtitle proofreading"); on Home, "AI text processing" no longer has a box inside a box, and the "Recognition plan" row is centered vertically. The Studio top bar is split into four color bands: navigation / view / tools / export; "Report a Problem" now shows its text, uses the alert color and sits to the right of "Bilingual / Translation", and "Export media" is always the last item. The four tool panels Motion, AI, Video and Clips were rearranged; in Motion a click applies the effect right away, and the bottom bar has only "Scope" and "Language layer". The Style page starts with "Apply to"; the background of the motion preview, the small effect cards and the "More presets…" window follows the theme (light themes no longer get an out-of-place navy background).
- **In Studio, the original and the translation can be moved, scaled and rotated separately**, and dragging on the canvas or scaling by the corner handles fills the values back in at the same time; by default, motion effects apply to both languages of the current subtitle together. When the main track is locked, there is a clear explanation and an "Unlock track" button.
- **MOSS Pro is much faster on long media.** Media longer than 25 minutes is cut at quiet spots into parts of about 20 minutes, which are uploaded in order, with up to 3 parts processed on MOSI at the same time; parts that come back first show temporary subtitles first. For one user's 96-minute stream recording, the whole episode went from 1,139 seconds to 286 seconds, with the same number of subtitles. Parts that were already submitted are not billed again; when MOSI's limit on simultaneous tasks is reached, the app waits a while and then submits, which does not count as a failure.
- **When MOSS Pro fails, the app says why.** The error message, the finished page, the "Submit the cloud recognition again?" confirmation box and the troubleshooting report all say "The MOSI task for part 2 / 5 (start–end) (task ID …) failed; reason returned by MOSI: …". The progress card shows which parts are in the cloud and how long the current part has been waiting; when the wait is far longer than usual, it tells you that you can keep waiting or cancel safely (nothing is uploaded again or billed twice). Error details no longer paste a long block of recognition-result JSON.
- **Clear messages when no API key is filled in.** In "AI text service settings → More options", "Line breaks by meaning" and "Subtitle proofreading" show as off, with the reason; your earlier choices are not changed and come back once you enter a key. Before recognition starts, if there is no key, or there is only primary transcription without character-level timestamps, the app asks once, "Continue?" (Continue / Add API key / Cancel / Don't remind me again).
- **Without a key, local line breaking cuts inside words less often**: a ？ or ！ at the end of a sentence no longer leaves stray characters dangling, adverbs, prepositions and conjunctions are not left at the end of a line, and "们", "过" and "之间" are not put at the start of a line.

#### Fixed

- **After a lone filler word was left out, the last step rebuilt a whole segment or even failed entirely** (`字幕保真检查未通过`; a user reported that a single "哦" ("oh") left 28 minutes without subtitles). With the clean transcription style, isolated filler words that do not fit into a neighboring subtitle are left out; the final check now recognizes these recorded omissions and no longer treats them as missing text.
- **When the source video had a few bad data packets, export failed at "Preparing Project"** (`MEDIA_PREFLIGHT … avcodec_send_packet()`, hit by a user exporting a Twitch recording). Now, like a player, the export skips packets the decoder rejects, and those one or two frames reuse the previous frame; a file from which not a single frame can be decoded still reports an error.
- **Subtitle tracks with the eye turned off were still burned into the finished video**; now they are not burned in, and when all of them are hidden, the finished video is bit-for-bit identical to an export without subtitles.
- **Exporting edits of long FLV files stalled for a long time at every segment** (each segment was decoded again from the start of the file): now the app first builds a seekable lossless copy and then exports; for an original project of 3 min 51 s with 14 segments, the export with subtitles takes about 132 seconds, with no pause longer than 5 seconds. The first export of such media has to wait a few minutes while the copy is built.

### Known limitations

- **No code signing.** Windows may show "Unknown publisher"; the Mac app is not notarized. Download only from this repository's Releases (or the GitCode mirror / gh-proxy links above) and check `SHA256SUMS.txt`; you do not need to, and should not, turn off antivirus or system security.
- **New projects that contain multi-track media cannot be opened by 0.8.3 or earlier** (the project records one extra audio track number). Projects without multi-track media are exactly the same as before and are not affected.
- **Multiple audio tracks**: "Match script" on Home still lets FFmpeg pick the audio track by itself; the tracks ticked on Home are remembered only while the app stays open; with several multi-track files in the queue, the selection window comes up for each of them in turn; after several tracks are selected and merged, "N when recognized" on the finished page counts only the first track ("N in the project now" is the merged total).
- **The first export of a long FLV** has to wait a few minutes while a continuous-timeline copy is built.
- **MOSS Pro on long media**: there are more parts, speaker numbers are labeled per part, and "Keep streamer only" is more likely to delete the wrong subtitles on long media (an existing problem; merging speakers across parts has not been done yet).
- **AI glossary proofreading page**: the "also add to the term library when replacing" checkbox from the design draft has not been implemented.
- **Interface translations**: the new text is translated into all 10 interface languages, and Traditional Chinese is converted character by character; languages other than English and Russian have not been looked at one by one in real windows.
- **The Mac build is experimental**: the new features in this release were not checked separately on Mac; the minimum system for Mac is still macOS 15 (a compatible build for macOS 14 is still being tested separately and is not part of this release).
- **Claude**: Anthropic's supported regions do not include mainland China, Hong Kong or Macau.
- **The Docker version is still 0.8.1** ([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)); this release does not update the Docker image.
- The other known limitations in the 0.8.3 and earlier release notes still apply.

このバージョンは開発者が日常的に使っている版から作ったもので、0.8.3 以降 1 日あまりの変更をすべて含みます：複数の音声トラックがある動画でようやくトラックを選べるようになり、書き出しページといくつかのよく使うウィンドウを作り直し、MOSS Pro での長い素材の処理が大幅に速くなりました。さらに、2 人のユーザーから報告された「最後の段階での失敗」と「書き出しの失敗」も修正しました。設定と認識結果の形式は変わっていないので、古いプロジェクトもそのまま開けます。**複数の音声トラックを含む素材を使った新しいプロジェクトは、0.8.3 以前のバージョンでは開けません**（「既知の制限」を参照）。

#### 新機能

- **複数の音声トラックがある動画：どのトラックも見えるようになり、認識の前にトラックを選びます。** 複数の音声トラックを含む MP4 / MKV（元の音声 + 吹き替え、ミックス + マイクなど）を字幕スタジオにドラッグすると、各音声トラックが映像トラックの下にそれぞれ 1 列（A1、A2…）として並び、名前、言語、チャンネルが表示され、波形はそれぞれのトラックの音声になります。最初はファイルの既定の音声トラックだけが鳴り、ほかの列はミュートです（完成動画の音声は以前と同じ）。吹き替えに切り替えるには A1 をミュートして A2 をオンにします。字幕スタジオで「字幕を認識」を押すか、ホームにファイルをドラッグして「字幕生成を開始」を押すと、まず「認識する音声トラックを選択」が表示されます：トラックごとにチェックボックスがあり、試聴できます。2 本目だけにチェックすると、モデルに送られるのは 2 本目の音声です。2 本にチェックするとそれぞれ 1 回ずつ認識し、字幕は音声トラックごとに「中国語原音 · S00」「第 2 吹き替え · S00」の 2 つのグループに分かれ、両方の「話者 1」が同じ人として扱われることはありません。あるトラックが失敗してもほかのトラックは通常どおり完了し、「失敗したタスクを再試行」はそのトラックだけをやり直します。遅れて始まる音声トラック（たとえば 3 秒後から音が入る吹き替え）も、波形、再生、書き出し、認識のすべてで正しい時刻に配置されます。ステレオや 5.1 のトラックが 1 本だけの場合は従来どおり 1 本として扱い、選択ウィンドウは出ません。
- **編集後のプロジェクトの音声を書き出し。** 書き出しページの「出力ファイル」の見出し行で「動画 / 音声」を選べます。音声を選ぶと、編集後のプロジェクトの音声をそのまま書き出します（6 種類の形式）。先に動画をエンコードする必要はありません。
- **字幕を「動画」タブで移動。** タイムラインやリストで字幕を選ぶと、「動画」タブにその字幕の位置、スケール、回転、アンカーが表示されます：原文と訳文を別々に調整でき、小さなプレビュー画面で丸い点をドラッグします。1 回のドラッグが 1 回の「元に戻す」の単位になります。複数の字幕を選ぶとまとめて変更します。動画クリップを選んだときは従来どおりクリップのカードが表示され、字幕を選んでもスタイルタブに戻らなくなりました。字幕の位置とスケールは全体で連動させることもできます（1 か所を変えると、すべてが追随します）。
- **「AI 用語集校正」ページで、特定の話者を非表示にしたり、その話者だけを表示したりできます**（ナレーションなど）：非表示の字幕は一覧に出ず、元の位置に「ナレーション N 件を非表示 · 表示」という 1 行が残ります。一括採用、「現在のリスト内」の置換、AI 校正はそれらを飛ばし、「プロジェクト全体」を選んだときだけ対象に含め、何か所含まれるかを明記します。

#### 改善

- **「字幕付き動画を書き出し」ページを刷新。** 左の列は「出力ファイル」「映像とエンコード」の 2 枚のカードと、折りたたまれた「詳細エンコード」「字幕ファイルのみ書き出し」の 2 行で構成し、既定ではスクロール不要です。接頭辞、ファイル名、接尾辞は 1 つの入力欄にまとめました。プリセットは横一列のタグです。書き出し範囲は、プレビューの下のタイムバーとイン点・アウト点だけで調整します。概要は横一列のカプセル表示です。右上には「通常の字幕：そのまま焼き込み」と直接表示します。
- **「AI 用語集校正」ページを刷新。** 検索と置換を、常に表示される 1 本のバーにまとめました（Ctrl+H を押す必要はもうありません）：「置換後」を空にすれば検索だけになり、検索欄には何か所目かが表示されます。「置換」は枠で囲まれた 1 か所だけを置き換え、Enter は「N 箇所をすべて置換」と同じです。左の列は幅を狭め、用語ライブラリ / 話者 / 正規表記の 3 枚のカードにしました。字幕は 1 件 1 行で表示します。
- **「一括置換」（Ctrl+H / Ctrl+F）をコンパクトなウィンドウに変更**：検索と置換の 2 つの入力欄、範囲のメニュー、横一列のオプションタグ、チェックできるプレビュー（削除される文字と置き換わる文字をそれぞれ色分け）で構成します。↓ で検索欄から置換欄に移り、Enter でチェックしたものを置換、Esc で閉じます。「AI クリーンアップ」は字幕リストの「AI 校正」の隣に移りました。「テキスト整理」は提供しなくなりました（文末の空白を消したいときは、一括置換で「正規表現」をオンにし、`\s+$` を検索して置換を空にしてください）。
- **ホームと字幕スタジオで同じ部品を使うようになりました。** ボタン、ドロップダウン、入力欄、数値欄は枠線のない塗りつぶしのブロックになり、説明と単位は欄の中に書き、状態はカプセル（「● オンライン · 設定済み」「✓ 字幕校閲」）で示します。ホームの「AI テキスト処理」は枠の中の枠をなくし、「認識プラン」の行は上下中央にそろえました。字幕スタジオの上部バーはナビゲーション / 表示 / ツール / 書き出しの 4 つの色帯に分け、「問題を報告」は文字付きで注意色にして「バイリンガル / 翻訳」の右に置き、映像と音声の書き出しは常に最後にしました。「モーション」「AI」「動画」「切り抜き」の 4 つのツールパネルを並べ直しました。モーションはクリックで選ぶとすぐ反映され、下部のバーは「範囲」「言語レイヤー」だけです。スタイルページのいちばん上は「適用先」です。モーションのプレビュー、効果の小さなカード、「その他のプリセット」ウィンドウの背景色はテーマに合わせるようになりました（ライトテーマで不自然な紺色の背景にならなくなりました）。
- **字幕スタジオで原文と訳文を別々に移動、拡大縮小、回転できます**。キャンバス上のドラッグや角での拡大縮小は、数値にも同時に反映されます。モーションは既定で、現在の字幕の二言語両方にまとめて適用されます。メイントラックがロックされているときは、はっきりした説明と「トラックのロックを解除」が表示されます。
- **MOSS Pro での長い素材の処理が大幅に速くなりました。** 25 分以上の素材は静かな箇所で約 20 分ずつの区間に分け、順番にアップロードし、最大 3 区間を同時に MOSI で処理します。先に戻ってきた区間から仮の字幕を表示します。あるユーザーの 96 分の配信録画では、全体が 1,139 秒から 286 秒になり、字幕の件数は同じでした。すでに送信した区間に重複して課金されることはありません。MOSI の同時タスクが上限に達しているときは少し待ってから送信し、失敗とは扱いません。
- **MOSS Pro が失敗したときに理由を説明します。** エラー表示、完了ページ、「クラウド認識をもう一度送信しますか？」の確認ボックス、トラブルシューティングレポートのすべてに「第 2 / 5 区間（開始–終了）の MOSI タスク（タスク番号 …）の実行に失敗しました。MOSI が返した理由：…」と書かれます。進捗カードには、いまクラウドで処理中なのがどの区間か、この区間をどれだけ待っているかを表示し、通常よりはるかに長く待っているときは、待ち続けるか安全にキャンセルできることを知らせます（再アップロードや重複課金はありません）。エラーの詳細に認識結果の JSON を長々と貼り付けることはなくなりました。
- **API キーが未入力のときに、はっきり伝えるようになりました。** 「AI テキストサービス設定 → その他のオプション」の「意味で文分割」「字幕校閲」はオフと表示され、その理由が書かれます。元の選択は変わらず、キーを入力すれば元に戻ります。認識を始める前に、キーがない場合や、メインの文字起こしだけで文字単位のタイムスタンプがない場合は、まず「続行しますか」と 1 回確認します（「続行する」/「API キーを入力」/「キャンセル」/「今後通知しない」）。
- **キー未入力時のローカル文分割で、単語の途中で切ることが減りました**：文末の ？！ で切れ端の文字が取り残されず、副詞・前置詞・接続詞を行末に残さず、「们、过、之间」を行頭に置きません。

#### 修正

- **単独のフィラーが 1 件省略されると、最後の段階で区間全体が作り直されたり、字幕全体が失敗したりする問題**（`字幕保真检查未通过`。ユーザーからの報告：「哦」1 つのせいで 28 分間字幕がなくなった）。書き起こしスタイルが clean のときは、隣の字幕に入れられない孤立したフィラーを省略します。最後の照合はこうした記録済みの省略を認識するようになり、文字の抜けとは見なさなくなりました。
- **元の動画に壊れたデータパケットが少しあると、書き出しが「プロジェクトを準備」で失敗する問題**（`MEDIA_PREFLIGHT … avcodec_send_packet()`。ユーザーが Twitch の録画を書き出したときに発生）。今はプレーヤーと同じように、デコーダーが受け付けないパケットを飛ばし、その 1〜2 フレームは直前のフレームを使います。1 フレームもデコードできないファイルは引き続きエラーになります。
- **目のアイコンをオフにした字幕トラックが、完成動画に焼き込まれてしまう問題**。今は焼き込みません。すべて非表示にしたときは、完成動画が字幕なしの書き出しとビット単位で同じになります。
- **長い FLV をカット編集したものを書き出すと、区間ごとに長く止まる問題**（区間ごとにファイルの先頭からデコードし直していました）：今はまずシーク可能なロスレスのコピーを作ってから書き出します。3 分 51 秒・14 区間の元のプロジェクトでは、字幕付きの書き出しが約 132 秒で、5 秒以上止まることはありませんでした。この種の素材を初めて書き出すときは、コピーを作るまで数分待つ必要があります。

### 既知の制限

#### 새 기능

- **다중 오디오 트랙 영상: 모든 오디오 트랙이 보이고, 인식 전에 오디오 트랙을 먼저 고릅니다.** 오디오 트랙이 여러 개인 MP4 / MKV(원음 + 더빙, 믹스 + 마이크 등)를 자막 스튜디오에 끌어다 놓으면, 오디오 트랙마다 영상 트랙 아래에 한 줄씩(A1, A2…) 자리를 잡고 이름, 언어, 채널이 적히며, 파형은 각 트랙 자신의 소리입니다. 처음에는 파일의 기본 오디오 트랙만 소리가 나고 나머지 줄은 음소거되어 있으며(최종 영상의 소리는 예전과 같음), 더빙으로 바꾸려면 A1을 음소거하고 A2를 켜면 됩니다. 자막 스튜디오에서 "자막 인식"을 누르거나, 홈에서 파일을 끌어다 놓은 뒤 "자막 생성 시작"을 누르면 먼저 "인식할 오디오 트랙 선택"이 나타납니다. 트랙마다 체크 상자가 하나씩 있고 미리 들어 볼 수 있습니다. 두 번째 트랙만 체크하면 모델에 들어가는 것은 두 번째 트랙의 소리이고, 두 트랙을 체크하면 각각 한 번씩 인식해 자막을 오디오 트랙별로 "중국어 원음 · S00", "두 번째 더빙 · S00" 두 그룹으로 나누며, 양쪽의 "화자 1"을 같은 사람으로 취급하지 않습니다. 어느 트랙이 실패해도 나머지 트랙은 그대로 완료되고, "실패한 작업 다시 시도"는 그 트랙만 다시 돌립니다. 늦게 시작하는 오디오 트랙(예: 3초 뒤에야 소리가 나는 더빙)도 파형, 재생, 내보내기, 인식에서 모두 올바른 시간에 놓입니다. 스테레오나 5.1 오디오 트랙이 하나뿐이면 예전처럼 한 트랙으로 다루며 선택 창이 나오지 않습니다.
- **편집한 프로젝트의 소리를 내보낼 수 있습니다.** 내보내기 페이지의 "출력 파일" 제목 줄에서 "영상 / 오디오"를 고를 수 있으며, 오디오를 고르면 편집한 프로젝트의 소리를 바로 내보냅니다(형식 6가지). 영상을 먼저 인코딩할 필요가 없습니다.
- **자막을 "영상" 탭에서 옮길 수 있습니다.** 타임라인이나 목록에서 자막을 선택하면 "영상" 탭에 그 자막의 위치, 배율, 회전, 앵커가 표시됩니다. 원문 / 번역문을 따로 조정하고, 작은 화면에서 동그란 점을 드래그하며, 한 번 드래그하면 실행 취소 한 단계입니다. 여러 개를 선택하면 함께 바뀝니다. 영상 클립을 선택하면 여전히 예전의 클립 카드가 나오고, 자막을 선택해도 더 이상 스타일 탭으로 돌아가지 않습니다. 자막 위치와 배율은 전체 연동할 수 있습니다(한 곳을 바꾸면 모두 따라 바뀜).
- **"AI 용어 라이브러리 교정" 페이지에서 특정 화자를 숨기거나 그 화자만 볼 수 있습니다**(내레이션 등): 숨긴 자막은 목록에 나오지 않고, 원래 자리에 "내레이션 N개 숨김 · 표시" 한 줄이 남습니다. 모두 적용, "현재 목록에서" 바꾸기, AI 교정은 모두 이 자막을 건너뛰며, "프로젝트 전체에서"를 고를 때만 포함하고 몇 곳이 들어 있는지 적어 줍니다.

- **"일괄 바꾸기"(Ctrl+H / Ctrl+F)가 간결한 창으로 바뀌었습니다**: 찾기와 바꾸기 칸 두 개, 범위 메뉴, 한 줄로 늘어선 옵션 태그, 체크해서 고르는 미리보기(지워지는 글자와 새로 들어가는 글자를 각각 다른 색으로 표시)로 이루어집니다. ↓로 찾기에서 바꾸기로 넘어가고, Enter는 체크한 항목을 바꾸며, Esc는 창을 닫습니다. "AI 정리"는 자막 목록의 "AI 교정" 옆으로 옮겼습니다. "텍스트 정리"는 더 이상 제공하지 않습니다(문장 끝 공백을 없애려면 일괄 바꾸기에서 "정규식"을 켜고 `\s+$`를 찾아 바꿀 내용을 비워 두세요).
- **홈과 자막 스튜디오가 같은 컴포넌트 세트를 쓰게 되었습니다.** 버튼, 드롭다운, 입력 칸, 숫자 칸은 테두리 없는 색 블록으로 바뀌었고, 설명과 단위는 칸 안에 적으며, 상태는 캡슐로 표시합니다("● 온라인 · 설정됨", "✓ 자막 교정"). 홈의 "AI 텍스트 처리"에서 상자 안의 상자를 없앴고, "인식 구성" 줄은 위아래 가운데로 맞췄습니다. 자막 스튜디오 상단 막대는 탐색 / 보기 / 도구 / 내보내기의 네 색 띠로 나뉩니다. "문제 신고"는 글자로 적히고 알림 색을 쓰며 "이중 언어 / 번역" 오른쪽에 놓이고, 영상·오디오 내보내기는 항상 맨 마지막입니다. 모션, AI, 영상, 클립 네 도구 패널을 다시 배치했습니다. 모션은 클릭하면 바로 적용되고, 아래 막대에는 "범위", "언어 레이어"만 있습니다. 스타일 페이지 맨 위에는 "적용 대상"이 있습니다. 모션 미리보기, 효과 미니 카드, "프리셋 더 보기" 창의 배경색은 테마를 따릅니다(밝은 테마에서 더 이상 어색한 남색 배경이 나오지 않음).
- **자막 스튜디오에서 원문과 번역문을 따로 이동, 배율 조정, 회전할 수 있으며**, 캔버스에서 드래그하거나 모서리를 끌어 크기를 바꾸면 그 값이 입력 칸에 함께 반영됩니다. 모션은 기본적으로 현재 자막의 두 언어에 함께 적용됩니다. 메인 트랙이 잠겨 있으면 분명한 설명과 "트랙 잠금 해제"가 표시됩니다.
- **MOSS Pro의 긴 소재 처리가 훨씬 빨라졌습니다.** 25분 이상인 소재는 조용한 곳에서 약 20분 단위 구간으로 잘라 순서대로 올리고, MOSI에서 최대 3개 구간을 동시에 처리하며, 먼저 돌아온 구간부터 임시 자막을 보여 줍니다. 한 사용자의 96분짜리 방송 녹화본은 한 회 전체가 1,139초에서 286초로 줄었고, 자막 개수는 같았습니다. 이미 제출한 구간은 다시 과금되지 않으며, MOSI의 동시 작업 수가 가득 차면 잠시 기다렸다가 제출하고 실패로 치지 않습니다.
- **MOSS Pro가 실패하면 원인을 알려 줍니다.** 오류 메시지, 완료 페이지, "클라우드 인식을 다시 제출할까요?" 확인 창, 문제 해결 보고서에 모두 "2 / 5 구간(시작–끝)의 MOSI 작업(작업 번호 …)이 실패했습니다. MOSI가 돌려준 원인: …"이라고 적습니다. 진행 카드에는 지금 클라우드에서 처리 중인 구간이 어느 것인지, 이 구간을 얼마나 기다렸는지 표시하고, 평소보다 훨씬 오래 걸리면 계속 기다리거나 안전하게 취소할 수 있다고 알려 줍니다(다시 올리거나 중복 과금되지 않음). 오류 상세 정보에 인식 결과 JSON을 길게 붙이지 않습니다.
- **API Key를 입력하지 않았을 때 분명히 알려 줍니다.** "AI 텍스트 서비스 설정 → 추가 옵션"의 "의미 단위 줄 나누기", "자막 교정"이 꺼짐으로 표시되고 그 이유가 적힙니다. 원래 고른 설정은 바뀌지 않으며 Key를 입력하면 돌아옵니다. 인식을 시작하기 전에 Key가 없거나, 주 전사만 있고 글자 단위 타임스탬프가 없으면 먼저 "계속할까요?"라고 한 번 묻습니다(계속 생성 / API Key 입력 / 취소 / 다음부터 알리지 않음).
- **Key가 없을 때 로컬 줄 나누기가 단어 중간에서 덜 자릅니다**: 문장 끝의 ？！ 뒤에 남은 글자를 따로 떼어 내지 않고, 부사, 전치사, 접속사를 줄 끝에 남기지 않으며, 중국어의 "们", "过", "之间"을 줄 맨 앞에 두지 않습니다.

#### 수정

- **감탄사 하나가 따로 생략되면 마지막 단계에서 구간 전체를 다시 만들거나 아예 전체가 실패하던 문제**(`字幕保真检查未通过`. 사용자 제보: "哦" 하나 때문에 28분 동안 자막이 없었음). 전사 스타일이 clean이면 이웃 자막에 넣을 수 없는 따로 떨어진 감탄사를 생략하는데, 마지막 대조 과정이 이제 기록된 이런 생략을 알아보고 더 이상 빠진 글자로 취급하지 않습니다.
- **원본 영상에 손상된 데이터 패킷이 몇 개 있으면 내보내기가 "프로젝트 준비"에서 실패하던 문제**(`MEDIA_PREFLIGHT … avcodec_send_packet()`. 사용자가 Twitch 녹화본을 내보낼 때 겪음). 이제 플레이어처럼 디코더가 받아들이지 않는 패킷을 건너뛰고, 그 한두 프레임은 앞 프레임을 그대로 씁니다. 프레임을 하나도 디코딩할 수 없는 파일은 여전히 오류를 냅니다.
- **눈 아이콘을 끈 자막 트랙이 여전히 최종 영상에 입혀지던 문제**: 이제 입히지 않습니다. 모두 숨기면 최종 영상은 자막 없이 내보낸 것과 비트 단위로 같습니다.
- **긴 FLV를 편집한 프로젝트를 내보낼 때 구간마다 오래 멈추던 문제**(구간마다 파일 처음부터 다시 디코딩함): 이제 먼저 탐색 가능한 무손실 사본을 만든 뒤 내보냅니다. 3분 51초, 14개 구간으로 된 원본 프로젝트를 자막과 함께 내보내는 데 약 132초 걸렸고, 5초 넘게 멈춘 적은 없었습니다. 이런 소재를 처음 내보낼 때는 사본을 만드느라 몇 분 기다려야 합니다.

### 이전 버전에서 업데이트하기

- **0.8.2, 0.8.3**: 메인 창 오른쪽 위 "업데이트 확인". 약 60 MB(프로그램 본체)만 내려받고, 나머지는 이미 설치된 것을 그대로 씁니다.
- **0.7.0–0.8.1**: 마찬가지로 "업데이트 확인". 이 버전들은 0.8.2에서 바뀐 FFmpeg, Python 실행 라이브러리, 오프라인 설치 패키지도 받아야 해서 모두 약 890 MB이며, Setup을 다시 내려받는 것과 비슷한 양입니다. **0.6.5**는 렌더러도 추가로 내려받습니다(합계 약 1.13 GB).
- 이번 버전의 업데이트 정보도 GitCode 국내 미러를 GitHub보다 앞에 둡니다. 설치된 0.6.5–0.8.2는 먼저 GitCode에서 내려받고(중국 본토에서는 GitHub보다 훨씬 빠름), GitCode에 연결되지 않으면 GitHub를 씁니다. 0.8.3은 업데이트 확인 때 먼저 응답한 출처에서 내려받고, 한 출처가 계속 느리면 자동으로 다른 출처로 바꿔 이어받습니다.
- 끊긴 다운로드는 이어받습니다. 내려받은 뒤 검증하고, 프로젝트를 저장하고 종료에 동의한 다음에 교체합니다. 실패하면 원래 버전으로 돌아갑니다. 설정, 용어집, 프로젝트, 내려받은 모델과 실행 환경은 유지되어 다시 준비할 필요가 없습니다.
- **0.6.0 이하**: 2ByteASR를 닫고 0.8.4 Setup을 실행해 **그대로 덮어 설치하세요. 먼저 제거하지 마세요.**
- **Mac**: 아직 앱 안 업데이트가 없습니다. 이전 버전을 종료하고 새 DMG를 열어 App을 "응용 프로그램"으로 끌어 바꾸면 됩니다. 설정, 모델, 프로젝트는 App 밖의 사용자 폴더에 있습니다.

**확인하지 않은 것**: 알려 준 사용자의 원본 영상과 프로젝트(손상된 패킷과 감탄사 두 건은 로그를 바탕으로 재현한 소재를 사용), 실제 중국어·일본어 입력기, 영어와 러시아어 외 화면 언어에서 실제 창으로 본 새 레이아웃, Python을 한 번도 설치하지 않은 깨끗한 컴퓨터에서의 처음 배포, 자막 정확도 청취 확인.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 "알 수 없는 게시자"가 표시될 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러, gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`를 확인하세요. 백신이나 시스템 보안을 끌 필요도 없고 꺼서도 안 됩니다.
- **다중 오디오 트랙 소재가 들어간 새 프로젝트는 0.8.3과 그 이전 버전에서 열 수 없습니다**(프로젝트에 오디오 트랙 번호가 하나 더 기록됨). 다중 오디오 트랙 소재가 없는 프로젝트는 이전과 완전히 같아서 영향을 받지 않습니다.
- **다중 오디오 트랙**: 홈의 "원고 맞추기"는 여전히 FFmpeg가 스스로 오디오 트랙을 고릅니다. 홈에서 체크한 오디오 트랙은 이번에 앱을 켜 둔 동안에만 기억됩니다. 대기열에 다중 오디오 트랙 파일이 여러 개 있으면 파일마다 선택 창이 나옵니다. 여러 트랙을 골라 합친 뒤 완료 페이지의 "인식 시 N줄"은 첫 번째 오디오 트랙만 셉니다("프로젝트 현재 N줄"이 합친 뒤의 전체 개수입니다).
- **긴 FLV를 처음 내보낼 때**는 연속 타임라인 사본을 만드느라 몇 분 기다려야 합니다.
- **MOSS Pro 긴 소재**: 구간이 더 많아지고 화자 번호는 구간별로 표시되며, "스트리머만 남기기"가 긴 소재에서 잘못 지울 가능성이 더 큽니다(원래 있던 문제이며, 구간을 넘나드는 화자 합치기는 아직 구현하지 않음).
- **"AI 용어 라이브러리 교정" 페이지**: 디자인 시안에 있던 "바꿀 때 용어집에도 함께 기록" 체크 상자는 구현하지 않았습니다.
- **화면 번역**: 새 문구는 화면 언어 10가지 모두에 번역이 있으며, 번체 중국어는 글자 단위로 변환했습니다. 영어와 러시아어 외의 언어는 실제 창에서 하나하나 보지 않았습니다.
- **Mac은 실험판**: 이번 버전의 새 기능은 Mac에서 따로 확인하지 않았습니다. Mac의 최소 시스템은 여전히 macOS 15입니다(macOS 14 호환판은 아직 따로 시험 중이며, 이번 버전에는 넣지 않았습니다).
- **Claude**: Anthropic 공식 지원 지역에 중국 본토, 홍콩, 마카오는 없습니다.
- **Docker 버전은 아직 0.8.1입니다**([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)). 이번 버전에서는 Docker 이미지를 업데이트하지 않았습니다.
