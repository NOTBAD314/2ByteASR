# 兔白字幕 2ByteASR 0.9.4

本版减少视频导出的重复处理，并修正字幕删除、复制和译文词库操作。比较基准为上一正式版 **0.9.3**。本次更新Windows；Mac仍为0.9.3。

## 新增

- 普通字幕提供可选双路视频编码，按帧边界分段、连续处理一次音频后拼接。默认仍为单路；启动前设置环境变量`TWOBYTEASR_EXPORT_SEGMENTS=2`启用，适用普通ASS/native与支持的简单视频图，高级字幕保持自身路线。是否更快请按本机完整导出时间比较。
- 随对应源码提供只读工程的一键性能采样入口，支持短片、整片、严格检查及缓存对照。

## 改进

- 常规导出改用容器/音视频信息及真正seek的有界抽检，避免编码完成后重复完整解码；严格完整解码仍可用于诊断。日志明确区分抽检与全片检查。
- 扩大简单视频图的直接导出范围，减少无用整片PTS索引和FFV1中间文件；隐藏与范围外素材先排除，复杂时钟、几何和转场保留可靠回退。
- 时间上不交叠的静态字幕与少量动效分别准备，静态使用相同浏览器和字体，减少重复透明帧渲染；交叠和全局环境效果仍走原路线。
- 可选双路导出减少中间段faststart搬移，最终MP4预留索引空间，避免再次整片重写。界面显示“检查成片”，总耗时计到最终文件可用。

## 修正

- 删除字幕同步清除显示、复制、保存和导出所见的对象，避免已删字幕残留。
- Ctrl+C/V复制字幕对象、Alt拖动副本与撤销重做保持对象独立。
- 译文词库追加导入保留已有条目和冲突提示，整库删除区分确认与取消。
- 中文启动自检不再误读正在进行的日语任务状态；失败及部分结果的同步提示按实际结果显示，保护已有字幕。

## 已知限制

- 十分钟结果仅覆盖上述硬件与合成4K30普通字幕场景，默认仍单路。原机工程、4K60长片、高级动效长工程与更复杂轨道未取得同等成绩；高级静态/动效短片未到6×。
- 常规有界抽检不等于全片完整验证。严格检查可额外耗时；音频人工听审、实体IME/多屏、其他硬件和长期稳定未新增证明。
- 原生0xC0000005首因、冷定位和忙机长尾仍未确认解决，独立术语/颜色R7候选不包含在本包。
- Windows程序与安装器没有Authenticode签名；随附SHA-256和既有发布者Ed25519签名。
