### 有什么变化（相对 1.1.0）

#### 新增

- **教学中心与分章练习。** 从第一份字幕开始，按需学习编辑、术语、兔白、压制、说话人、样式和声音剪辑；教程可跳过或按 Esc 退出。
- **兔白可以看应用窗口。** 开启截图权限并选择支持看图的模型后，可结合当前界面提问，聊天中能查看截图缩略图。
- **兔白任务工具与授权文件夹。** 用任务模式分步检查和处理问题，按授权读取文件夹内容；可直接开始一段新对话。
- **术语文件导入与 AI 整理。** 导入常见文本、表格或 JSON 词库，在预览中检查整理结果后写入；可用“有冲突”筛选集中查看待处理项。
- **我的改动。** 保存自己的界面样式、文字与说明，更新后继续保留，可停用或恢复；扩展脚本默认关闭。

#### 改进

- **AI 失败后可集中再试一次。** 校对或断句遇到格式错误、空响应或截断时，可在同一服务和模型中提高一级思考补救；有独立开关和数量上限，失败仍保留原文或本地断句。
- **术语与字幕操作更紧凑。** 术语卡片显示选项并入操作行，编辑后的列表位置保留；字幕列表可直接问兔白，校对提示改为紧凑卡片。

#### 修正

- **压制结束后“在文件夹中显示”没有打开可见窗口。** 现在定位到成片，失败时尝试打开所在文件夹，并提示文件已移动或操作失败。
- **Mac 大词库统计或冲突数没有更新。** 补齐后台统计进程入口，较大词库也能显示统计与冲突。

### 已经装过旧版本

- **Windows 1.1.0**：使用“检查更新”，约 **〔待填：更新 MB〕 MB**；也可保存并退出后运行 Setup 覆盖安装。
- **Windows 0.6.5–1.0.2**：使用“检查更新”，按已装组件补齐差异，下载量随起始版本变化。
- **更早的 Windows 版本**：保存工程并退出，运行新 Setup 覆盖安装，不要先卸载。
- **Apple Silicon Mac**：保存工程并退出，将新应用拖入 Applications 覆盖旧应用。
- 覆盖安装保留工程、设置、词库、模型和运行环境；兔白读取与修改遵守所选权限。

### What changed (since 1.1.0)

#### New

- **Tutorial center.** Start with your first subtitles, then choose lessons for editing, glossaries, Bunny, exports, speakers, styles and audio editing.
- **Bunny vision and task tools.** With permission and a vision-capable model, ask about the current app window. Use task mode, authorized folders and fresh conversations for guided work.
- **Glossary import and AI cleanup.** Preview text, table or JSON imports before applying them, and filter conflicting entries.
- **My changes.** Keep custom interface styles, wording and instructions across updates, with disable and restore controls. Extension scripts start disabled.

#### Improved

- Failed AI proofreading or segmentation can receive one bounded rescue round using the same service and model at a higher thinking level. Original text or local segmentation remains available when rescue fails.
- Compact proofreading cards and glossary controls, direct Bunny access from subtitles, and preserved glossary scroll position after edits.

#### Fixed

- “Show in folder” opening an invisible window after video export.
- Empty statistics or conflict counts for large Mac glossaries, with the background worker entry now available.

### Updating

From Windows 1.1.0, use “Check for updates” (about **〔待填：更新 MB〕 MB**). From 0.6.5–1.0.2, missing components are added as needed. Older Windows versions can install over the existing copy after quitting. On Mac, quit and replace the app in Applications. Projects, settings, glossaries, models and runtimes are preserved.
