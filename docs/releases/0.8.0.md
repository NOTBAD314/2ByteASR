### 为什么是 0.8.0

这一版的改动比以往任何一版都多，所以版本号从 0.7 升到 0.8：首页、术语库、工作台样式与动效、快捷键、说话人、导出这些界面大面积重做；线上词库的投稿流程正式上线；说话人管理和动效设计面板重做后正式启用；视频片段之间可以加转场；AI 服务多了 Claude；安装与运行也放宽了——支持更旧的 Windows、模型和运行环境可以不放在 C 盘、没有显卡驱动的电脑也能打开播放器。工程文件、设置、识别结果的格式都没有变，0.7.x 的工程直接打开即可。

### 这一版的变化（相对 0.7.5）

#### 界面重做

- **首页。** 「识别方案」一行放先选目标、当前方案、⋯ 和高级设置；还没选素材时拖放区收成一行（图标、标题与格式、「选择素材」）。右边一张卡从上到下是三张模型卡、AI 智能断句、内容与术语（游戏名称 | 术语库校对 | 联网补充核验）、字幕语言与输出。窗口高时多出来的高度分给拖放区和模型卡，窗口矮时页面可以滚动，底部按钮栏不动。深色主题下卡片底色和分隔线调淡。
- **首页三张模型卡。** 顶行是角色名和状态（要安装模型或配置 API 时按钮也在这一行），名字旁边是模型自己的标志；下面一行写所选模型的语言和用途，例如 MOSS“50+ 种语言 · 转写并区分说话人”。以前这一行是写死的角色说明，主力转写永远写“中文多人转写与说话人区分”。
- **选择模型窗口与模型工坊：每张卡标出语言。** 固定顺序“中文、粤语、方言、英语、日语、韩语”，再加「+N 种」：实心是主要支持，虚线框是可用但效果一般，删除线是不支持，点线框是官方没写；资料只取各模型的官方说明。Qwen Cloud、阿里云百炼、MOSS 云端、Spark-ASR-2.0 换上各自的标志。
- **术语库页。** 页首两个分页「我的词库」「线上词库」。左边是平的词库列表，「新建」点了才展开；右边一张内容卡：加词栏（听错的写法 → 正确写法 · 分类）、「批量映射…」「试一句字幕」、工具行、词条表、本批开关。AI 建库的五个动作和 AI 服务选择收进「AI 更新 ▾」，改名、给 AI 的说明、导出、删除收进「⋯」；选了词条才出现确认、隐藏、删除。空词库显示两张起点卡片：「从线上词库下载」「自己整理」。
- **工作台「样式」页。** 颜色按钮本身就是方形色块；背景、阴影、发光都是行尾同一列的开关；阴影展开后左边圆盘调方向，右边是距离、不透明度、模糊、扩散；左侧标签与控件各自排成一列，面板拉宽后也对齐，英文等较长的翻译会把标签列整体加宽；打开的属性右侧显示它的颜色并渐变到透明；不再有文字预览，一屏能看到更多。
- **快捷键设置页。** 按用途分组的一个列表，每行只有功能名和键帽，点一下再按新组合（Esc 取消），重复的会写明；能改的快捷键从 67 个加到 98 个（跳到开头 / 结尾、前后 1 秒、时间轴缩放、字幕提前 / 推后 0.1 秒、导出、全屏、打开设置等）。「外观」里的主题名改成“深紫 / 莓红”“黑 / 黄”这类，已保存的主题照旧生效。
- **导出字幕（Ctrl+E）。** 四种格式是卡片，各写一句用途；说话人和保存位置是分段按钮；下面列出会写出的文件，已有同名标“会替换”；工程有译文时可选原文 / 译文 / 双语。导出后同一个窗口变成结果页（复制路径、打开文件夹）。首页完成页的「导出字幕」换成同一套卡片。
- **审核模式（R）的改字建议。** 句子保持完整，有疑问的字黄底加下划线；每种候选写法是字上方的一个小标签，点哪个就只把那一处改成哪个（可撤销）；鼠标停在标记上提示来源。
- **工作台。** 工程名长时，“已自动保存 / 素材离线”不再压到主页、工程库图标；窗口窄时工具栏按钮依次收进「⋯」。字幕列表和工具面板每次打开工程都展开。时间轴「调整」菜单只留四个一键操作（新字幕自动避让、重新排版选中 / 全部字幕的位置、衔接 0.5 秒以内的间隙）。快捷键面板右上角有 ×。

#### 线上词库与术语库

- **投稿我的词库改成三步。** 先选词库（列出每个词库和确认过的词数，从线上装来的库写明“投稿会作为它的新版本”）→ 再检查要上传的内容（每个词一行，可以逐个勾掉，按“改字规则 / 热词 / 有提醒 / 不上传”筛选；提醒按类合成一句话，不再是几十行一模一样的警告）→ 最后署名、同意 CC0，用 GitCode / GitHub 投稿或只导出文件。勾掉的词不会进导出文件；理由、来源、任务编号、日期仍然只留在你的电脑上。
- **分享入口。** 词库标题旁有「分享到线上词库」，直接到第 2 步；已确认 50 条以上、线上还没有这个游戏时提示一次，关掉就不再出现。
- 英文界面里“热词”以前显示成 “Chinese”，改成 “Hotwords”。

#### 说话人管理

- 每位说话人一张卡：名字直接改，点色点换颜色，★ 主播、👁 显示点一下就切换，▶ 试听代表句，点时间条任一段从那里听。
- 识别出来的说话人有「主要 / 游戏声 / 忽略」和「合并到 ▾」，选了立即生效、一步可撤销（Ctrl+Z 也行），只动这一位的字幕：你删过的、改过归属的字幕不会回来。忽略的人卡片变淡，选「主要」就回来。以前是两页表格加一大段说明，改颜色、改用途都要再按一次「应用」。

#### 动效设计面板

- 工作台工具面板的「动效」页正式启用：顶部一排显示入场、出场、循环、逐词各选了什么；时长、强度（轻 / 标准 / 强）、方向在页上调；卡片按分类筛选（基础、弹跳、逐字、电影感、故障等），静止时显示最有辨识度的一瞬，悬停播放。
- 效果补到入场 33、出场 20、循环 13、逐词 15 个。“电影感”一组（冲刺推入、推近模糊、闪白、对开合拢、立体翻转、甩入、光扫等）与逐字一组（打字机带光标、逐字浮现、波浪弹入、失焦聚焦等）都是按通用手法自己实现的，没有用任何插件的代码或素材。
- 逐词效果按真实字词时间走，可以先选当前 / 已选 / 同一说话人 / 全部字幕，预览后应用，可撤销；缺少可靠字词时间时保留整句并说明原因。蓝白卡拉 OK 和流星点读连续扫过短字间隙，长停顿保留。
- 带逐字特效的字幕导出 ASS 快 2–3 倍（结果逐字节相同）。

#### 视频片段转场

- 同一轨两个视频片段之间的接缝，除了原来的交叉溶解，还能选推移模糊、甩镜、缩放模糊、闪白（或闪黑）、色散故障、拉伸。推移和甩镜可选上下左右，拉伸可选横向 / 纵向，强度 50%–150%。
- 视频工具页「转场」框里每种效果是一张会动的小卡片；「设为默认」后，Ctrl+D / 「应用默认转场」就用它。时间轴上的转场框挪到片段底部，不再挡住片段名称。
- 预览（暂停、拖动、播放）、压制成片和「保存当前帧」用同一份画法。

#### AI 功能

- **AI 服务加 Claude。** 「AI 智能断句设置」和工作台「AI 特效字幕」的服务商里多了 Claude API（`claude-opus-5-5` 预填，另有 `claude-sonnet-5-5`、`claude-haiku-5-5`，「刷新模型」读你账户能用的列表）。兔白用自己现有的网络层直接调用 Anthropic Messages API，没有另装软件包；字幕校对、全文断句、翻译、术语整理和 AI 特效字幕都能用。出错时写明原因（Key 无效、账单、权限、模型不可用、限速、服务过载）；「申请教程」里有 Claude 的申请步骤。
- **没填 API Key 时先说明。** 工作台 AI 断句、AI 词库校对、AI 设计、查找替换的 AI 预览、字幕翻译、术语库 AI 建库等自己点的 AI 功能，没 Key 时先弹“这个功能要用 AI，需要先填 API Key”（「API Key 是什么？」打开图解说明），不发请求；剪辑助手的高光分析直接用本地结果并写明原因。以前只看到一行“缺少 API 密钥”的报错。
- **翻译窗口显示请求日志。** 每批请求、耗时、用量与失败原因，可复制完整日志（API Key 等凭证自动脱敏；日志含字幕原文，分享前请检查）。Gemini 3 快速翻译用低思考强度；输出被截断后拆批重试，不再阻止后续批次。

#### 识别

- **字幕时间轴说同一个模型。** 字幕语言是日语或英语时，字词时间由 Qwen3-ForcedAligner 对齐，FireRedASR2-AED 只用于中文。以前「选择字幕时间轴模型」写“当前：FireRedASR2-AED”，首页卡却写“Qwen3 对齐”，两边都不说为什么；现在两处同名，并写明“字幕语言是日语，FireRedASR2-AED 只用于中文”。改回中文后 FireRed 照常使用。
- **Windows 的模型列表不再列出 Apple 专用的 MLX 版**；时间轴关闭时日语 CTC 显示「使用」，点了会接通已安装的 Qwen3 时间轴。
- **MOSS 长录播先算容量再分段**，3 小时以上的录播不再在分段前超出上限；失败时先显示原始原因和处理建议，不再只看到一段状态 JSON。

#### 安装与运行

- **Setup 支持 Windows 10 1809（版本号 17763）及以上**，含 Windows 10 LTSC 2019 / 2021、Windows 11、Windows Server 2019 / 2022。以前写的“22H2 及以上”只是当初开发电脑的版本号，不是技术要求。更旧的系统会看到中文说明（Windows 7 / 8.1 无法运行）。
- **模型和运行环境可以不放在 C 盘。** 新安装时，本地模型和运行环境（每套约 5 GB）都放在你选的安装文件夹里；Setup 的“选择安装位置”页会说明大概要多少空间，C 盘剩余不多时提醒换盘。已经装好的用户，运行环境仍在原处、照常可用；想腾出 C 盘，打开「应用设置 → 存储与缓存 → 移到其他位置…」，模型和运行环境会一起移过去：先检查空间，可以取消，新位置确认能启动后才删除旧文件，出错自动还原，不用重新下载。识别、下载或导出进行中时不能移动。
- **没有显卡驱动的电脑也能打开工作台播放器。** 虚拟机、远程桌面服务器、只装微软基本显示驱动的电脑，以前打开工作台会等 30 秒后显示“准备播放器失败，准备超时”。现在随包附一份 Khronos Vulkan 运行库，只在系统里没有时才用（有显卡驱动的电脑行为不变）；万一播放器仍启动不了，马上说明原因和办法。
- **中国大陆下载备援。** 程序内更新和线上词库在 GitHub、GitCode 都不通时，最后还会试 gh-proxy.org。

#### 其他修正

- 字幕背景开过就关不掉、红色改成粉色画面仍是红色（阴影半透明或带模糊时一定会这样）；已经存下的这类工程打开后显示正确颜色。
- 应用设置没改也问“要不要保存”。
- 改过的快捷键，工具栏提示、“更多”菜单、右键入点 / 出点、首页开始按钮、导出页的 I / O 和时间轴全选都跟着当前的键；清空的写“未绑定”。
- 「上一条」「下一条」、在列表或时间轴点选、播放跟随时，“跳转”框都显示当前字幕的序号。
- 字体下拉框点一下就打开并保持打开；换字体后不再沿用上一款的字重。
- 动效页来回切换分类时卡片不再叠在一起。
- 工作台在画面上时，界面缩放不再接手 Ctrl+滚轮（指针在时间轴上只缩放时间轴；对话框里照旧能缩放界面）。

### 已经装过旧版本

- **0.7.0–0.7.5**：主界面右上角“检查更新”，下载程序与许可材料两部分（约 79 MB）。**0.6.5** 会多下载 Python 运行环境与渲染器。下载后校验，等你保存工程并同意退出后才替换；失败会自动恢复原版本。设置、词库、工程、已下载的模型与运行环境都保留，运行环境也留在原来的位置。
- **0.6.0 及更早**：关闭兔白字幕，运行 0.8.0 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：还没有程序内更新。退出旧版，打开新的 DMG，把 App 拖进“应用程序”替换即可；设置、模型和工程存放在 App 以外的用户资料夹。

### Why 0.8.0

This release has more changes than any release before it, so the version number moves from 0.7 to 0.8. Large parts of the interface were redone: the home page, the term library, Studio styles and motion, shortcuts, speakers and export. The online glossary submission flow is now officially live. Speaker management and the motion design panel were rebuilt and are now enabled. You can add transitions between video clips. Claude joins the AI services. Installing and running are less demanding: older versions of Windows are supported, models and runtimes no longer have to be on drive C, and computers without a graphics driver can open the player. The formats of project files, settings and recognition results have not changed; 0.7.x projects open as they are.

### What changed (compared with 0.7.5)

#### Redesigned interface

- **Home page.** The "Recognition plan" row holds Pick a goal first, Current plan, ⋯ and Advanced settings. Before you choose any media, the drop area shrinks to one row (icon, title and formats, "Choose media"). The card on the right holds, from top to bottom, the three model cards, AI smart segmentation, Content & terms (game name | Glossary correction | Additional web verification) and Subtitle language and output. When the window is tall, the extra height goes to the drop area and the model cards; when it is short, the page scrolls and the button bar at the bottom stays put. In dark themes, card backgrounds and divider lines are toned down.
- **The three model cards on the home page.** The top row shows the role name and status (when a model needs installing or an API needs setting up, the button is in this row too), with the model's own logo next to the name. The row below shows the selected model's languages and purpose, for example "50+ languages · Transcribes and tells speakers apart" for MOSS. That row used to be a fixed description of the role: primary transcription always said "Chinese multi-speaker transcription and speaker separation".
- **"Choose a model" window and Model workshop: every card lists its languages.** Always in the order "Chinese, Cantonese, Dialects, English, Japanese, Korean", followed by "+N more": solid means main support, a dashed outline means usable but with mediocre results, strikethrough means not supported, and a dotted outline means the official documentation does not say; the information comes only from each model's official documentation. Qwen Cloud, Alibaba Cloud Bailian, MOSS cloud and Spark-ASR-2.0 now show their own logos.
- **Term library page.** Two tabs at the top: "My term libraries" and "Online glossary". On the left is a flat list of libraries, and "New" expands only when you click it. On the right is one content card: the add-term bar (misheard spelling → correct spelling · category), "Bulk mapping…", "Try a subtitle line", a tool row, the term table and the switch for the current batch. The five AI library-building actions and the choice of AI service are in "AI update ▾"; Rename, Notes for AI, Export and Delete are in "⋯"; Confirm, Hide and Delete appear only after you select terms. An empty library shows two starting cards: "Download from the online glossary" and "Make your own".
- **Studio "Style" page.** Colour buttons are themselves square swatches; background, shadow and glow are all switches in the same column at the end of their rows. When shadow is expanded, the dial on the left sets the direction, with distance, opacity, blur and spread on the right. Labels on the left and controls each line up in their own column and stay aligned when the panel is widened; longer translations such as English widen the whole label column. An open property shows its colour on the right, fading to transparent. The text preview is gone, so more fits on one screen.
- **Shortcut settings page.** One list grouped by purpose; each row has only the action name and its keys. Click a row and press the new combination (Esc cancels); duplicates are pointed out. The number of shortcuts you can change grew from 67 to 98 (jump to start / end, 1 second back / forward, timeline zoom, move subtitles 0.1 seconds earlier / later, export, full screen, open settings and more). Theme names in "Appearance" now read like "Dark purple / Berry" and "Black / Yellow"; a saved theme keeps working.
- **Export subtitles (Ctrl+E).** The four formats are cards, each with one sentence on what it is for; speakers and save location are segmented buttons; below them is the list of files that will be written, and an existing file with the same name is marked "will be replaced"; when the project has a translation you can choose Original / Translated text / Bilingual. After exporting, the same window becomes a results page (Copy Path, Open folder). "Export subtitles" on the home page's finished screen now uses the same cards.
- **Correction suggestions in Review mode (R).** The sentence stays whole, and doubtful characters get a yellow background and an underline. Each candidate spelling is a small tag above the characters; clicking one changes only that spot to it (undoable). Hovering over a mark shows where the suggestion came from.
- **Studio.** With a long project name, "Autosaved / Media offline" no longer runs over the Home and Project library icons; in a narrow window, toolbar buttons move into "⋯" one by one. The subtitle list and the tool panel are expanded every time a project opens. The timeline "Adjust" menu keeps only four one-click actions (automatic overlap avoidance for new subtitles, re-layout of the selected / all subtitles, closing gaps of 0.5 seconds or less). The shortcut panel has a × at the top right.

#### Online glossary and term libraries

- **Submitting your library now takes three steps.** First choose a library (each library is listed with its number of confirmed words; one installed from the online glossary says "a submission becomes its next version") → then check what will be uploaded (one row per word, each can be unticked, filter by "Correction rules / Hotwords / With warnings / Not uploaded"; warnings of the same kind are merged into one sentence instead of dozens of identical lines) → finally add your name, agree to CC0, and submit through GitCode / GitHub or just export the file. Unticked words are not in the exported file; reasons, sources, task IDs and dates still stay on your computer.
- **Share button.** "Share to online glossary" next to the library title goes straight to step 2. When a library has 50 or more confirmed entries and the online glossary has nothing for that game yet, the app suggests sharing once; close the hint and it does not come back.
- In the English interface, "Hotwords" used to show as "Chinese"; it now says "Hotwords".

#### Speaker management

- One card per speaker: edit the name in place, click the colour dot to change the colour, click ★ (streamer) or 👁 (show) to toggle them, ▶ plays a representative line, and clicking any segment of the time bar plays from there.
- Recognised speakers have "Main / Game audio / Ignore" and "Merge into ▾". A choice takes effect at once, can be undone in one step (Ctrl+Z works too) and touches only that speaker's subtitles: subtitles you deleted or reassigned do not come back. An ignored speaker's card fades; choose "Main" to bring it back. Before, this was two pages of tables plus a long explanation, and changing a colour or a role needed one more click on "Apply".

#### Motion design panel

- The "Motion" page in the Studio tool panel is now enabled. A row at the top shows what is chosen for Entrance, Exit, Loop and Words; duration, strength (Light / Standard / Strong) and direction are adjusted on the page; cards can be filtered by category (Basic, Bounce, Per letter, Cinematic, Glitch and more), show their most recognisable moment when still, and play on hover.
- There are now 33 entrance, 20 exit, 13 loop and 15 word effects. The "Cinematic" group (Push in, Zoom blur, Flash, Doors, Flip, Whip in, Shine in and more) and the per-letter group (Typewriter with a cursor, Letters rise, Wave in, Defocus and more) were written from scratch following common techniques; no plugin's code or assets were used.
- Word effects follow the real word timing. You can first choose the current / selected / same-speaker / all subtitles, preview, then apply, and undo. When reliable word timing is missing, the whole line is kept and the reason is shown. Blue-white karaoke and Meteor read sweep straight across short gaps between words and keep long pauses.
- Exporting ASS for subtitles with per-letter effects is 2–3 times faster (the output is byte-for-byte the same).

#### Video clip transitions

- At the join between two video clips on the same track, besides the existing Cross Dissolve you can now choose Push Blur, Whip Pan, Zoom Blur, Flash (or Dip to Black), Chroma Glitch and Stretch. Push Blur and Whip Pan can go up, down, left or right, Stretch can be horizontal / vertical, with strength 50%–150%.
- In the "Transition" box on the video tool page, each effect is a small animated card; after "Set as Default", Ctrl+D / "Apply Default Transition" uses it. The transition box on the timeline moved to the bottom of the clip and no longer covers the clip name.
- Preview (paused, scrubbing, playing), the burned-in video and "Save Current Frame" all use the same drawing code.

#### AI features

- **Claude added as an AI service.** The providers in "AI segmentation settings" and in Studio's "AI effect captions" now include the Claude API (`claude-opus-5-5` filled in, plus `claude-sonnet-5-5` and `claude-haiku-5-5`; "Refresh models" reads the list your account can use). 2ByteASR calls the Anthropic Messages API directly through its own existing network code, with no extra package installed; subtitle proofreading, full-text segmentation, translation, term organising and AI effect captions all work with it. Errors state the reason (invalid key, billing, permissions, model unavailable, rate limit, service overloaded); the "Sign-up guide" includes the steps for Claude.
- **Without an API key, the app explains first.** AI features you start yourself, such as Studio AI segmentation, AI glossary proofreading, AI Design, the AI preview in find and replace, subtitle translation and AI library building on the term library page, now first show "This feature uses AI, so it needs an API key first." when no key is set ("What is an API key?" opens an illustrated explanation) and send no request; the Clip Assistant's highlight analysis uses the local results directly and says why. Before, you only saw a one-line "missing API key" error.

Gemini 3 fast translation uses low thinking effort; truncated output is retried in smaller batches and no longer blocks the batches after it.

- **The subtitle timeline now names the same model everywhere.** When the subtitle language is Japanese or English, word timing is aligned by Qwen3-ForcedAligner, and FireRedASR2-AED is used only for Chinese. - **Setup supports Windows 10 1809 (build 17763) or later**, including Windows 10 LTSC 2019 / 2021, Windows 11 and Windows Server 2019 / 2022. The "22H2 or later" stated before was only the version of the development computer at the time, not a technical requirement. - **Models and runtimes no longer have to be on drive C.** On a new installation, local models and runtimes (about 5 GB per set) go into the installation folder you choose; Setup's install-location page says roughly how much space is needed and suggests another drive when C is low on space. On existing installations, runtimes stay where they are and keep working; to free up drive C, open "App Settings → Storage and cache → Move elsewhere…" and models and runtimes are moved together: space is checked first, you can cancel, the old files are deleted only after the app is confirmed to start from the new location, anything that goes wrong is rolled back automatically, and nothing has to be downloaded again. #### AI 機能

- **AI サービスに Claude を追加。** 「AI 自動文分割の設定」と字幕スタジオの「AI エフェクト字幕」のサービス提供元に Claude API が加わりました（`claude-opus-5-5` が入力済みで、ほかに `claude-sonnet-5-5`、`claude-haiku-5-5`。「モデルを更新」であなたのアカウントで使えるモデルの一覧を読み込みます）。2ByteASR は既存の自前のネットワーク処理で Anthropic Messages API を直接呼び出し、パッケージを追加でインストールしてはいません。字幕校正、全文の文分割、翻訳、用語の整理、AI エフェクト字幕のすべてで使えます。エラーのときは原因（キーが無効、請求、権限、モデルが使えない、レート制限、サービスの過負荷）を表示します。「申請ガイド」に Claude の申請手順があります。

- **翻訳ウィンドウに要求ログを表示。** バッチごとのリクエスト、所要時間、使用量、失敗の原因を表示し、ログ全体をコピーできます（API キーなどの認証情報は自動で伏せます。ログには字幕の原文が含まれるので、共有する前に確認してください）。Gemini 3 の高速翻訳は思考の強さを低くして使います。出力が途中で切れたときはバッチを分けて再試行し、後続のバッチを止めなくなりました。

#### 認識

- **字幕タイムラインの表示が同じモデルを指すように。** 字幕の言語が日本語か英語のときは、文字・単語のタイミングを Qwen3-ForcedAligner で合わせ、FireRedASR2-AED は中国語にだけ使います。以前は「字幕タイムラインのモデルを選択」に「現在：FireRedASR2-AED」と書かれる一方で、ホームのカードには「Qwen3 アライナー」と書かれ、どちらも理由を書いていませんでした。今は 2 か所で同じ名前になり、「字幕の言語が日本語のため、FireRedASR2-AED は中国語専用です」と理由も書きます。中国語に戻すと FireRed は通常どおり使われます。
- **Windows のモデル一覧に Apple 専用の MLX 版が出なくなりました。** タイムラインがオフのとき、日本語 CTC には「使用」が表示され、押すとインストール済みの Qwen3 タイムラインにつながります。
- **MOSS の長時間の録画は、先に容量を計算してから分割します。** 3 時間以上の録画が分割の前に上限を超えることはなくなりました。失敗したときは、状態の JSON だけを見せるのではなく、元の原因と対処方法を先に表示します。

AI 서비스에 Claude가 추가되었습니다. 설치와 실행 조건도 넓혔습니다. 더 오래된 Windows를 지원하고, 모델과 실행 환경을 C 드라이브가 아닌 곳에 둘 수 있으며, 그래픽 드라이버가 없는 컴퓨터에서도 플레이어를 열 수 있습니다. 프로젝트 파일, 설정, 인식 결과의 형식은 바뀌지 않았으므로 0.7.x 프로젝트를 그대로 열면 됩니다.

### 바뀐 점(0.7.5와 비교)

#### 다시 만든 화면

- **홈.** '인식 구성' 줄에 '먼저 목표 선택', 현재 구성, ⋯, 고급 설정이 들어갑니다. 아직 미디어를 고르지 않았을 때는 끌어다 놓는 영역이 한 줄(아이콘, 제목과 형식, '미디어 선택')로 줄어듭니다. 오른쪽 카드 하나에 위에서부터 모델 카드 세 장, AI 줄 나누기, 콘텐츠 및 용어(게임 이름 | 용어 라이브러리 교정 | 추가 웹 검증), 자막 언어 및 출력이 있습니다. 창이 높으면 남는 높이를 끌어다 놓는 영역과 모델 카드가 나눠 갖고, 창이 낮으면 페이지를 스크롤할 수 있으며 아래쪽 버튼 줄은 움직이지 않습니다. 다크 테마에서는 카드 배경색과 구분선을 옅게 했습니다.
- **홈의 모델 카드 세 장.** 맨 윗줄에는 역할 이름과 상태가 있고(모델을 설치하거나 API를 설정해야 할 때는 그 버튼도 이 줄에 있음), 이름 옆에는 모델 자체의 로고가 붙습니다. 그 아래 줄에는 고른 모델의 언어와 용도를 씁니다. 예를 들어 MOSS는 '50개 이상 언어 · 전사와 화자 구분'입니다. 예전에는 이 줄이 고정된 역할 설명이어서 주 전사에는 늘 '중국어 다인 전사 및 화자 구분'이라고 쓰여 있었습니다.
- **모델 선택 창과 모델 워크숍: 카드마다 언어 표시.** '중국어, 광둥어, 방언, 영어, 일본어, 한국어'의 고정된 순서에 '외 N개'가 붙습니다. 속이 찬 표시는 주요 지원, 파선 테두리는 쓸 수는 있지만 성능이 보통, 취소선은 지원 안 함, 점선 테두리는 공식 정보 없음입니다. 정보는 각 모델의 공식 설명에서만 가져왔습니다. Qwen Cloud, Alibaba Cloud Bailian, MOSS 클라우드, Spark-ASR-2.0은 각자의 로고로 바꿨습니다.
- **용어집 페이지.** 페이지 위에 '내 용어 라이브러리', '온라인 용어집' 두 탭이 있습니다. 왼쪽은 계층 없는 용어집 목록이며 '새로 만들기'는 눌러야 펼쳐집니다. 오른쪽은 내용 카드 하나로, 단어 추가 줄(잘못 들린 표기 → 올바른 표기 · 분류), '일괄 매핑…', '자막 한 줄 시험', 도구 줄, 항목 표, 이번 배치 사용 스위치가 있습니다. AI로 용어집을 만드는 다섯 가지 동작과 AI 서비스 선택은 'AI 업데이트 ▾'에, 이름 바꾸기, AI에게 주는 설명, 내보내기, 삭제는 '⋯'에 넣었습니다. 항목을 골라야 확인, 숨기기, 삭제가 나타납니다. 빈 용어집에는 시작 카드 두 장 '온라인 용어집에서 내려받기', '직접 만들기'가 보입니다.
- **자막 스튜디오 '스타일' 페이지.** 색 버튼 자체가 네모난 색 견본입니다. 배경, 그림자, 글로우는 모두 줄 끝 같은 열에 있는 스위치입니다. 그림자를 펼치면 왼쪽 원판으로 방향을 맞추고, 오른쪽에서 거리, 불투명도, 블러, 확산을 조절합니다. 왼쪽 이름표와 컨트롤이 각각 한 열로 정렬되어 패널을 넓혀도 줄이 맞고, 영어처럼 번역이 긴 언어에서는 이름표 열 전체가 넓어집니다. 펼친 속성은 오른쪽에 그 색이 보이고 투명하게 그러데이션됩니다. 글자 미리 보기는 없어졌고 한 화면에 더 많이 보입니다.
- **단축키 설정 페이지.** 용도별로 묶은 목록 하나로, 줄마다 기능 이름과 키캡만 있습니다. 한 번 클릭하고 새 조합을 누르면 되고(Esc는 취소), 겹치는 키는 그렇다고 적어 줍니다. 바꿀 수 있는 단축키가 67개에서 98개로 늘었습니다(처음 / 끝으로 이동, 1초 앞 / 뒤로 이동, 타임라인 확대/축소, 자막 0.1초 앞당기기 / 늦추기, 내보내기, 전체 화면, 설정 열기 등). '모양'의 테마 이름을 '짙은 보라 / 베리', '검정 / 노랑' 같은 식으로 바꿨고, 저장된 테마는 그대로 적용됩니다.
- **자막 내보내기(Ctrl+E).** 네 가지 형식이 카드로 나오고 각각 용도를 한 문장으로 적었습니다. 화자와 저장 위치는 세그먼트 버튼입니다. 아래에 쓰게 될 파일을 나열하고, 같은 이름의 파일이 이미 있으면 '교체됩니다'라고 표시합니다. 프로젝트에 번역문이 있으면 원문 / 번역문 / 이중 언어를 고를 수 있습니다. 내보낸 뒤에는 같은 창이 결과 페이지(경로 복사, 폴더 열기)로 바뀝니다. 홈 완료 페이지의 '자막 내보내기'도 같은 카드로 바꿨습니다.
- **검토 모드(R)의 수정 제안.** 문장은 끊기지 않고 그대로 보이며, 의심스러운 글자는 노란 바탕에 밑줄이 그어집니다. 후보 표기마다 글자 위에 작은 라벨이 하나씩 붙고, 누른 라벨대로 그 한 곳만 바뀝니다(실행 취소 가능). 표시 위에 마우스를 올리면 출처를 알려 줍니다.
- **자막 스튜디오.** 프로젝트 이름이 길어도 '자동 저장됨 / 미디어 오프라인'이 홈, 프로젝트 라이브러리 아이콘을 더 이상 덮지 않습니다. 창이 좁으면 도구 모음 버튼이 차례로 '⋯' 안으로 들어갑니다. 자막 목록과 도구 패널은 프로젝트를 열 때마다 펼쳐집니다. 타임라인 '조정' 메뉴에는 한 번에 실행되는 네 가지 동작만 남겼습니다(새 자막 자동 겹침 회피, 선택한 자막 / 모든 자막 위치 다시 배치, 0.5초 이내 간격 이어 붙이기). 단축키 패널 오른쪽 위에 ×가 있습니다.

#### 온라인 용어집과 용어집

- **내 용어집 제출이 세 단계로 바뀌었습니다.** 먼저 용어집을 고르고(용어집마다 확인한 단어 수를 보여 주며, 온라인에서 설치한 용어집에는 '제출하면 그 새 버전이 됩니다'라고 적음) → 올릴 내용을 확인하고(단어마다 한 줄이며 하나씩 선택을 해제할 수 있고, '교정 규칙 / 핫워드 / 경고 있음 / 올리지 않음'으로 거를 수 있음. 경고는 종류별로 한 문장으로 묶어, 똑같은 경고가 수십 줄 이어지지 않음) → 마지막으로 서명하고 CC0에 동의한 뒤 GitCode / GitHub로 제출하거나 파일만 내보냅니다. 선택을 해제한 단어는 내보낸 파일에 들어가지 않습니다. 이유, 출처, 작업 번호, 날짜는 여전히 내 컴퓨터에만 남습니다.
- **공유 입구.** 용어집 제목 옆에 '온라인 용어집에 공유'가 있으며 바로 2단계로 갑니다. 확인한 항목이 50개 이상이고 온라인에 아직 그 게임이 없으면 한 번 알려 주며, 닫으면 다시 나오지 않습니다.
- 영어 화면에서 '핫워드'가 예전에는 'Chinese'로 보였는데, 이제 'Hotwords'로 나옵니다.

#### 화자 관리

- 화자마다 카드가 한 장입니다. 이름은 바로 고치고, 색 점을 눌러 색을 바꾸며, ★ 스트리머와 👁 표시는 한 번 누르면 전환됩니다. ▶로 대표 문장을 들어 보고, 시간 막대의 아무 구간이나 누르면 거기서부터 들을 수 있습니다.
- 인식된 화자에는 '주요 / 게임 소리 / 무시'와 '병합 대상 ▾'이 있습니다. 고르면 바로 적용되고 한 번에 실행 취소할 수 있으며(Ctrl+Z도 가능), 그 화자의 자막만 바뀝니다. 내가 지웠거나 화자를 바꾼 자막은 돌아오지 않습니다. 무시한 화자의 카드는 흐려지고, '주요'를 고르면 돌아옵니다. 예전에는 표 두 페이지와 긴 설명이 있었고, 색이나 용도를 바꿀 때마다 '적용'을 한 번 더 눌러야 했습니다.

#### 모션 디자인 패널

- 자막 스튜디오 도구 패널의 '모션' 페이지를 정식으로 켰습니다. 맨 위 한 줄에 등장, 퇴장, 반복, 단어별에서 각각 무엇을 골랐는지 보입니다. 길이, 강도(약 / 표준 / 강), 방향은 페이지에서 조절합니다. 카드는 분류(기본, 바운스, 글자별, 시네마틱, 글리치 등)로 거를 수 있고, 멈춰 있을 때는 가장 알아보기 쉬운 순간을 보여 주며 마우스를 올리면 재생합니다.
- 효과를 등장 33개, 퇴장 20개, 반복 13개, 단어별 15개로 늘렸습니다. '시네마틱' 묶음(푸시 인, 줌 블러, 플래시, 양문 닫기, 입체 뒤집기, 휩 인, 샤인 인 등)과 글자별 묶음(커서가 있는 타자기, 글자별 떠오르기, 웨이브 인, 디포커스 등)은 모두 일반적인 기법으로 직접 구현했으며, 어떤 플러그인의 코드나 소재도 쓰지 않았습니다.
- 단어별 효과는 실제 글자·단어 타이밍을 따릅니다. 현재 / 선택됨 / 같은 화자 / 모든 자막 중에서 먼저 범위를 고르고, 미리 본 뒤 적용하며, 실행 취소할 수 있습니다. 믿을 만한 단어 타이밍이 없으면 문장 전체를 그대로 두고 이유를 알려 줍니다. 파랑·흰색 노래방과 별똥별 읽기는 글자 사이의 짧은 틈을 끊김 없이 지나가고, 긴 멈춤은 그대로 둡니다.
- 글자별 효과가 있는 자막을 ASS로 내보내는 속도가 2–3배 빨라졌습니다(결과는 바이트 단위로 같음).

#### 영상 클립 전환 효과

- 같은 트랙에 있는 두 영상 클립 사이의 이음매에 원래 있던 크로스 디졸브 말고도 푸시 블러, 휩 팬, 줌 블러, 플래시(또는 검은 플래시), 색 번짐 글리치, 늘이기를 고를 수 있습니다. 푸시와 휩 팬은 위 / 아래 / 왼쪽 / 오른쪽을, 늘이기는 가로 / 세로를 고를 수 있고, 강도는 50%–150%입니다.
- 영상 도구 페이지의 '전환 효과' 상자에는 효과마다 움직이는 작은 카드가 하나씩 있습니다. '기본값으로 설정'을 누르면 Ctrl+D / '기본 전환 효과 적용'이 그 효과를 씁니다. 타임라인의 전환 효과 상자는 클립 아래쪽으로 옮겨 클립 이름을 더 이상 가리지 않습니다.
- 미리 보기(일시 정지, 드래그, 재생), 자막을 입힌 최종 영상, '현재 프레임 저장'이 같은 방식으로 그립니다.

#### AI 기능

- **AI 서비스에 Claude 추가.** 'AI 줄 나누기 설정'과 자막 스튜디오 'AI 효과 자막'의 서비스 제공업체에 Claude API가 생겼습니다(`claude-opus-5-5`가 미리 입력되어 있고 `claude-sonnet-5-5`, `claude-haiku-5-5`도 있으며, '모델 새로고침'은 내 계정에서 쓸 수 있는 목록을 읽어 옵니다). 2ByteASR는 기존 네트워크 계층으로 Anthropic Messages API를 직접 호출하며, 패키지를 따로 설치하지 않았습니다. 자막 교정, 전체 줄 나누기, 번역, 용어 정리, AI 효과 자막에서 모두 쓸 수 있습니다. 오류가 나면 원인(Key 무효, 결제, 권한, 모델 사용 불가, 속도 제한, 서비스 과부하)을 적어 줍니다. '신청 안내'에 Claude 신청 단계가 있습니다.
- **API Key가 없으면 먼저 알려 줍니다.** 자막 스튜디오의 AI 줄 나누기, AI 용어 라이브러리 교정, AI 디자인, 찾기 및 바꾸기의 AI 미리 보기, 자막 번역, 용어집의 AI 용어집 구축처럼 직접 실행하는 AI 기능은 Key가 없으면 먼저 '이 기능은 AI를 사용하므로 먼저 API Key를 입력해야 합니다' 창을 띄우고('API Key란?'을 누르면 그림 설명이 열림) 요청은 보내지 않습니다. 클립 어시스턴트의 하이라이트 분석은 바로 로컬 결과를 쓰고 그 이유를 적어 줍니다. 예전에는 'API 키 없음'이라는 오류 한 줄만 보였습니다.
- **번역 창에 요청 로그 표시.** 배치별 요청, 소요 시간, 사용량, 실패 원인이 보이고 전체 로그를 복사할 수 있습니다(API Key 같은 인증 정보는 자동으로 가려짐. 로그에는 자막 원문이 들어 있으니 공유 전에 확인하세요). Gemini 3 빠른 번역은 낮은 사고 강도를 씁니다. 출력이 잘리면 배치를 나눠 다시 시도하며, 뒤의 배치를 더 이상 막지 않습니다.

#### 인식

- **자막 타임라인 모델이 두 곳에서 같게 표시됩니다.** 자막 언어가 일본어나 영어일 때는 Qwen3-ForcedAligner가 글자·단어 타이밍을 정렬하고, FireRedASR2-AED는 중국어에만 쓰입니다. 예전에는 '자막 타임라인 모델 선택'에 '현재: FireRedASR2-AED'라고 나오는데 홈 카드에는 'Qwen3 정렬'이라고 나왔고, 어느 쪽도 이유를 말하지 않았습니다. 이제 두 곳의 이름이 같고, '자막 언어가 일본어라서 FireRedASR2-AED은(는) 중국어에만 쓰입니다'라고 적습니다. 중국어로 되돌리면 FireRed를 평소처럼 씁니다.
- **Windows의 모델 목록에 Apple 전용 MLX 판이 더 이상 나오지 않습니다.** 타임라인이 꺼져 있을 때 일본어 CTC에 '사용'이 보이고, 누르면 설치된 Qwen3 타임라인을 연결합니다.
- **MOSS의 긴 녹화본은 용량을 먼저 계산한 뒤 나눕니다.** 3시간이 넘는 녹화본이 나누기 전에 한도를 넘는 일이 없어졌습니다. 실패하면 원래 원인과 해결 방법을 먼저 보여 주며, 상태 JSON 한 덩어리만 보이지 않습니다.

#### 설치와 실행

- **Setup이 Windows 10 1809(버전 번호 17763) 이상을 지원합니다.** Windows 10 LTSC 2019 / 2021, Windows 11, Windows Server 2019 / 2022도 포함됩니다. 예전에 적었던 '22H2 이상'은 처음 개발한 컴퓨터의 버전이었을 뿐 기술적인 요구 사항이 아니었습니다. 더 오래된 시스템에서는 중국어 안내가 나옵니다(Windows 7 / 8.1에서는 실행할 수 없음).
- **모델과 실행 환경을 C 드라이브가 아닌 곳에 둘 수 있습니다.** 새로 설치하면 로컬 모델과 실행 환경(한 벌에 약 5 GB)이 모두 내가 고른 설치 폴더에 들어갑니다. Setup의 '설치 위치 선택' 페이지에서 대략 필요한 공간을 알려 주고, C 드라이브의 남은 공간이 적으면 다른 드라이브를 고르라고 알려 줍니다. 이미 설치한 사용자의 실행 환경은 원래 자리에 그대로 있고 평소처럼 쓸 수 있습니다. C 드라이브를 비우고 싶다면 '앱 설정 → 저장소 및 캐시 → 다른 위치로 이동…'을 여세요. 모델과 실행 환경이 함께 옮겨집니다. 먼저 공간을 확인하고, 중간에 취소할 수 있으며, 새 위치에서 시작되는 것을 확인한 뒤에야 예전 파일을 지우고, 오류가 나면 자동으로 되돌리며, 다시 내려받을 필요가 없습니다. 인식, 다운로드, 내보내기 중에는 옮길 수 없습니다.
- **그래픽 드라이버가 없는 컴퓨터에서도 자막 스튜디오 플레이어를 열 수 있습니다.** 가상 머신, 원격 데스크톱 서버, Microsoft 기본 디스플레이 드라이버만 있는 컴퓨터에서는 예전에 자막 스튜디오를 열면 30초를 기다린 뒤 '플레이어 준비 실패, 준비 시간 초과'가 나왔습니다. 이제 Khronos Vulkan 런타임 라이브러리를 함께 넣었으며, 시스템에 없을 때만 씁니다(그래픽 드라이버가 있는 컴퓨터는 동작이 그대로). 그래도 플레이어가 시작되지 않으면 바로 원인과 해결 방법을 알려 줍니다.
- **중국 본토용 다운로드 예비 경로.** 앱 안 업데이트와 온라인 용어집은 GitHub와 GitCode에 모두 연결되지 않으면 마지막으로 gh-proxy.org도 시도합니다.

#### 기타 수정

- 자막 배경을 한 번 켜면 끌 수 없던 문제, 빨간색을 분홍색으로 바꿔도 화면은 빨간색으로 남던 문제(그림자가 반투명이거나 블러가 있으면 반드시 생김)를 고쳤습니다. 이미 저장된 이런 프로젝트도 열면 올바른 색으로 보입니다.
- 앱 설정에서 아무것도 바꾸지 않았는데도 '저장할까요?'라고 묻던 문제를 고쳤습니다.
- 단축키를 바꾸면 도구 모음 도움말, '더 보기' 메뉴, 오른쪽 클릭의 인 포인트 / 아웃 포인트, 홈의 시작 버튼, 내보내기 페이지의 I / O, 타임라인 모두 선택이 모두 현재 키를 따릅니다. 지운 단축키는 '지정 안 됨'으로 보입니다.
- '이전', '다음'을 누르거나, 목록이나 타임라인에서 클릭해 고르거나, 재생을 따라갈 때 '이동' 상자에 현재 자막의 번호가 보입니다.
- 글꼴 드롭다운을 한 번 누르면 열리고 열린 채로 있습니다. 글꼴을 바꾼 뒤 이전 글꼴의 굵기를 더 이상 이어 쓰지 않습니다.
- 모션 페이지에서 분류를 오가며 바꿀 때 카드가 더 이상 겹치지 않습니다.
- 자막 스튜디오가 화면에 있을 때 인터페이스 배율이 Ctrl+휠을 더 이상 가로채지 않습니다(포인터가 타임라인 위에 있으면 타임라인만 확대/축소하고, 대화 상자에서는 예전처럼 인터페이스 배율을 바꿀 수 있음).

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 '알 수 없는 게시자'로 보일 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러·gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`로 확인하세요. 백신이나 보안 설정을 끌 필요는 없으며 꺼서도 안 됩니다.
- **Mac 판은 실험판입니다**: GitHub 가상 Mac에서만 확인했고 실제 Mac과 메모리 8 GB Mac에서는 확인하지 않았습니다. 창이 아주 좁으면 자막 스튜디오 위쪽 도구 모음이 겹칩니다.
- **Claude**: Anthropic이 공식 지원하는 지역에 중국 본토, 홍콩, 마카오는 들어 있지 않습니다.
- **AI 서비스 설정**: "AI 줄 나누기 설정"에서 서비스를 바꿔도 모델 목록은 이전 서비스의 것으로 남아 있습니다. "모델 새로고침"을 눌러야 바뀝니다(모든 서비스가 같음).
- **실행 환경 위치**: 0.8.0을 새로 설치한 뒤 0.7.5로 되돌리면 0.7.5는 프로그램 폴더 안의 실행 환경을 찾지 못하므로 한 번 다시 준비해야 합니다.
- **이전 버전에서 새 프로젝트 열기**: 새 전환 효과를 쓴 프로젝트는 이전 버전의 2ByteASR에서도 열리지만, 새 효과는 크로스 디졸브로 재생됩니다.
- **온라인 용어집**: GitCode 약관에는 로그인하지 않은 방문자는 내려받을 수 없다고 되어 있지만 지금은 내려받을 수 있습니다. 제출에는 GitHub 또는 GitCode 계정이 필요합니다.
- **수식**: 위아래로 쌓는 표기(분수, 행렬)는 아직 한 줄로 보입니다.
- **로컬 MCP**: Claude Desktop 설정을 쓰려면 먼저 Claude를 완전히 종료해야 합니다. Claude 자체의 동작 때문입니다.
