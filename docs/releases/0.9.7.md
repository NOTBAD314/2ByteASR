# 兔白字幕 2ByteASR 0.9.7

2026-11-09。本次相对正式版 **0.9.6**，增加字幕编辑浮窗的文字光标切割，并合入此前日常的字幕质量、译名校验、VAD与术语搜索修订。Windows与Apple Silicon Mac同步提供。

## 新增

- 字幕编辑浮窗增加“在光标处切割”、显式“C切割模式”和播放头校准开关。默认c/C输入字符，开启模式后按C切割，Shift+Enter继续换行。
- 使用正在编辑的最新文字切割，支持连续分段、上一段/下一段编辑和窗口内撤销。确认统一形成一次工程撤销步骤，取消恢复暂存前的字幕。
- 识别覆盖状态展示待恢复的语音缺口，提供项目时间跳转和现有局部识别入口，帮助检查识别后仍缺字的区间。

## 改进

- 文字光标切点优先使用当前有效的字词时间。正文发生变化或缺少可靠对齐时显示“估算切点”，允许主动用字幕内部的播放头校准，两段各保留至少50毫秒。
- 大量字幕工程的浮窗切割局部更新相关列表行和时间轴索引，沿用现有预览与自动保存调度。
- Qwen Audio 3.1断句对超预算单源段分块，独立检查模型断点，并对异常断句作有界局部修整，保留逐字守恒校验。
- 长音频VAD采用显式分块，减少单次处理的内存占用，记录实际worker执行信息。

## 修正

- 修正术语搜索后卡片持续闪烁、五/六列反复重排。统一滚动条空间预算，合并布局请求并复用相同查询结果。
- 修正完整译名被截短或漏名后仍沿用完成状态的情况，补翻与失败重试使用当前词库规则，已合规译文和人工译文按既有保护规则处理。
- 原文切割后缺少可靠原译映射时，完整译文保留一次，并保留整句参考和待对齐标记。关联译文层本身缺少原文位置映射时，提示转到原文层操作。

- 修正云端识别返回说话人证据时的局部导入遮蔽错误，恢复对应结果构建。
- Windows修正工程异步保存后退出更新时丢失更新待办的问题。

## 下载与升级

Windows下载 `2ByteASR-Setup-0.9.7.exe`，也可使用程序内更新。0.9.6用户请先手动保存工程，再检查更新，避免旧客户端在更新提示中异步保存后丢失更新待办。Apple Silicon Mac下载 `2ByteASR-0.9.7-macos-arm64-Setup.dmg`，将应用拖入Applications。保存工程并退出程序后覆盖安装。

Windows适用Windows 10 1809及以上64位。本地识别按所选路线准备模型与运行环境。云端路线使用自备服务配置，向所选提供商提交音频或字幕文本。

## English

Compared with **0.9.6**, this release adds cursor-based splitting in the caption editor, an explicit C split mode, continuous segment editing and one project undo transaction. Existing daily changes include bounded Qwen Audio 3.1 sentence repair, chunked VAD, complete translated-name validation and stable glossary search/card layout.

Valid word alignment determines the cut when available. Changed or unaligned text uses an explicitly marked estimate, with opt-in playhead calibration. Full translations are retained once and marked for review when there is no reliable source-to-translation mapping. Physical IME/input latency, original long-project workloads and endurance remain outside the verified scope. Platform-specific verification and signing limits are listed above.
