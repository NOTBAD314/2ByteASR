### 这一版有什么（相对 0.8.1）

这一版来自开发者日常使用的版本，0.8.1 之后三天的改动全部在内：界面和字幕都多了几种语言，加了问题回报、API 用量、预览画质等功能，首次打开改成先推荐云端识别，并修正了一批用户反馈的问题。工程文件、设置、识别结果的格式都没有变，旧工程可以直接打开。

#### 新增

- **界面多了六种语言：西班牙语、德语、法语、葡萄牙语（巴西）、意大利语、俄语。** 顶栏和首次设置的语言选单都能选，切换后立即生效、重启后保持。放不下的地方用了更短的说法。
- **字幕语言多了繁体中文、韩语，以及西、德、法、葡、意、俄六种语言。** 首页「字幕语言与输出」里“中文”分成简体中文和繁体中文：选繁体中文后，识别结果、工作台和所有导出都是繁体字（只转字形，不改地区用词）。新加的语言用 Qwen3-ASR 加 Qwen3 对齐，按单词断句；译文和双语可以翻成中文或互译，例如“韩中双语”。
- **工作台「字幕简繁转换」。** 把选中或全部字幕的中文原文或中文译文转成繁体或简体：先预览，一步撤销，时间不变。日文工程只转其中的中文译文。繁体工程里，词库校对不再把简繁差异当成错字。
- **「回报问题」：遇到问题可以一键整理诊断包。** 打开后先看到以按下回报那一刻为中心的时间轴和你的操作轨迹，最该看的一步标着“从这里开始”，每条问题写了“可以先试”的做法；「导出诊断包…」生成 ZIP。程序平时只记录重要操作，不记录字幕正文、媒体或 API Key；ZIP 不会自动上传，发不发由你决定。入口是工作台上的旗子图标。
- **API 用量与估算费用。** 在线识别、AI 断句、校对、翻译的每次请求都单独记账（记服务商返回的 Token 数或秒数，重试也分开记）。识别时步骤卡显示“本步用量”和“任务累计”；工作台「•••」→「API 用量与费用」和应用设置里可按软件、工程、任务查看。服务商没给用量时写“未知”，不按字数猜。
- **翻译所选字幕，合并时一起更新翻译。** 工作台右键「翻译所选字幕 / 更新所选翻译」（Ctrl+Alt+T）和「合并并更新翻译」。手工改过的译文会保留。
- **字幕前可以显示说话人姓名。** 在「说话人管理」上方勾选，按工程保存；预览、成片和导出的 SRT / ASS / TXT 都带姓名，双语字幕只显示一次。
- **播放预览「原画 / 1/2 画质 / 1/4 画质」。** 在倍速选单旁边，只缩小预览画面，字幕仍然清晰，导出不受影响；对显卡较弱的电脑和多轨画中画有帮助。
- **字幕救援。** 工程因数据冲突打不开时，提示框里有「字幕救援…」：不用播放器、不用重新识别，就能从最后保存的工程导出所有说话人的 SRT，并附逐条核对清单。
- **意外退出后可以找回没确认的编辑。** 正在编辑的文字单独存成草稿，下次打开时可以选择恢复。
- **下载本机模型前先看显卡和显存。** 放不下、会很吃力或没有 NVIDIA 显卡时，先说明情况并建议改用 MOSS Pro 云端；只是提醒，仍然可以下载。
- **字幕时间轴新增 Montreal Forced Aligner（实验，只在 Windows）。** 在模型工坊「字幕时间轴」里安装（运行环境下载约 340 MB、装好约 2.1 GB，中日模型约 270 MB）。中文游戏解说的效果和 Qwen3 对齐差不多；日语里的人名、拟声词常放错位置，所以只是实验选项。

#### 改进

- **首次打开先推荐云端识别，新手教学重写。** “云端识别”（MOSS Pro 云端转写 + FireRedASR2 在本机对准时间；没有 NVIDIA 显卡时改用 Qwen3 对齐）排第一并默认带教学：教学带你申请 MOSS Pro（可跳过）、填写 DeepSeek 的 API Key 并测试连接，说明翻译、AI 断句、AI 校对都要用到它。时间轴模型等教学结束后才下载。「字幕语言与输出」的每个选单上方加了小标题，下面一行写“字幕会显示：……”。
- **工作台工具栏整理。** 「保存 / 撤销 / 重做」在工具面板标题行右侧，快捷键照常；「双语」「字幕简繁转换」在工具栏上，「API 用量与费用」在「•••」里；窗口窄时按钮先收进「•••」，放得下再放回来。
- **时间轴工具列回到一行，播放条对准画面。** 媒体池、新建轨道和转场收进「…」，「添加字幕」只剩 T，波形、缩略图等显示开关改成图标；窗口变窄时逐级收起，不再换成两行；轨道名上方的“+”可以新建轨道。
- **调大界面缩放后，提示文字不再被截掉。**
- **大工程编辑更顺。** 上万条字幕的工程里打字不再每次重新冻结整份数据（本机一万条字幕连续输入，最慢 5% 的按键从约 0.4 秒降到约 0.08 秒）；自动保存少做一轮整理。
- **一千多条字幕批量改样式后不再越改越卡。** 批量「已选」不再给每条字幕各留一份样式副本，旧工程打开时去掉没人用的副本。本机 2000 条工程：之后每次按 Enter 约 0.17 秒（以前 2.8–3.4 秒）；带 2001 份副本的工程 11 秒打开（以前约 25 秒）。
- **打开工程默认暂停。** 停在上次的位置，按播放或空格键才出声。
- **本地模型加载时少占虚拟内存。** MOSS、FireRedASR2、Qwen3-ASR 和日语 CTC 改用只读方式读取权重，页面文件偏小的电脑更不容易报“页面文件太小”（os error 1455）。
- **在线识别和 AI 步骤边做边显示进度。** 云端识别显示上传、排队、识别中；AI 校对和断句每返回一批就显示出来，并写明第几批、重试了几次。
- **准备运行环境时能看到 PyTorch 的下载进度，可以续传。** 速度持续很慢时会边下边试其他来源；下载源选 ModelScope 或 HF 镜像时，运行环境也优先走国内镜像。
- **首次部署更稳。** 专用运行环境由程序登记和保护，坏了可以在模型工坊「重建专用环境」，已校验的模型不重下；MOSS 安装不再临时连 PyPI；下载窗口可以「导出部署诊断」。
- **程序内更新同时问 GitHub 和 GitCode**，哪边先给出签名正确的更新信息就用哪边。这要从 0.8.2 之后的更新起生效（升到 0.8.2 这一次用的仍是旧版自带的更新程序）。
- **英文字幕断句更自然**，不再碎成很多短条；**缺 API Key 时直接打开对应服务的 Key 设置**，出错时分清是缺 Key、Key 无效、余额不足、限流、模型不存在还是网络问题；**日语句首更准**（装了日语 CTC 时）。
- **Windows 随附的 FFmpeg 换成构建材料完整公开的版本。** 改用 BtbN FFmpeg-Builds 的固定构建（FFmpeg 9.0.2），构建仓库快照和 105 个依赖的固定提交随 `ThirdParty-Materials` 附件提供，补上了以前 gyan 版缺的构建材料；编码、字幕烧录和音频提取的结果与以前相同。各依赖库的许可原文仍在整理中（见 `licenses/DISTRIBUTION-STATUS.md`）。

#### 修正

- **日语长视频在最后一步“锁定最终字幕时间轴”失败，报 `Qwen 单条本地修复未覆盖完整原文。`** 视频里有很长的拖音时，拆短太长的字幕可能选进一条走不通的切法，前面的识别、校对、断句全部白做。现在切不开时一律硬切，文字一个不少。重新识别失败过的视频时，音频处理、主力转写和云端校对的缓存都会沿用，不必整部从头跑。
- **日语字幕之间闪一帧空白；「メガネメガネ…」这类重复叠成几条**（MOSS Pro + 日语 CTC）。已有工程要重新识别才有效果。
- **编辑过的字幕导出 SRT 失败或条数不对。** 现在导出后会读回来逐条核对条数、时间、文字和说话人，全部通过才替换旧文件，失败时不会覆盖原来的输出。
- **合并字幕后只剩第一条的译文。** 普通合并现在把所有译文一起合并，撤销、重做、保存和导出都一致。旧版里已经合并并保存的工程，丢掉的译文不会自动找回。
- **打开工程常报“准备超时”。** “发现自动恢复版本”提示停留的时间不再计入，30 秒没有任何进展才算超时。
- **双语工程暂停后、或连续切换工程时，字幕迟迟不出来。**
- **翻译还没完成就切换、关闭或重开工程，结果会写进另一个工程。**
- **关掉全部词库后，仍新生成一大批“缺少术语”提示。**
- **新增字幕后，列表没有停在新字幕上；顶部时间码框挤到旁边的按钮；快速重复点「应用设置」会开出多个窗口。**
- **模型下载重启后报 416 错误；模型位置设成整个磁盘（例如 `E:\`）或文件夹名带 `[ ]` 时下载失败；程序或模型在中文路径下时 Qwen、FireRed 加载失败。**
- **完成页「恢复已有识别结果…」点了没反应；导出时选 AV1 软件编码必定失败；准备运行环境时卡在“另一个程序正在使用此文件”。**

另外，程序源码改为按功能分目录（`twobyteasr/` 下的 app、recognition、studio 等子目录），AI 断句结果的数据核对更严格。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases（或上面的 GitCode 镜像、gh-proxy 链接）下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **长时间编辑偶尔仍会明显卡一下**（一万条字幕边播放边删改时）；2000 条字幕一次改位置仍要 4–5 秒。
- **没填 API Key、用本地规则断句时，语速快又不停顿的地方会切在词中间**；没填 Key 时 AI 设置里的两个 AI 开关仍显示开着，实际用的是本地规则。
- **日语**：用 SenseVoice 识别整集时断句不自然（不会失败，但会退回长段再按 5 秒切）；用 DeepSeek 做 AI 断句时大部分批次会退回本地规则；AI 断句仍偏碎，短条较多。
- **界面翻译还没补齐**：一部分较新的提示在所有非中文界面里显示中文；「回报问题」的新文字在西、德、法、葡、意、俄界面显示英文；六种新语言没有请母语者通读。
- **窗口很窄时**（约 1500 px 以下）工作台顶部按钮会叠在一起。
- **预览画质选 1/2、1/4 时，视频仍按原分辨率解码**，CPU 占用不会下降。

### What is new in this release (compared with 0.8.1)

This release comes from the version the developer uses every day and includes all changes from the three days since 0.8.1: both the interface and subtitles gain several languages; there are new features such as problem reporting, API usage and preview quality; the first launch now recommends cloud recognition first; and a batch of problems reported by users are fixed. Project, settings and recognition-result formats are unchanged, so older projects open as they are.

#### New

- **Six more interface languages: Spanish, German, French, Portuguese (Brazil), Italian and Russian.** You can choose them in the language menus in the top bar and in first-time setup; a switch takes effect at once and is kept after a restart. Where text did not fit, shorter wording is used.
- **Subtitles gain Traditional Chinese, Korean and six more languages: Spanish, German, French, Portuguese, Italian and Russian.** In "Subtitle language and output" on Home, "Chinese" is now split into "Simplified Chinese" and "Traditional Chinese": with Traditional Chinese selected, the recognition result, Studio and every export use Traditional characters (only character forms are converted; region-specific vocabulary is not changed). The new languages use Qwen3-ASR with Qwen3 alignment and break lines by word; translations and bilingual subtitles can go into Chinese or between the languages, for example "Korean + Chinese".
- **"Subtitle Simplified/Traditional conversion" (字幕简繁转换) in Studio.** Converts the Chinese original or the Chinese translation of the selected or all subtitles to Traditional or Simplified characters: you preview first, one step undoes it, and timing does not change. In Japanese projects only the Chinese translation is converted. In Traditional Chinese projects, term-library proofreading no longer treats Simplified/Traditional differences as typos.
- **"Report a Problem": put together a diagnostics package in one click when something goes wrong.** It opens on a timeline centered on the moment you pressed it, together with a trail of what you did; the step most worth looking at is marked "Start here", and each problem lists what you can "Try first"; "Export diagnostics…" creates a ZIP. In normal use the app records only important actions, never subtitle text, media or API keys; the ZIP is not uploaded automatically, and whether to send it is up to you. The entry point is the flag icon in Studio.
- **API usage and estimated cost.** Every request for online recognition, AI line breaking, proofreading and translation is recorded on its own (the token count or seconds returned by the provider; retries are recorded separately too). During recognition, the step card shows "This step" and "Task total"; in Studio under "•••" → "API usage and cost" (API 用量与费用) and in App Settings you can view usage by app, project and task. When a provider returns no usage, it says "Unknown" instead of guessing from the character count.
- **Translate selected subtitles, and update translations when merging.** Right-click in Studio: "Translate selected subtitles / Update selected translations" (翻译所选字幕 / 更新所选翻译, Ctrl+Alt+T) and "Merge and update translation" (合并并更新翻译). Translations you edited by hand are kept.
- **Speaker names can be shown in front of subtitles.** Tick the option above "Speaker Management"; it is saved per project. The preview, the exported video and exported SRT / ASS / TXT all include the names; bilingual subtitles show the name only once.
- **Playback preview "Full / 1/2 res / 1/4 res".** Next to the speed menu; it only shrinks the preview picture, subtitles stay sharp and exports are not affected; it helps on computers with weaker graphics cards and with multi-track picture-in-picture.
- **Subtitle rescue.** When a project cannot be opened because of a data conflict, the message box offers "Subtitle rescue…" (字幕救援…): without the player and without recognizing again, it exports SRT for all speakers from the last saved project, together with a line-by-line checklist.
- **Unconfirmed edits can be recovered after an unexpected exit.** Text you are editing is saved separately as a draft, and the next time you open the project you can choose to restore it.
- **Graphics card and video memory are checked before you download a local model.** When the model will not fit, will struggle, or there is no NVIDIA graphics card, the app explains the situation first and suggests MOSS Pro cloud instead; it is only a reminder, and you can still download.
- **Montreal Forced Aligner added for the subtitle timeline (experimental, Windows only).** Install it under "Subtitle timeline" in Model workshop (runtime download about 340 MB, about 2.1 GB once installed; Chinese and Japanese models about 270 MB). On Chinese game commentary it does about as well as Qwen3 alignment; in Japanese it often misplaces names and onomatopoeia, so it is only an experimental option.

#### Improved

- **The first launch recommends cloud recognition first, and the beginner tutorial was rewritten.** "Cloud recognition" (MOSS Pro cloud transcription + FireRedASR2 aligning the timing on this computer; Qwen3 alignment when there is no NVIDIA graphics card) is listed first and comes with the tutorial by default: the tutorial walks you through applying for MOSS Pro (can be skipped), entering a DeepSeek API key and testing the connection, and explains that translation, AI line breaking and AI proofreading all use it. The timeline model is downloaded only after the tutorial ends. Each menu in "Subtitle language and output" now has a small title above it, and a line below it says "Subtitles will show: …".
- **Studio toolbar tidied up.** "Save / Undo / Redo" sit at the right of the Tools Panel's title row, and the shortcuts work as before; "Bilingual" and "Subtitle Simplified/Traditional conversion" are on the toolbar, and "API usage and cost" is under "•••"; when the window is narrow, buttons move into "•••" first and come back when there is room.
- **The timeline toolbar is back to one row, and the playback controls line up with the picture.** Media Pool, new track and transitions are in "…", "Add Subtitle" is just a T, and display switches such as waveform and thumbnails became icons; as the window narrows, items collapse step by step instead of wrapping onto two rows; the "+" above the track names creates a new track.
- **Tooltips are no longer cut off after you increase the interface zoom.**
- **Smoother editing in large projects.** In projects with tens of thousands of subtitles, typing no longer re-freezes the whole project data each time (typing continuously in a 10,000-subtitle project on the developer's computer, the slowest 5% of keystrokes went from about 0.4 s to about 0.08 s); autosave does one less cleanup pass.
- **Batch style changes on more than a thousand subtitles no longer make editing slower and slower.** Batch "Selected" no longer leaves a separate copy of the style on every subtitle, and unused copies are removed when an older project is opened. On a 2000-subtitle project on the developer's computer: each later Enter takes about 0.17 s (2.8–3.4 s before); a project carrying 2001 copies opens in 11 s (about 25 s before).
- **Projects open paused.** They stop at the last position, and sound starts only when you press Play or the Space bar.
- **Local models use less virtual memory while loading.** MOSS, FireRedASR2, Qwen3-ASR and Japanese CTC now read their weights read-only, so computers with a small page file are less likely to report "The paging file is too small" (os error 1455).
- **Online recognition and AI steps show progress as they go.** Cloud recognition shows uploading, queued and recognizing; AI proofreading and line breaking show each batch as soon as it returns, with the batch number and how many retries it took.
- **While the runtime is being prepared you can see PyTorch's download progress, and the download can resume.** When the speed stays very slow, other sources are tried while the download continues; when the download source is ModelScope or the HF mirror, the runtime also prefers mirrors in mainland China.
- **First-time deployment is more reliable.** The dedicated runtime is registered and protected by the app; if it breaks, use "Rebuild dedicated environment" (重建专用环境) in Model workshop, and models that have already been verified are not downloaded again; installing MOSS no longer connects to PyPI on the fly; the download window can "Export deployment diagnostics" (导出部署诊断).
- **In-app updates now ask both GitHub and GitCode**, and use whichever first returns update information with a valid signature. This takes effect from the updates after 0.8.2 (the update to 0.8.2 itself still uses the updater that comes with the old version).
- **English subtitles break into lines more naturally** instead of falling apart into many short lines; **when an API key is missing, that service's key settings open directly**, and errors tell apart a missing key, an invalid key, insufficient balance, rate limiting, a model that does not exist and network problems; **Japanese sentence starts are more accurate** (with Japanese CTC installed).
- **The FFmpeg bundled on Windows now comes with complete public build materials.** It is a pinned BtbN FFmpeg-Builds build (FFmpeg 9.0.2); the build repository snapshot and the pinned commits of its 105 dependencies are in the `ThirdParty-Materials` attachment, filling the build-material gap of the earlier gyan build. Encoding, subtitle burn-in and audio extraction give the same results as before. Collecting the license texts of every dependency is still in progress (see `licenses/DISTRIBUTION-STATUS.md`).

#### Fixed

- **Long Japanese videos failed at the last step, "Lock the final subtitle timeline", with `Qwen 单条本地修复未覆盖完整原文。`** When a video had very long drawn-out sounds, splitting an over-long subtitle could pick a way of cutting that could not work, and all the recognition, proofreading and line breaking before it was wasted. Now, when a line cannot be split, it is always cut hard, and no text is lost. When you recognize a video that failed before again, the cached audio processing, main transcription and cloud proofreading are reused, so the whole video does not have to run from the beginning.
- **A blank frame flashed between Japanese subtitles; repeats such as 「メガネメガネ…」 piled up into several lines** (MOSS Pro + Japanese CTC). Existing projects need to be recognized again for this to take effect.
- **Exporting SRT from edited subtitles failed or produced the wrong number of lines.** After exporting, the file is now read back and the line count and each line's timing, text and speaker are checked; the old file is replaced only when everything passes, and a failure never overwrites the previous output.
- **After merging subtitles, only the first line's translation was left.** A normal merge now merges all translations too, consistently across undo, redo, saving and export. In projects already merged and saved with an older version, the lost translations are not recovered automatically.
- **Opening a project often reported "preparation timed out".** Time spent on the "Unsaved Recovery Version Found" prompt no longer counts, and a timeout is reported only after 30 seconds without any progress.
- **In bilingual projects, subtitles were slow to appear after pausing or when switching projects one after another.**
- **Switching, closing or reopening a project before translation finished wrote the results into another project.**
- **After turning off all term libraries, a large batch of new "missing term" hints was still generated.**
- **After adding a subtitle, the list did not stay on the new subtitle; the timecode box at the top was squeezed against the button next to it; quickly clicking "App Settings" repeatedly opened several windows.**
- **Model downloads reported error 416 after a restart; downloads failed when the model location was a whole drive (such as `E:\`) or a folder name contained `[ ]`; Qwen and FireRed failed to load when the app or the models were in a path with Chinese characters.**
- **"Recover recognition results…" on the completion page did nothing; exports with AV1 software encoding always failed; preparing the runtime got stuck on "another program is using this file".**

In addition, the app's source code is now organized into folders by function (subfolders such as app, recognition and studio under `twobyteasr/`), and the data checks on AI line-breaking results are stricter.

### Known limitations

- **No code signing.** Windows may show "Unknown publisher"; the Mac app is not notarized. Download only from this repository's Releases (or the GitCode mirror / gh-proxy links above) and check `SHA256SUMS.txt`; you do not need to, and should not, turn off antivirus or system security.
- **Long editing sessions can still hitch noticeably now and then** (when deleting and editing among 10,000 subtitles during playback); moving 2000 subtitles at once still takes 4–5 seconds.
- **Without an API key, local-rule line breaking can cut in the middle of a word where speech is fast and has no pauses**; without a key, the two AI switches in the AI settings still show as on, although local rules are what is actually used.
- **Japanese**: recognizing a whole episode with SenseVoice gives unnatural line breaks (it does not fail, but falls back to long segments cut every 5 seconds); with DeepSeek for AI line breaking, most batches fall back to local rules; AI line breaking is still on the choppy side, with many short lines.
- **Interface translations are not complete yet**: some newer messages show Chinese in every non-Chinese interface; the new text in "Report a Problem" shows English in the Spanish, German, French, Portuguese, Italian and Russian interfaces; the six new languages have not been read through by native speakers.
- **In a very narrow window** (below about 1500 px), the buttons at the top of Studio overlap.
- **With preview quality at 1/2 or 1/4, video is still decoded at full resolution**, so CPU usage does not go down.
- **Simplified/Traditional conversion uses OpenCC** and inherits its mistakes (for example “头发干了”); region-specific vocabulary is not converted.
- **MFA (experimental)**: Japanese accuracy is mediocre; the models are only on Hugging Face (hf-mirror from mainland China), so the download fails when the download source is ModelScope; Windows only.
- **Existing projects do not pick up the new timeline fixes automatically**; recognize them again (the cache is reused).
- **The Mac build is experimental**: the new features in this release were not checked separately on Mac; MFA and the first-time deployment fixes are for Windows only.
- **Claude**: Anthropic's supported regions do not include mainland China, Hong Kong or Macau.
- **The Docker version is still 0.8.1** ([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)); this release does not update the Docker image.
- The other known limitations in the 0.8.1 and 0.8.0 release notes still apply; the third-party licensing item has been updated, see the FFmpeg item above and `licenses/DISTRIBUTION-STATUS.md`.

### このバージョンの新しい点（0.8.1 との比較）

このバージョンは開発者が日常的に使っている版から作ったもので、0.8.1 以降 3 日間の変更をすべて含みます。UI と字幕の対応言語が増え、問題の報告、API 使用量、プレビュー画質などの機能を追加し、初回起動ではまずクラウド認識をおすすめするようにし、ユーザーから報告された一連の問題を修正しました。プロジェクトファイル、設定、認識結果の形式は変わっていないので、古いプロジェクトもそのまま開けます。

#### 新機能

- **UI に 6 言語を追加：スペイン語、ドイツ語、フランス語、ポルトガル語（ブラジル）、イタリア語、ロシア語。** 上部バーと初回設定の言語メニューで選べます。切り替えるとすぐ反映され、再起動後も保たれます。収まらない箇所は短い表現にしました。
- **字幕に繁体字中国語、韓国語と、スペイン語・ドイツ語・フランス語・ポルトガル語・イタリア語・ロシア語の 6 言語を追加。** ホームの「字幕の言語と出力」で「中国語」が「中国語（簡体字）」と「中国語（繁体字）」に分かれました。繁体字を選ぶと、認識結果、字幕スタジオ、すべての書き出しが繁体字になります（字形だけを変換し、地域ごとの用語には置き換えません）。新しい言語は Qwen3-ASR と Qwen3 アライメントを使い、単語単位で区切ります。訳文と二言語字幕は中国語への翻訳や言語間の相互翻訳ができ、例えば「韓中二言語」も作れます。
- **字幕スタジオに「字幕の簡体字・繁体字変換」（字幕简繁转换）。** 選択した字幕またはすべての字幕について、中国語の原文または中国語訳を繁体字か簡体字に変換します。先にプレビューでき、1 回で元に戻せ、タイミングは変わりません。日本語のプロジェクトでは中国語訳だけを変換します。繁体字のプロジェクトでは、用語辞書による校正が簡体字と繁体字の違いを誤字として扱わなくなりました。
- **「問題を報告」：問題が起きたら診断パッケージをワンクリックでまとめられます。** 開くと、報告ボタンを押した瞬間を中心にしたタイムラインと操作の履歴が表示されます。いちばん見るべき手順には「ここから確認」の印が付き、問題ごとに「まず試すこと」が書かれています。「診断を書き出す…」で ZIP を作成します。アプリは普段、重要な操作だけを記録し、字幕の本文、メディア、API キーは記録しません。ZIP は自動でアップロードされず、送るかどうかはあなたが決めます。入口は字幕スタジオの旗のアイコンです。
- **API 使用量と推定料金。** オンライン認識、AI 文分割、校正、翻訳のリクエストを 1 回ずつ記録します（サービスが返したトークン数または秒数を記録し、再試行も別々に記録）。認識中はステップカードに「このステップ」と「タスク累計」を表示します。字幕スタジオの「•••」→「API 使用量と料金」（API 用量与费用）とアプリ設定で、アプリ全体・プロジェクト・タスクごとに確認できます。サービスが使用量を返さないときは「不明」と表示し、文字数から推測しません。
- **選択した字幕を翻訳し、結合と同時に翻訳も更新。** 字幕スタジオの右クリックメニューに「選択した字幕を翻訳／選択した翻訳を更新」（翻译所选字幕 / 更新所选翻译、Ctrl+Alt+T）と「結合して翻訳を更新」（合并并更新翻译）を追加しました。手で直した訳文は保持されます。
- **字幕の前に話者名を表示できます。** 「話者管理」の上でチェックを入れ、プロジェクトごとに保存されます。プレビュー、書き出した動画、書き出した SRT / ASS / TXT のすべてに名前が入り、二言語字幕では 1 回だけ表示します。
- **再生プレビューの「フル画質／1/2 画質／1/4 画質」。** 再生速度メニューの隣にあります。プレビューの映像だけを縮小し、字幕は鮮明なまま、書き出しにも影響しません。グラフィックカードが弱めの PC や、複数トラックのピクチャー・イン・ピクチャーで役立ちます。
- **字幕レスキュー。** データの衝突でプロジェクトを開けないとき、メッセージボックスに「字幕レスキュー…」（字幕救援…）が表示されます。プレーヤーも再認識も使わずに、最後に保存したプロジェクトから全話者の SRT を書き出し、1 件ずつ確認できるチェックリストも付けます。
- **予期しない終了の後でも、確定していない編集を取り戻せます。** 編集中の文字は下書きとして別に保存され、次に開いたときに復元するかどうかを選べます。
- **ローカルモデルをダウンロードする前にグラフィックカードとビデオメモリを確認します。** 収まらない、かなり重くなる、NVIDIA のグラフィックカードがない、という場合は先に状況を説明し、MOSS Pro クラウドへの切り替えを提案します。あくまで注意で、そのままダウンロードもできます。
- **字幕タイムラインに Montreal Forced Aligner を追加（実験的、Windows のみ）。** モデルワークショップの「字幕タイムライン」でインストールします（実行環境のダウンロード約 340 MB、インストール後約 2.1 GB、中国語・日本語モデル約 270 MB）。中国語のゲーム実況では Qwen3 アライメントとほぼ同じ結果です。日本語では人名や擬音語の位置がずれることが多いため、実験的な選択肢にとどめています。

#### 改善

- **初回起動ではまずクラウド認識をおすすめし、はじめてのチュートリアルを書き直しました。** 「クラウド認識」（MOSS Pro クラウドで文字起こし + この PC の FireRedASR2 でタイミング合わせ。NVIDIA のグラフィックカードがない場合は Qwen3 アライメント）がいちばん上に並び、既定でチュートリアル付きです。チュートリアルでは MOSS Pro の申請（スキップ可）、DeepSeek の API キーの入力と接続テストを案内し、翻訳、AI 文分割、AI 校正のすべてでこのキーを使うことを説明します。タイムラインのモデルはチュートリアルが終わってからダウンロードします。「字幕の言語と出力」の各メニューの上に小見出しを付け、その下の行に「字幕の表示：……」と書くようにしました。
- **字幕スタジオのツールバーを整理。** 「保存／元に戻す／やり直す」はツールパネルのタイトル行の右側にあり、ショートカットキーはこれまでどおり使えます。「バイリンガル」と「字幕の簡体字・繁体字変換」はツールバーに、「API 使用量と料金」は「•••」の中にあります。ウィンドウが狭いときはボタンがまず「•••」に入り、収まる幅になれば元に戻ります。
- **タイムラインのツール列が 1 行に戻り、再生コントロールが映像にそろうようになりました。** メディアプール、トラックの新規作成、トランジションは「…」に入り、「字幕を追加」は T だけになり、波形やサムネイルなどの表示切り替えはアイコンになりました。ウィンドウが狭くなると段階的に折りたたみ、2 行にはなりません。トラック名の上の「+」でトラックを新規作成できます。
- **UI の拡大率を上げても、説明の文字が切れなくなりました。**
- **大きなプロジェクトの編集がなめらかに。** 字幕が数万件あるプロジェクトでも、文字を入力するたびにデータ全体を固め直さなくなりました（開発者の PC で 1 万件の字幕に続けて入力したとき、遅いほうから 5% のキー入力が約 0.4 秒から約 0.08 秒に短縮）。自動保存での整理も 1 回減りました。
- **1000 件以上の字幕のスタイルを一括で変えた後、編集がどんどん重くなる問題を解消。** 一括の「選択済み」で字幕ごとにスタイルのコピーを残さなくなり、古いプロジェクトを開いたときに使われていないコピーを削除します。開発者の PC の 2000 件のプロジェクトでは、その後の Enter が毎回約 0.17 秒（以前は 2.8〜3.4 秒）、コピーが 2001 個あるプロジェクトが 11 秒で開きます（以前は約 25 秒）。
- **プロジェクトは一時停止の状態で開きます。** 前回の位置で止まり、再生ボタンかスペースキーを押すまで音は出ません。
- **ローカルモデルの読み込みで使う仮想メモリを減らしました。** MOSS、FireRedASR2、Qwen3-ASR、日本語 CTC は重みを読み取り専用で読み込むようになり、ページングファイルが小さめの PC でも「ページング ファイルが小さすぎます」（os error 1455）が出にくくなりました。
- **オンライン認識と AI の手順で、進捗を処理しながら表示します。** クラウド認識はアップロード中・順番待ち・認識中を表示します。AI 校正と文分割はバッチが返るたびに結果を表示し、何番目のバッチか、何回再試行したかも示します。
- **実行環境の準備中に PyTorch のダウンロード進捗が見え、途中から再開できます。** 速度がずっと遅いときは、ダウンロードを続けながら別の取得元も試します。ダウンロード元に ModelScope か HF ミラーを選んでいる場合は、実行環境も中国国内のミラーを優先します。
- **初回のデプロイがより安定しました。** 専用の実行環境はアプリが登録して保護し、壊れたときはモデルワークショップの「専用環境を再構築」（重建专用环境）で作り直せます。検証済みのモデルは再ダウンロードしません。MOSS のインストールでその場で PyPI に接続しなくなりました。ダウンロードウィンドウから「デプロイ診断を書き出す」（导出部署诊断）ができます。

- **英語字幕の区切りが自然になり**、短い行に細かく分かれなくなりました。**API キーがないときは該当サービスのキー設定を直接開き**、エラー時にはキーがない、キーが無効、残高不足、レート制限、モデルが存在しない、ネットワークの問題のどれかを区別して表示します。**日本語の文頭がより正確になりました**（日本語 CTC をインストールしている場合）。

#### 修正

- **日本語の長い動画が最後の段階「最終字幕タイムラインの確定」で失敗し、`Qwen 单条本地修复未覆盖完整原文。` と表示される問題。** 動画にとても長く伸ばした音があると、長すぎる字幕を短く分けるときにうまくいかない切り方を選ぶことがあり、それまでの認識、校正、文分割がすべて無駄になっていました。分けられないときは必ず強制的に切るようになり、文字は 1 文字も失われません。失敗した動画を認識し直すときは、音声処理、メインの文字起こし、クラウド校正のキャッシュを引き継ぐので、動画全体を最初からやり直す必要はありません。
- **日本語の字幕の間で 1 フレームだけ空白が出る問題、「メガネメガネ…」のような繰り返しが何行にも重なる問題**（MOSS Pro + 日本語 CTC）。既存のプロジェクトは認識し直すと反映されます。
- **編集した字幕を SRT に書き出すと失敗する、または件数が合わない問題。** 書き出した後にファイルを読み戻し、件数と各字幕の時刻、文字、話者を照合して、すべて合格したときだけ古いファイルを置き換えます。失敗しても元の出力は上書きしません。
- **字幕を結合すると最初の字幕の訳文しか残らない問題。** 通常の結合でもすべての訳文をまとめて結合するようになり、元に戻す、やり直す、保存、書き出しのどれでも同じ結果になります。旧バージョンですでに結合して保存したプロジェクトでは、失われた訳文は自動では戻りません。
- **プロジェクトを開くとよく「準備がタイムアウト」と表示される問題。** 「未保存の復元データが見つかりました」の確認が出ている時間は数えなくなり、30 秒間まったく進まないときだけタイムアウトにします。
- **二言語のプロジェクトで、一時停止の後やプロジェクトを続けて切り替えたときに、字幕がなかなか表示されない問題。**
- **翻訳が終わる前にプロジェクトを切り替える、閉じる、開き直すと、結果が別のプロジェクトに書き込まれる問題。**
- **用語辞書をすべてオフにしても、「用語の不足」の通知が大量に作られる問題。**
- **字幕を追加しても一覧が新しい字幕の位置にとどまらない問題、上部のタイムコード欄が隣のボタンに押しつぶされる問題、「アプリ設定」を素早く続けてクリックするとウィンドウが複数開く問題。**
- **モデルのダウンロードが再起動後に 416 エラーになる問題、モデルの保存先をドライブ全体（例 `E:\`）にしたときやフォルダー名に `[ ]` が入っているときにダウンロードが失敗する問題、アプリやモデルが中国語を含むパスにあると Qwen と FireRed の読み込みが失敗する問題。**
- **完了ページの「認識結果を復元…」を押しても反応しない問題、書き出しで AV1 ソフトウェアエンコードを選ぶと必ず失敗する問題、実行環境の準備が「別のプログラムがこのファイルを使用中」で止まる問題。**

このほか、プログラムのソースコードを機能ごとのフォルダーに分けました（`twobyteasr/` の下の app、recognition、studio などのサブフォルダー）。AI 文分割の結果に対するデータの確認も厳しくしました。

#### 새 기능

- **화면 언어 여섯 가지 추가: 스페인어, 독일어, 프랑스어, 포르투갈어(브라질), 이탈리아어, 러시아어.** 위쪽 막대와 처음 설정의 언어 메뉴에서 고를 수 있고, 바꾸면 바로 적용되며 다시 시작해도 유지됩니다. 자리가 모자란 곳은 더 짧은 표현을 썼습니다.
- **자막 언어에 번체 중국어, 한국어와 스페인어·독일어·프랑스어·포르투갈어·이탈리아어·러시아어 여섯 가지 추가.** 홈의 "자막 언어 및 출력"에서 "중국어"가 "중국어(간체)"와 "중국어(번체)"로 나뉘었습니다. 번체를 고르면 인식 결과, 자막 스튜디오, 모든 내보내기가 번체자로 나옵니다(글자 모양만 바꾸고 지역별 어휘는 바꾸지 않음). 새 언어는 Qwen3-ASR과 Qwen3 정렬을 쓰며 단어 단위로 줄을 나눕니다. 번역과 이중 언어 자막은 중국어로 옮기거나 언어끼리 서로 옮길 수 있으며, 예를 들어 "한국어 + 중국어 이중 언어"를 만들 수 있습니다.
- **자막 스튜디오 "자막 간체/번체 변환"(字幕简繁转换).** 선택한 자막이나 모든 자막의 중국어 원문 또는 중국어 번역문을 번체나 간체로 바꿉니다. 먼저 미리 보고, 한 번에 되돌릴 수 있으며, 타이밍은 바뀌지 않습니다. 일본어 프로젝트에서는 그 안의 중국어 번역문만 바꿉니다. 번체 프로젝트에서는 용어집 교정이 간체·번체 차이를 더 이상 오타로 보지 않습니다.
- **"문제 신고": 문제가 생기면 진단 패키지를 한 번에 정리할 수 있습니다.** 열면 신고 버튼을 누른 순간을 가운데에 둔 타임라인과 내가 한 작업의 흔적이 먼저 보이고, 가장 먼저 봐야 할 단계에는 "여기부터 확인"이 표시되며, 문제마다 "먼저 해 볼 것"이 적혀 있습니다. "진단 내보내기…"로 ZIP을 만듭니다. 앱은 평소 중요한 작업만 기록하며 자막 본문, 미디어, API 키는 기록하지 않습니다. ZIP은 자동으로 올라가지 않으며, 보낼지는 직접 정합니다. 입구는 자막 스튜디오의 깃발 아이콘입니다.
- **API 사용량과 예상 비용.** 온라인 인식, AI 줄 나누기, 교정, 번역의 요청을 하나하나 따로 기록합니다(서비스가 돌려준 토큰 수나 초를 기록하고, 재시도도 따로 기록). 인식하는 동안 단계 카드에 "이 단계"와 "작업 누계"가 표시되고, 자막 스튜디오 "•••" → "API 사용량과 비용"(API 用量与费用)과 앱 설정에서 앱 전체, 프로젝트, 작업별로 볼 수 있습니다. 서비스가 사용량을 주지 않으면 "알 수 없음"으로 적고, 글자 수로 추측하지 않습니다.
- **선택한 자막 번역, 병합할 때 번역도 함께 업데이트.** 자막 스튜디오 오른쪽 클릭 메뉴의 "선택한 자막 번역 / 선택한 번역 업데이트"(翻译所选字幕 / 更新所选翻译, Ctrl+Alt+T)와 "병합하고 번역 업데이트"(合并并更新翻译). 직접 고친 번역문은 유지됩니다.
- **자막 앞에 화자 이름을 표시할 수 있습니다.** "화자 관리" 위에서 체크하며 프로젝트별로 저장됩니다. 미리보기, 내보낸 영상, 내보낸 SRT / ASS / TXT 모두에 이름이 들어가며, 이중 언어 자막에서는 한 번만 표시합니다.
- **재생 미리보기 "원본 화질 / 1/2 화질 / 1/4 화질".** 배속 메뉴 옆에 있으며, 미리보기 화면만 줄이고 자막은 그대로 선명하며 내보내기에는 영향이 없습니다. 그래픽카드가 약한 컴퓨터나 여러 트랙의 화면 속 화면에 도움이 됩니다.
- **자막 구출.** 데이터 충돌로 프로젝트가 열리지 않을 때 알림 창에 "자막 구출…"(字幕救援…)이 있습니다. 플레이어 없이, 다시 인식하지 않고도 마지막으로 저장된 프로젝트에서 모든 화자의 SRT를 내보내며, 한 줄씩 확인할 수 있는 점검 목록도 함께 만듭니다.
- **예기치 않게 종료된 뒤에도 확정하지 않은 편집을 되찾을 수 있습니다.** 편집 중인 글자는 따로 초안으로 저장되고, 다음에 열 때 복원할지 고를 수 있습니다.
- **로컬 모델을 내려받기 전에 그래픽카드와 비디오 메모리를 먼저 확인합니다.** 들어가지 않거나 많이 버겁거나 NVIDIA 그래픽카드가 없으면 먼저 상황을 설명하고 MOSS Pro 클라우드로 바꾸도록 권합니다. 알림일 뿐이므로 그래도 내려받을 수 있습니다.
- **자막 타임라인에 Montreal Forced Aligner 추가(실험, Windows만).** 모델 워크숍 "자막 타임라인"에서 설치합니다(실행 환경 내려받기 약 340 MB, 설치 후 약 2.1 GB, 중국어·일본어 모델 약 270 MB). 중국어 게임 해설에서는 Qwen3 정렬과 비슷한 결과를 냅니다. 일본어에서는 사람 이름과 의성어를 엉뚱한 위치에 두는 경우가 많아 실험 옵션으로만 둡니다.

#### 개선

- **처음 열면 클라우드 인식을 먼저 추천하고, 초보자 튜토리얼을 새로 썼습니다.** "클라우드 인식"(MOSS Pro 클라우드 받아쓰기 + 이 컴퓨터의 FireRedASR2로 타이밍 맞추기. NVIDIA 그래픽카드가 없으면 Qwen3 정렬)이 맨 앞에 있고 기본으로 튜토리얼이 함께 나옵니다. 튜토리얼은 MOSS Pro 신청(건너뛸 수 있음), DeepSeek API 키 입력과 연결 테스트를 안내하고, 번역, AI 줄 나누기, AI 교정에 모두 이 키가 쓰인다고 설명합니다. 타임라인 모델은 튜토리얼이 끝난 뒤에야 내려받습니다. "자막 언어 및 출력"의 메뉴마다 위에 작은 제목을 달고, 아래 줄에 "자막에 표시: ……"를 적었습니다.
- **자막 스튜디오 도구 모음 정리.** "저장 / 실행 취소 / 다시 실행"은 도구 패널 제목 줄 오른쪽에 있고 단축키는 그대로입니다. "이중 언어"와 "자막 간체/번체 변환"은 도구 모음에, "API 사용량과 비용"은 "•••" 안에 있습니다. 창이 좁으면 버튼이 먼저 "•••"로 들어가고, 자리가 생기면 다시 나옵니다.
- **타임라인 도구 줄이 다시 한 줄이 되고, 재생 컨트롤이 화면에 맞춰 정렬됩니다.** 미디어 풀, 새 트랙, 전환 효과는 "…" 안으로 들어가고, "자막 추가"는 T 하나만 남았으며, 파형·썸네일 같은 표시 스위치는 아이콘이 되었습니다. 창이 좁아지면 단계적으로 접히며 두 줄로 바뀌지 않습니다. 트랙 이름 위의 "+"로 새 트랙을 만들 수 있습니다.
- **화면 배율을 키워도 설명 글자가 잘리지 않습니다.**
- **큰 프로젝트 편집이 더 부드러워졌습니다.** 자막이 수만 개인 프로젝트에서도 글자를 칠 때마다 전체 데이터를 다시 고정하지 않습니다(개발자 컴퓨터에서 자막 1만 개 프로젝트에 이어서 입력했을 때 가장 느린 5% 키 입력이 약 0.4초에서 약 0.08초로 줄어듦). 자동 저장도 정리 작업을 한 번 덜 합니다.
- **자막 1000개 이상의 스타일을 한꺼번에 바꾼 뒤 편집할수록 느려지던 문제가 없어졌습니다.** 일괄 "선택됨"이 더 이상 자막마다 스타일 사본을 하나씩 남기지 않고, 이전 프로젝트를 열 때 쓰이지 않는 사본을 지웁니다. 개발자 컴퓨터의 자막 2000개 프로젝트에서 그 뒤 Enter를 누를 때마다 약 0.17초(예전에는 2.8~3.4초), 사본이 2001개 있는 프로젝트가 11초 만에 열립니다(예전에는 약 25초).
- **프로젝트를 열면 기본으로 일시 정지 상태입니다.** 지난번 위치에 멈춰 있고, 재생이나 Space 키를 눌러야 소리가 납니다.
- **로컬 모델을 불러올 때 가상 메모리를 덜 씁니다.** MOSS, FireRedASR2, Qwen3-ASR, 일본어 CTC가 가중치를 읽기 전용으로 읽어, 페이징 파일이 작은 컴퓨터에서 "페이징 파일이 너무 작습니다"(os error 1455)가 덜 나옵니다.
- **온라인 인식과 AI 단계가 진행 상황을 처리하면서 바로 보여 줍니다.** 클라우드 인식은 업로드 중, 대기 중, 인식 중을 표시합니다. AI 교정과 줄 나누기는 배치가 돌아올 때마다 결과를 보여 주고, 몇 번째 배치인지, 몇 번 재시도했는지도 적습니다.
- **실행 환경을 준비할 때 PyTorch 다운로드 진행률이 보이고, 이어받을 수 있습니다.** 속도가 계속 아주 느리면 내려받으면서 다른 출처도 시도합니다. 다운로드 출처를 ModelScope나 HF 미러로 고르면 실행 환경도 중국 국내 미러를 먼저 씁니다.
- **처음 배포가 더 안정적입니다.** 전용 실행 환경은 앱이 등록하고 보호하며, 망가지면 모델 워크숍의 "전용 환경 다시 만들기"(重建专用环境)로 다시 만들 수 있고 검증된 모델은 다시 내려받지 않습니다. MOSS를 설치할 때 그 자리에서 PyPI에 접속하지 않습니다. 다운로드 창에서 "배포 진단 내보내기"(导出部署诊断)를 할 수 있습니다.
- **앱 안 업데이트가 GitHub와 GitCode에 함께 묻고**, 서명이 올바른 업데이트 정보를 먼저 준 쪽을 씁니다. 이는 0.8.2 이후의 업데이트부터 적용됩니다(0.8.2로 올리는 이번 업데이트는 여전히 이전 버전에 들어 있는 업데이트 프로그램을 씁니다).
- **영어 자막의 줄 나누기가 더 자연스러워져** 짧은 줄로 잘게 쪼개지지 않습니다. **API 키가 없으면 해당 서비스의 키 설정을 바로 엽니다.** 오류가 나면 키 없음, 잘못된 키, 잔액 부족, 요청 제한, 없는 모델, 네트워크 문제 중 무엇인지 구분합니다. **일본어 문장 시작이 더 정확해졌습니다**(일본어 CTC를 설치한 경우).
- **Windows에 함께 들어 있는 FFmpeg를 빌드 자료가 모두 공개된 판으로 바꿈.** BtbN FFmpeg-Builds의 고정 빌드(FFmpeg 9.0.2)를 쓰고, 빌드 저장소 스냅숏과 의존 라이브러리 105개의 고정 커밋을 `ThirdParty-Materials` 첨부 파일에 넣었습니다. 예전 gyan 판에 없던 빌드 자료를 채운 것입니다. 인코딩, 자막 입히기, 오디오 추출 결과는 예전과 같습니다. 각 의존 라이브러리의 라이선스 원문은 아직 정리 중입니다(`licenses/DISTRIBUTION-STATUS.md` 참고).

#### 수정

- **긴 일본어 영상이 마지막 단계 "최종 자막 타임라인 확정"에서 실패하고 `Qwen 单条本地修复未覆盖完整原文。`가 나오던 문제.** 영상에 아주 길게 끄는 소리가 있으면, 너무 긴 자막을 짧게 나눌 때 통하지 않는 자르는 방법을 고를 수 있었고, 그 전의 인식, 교정, 줄 나누기가 모두 헛수고가 되었습니다. 이제 나눌 수 없으면 무조건 강제로 자르며 글자는 하나도 빠지지 않습니다. 실패했던 영상을 다시 인식하면 오디오 처리, 주 받아쓰기, 클라우드 교정 캐시를 그대로 쓰므로 영상 전체를 처음부터 다시 돌리지 않아도 됩니다.
- **일본어 자막 사이에 한 프레임 동안 빈 화면이 깜박이던 문제, "メガネメガネ…" 같은 반복이 여러 줄로 겹치던 문제**(MOSS Pro + 일본어 CTC). 기존 프로젝트는 다시 인식해야 적용됩니다.
- **편집한 자막을 SRT로 내보내면 실패하거나 줄 수가 맞지 않던 문제.** 이제 내보낸 뒤 파일을 다시 읽어 줄 수와 각 줄의 시간, 글자, 화자를 대조하고, 모두 통과해야 이전 파일을 바꿉니다. 실패하면 원래 출력을 덮어쓰지 않습니다.
- **자막을 병합하면 첫 줄의 번역만 남던 문제.** 일반 병합도 이제 모든 번역을 함께 병합하며, 실행 취소, 다시 실행, 저장, 내보내기 모두 결과가 같습니다. 이전 버전에서 이미 병합해 저장한 프로젝트의 사라진 번역은 자동으로 돌아오지 않습니다.
- **프로젝트를 열면 "준비 시간 초과"가 자주 나던 문제.** "저장되지 않은 자동 복구본을 찾았습니다" 안내가 떠 있는 시간은 더 이상 세지 않고, 30초 동안 아무 진전이 없을 때만 시간 초과로 봅니다.
- **이중 언어 프로젝트에서 일시 정지한 뒤나 프로젝트를 잇달아 바꿀 때 자막이 한참 동안 나오지 않던 문제.**
- **번역이 끝나기 전에 프로젝트를 바꾸거나 닫거나 다시 열면 결과가 다른 프로젝트에 들어가던 문제.**
- **용어집을 모두 꺼도 "용어 누락" 알림이 새로 잔뜩 생기던 문제.**
- **자막을 새로 추가해도 목록이 새 자막에 머물지 않던 문제, 위쪽 타임코드 칸이 옆 버튼에 밀려 찌그러지던 문제, "앱 설정"을 빠르게 여러 번 누르면 창이 여러 개 열리던 문제.**
- **모델 다운로드가 다시 시작한 뒤 416 오류가 나던 문제, 모델 위치를 드라이브 전체(예: `E:\`)로 정하거나 폴더 이름에 `[ ]`가 있으면 다운로드가 실패하던 문제, 앱이나 모델이 중국어가 들어간 경로에 있으면 Qwen과 FireRed를 불러오지 못하던 문제.**
- **완료 페이지의 "기존 인식 결과 복구…"를 눌러도 반응이 없던 문제, 내보낼 때 AV1 소프트웨어 인코딩을 고르면 반드시 실패하던 문제, 실행 환경을 준비하다 "다른 프로그램이 이 파일을 사용 중"에서 멈추던 문제.**

그 밖에 프로그램 소스 코드를 기능별 폴더로 나누었고(`twobyteasr/` 아래의 app, recognition, studio 등 하위 폴더), AI 줄 나누기 결과에 대한 데이터 확인을 더 엄격하게 했습니다.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 "알 수 없는 게시자"가 표시될 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러, gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`를 확인하세요. 백신이나 시스템 보안을 끌 필요도 없고 꺼서도 안 됩니다.
- **오래 편집하면 아직도 가끔 눈에 띄게 한 번씩 멈칫합니다**(자막 1만 개를 재생하면서 지우고 고칠 때). 자막 2000개의 위치를 한 번에 바꾸면 여전히 4~5초가 걸립니다.
- **API 키 없이 로컬 규칙으로 줄을 나누면, 말이 빠르고 쉬지 않는 곳에서 단어 중간이 잘릴 수 있습니다.** 키가 없을 때 AI 설정의 AI 스위치 두 개는 켜진 것으로 보이지만 실제로는 로컬 규칙을 씁니다.
- **일본어**: SenseVoice로 한 회 전체를 인식하면 줄 나누기가 자연스럽지 않습니다(실패하지는 않지만 긴 구간으로 돌아가 5초마다 자름). DeepSeek로 AI 줄 나누기를 하면 대부분의 배치가 로컬 규칙으로 돌아갑니다. AI 줄 나누기는 아직 잘게 나뉘는 편이라 짧은 줄이 많습니다.
- **화면 번역이 아직 다 채워지지 않았습니다**: 일부 새 안내는 중국어가 아닌 모든 화면에서 중국어로 나옵니다. "문제 신고"의 새 문구는 스페인어, 독일어, 프랑스어, 포르투갈어, 이탈리아어, 러시아어 화면에서 영어로 나옵니다. 새 언어 여섯 가지는 원어민 검토를 받지 않았습니다.
- **창이 아주 좁으면**(약 1500 px 미만) 자막 스튜디오 위쪽 버튼이 겹칩니다.
- **미리보기 화질을 1/2, 1/4로 해도 영상은 원래 해상도로 디코딩되므로** CPU 사용량은 줄지 않습니다.
- **간체/번체 변환은 OpenCC를 그대로 쓰므로** OpenCC 자체의 오변환이 있습니다(예: "头发干了"). 지역별 어휘 변환은 하지 않습니다.
- **MFA(실험)**: 일본어 정확도는 보통 수준입니다. 모델은 Hugging Face에만 있어(중국 국내에서는 hf-mirror 경유) 다운로드 출처를 ModelScope로 고르면 실패합니다. Windows만 지원합니다.
- **기존 프로젝트에는 새 타임라인 수정이 자동으로 적용되지 않습니다.** 다시 인식하세요(캐시를 그대로 씀).
- **Mac은 실험판**: 이번 버전의 새 기능은 Mac에서 따로 확인하지 않았습니다. MFA와 처음 배포 관련 수정은 Windows만 대상입니다.
- **Claude**: Anthropic 공식 지원 지역에 중국 본토, 홍콩, 마카오는 없습니다.
- **Docker 버전은 아직 0.8.1입니다**([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)). 이번 버전에서는 Docker 이미지를 업데이트하지 않았습니다.
