# 2ByteASR 0.9.5

2026-11-06，Windows 正式版；相对上一正式版 **0.9.4**。本版以当前已验收的联合日常为基础。macOS 保持 0.9.3。

## 新增

- 导出默认提供自动加速选择：结合字幕路线、完整处理成本和可用资源，选择普通字幕的单路或双路编码；仍可手动选择。高级字幕继续使用专用路线。

## 改进

- 减少长工程中选区、查找、重复装载和字幕证据复制的开销，降低频繁点击、批量编辑和定位时的等待；冷操作和忙碌时的长尾仍存在。
- 高级导出代码随包预构建，分离代码、字幕资产与结果缓存；编辑只失效相关字幕资产，减少首次导出及重复导出的准备工作。
- 改进长视频分段读取、静态字幕帧复用与临时文件释放，降低导出过程的临时磁盘占用。
- 术语词卡更易浏览；填充、描边、背景、阴影与发光的渐变/透明度编辑采用当前日常修订，并核对保存重开后的结果。

## 修正

- 修正失效系统代理影响运行环境部署时的回退处理。
- 修正云字幕处理的预算与思考参数兼容、局部分组失败后的回退及短尾处理。
- 修正首次轨道操作的准备状态和隐藏/全透明字幕仍可能被预览画布点中的问题。
- 修正导出中较晚时间点读取、源文件身份校验、封装恢复、任务临时目录清理及实际字体首帧等待。

## 下载与升级

从 [GitCode](https://gitcode.com/Notbad314/2ByteASR/releases/tag/v0.9.5) 或 [GitHub](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.9.5) 下载 `2ByteASR-Setup-0.9.5.exe`，也可使用程序内更新。覆盖安装即可，保留工程、配置、模型和运行环境。

适用 Windows 10/11 x64；NVIDIA 硬件编码需要可用的驱动与 NVENC，其他设备采用可用路线。首次设置按所选模型下载对应文件；默认模型约 7 GB，启用可选 Qwen 复核约 11.7 GB。云端文字处理由用户选择并配置供应商，需按设置联网；本版未新增付费请求验证。

## 实际验证与限制

本版固定源15个定向测试文件130项及两项Node缓存/字体像素检查通过。最终同一EXE完成两档缩放编辑、保存重开、双语、首次轨道/隐藏命中、术语/颜色和普通自动/显式单路/双路/数值内边距高级样式重复导出共1041项检查；六份成片完整音视频解码通过。Setup全新安装、0.9.4覆盖升级、卸载、四次正常启动及真实本机签名更新通过，检查忙碌/未保存阻止、断线续传与资料保留。2068项公开来源逐字节重现构建输入；351原生库、151标准库及922Tcl输入保持。高级导出预构建不含本机构建路径与调试映射。原始Cyberpunk预设失败另列，不计通过。

既有一小时导出样本使用指定硬件与合成素材，不能代表原用户工程、复杂长4K60或其他机器。严格九分钟目标、六小时连续使用、忙机/冷操作长尾、实体多屏/IME和原生闪退首因仍未关闭。尚未进入日常的 GitHub #11–#15 源码修订不包含在此安装包。程序和安装器无 Authenticode 签名；附件使用 SHA-256 与既有 Ed25519 签名。第三方精确重建及组合权利的既有边界保留，不宣称全部关闭。

云字幕协议的原中转与原事故现场未重新实测，本轮没有新增付费识别请求；定向回归不代表全仓或全量CI通过。

新装验收使用独立测试目录，检查安装器、GUI启动、覆盖和卸载；本轮未重跑干净Windows上的完整模型初始化与完整ASR，也未确认原机`c10.dll / WinError 1114`首因。

本轮发现并保留一项高级预设限制：原始 Cyberpunk HUD 配方的背景 `padding` 为列表，压制归一化目前要求数值，可能出现 `float() ... not 'list'` 并中止导出。正式包的高级导出验收限定显式横/纵数值内边距的样式；原始预设不计通过，也未宣称已修复。

## English

Compared with **0.9.4**:

- **Added:** automatic single/dual-segment selection for ordinary caption exports, with manual choices retained. Advanced captions use their dedicated route.
- **Improved:** prebuilt advanced-export code, targeted cache invalidation, less repeated long-project work and lower export scratch usage. Includes the current daily glossary, color and playback revisions.
- **Fixed:** deployment-proxy fallback, cloud-caption parameters and short-tail handling, initial track controls, hidden-caption hit testing, bounded late seeks, temporary-directory cleanup and first-frame font readiness.

Windows x64 only; Mac remains at 0.9.3. Save work and close the app before installing over the previous version. Final validation and its scope are listed above. Synthetic benchmarks do not establish performance for the original project, complex long 4K60 footage or other hardware. Cold-operation, endurance and native-crash limits remain. Binaries have no Authenticode signature; SHA-256 and the existing Ed25519 signatures are supplied. Source-only GitHub #11–#15 revisions are outside this daily-based release.

Known advanced-preset limitation: the original Cyberpunk HUD recipe uses list-valued background padding, which the current numeric export normalizer rejects. Advanced-export acceptance covers explicit numeric X/Y padding; the unmodified preset remains a disclosed failure.

Installer QA used isolated profiles. Clean-OS model initialization and complete ASR were not rerun; the original machine's DLL-initialization cause remains unresolved.
