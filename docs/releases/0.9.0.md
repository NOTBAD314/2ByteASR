# 兔白字幕 2ByteASR 0.9.0

本版将 2026-10-31 当前日常中的字幕编辑、SRT 导入、双语样式、时间轴及转写保真修订整理为正式安装包。比较基准是上一正式版 **0.8.8**。

## 新增

- **停靠字幕编辑区。** 编辑区位于视频与时间轴之间，输入实时预览；支持候选采纳、Shift+A/D 切换、Shift+S 取消、Shift+P 切换当前草稿人称，Enter 确认保存并关闭。通用 E 默认暂停并优先编辑译文，设置中可调整。
- **SRT 追加或替换导入与分轨。** 保留说话人、源语言和译文层信息，避免导入时 cue 身份冲突；继续导出分层字幕。
- **双语自动排列恢复入口与字体实际字形预览。** 样式管理中可以明确恢复自动排列；字体选框及可见列表呈现真实字形和中文示例。

## 改进

- 大工程编辑按变化字段提交，减少重复字形与几何准备；缩放、剃刀、选区、缩略图和波形更新减少无关工作。
- 原文与译文按各自真实尺寸排列，预设与语言范围更易操作；呼吸动效减少重复渲染。已有手动层坐标继续保留，恢复自动排列支持撤销。
- 校对建议、证据来源、完成页与失败说明更明确；批量替换、试听及语言层编辑衔接改进。0.8.8 已有的阶段重试继续保留。
- 首页工作台入口、识别弹窗圆角与标题布局、时间轴媒体圆角及窗口边缘处理经过修订。

## 修正

- 重叠讲座片段的连续跨度和局部重建保留文字、数字顺序，避免包含和链式重叠使转写内容被错误拼接；转写规则与旧缓存身份同步更新。
- 局部识别的不同说话人标签保持独立，名称、名册和字幕结果一起撤销，避免按旧轨道位置误合并。
- 编辑确认与 Ctrl+S 真正写盘；写入失败保留草稿供重试。修订输入组合、嵌套弹窗、异步旧列表覆盖与工程恢复比较的阻塞。
- 修订隐藏译文、英语/意大利语来源冲突、恢复结果与导出同步等路径；服务端返回错误语言仍可能发生，客户端提示不代表供应商已修复。
- 字体和语言控件间距、预设宽度、快捷说明遮挡及片尾真实区间处理修正。

## 实际验证

此处随最终候选的真实检查回执更新；发布前以本轮完成计划为准。历史日常检查不代替 0.9.0 安装包检查。

## 已知限制

- 偶发原生访问违规仍未定位；本日常原入口曾在缓存反序列化期间出现一次 0xC0000005，同包新隔离副本复验通过。不能保证全部闪退已解决。
- 用户报告的视频整段透明瞬态尚未复现；窗口边缘检查只覆盖实际采样，不覆盖每个显示刷新。
- 冷缓存、大工程全量提交、复杂描边及长时间编辑仍可能停顿，不保证稳定 60 FPS。实体 IME、其他硬件及完整长片耐久未由本轮覆盖。
- macOS 仍为实验版；虚拟机检查不能替代实体 Mac 和声学听审。未执行的云端、Keychain、MLX/MPS 大模型与硬件编码按实际回执列明。
- Windows EXE 无 Authenticode 签名，Mac 无 Apple 公证；提供 SHA-256 和既有发布者 Ed25519 签名，不需要关闭系统安全设置。
