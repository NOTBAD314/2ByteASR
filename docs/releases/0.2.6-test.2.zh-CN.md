# 2ByteASR 0.2.6-test.2 · Windows x64 测试候选版

**审核草稿 · Pre-release · 尚未公开发布**

从语音识别到字幕精修：面向视频创作者、直播切片与游戏内容制作的桌面字幕工作台。

## 相比上次 v0.1.5 展示的主要变化

上次发布围绕识别流水线与字幕文件输出；本次候选安装版已经包含 Studio 工作台，可结合视频、波形和时间轴校对字幕，组织多段素材与说话人字幕轨，调整基础样式并导出。模型工坊展示按角色选择、下载或配置模型的准备流程，术语库集中管理游戏词条和纠错关系。

这些变化依据本包运行界面和同包验收记录整理，不把本地全部开发提交列为已交付。此次打包还处理了安装根日志写入、运行库约束路径空格和 SentencePiece 中文路径三个安装阻断。

## 首次运行

安装后按需选择模型；包内不含模型权重，本地识别首次需联网准备模型与运行库，并预留额外空间。在线 API、云端校对与 AI 断句需要对应账户、API Key 和可能的服务费用；关闭不使用的云端角色。先用短素材验证自己的设备与方案，再处理长视频。

本包未签名，Windows 可能显示来源或信誉提示；核对来源与哈希，不关闭系统保护。
