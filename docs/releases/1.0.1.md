### 有什么变化（相对 1.0.0）

#### 新增

- **首页模型卡片筛选。** 按角色推荐、云端或本机等条件挑选模型，直接查看支持语言和参考分，保留下载与 API 配置入口。
- **三步匹配已有文稿。** 选素材、贴文稿、开始匹配；支持拖入素材和行数提示。

#### 改进

- **模型工坊更好读。** 语言、准确度、速度和操作统一列宽，列表靠近详情；宽屏下同步调整侧栏、模型行与详情的阅读大小。
- **设置更好找。** 圆角导航按问题分组，胶囊控件集中常用选项。
- **切页和筛选更跟手。** 模型卡、状态和记录摘要按需复用，重词库统计移到后台；导航或重新抓取会优先中止旧反馈。
- **更新内容一眼看清。** 彩色亮点标题直接说明本版变化，更新按钮显示实际下载大小。

#### 修正

- **模型工坊缩放后，滚出来的新行列不齐。** 后加载的行现在同步当前比例，语言胶囊、分数和操作保持对齐。
- **大比例下模型卡右侧内容被裁切。** 调整横向边界，支持语言保持单行，完整内容可悬停查看。
- **兔白碰撞反馈拖慢操作。** 缩短并局部处理碰撞反馈，减少切页和操作时的等待。

### 已经装过旧版本

- **Windows 1.0.0**：使用“检查更新”，约 **〔待填：更新大小〕 MB**；也可保存并退出后运行 Setup 覆盖安装。
- **Windows 0.6.5–0.9.8**：使用“检查更新”，按已装组件补齐差异，下载量随起始版本变化。
- **更早的 Windows 版本**：保存工程并退出，运行新 Setup 覆盖安装，不要先卸载。
- **Apple Silicon Mac**：保存工程并退出，将新应用拖入 Applications 覆盖旧应用。
- 工程、设置、词库、模型和运行环境的格式不变，覆盖安装保留已有资料。

### What changed (since 1.0.0)

#### New

- **Filter model cards on Home.** Choose by role, cloud/local execution, language and reference scores, with download and API setup controls.
- **Three-step transcript matching.** Pick media, paste the transcript and start matching, with drag-and-drop and line counts.

#### Improved

- Aligned workshop columns, less wasted space and coordinated reading sizes on wider windows.
- Reorganized settings, reusable model cards and record summaries, background glossary counts and quicker cancellation of old feedback.
- Clearer colored update highlights and the actual download size on the update button.

#### Fixed

- Newly loaded workshop rows losing column alignment after scaling.
- Model-card content clipping at larger scales; supported languages stay on one line with full hover text.
- Bunny collision feedback delaying other interactions.

### Updating

From Windows 1.0.0, use “Check for updates” (about **〔待填：更新大小〕 MB**). From 0.6.5–0.9.8, missing components are added as needed. Older Windows versions can install over the existing copy after quitting. On Mac, quit and replace the app in Applications. Existing projects, settings, glossaries, models and runtimes are preserved.
