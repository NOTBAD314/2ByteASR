### 有什么变化（相对 1.0.1）

#### 新增

- **多语言术语与译文术语管理。** 外语名称可以独立保存或关联原名，AI 生成的名称按语言逐项确认；翻译和译文校对按实际语言方向使用术语。
- **首次使用引导。** 新安装先确认识别方案，再进入教学；未完成教学时下次继续进入，已有用户仍可从原入口手动打开。

#### 改进

- **对照原声校对双语字幕。** 原文和译文共用同一组与原声试听，便于一起检查、决定是否采用建议。
- **术语名称更好读。** 名称优先完整显示，分类按空间换行；窗口变窄时工具栏及时重排。
- **术语 AI 任务更清楚。** 菜单按任务分组，标明当前服务能否联网；查名称可先试做 20 条，再选择处理范围。
- **工坊遵循你的显示比例。** 100%、120%、150% 跟随所选比例，宽窗口不再额外放大列表。

#### 修正

- **校对出现纯标点修改或无依据扩写。** 默认审核聚焦内容问题，字数、行数和拆条不再单独形成校对建议，历史决定保留。
- **字幕时间戳选到了不支持对齐的模型。** 时间戳仅列出能在本机执行的时间戳或对齐模型，主力转写仍可使用云端。
- **校对窗口的主题与窄窗操作受影响。** 恢复控件样式和窄窗口下的操作入口。
- **Mac 的重点文字偏细。** 标题和主按钮使用随包粗体，重点更清楚。

### 已经装过旧版本

- **Windows 1.0.1**：使用“检查更新”，约 **117 MB**；也可保存并退出后运行 Setup 覆盖安装。
- **Windows 0.6.5–1.0.0**：使用“检查更新”，按已装组件补齐差异，下载量随起始版本变化。
- **更早的 Windows 版本**：保存工程并退出，运行新 Setup 覆盖安装，不要先卸载。
- **Apple Silicon Mac**：保存工程并退出，将新应用拖入 Applications 覆盖旧应用。
- 覆盖安装保留工程、设置、词库、模型和运行环境；已完成的字幕仍需主动检查并采用术语或校对建议。

### What changed (since 1.0.1)

#### New

- **Multilingual terms and translation terminology.** Store foreign names independently or link them to the original; review AI suggestions separately for each language and use terms for the selected translation direction.
- **First-run guidance.** Confirm a recognition setup before the tutorial; unfinished tutorials reopen next time, while existing users keep their manual entry.

#### Improved

- Original and translated subtitles share a proofing group and original-audio preview.
- More room for term names, wrapping categories and responsive glossary controls.
- Clearer AI task menus show web-search capability; try name lookup on 20 terms before choosing a larger scope.
- Workshop scaling follows your selected display size without extra enlargement on wide windows.

#### Fixed

- Default proofing proposing punctuation-only edits or unsupported expansions, with length and line splitting removed from content review.
- Ineligible models appearing in timestamp selection; timestamp and alignment models must run locally, while main transcription can remain cloud-based.
- Proofing controls losing theme styling or becoming difficult to reach in narrow windows.
- Emphasized text appearing too light on Mac; headings and primary controls now use the bundled heavy face.

### Updating

From Windows 1.0.1, use “Check for updates” (about **117 MB**). From 0.6.5–1.0.0, missing components are added as needed. Older Windows versions can install over the existing copy after quitting. On Mac, quit and replace the app in Applications. Projects, settings, glossaries, models and runtimes are preserved. Apply term and proofing suggestions explicitly to existing subtitles.
