# 兔白字幕 2ByteASR 0.9.3

本版新增左侧源素材预览和有方向的翻译术语库，改善长工程绘制、校对往返与外观取色。比较基准为上一正式版 **0.9.2**。

## 新增

- **媒体池与独立源预览。** 缩略图／列表查看素材，在左侧源预览播放、定位、选择音频流和设置入出点；选段可按音视频、仅视频或仅音频模式明确加入目标轨道，并一步撤销。
- **有方向的翻译／译文术语库。** 原文校对库与翻译库分别选择；翻译映射带明确源语言与目标语言，可导入、导出并随工程保存，进入真实翻译请求和译名检查。手工译文、异步迟到结果及撤销边界继续保持。
- **可定位的导出问题列表。** 发现空原文时可定位、检查原稿、编辑、逐条恢复或确认有意留空，再重新检查。
- **识别中断记录与检查点恢复。** 任务从开始即记录，保留已有转写与阶段结果，减少中断后重复处理；识别执行隔离与中文分片流水随本版纳入。

## 改进

- **真实长工程交互。** 校对页仅排版可见行，复用有界文本缓存，减少范围切换、审核摘要和页面返回的重复工作；波形准备移出绘制路径，密集原译字幕块批量绘制。文字、双语、缩略图、波形和动效仍保留。
- **词库卡片与术语输入。** 一个规范词显示多个听错写法；六列、约四行随视口分配，文字与卡片同步放大，长内容省略但可完整悬浮查看，搜索、筛选、多选与编辑保持。
- **统一外观取色。** 填充、两层描边、背景、阴影和发光使用同一调色体系；填充支持纯色与线性／径向渐变，其余入口按实际渲染能力提供纯色。改进方形色区居中、透明度、取消、单步撤销、保存及预览样例。
- 保留原日常已经完成的长工程分阶段加载、缓存重开、AI校对采用／局部撤回与批量替换修订。

## 修正

- 外部文件拖入媒体池只新增资产，避免误建轨道或延长工程；只有明确加入或拖到时间轴才插入一次。
- 源素材与工程预览分别保持播放意图，修订互相隐式暂停、迟到启动回执和旧输出窗口回收；源播放器退出后可重新建立。
- 修订校对返回时时间轴尺度随隐藏期间布局变化而放大，保留当前工程与代次的视口。
- 修订取色模态会话提前取消、第二层描边关闭时的空色值、阴影独立透明度及局部样式遮蔽；描边样例保留颜色对象和alpha，透明发光不强制绘制。
- 修订校对提交失败仍显示成功、建议局部撤回丢失、非文本变更使替换预览失效和工程恢复弹窗交互等问题。

## 已知限制

- 冷绘制约202ms、首次校对约799ms、定位约620ms仍有长尾；定位总耗时在配对中未整体提速，没有证明所有输入≤100ms、全程60fps或每次额外字幕延迟≤200ms。目标帧／叠层采用回执与物理首像素时延分别看待。
- 原生0xC0000005首因仍未确定，成功退出的后续轮次不能证明已根治。原十四分钟第二素材未找到，源矩阵使用合成素材；实体OLE/IME、多屏混合DPI、其他硬件/Mac及长时间耐久未新增证明。
- 日常原入口第一次复验出现一次分栏高度差异，时间轴跨度／播放头／视频尺度保持；同包独立五轮校对25项及完整63项复跑通过，失败轮保留，不宣称布局长期无波动。
- 强发光／大量动效仍可能耗时；识别和翻译质量依赖所选服务。本轮不新增付费整段识别，云端失败、回退和人工听审的既有边界保留。
- Windows程序／安装器无Authenticode签名；提供SHA-256与既有发布者Ed25519签名。
