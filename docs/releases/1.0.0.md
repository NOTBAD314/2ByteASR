# 兔白字幕 2ByteASR 1.0.0

2026-11-12。本版相对正式版 **0.9.8**，整合最新日常的字幕编辑、双语保护、说话人管理、定位导航、教学和诊断修订，提供 Windows 与 Apple Silicon Mac 安装包。Mac 上一正式版为 0.9.7，本次同时接入 0.9.8 的字幕固定避让、中文完整表达、整工程审核与独立字幕导出工作进程。

## 新增

- 说话人管理提供分区面板，可拖放换组、合并角色和整组确认，保留原详情操作。
- 工作台增加“当前字幕”定位胶囊及起止按钮，选中定位并居中，默认 Alt+J 在字幕起止间往返。
- 教学加入兔白向导、声音及主动气泡，保留原版教学动画和减少动态选项。

## 改进

- 更新模型工坊、识别记录、更新窗口、完成页、字幕列表及外观面板，术语和翻译操作的内容与状态更清晰。
- 编辑浮窗即时预览草稿，改进首次关联切割、字幕建议和原文/译文编辑目标。
- 日语工程采用 15 秒选中定位窗口，改善角色显隐与空词库时的原译校对，保护校对来源和版本。
- 合格 AI 断句边界优先保留，异常范围局部修复或回退；降低审核重复提示，保留待试听证据。
- 分批加载工程和图片缓存，统一界面样式继承，恢复原教学 WebP 动画的选择与释放。

## 修正

- 修正短字幕交接时的初始位置、主稿与双语内容误删、来源字符映射及独立轨道导出问题。
- 修正旧投影删除和跨说话人候选失效、首次切割归属，以及原译显隐与编辑目标不一致。
- 修正说话人胶囊因字幕数量长度不同导致的列错位，清理列表状态与悬停说明。
- 修正主页诊断导出的参数准备、可选记录及失败反馈，默认保存到已有用户目录；支持缺少记录时导出带缺失原因的诊断包。
- Mac 接入原生入口的字幕导出工作进程分派与管道恢复。

## 下载与升级

Windows 使用 `2ByteASR-Setup-1.0.0.exe`，保存工程并退出后覆盖安装，或通过程序内更新。支持 Windows 10 1809 及以上 64 位。

Apple Silicon Mac 使用 `2ByteASR-1.0.0-macos-arm64-Setup.dmg`，退出应用后将 `2ByteASR.app` 拖入 Applications 覆盖安装。系统支持与本版实测范围随原生验收结果记录。

本地识别需按所选路线下载固定模型和运行环境；默认本地路线约 7 GB，加入可选 Qwen 复核约 11.7 GB，以模型工坊实际选择为准。云端路线向用户配置的提供商提交音频或字幕文本。

## 实际验证与限制

本节将在最终固定安装包验收后填入实际结果；当前为未发布草稿。

现有原音听审、日语人工准确率、真实新云端质量、实体输入法、多屏 DPI、其它硬件和长期耐久未新增保证。大工程冷加载、保存与部分交互仍有长帧。版本号 1.0.0 不改变这些验证边界。Windows 无 Authenticode 签名；Mac 使用 ad-hoc 签名，未完成 Apple 公证。提供 SHA-256、Ed25519 签名、对应源码和第三方材料；精确重建与组合权利的既有边界见许可材料。
