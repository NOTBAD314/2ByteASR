### 有什么变化（相对 0.9.8）

#### 新增

- **兔白陪你学。** 教学加入兔白向导、可关闭的动物语音和知识气泡；可以抓起兔白抛出，让它在窗口内反弹。
- **当前字幕胶囊与快捷定位。** 选中字幕后可直接定位、居中和使用合并/删除操作；起止图标与 **Alt+J** 可在字幕两端往返，快捷键可修改。
- **说话人拖拽分区。** 主要角色、次要角色、游戏声和已忽略四个区，支持拖放换组、合并角色和整组确认，原详情操作保留。

#### 改进

- **常用窗口更好找。** 模型工坊、识别记录、完成页、翻译、更新和外观窗口重新整理，范围和处理状态更清楚。
- **编辑时立即看见草稿。** 编辑浮窗、Shift+P 和“他 / 她”操作及时更新预览；原文和译文按实际选中目标编辑。
- **日语工程定位更集中。** 选中字幕使用 15 秒定位窗口，完善角色显隐、空词库校对和校对来源保护。
- **字幕断句和审核更稳。** 保留合格 AI 边界，异常区间局部修复或回退；减少重复提示，保留待试听证据。
- **加载和教学更连贯。** 分批加载工程、缓存图片，恢复原版教学动画；选择游戏后关联术语库，手动关闭后不反复打开。

#### 修正

- **短字幕交接时先跳一下、主稿或双语字幕被误删。** 修订交接位置、来源字符映射和独立轨道导出。
- **原文和译文显隐、按 E 打开的语言不一致。** 同时修订旧投影删除、跨说话人建议和首次切割归属。
- **说话人字幕数一长，后面的胶囊就错位。** 改为等宽列，并清理列表状态和悬停浮窗。
- **“回报问题”导出失败没有明确反馈。** 现在会说明缺少的记录或失败原因，可重试，默认保存到已有用户目录。
- **Mac 冷启动导出字幕一直等待。** 修订原生导出工作进程与较大请求的管道传输，保留取消操作。

Mac 上一正式版为 **0.9.7**；这次还接入 0.9.8 的固定字幕避让、中文完整表达、整工程审核和独立字幕导出工作进程。

### 已经装过旧版本

- **Windows 0.9.8**：使用“检查更新”，约 **407 MB**；也可退出程序后运行 Setup 覆盖安装。
- **Windows 0.6.5–0.9.7**：同样使用“检查更新”，会按已装组件补齐差异；下载量因起始版本而异。
- **Windows 0.6.0 及更早**：保存工程并关闭程序，直接运行 1.0.0 Setup 覆盖安装，**不要先卸载**。
- **Apple Silicon Mac**：保存工程并退出，将新应用拖入 Applications 覆盖旧应用；本次没有验证旧版 Mac 实际覆盖过程。
- 工程、设置、词库、模型和运行环境的格式不变。Windows 更新支持续传；保存并同意后才替换，失败时恢复原版本。

本轮验证了 Windows 新装、真实 0.9.8 签名升级和字幕/视频导出，以及同一 Mac DMG 在 macOS 15.8.2 / 26.7.2 的安装、编辑和导出。[实际检查记录](https://github.com/NOTBAD314/2ByteASR/releases/download/v1.0.0/README.zh-CN.md)保留未通过的旧断言；[已知问题](https://github.com/NOTBAD314/2ByteASR/blob/v1.0.0/docs/releases/1.0.0-known-issues.md)包括译文按旧词筛选时可能移出列表，以及 Mac 过长自定义临时目录可能导致启动失败。原音准确率、实体输入法、多屏、其它硬件和长期耐久没有新增保证；Windows 未作 Authenticode 签名，Mac 未作 Apple 公证，macOS 14 仅完成静态兼容核对。

### What changed (since 0.9.8)

#### New

- **Learn with Tubai.** Bunny-guided tutorials, optional animal voice and tips; grab and fling the bunny around the window.
- **Current-caption controls.** Locate, centre, merge and delete the selected caption; endpoint icons and rebindable **Alt+J** navigate its boundaries.
- **Grouped speaker management.** Drag between four zones, merge speakers and confirm whole groups while keeping the existing detail controls.

#### Improved

- Clearer model workshop, history, completion, translation, update and appearance windows; live editing drafts and explicit original/translation targets.
- Focused Japanese navigation, bilingual source protection, AI boundary handling, caption handoffs and review feedback.
- Staged project loading, image caching, original tutorial animations and automatic game-glossary association.

#### Fixed

- Jumping short-caption handoffs, lost original/bilingual content, projection deletion, cross-speaker suggestions and first-cut ownership.
- Language visibility and E-key target mismatches, uneven speaker-pill columns and unclear diagnostic-export failures.
- Cold Mac subtitle exports hanging on larger requests; cancellation remains available.

Mac users also receive the changes deferred from 0.9.8; their previous formal build was 0.9.7.

### Updating

From Windows 0.9.8, use “Check for updates” (about **407 MB**). From 0.6.5–0.9.7, missing components are added as needed. From older versions, close the app and install over it without uninstalling. On Mac, quit and replace the app in Applications; an actual old-Mac overlay was not tested. Project and settings formats remain unchanged.

Validated Windows installation, an actual signed 0.9.8 update and subtitle/video exports; the same Mac DMG passed installation, editing and export on macOS 15.8.2 / 26.7.2. [Validation scope](https://github.com/NOTBAD314/2ByteASR/releases/download/v1.0.0/README.zh-CN.md) retains existing failed assertions; [known issues](https://github.com/NOTBAD314/2ByteASR/blob/v1.0.0/docs/releases/1.0.0-known-issues.md) include an edited translation disappearing from an old-word search and Mac startup failing with an excessively long custom temporary path. Original-audio accuracy, physical IMEs, multiple displays, other hardware and endurance remain unverified. Windows is not Authenticode-signed; Mac is not notarized, and macOS 14 compatibility was checked statically only.
