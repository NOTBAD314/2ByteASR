### 有什么变化（相对 1.0.2）

#### 新增

- **问问兔白。** 用自然语言查找功能、了解工程和检查字幕，也能修改原文/译文、安排步骤或保存操作配方；修改按权限确认，可查看记录并撤销。
- **多轨调音台与工程响度。** 各轨用竖推子共同试听，一次应用或整体撤销；测量响度后选择目标，一键匹配。
- **任务详情与 API 用量日历。** 对照原文、模型分段和实际写回结果；按日期、任务、步骤或问题筛选请求与估算费用。
- **Qwen3 对齐 · Ultra。** 在支持的平台与运行环境中选择本地对齐方式，安装、环境、验证和当前选择分别显示。

#### 改进

- **直接拖动画面里的字幕。** 按住可见字幕暂停、选中并移动，支持原文与译文图层、撤销和取消。
- **候选校对与批量视频更顺手。** Shift+F 选择，Shift+A/D 切换，Shift+E 采纳，Shift+S 回正文；已完成视频可先校对，其余继续后台处理。
- **动效时长可以拖动调整。** 按入场、停留/循环、出场排列，拖动把手改时长，一步撤销；短窗口可滚动查看效果。
- **兔白的引导与隐私设置更完整。** 支持工程内聊天、口述断句偏好与小范围试跑；读取、记忆、聊天保存和操作权限可分别管理。
- **保存和恢复选择更清楚。** 保存、不保存、取消并列显示，恢复卡显示日期时间；默认打开较新的自动恢复，也可改为每次询问。

#### 修正

- **启动或切换模型时出现空白窗、重复卡片与状态不一致。** 整组加载模型，统一工坊与首页选择，已有验证记录可复用。
- **批量视频收尾覆盖已经人工校对的内容。** 已交付工程不再整批重存，保留人工改字、改时、切割和删除。
- **视频链接重复解析或下载。** 合并相同请求，取消后可以重试。
- **兔白清空聊天、关闭读取或切换工程后仍带入旧内容。** 按工程隔离记录，关闭相应权限后遵守新的读取与保存范围。

### 已经装过旧版本

- **Windows 1.0.2**：使用“检查更新”，约 **267 MB**；也可保存并退出后运行 Setup 覆盖安装。
- **Windows 0.6.5–1.0.1**：使用“检查更新”，按已装组件补齐差异，下载量随起始版本变化。
- **更早的 Windows 版本**：保存工程并退出，运行新 Setup 覆盖安装，不要先卸载。
- **Apple Silicon Mac**：保存工程并退出，将新应用拖入 Applications 覆盖旧应用。
- 覆盖安装保留工程、设置、词库、模型和运行环境；AI 建议仍需按所选权限确认和采用。

### What changed (since 1.0.2)

#### New

- **Ask Bunny.** Find features, inspect your project and subtitles, edit original or translated text, and save action recipes. Changes follow your permissions and support an operation log and undo.
- **Track mixer and project loudness.** Preview multiple track faders together and match measured loudness to a selected target.
- **Task details and API usage calendar.** Compare source text, model segments and written results; filter requests and estimated costs by date, task, step or question.
- **Qwen3 alignment · Ultra.** Select local alignment on supported platforms, with separate installation, environment, validation and selection states.

#### Improved

- Hold visible captions to pause, select and drag them, including translated layers.
- Use Shift+F/A/D/E/S for subtitle candidates; proof completed videos while the rest of the batch continues.
- Drag entrance, hold/loop and exit durations with one-step undo.
- Project-specific Bunny chats, spoken segmentation preferences, small trial runs and separate privacy controls.
- Clear Save / Don’t save / Cancel choices and dated recovery cards.

#### Fixed

- Blank windows, duplicate model cards and inconsistent selection or readiness during startup and model switching.
- Batch completion overwriting manual text, timing, splits or deletions in already delivered projects.
- Duplicate link parsing or downloads, with retry available after cancellation.
- Old chat content crossing project boundaries or surviving cleared chats and disabled reading permissions.

### Updating

From Windows 1.0.2, use “Check for updates” (about **267 MB**). From 0.6.5–1.0.1, missing components are added as needed. Older Windows versions can install over the existing copy after quitting. On Mac, quit and replace the app in Applications. Projects, settings, glossaries, models and runtimes are preserved.
