### 有什么变化（相对 1.1.2）

#### 新增

- **从字幕编辑直接查找和替换。** 选中文字后按 Ctrl+F 或 Ctrl+H，打开批量替换并自动带入选中文字。

#### 改进

- **打开工程时界面更容易保持响应。** 切片规则在后台准备，减少隐藏页排版、时间轴重画和界面线程的写入工作。
- **Windows 启动和切页更平滑。** 可先显示上次的首页画面，首页就绪后再淡出。侧栏切页和设置对话框的转场也更连贯。
- **部分字幕和分层影片导出更省时。** 只有入场和退场的字幕可以复用停留帧。部分画中画、色键和混合图层减少中间步骤。
- **兔白读长句时更轻快。** 减少偏低、下滑的音节，聊天窗口在多句回复和跟随主窗口时更稳定。
- **新手教学更容易接着学。** 按学习路径排列章节，并标出建议的下一章。

#### 修正

- **线上识别提前结束会遗漏后半段。** 现在会在具备条件时尝试补齐，并标出仍疑似漏识别的区间。
- **切换工程时，加载遮罩挡住「储存工程修改」。** 弹窗现在可点击，切换会等储存结束。
- **校对后跳离原字幕行。** 局部采纳后先留在原行，方便接着核对。

### 已经装过旧版本

- **Windows 1.1.2** 可在程序内「检查更新」，约 **119 MB**，也可保存并退出后运行 Setup 覆盖安装。
- **Windows 0.6.5–1.1.1** 可在程序内更新，下载量取决于已安装的组件。
- **更早的 Windows 版本** 可在保存并退出后直接运行 Setup 覆盖安装。
- 覆盖安装会保留工程、设置、词库、模型和运行环境。

### What changed since 1.1.2

#### New

- **Find and replace from the subtitle editor.** Carry selected text into batch replace with Ctrl+F or Ctrl+H.

#### Improved

- **Smoother project opening and navigation.** Project preparation does less work on the interface thread. On Windows, startup can show the last Home screen while the app loads.
- **Faster exports in supported cases.** Entrance and exit animations can reuse held frames, and some layered exports skip intermediate work.
- **Brighter Bunny voice and a clearer tutorial path.** Long replies use fewer low, falling syllables, and tutorials suggest which chapter to take next.

#### Fixed

- Interrupted online recognition can recover missing text when possible and flag suspected gaps.
- The save prompt remains clickable while switching projects. Applying a proofreading suggestion keeps the current subtitle row in view.

### Upgrading

- **Windows 1.1.2** can use Check for updates (about **119 MB**) or run Setup over the existing installation.
- **Windows 0.6.5–1.1.1** downloads only the components that need updating. Earlier versions can use Setup.
- Overlay installation keeps projects, settings, glossaries, models, and runtimes.
