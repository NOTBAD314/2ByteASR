### 这一版有什么（相对 0.8.4）

这一版来自开发者日常使用的版本，0.8.4 之后一天的改动全部在内：字幕工作台能只重新识别一段、普通字幕有了局部格式和原文 / 译文分开的样式、素材可以先预览再把画面和声音分开拖进轨道；术语库能写符号、能删自带词库；新手教学重做；还修了用户回报的两种 MOSS Pro 整个识别失败。设置和识别结果的格式没有变，旧工程可以直接打开；**用了局部格式或分层样式的工程，0.8.4 及更早的版本打开看不到这些格式**（见“已知限制”）。Mac 版的最低系统从 macOS 15 改为 **macOS 14**。

#### 新增

- **只重新识别一段字幕。** 某一段识别错了不用整集重跑：在字幕工作台用 I / O 设好入点、出点，在时间轴上右键「只重新识别这一段字幕…」。它打开平常的「识别字幕」窗口（同一套方案、模型、词库），只识别入点到出点这一段并换掉这一段的字幕；段外的字幕、样式、剪辑和说话人轨都不动，一次替换是一步撤销。入点或出点落在某条字幕中间时整条一起重新识别，窗口里写明实际范围；这一段有你手改过的字幕时开始前先问，识别途中又改了再问一次。不能用时选项后面写原因（没设入出点、不到 1 秒、正在识别、多音轨素材、字幕轨锁住）。
- **普通字幕局部格式。** 字幕编辑框上方可选「纯文字 / Markdown」：`**粗体**`、`*斜体*`、`==重点==`、换行与局部颜色。只是显示格式，字幕正文和字级时间不变；原文、译文各有自己的局部格式。
- **原文 / 译文 / 整组分开设样式。** 样式面板可选「原文 / 译文 / 整组」，译文可以有自己的字号、颜色；双语的位置与对齐选「整组」再调。样式「应用到」默认改为「已选」：只改选中的字幕，可以不连续多选（例如第 2、第 5 条），改一项（例如字号）只改那一项，一次拖动一步撤销。拆分字幕时译文按词界估分并标「待核对」，合回去恢复原句译文与格式。
- **工作台双击素材先预览，画面和声音分开拖。** 在「素材」页的媒体池双击文件，左侧字幕列表的位置换成它的预览（可以播放、拖进度，工程自动暂停；「返回字幕列表」回去）。预览下面「视频+音频 / 仅视频 / 仅音频」拖到时间线轨道上，拖动时显示会落在哪一条、哪一段，点一下就加到播放头；媒体池的行也能直接拖，右键可以只加视频或只加音频。时间线上的视频片段右键「分离音频」，画面和声音成为两个片段，可以各自移动、删除。每次放下、分离都是一步撤销，工程文件格式没变。
- **术语可以写符号，自带词库可以删除。** 以前保存术语时会悄悄删掉 `《》（）·：` 等符号（`漂泊者·男` 存成 `漂泊者男`、`Re:Zero` 存成 `ReZero`），现在照你写的保存，识别出的字幕里也保留（字幕里的 `漂泊者男` 会改回 `漂泊者·男`；符号在两端的只按你填的“听错的写法”替换）。原神、明日方舟这些软件自带的词库在「⋯」或列表右键「删除词库…」：不再出现、不再用于识别，自带的内容不会被改，「新建」→「恢复自带词库」放回。
- **词库视觉强调与说话人姓名模板。** 词库里的词可以另开「强调」，只改字幕外观、不做替换；说话人姓名由模板读取，改名立即更新，不写进字幕正文。审核模式下 W / A 到下一条、S / D 到上一条（在输入框里打字不受影响）。
- **每次打开软件检查更新并提醒。** 打开约 5 秒后检查一次（10 分钟内重开用上次的结果），有新版本自动弹出「发现新版本」窗口；正在识别、开着别的窗口或在看新手教学时先不弹，同一次打开只弹一次。弹窗里或「应用设置 → 关于」取消「打开软件时自动检查并提醒」就不再弹（照旧每天在后台检查一次，只在按钮上标出新版本）。
- **MAI-Transcribe 2 能配置了。** 模型工坊的 MAI 卡改为 MAI-Transcribe 2（OpenRouter · `microsoft/mai-transcribe-2`，约 $0.10 / 小时，字级时间、说话人），点「配置」贴上 OpenRouter Key 就能用；转写风格和词库专名真正传给 MAI（不给词库时「鸣潮、今汐、长离」写成「明朝、金犀」，给了全对）。「申请与设置 API」里 Qwen 那一项可选中国站「千问AI平台」或国际站「Qwen Cloud」，简体中文界面默认中国站。

#### 改进

- **新手教学改版。** 第一步就选「云端识别 / 本地识别」和视频主要语言，按语言推荐模型与时间戳（中文 FireRedASR2，其他语言 Qwen3 对齐）；教学框淡入不再在四角闪方块；放入示范视频后等首页停稳再出下一步；进工作台后教 C 裁剪、B 合并工具、Shift+Q / Shift+W 波纹合并、T 新建字幕轨。
- **「应用设置」点开就能用。** 以前每次都把八个分类全部建好，约 1.8 秒后才能操作；现在只建当前分类，其他分类第一次点到才建（改过的值都保留），没改过的窗口下次直接复用：1 小时工程上打开到可用约 1.8 秒 → 约 0.08 秒。
- **第一次进工作台更快，回主页保留工程。** 第一次进工作台分步建立，先显示「正在创建工作台界面…」，可以随时返回主页；回主页时工作台暂停，工程、撤销、选取和播放位置都保留，再进去直接接着用。进工作台不再闪出小窗口；快捷键键帽 Ctrl+Shift+S 不再被截断。
- **横向拖动工作区分隔条时视频保持比例**，不再被压扁；拖动时少做重复的重绘。
- **剪辑建议（弹幕分析）**：每条建议有可查的字幕 / 弹幕依据，卡片、范围预览、手动起止和待生成清单用同一个范围；删掉旧录播后用实际保留的来源；浏览视频不再跳工具页，重新打开工程时工具页回到原来那页。
- **术语库「智能建词」接上 DeepSeek 后 AI 增强能用了**：以前 DeepSeek 先思考把额度用光、返回空内容，界面却说「API 密钥无效」；现在走和 AI 断句相同的通道，出错时按真实原因写（密钥 / 余额 / 太频繁 / 连不上），贴进来的表格按列读标准词、分类和别名。
- 首页「识别方案」菜单在模型还在下载时也写出选好的方案；工作台新面板的文字跟着界面语言走，局部格式工具栏的下拉框不再被按钮盖住。

#### 修正

- **MOSS Pro 一段被 MOSI 内容审查拦下时，整个任务失败**（用户回报，`safety guardrail blocked`）。现在被拦的段不让任务失败，其余段照常交完；被拦的那段默认用这台电脑上已安装的本地主力模型补识别并在审核里标出，没有本地模型就空着并说明。想再用 MOSS Pro 试，「切成小段再交 MOSI…」先说明会再计费、能不能通过不确定，确认后只把被拦的段切成约 3 分钟重交。被拦的段从不原样重交。
- **MOSS Pro「句段时间越出提交的音频」时整个识别失败，怎么重试都一样**（用户回报，0.8.4 一集英语唱歌直播）。现在结尾超出的截到这段音频结尾，时间在音频之外、起止颠倒或没有时间的句子去掉，其余照常出字幕；排查报告写出在哪几段、截短和去掉了几句。0.8.4 里失败的任务更新后再识别即可，MOSI 还保留结果时直接取回、不重新上传。
- 删掉的自带词库（例如鹰角嘉年华）下次打开术语库又冒出来。
- 阴影面板输入的模糊、角度等数值不生效，角度盘拖了没反应；局部样式丢掉原本的视觉设计（AI 设计的阴影 / 动效）；套了网页主题的字幕预览要等好几秒；转繁简后撤销没有完全复原；播放叠加画面的暂存文件越积越多。

### 已经装过旧版本

- **0.8.2–0.8.4**：主界面右上角“检查更新”。只下载约 61 MB（程序本身），其余部分沿用已装的。
- **0.7.0–0.8.1**：同样用“检查更新”。这些版本还要补上 0.8.2 换过的随附 FFmpeg、Python 运行库与离线安装包，共约 890 MB，和重新下载 Setup 差不多；**0.6.5** 还要多下载渲染器（共约 1.13 GB）。
- 这一版的更新清单仍把 GitCode 国内镜像排在 GitHub 前面：已安装的 0.6.5–0.8.2 会先从 GitCode 下载，在中国大陆比 GitHub 快得多，GitCode 下不了时再用 GitHub；0.8.3、0.8.4 从检查更新时先回应的来源下载，某个来源一直很慢时自动换来源续传。
- 下载可以断点续传；下载后校验，等你保存工程并同意退出后才替换；失败会自动恢复原版本。设置、词库、工程、已下载的模型与运行环境都保留，不需要重新准备。
- **0.6.0 及更早**：关闭兔白字幕，运行 0.8.5 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：还没有程序内更新。退出旧版，打开新的 DMG，把 App 拖进“应用程序”替换即可；设置、模型和工程存放在 App 以外的用户资料夹。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases（或上面的 GitCode 镜像、gh-proxy 链接）下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **用了局部格式或分层样式的工程，0.8.4 及更早的版本打开看不到这些格式**（存在每条字幕已有的外观字段里，字幕正文不受影响）。含多音轨素材的工程仍然只有 0.8.4 及以后能打开。
- **只重新识别一段**：还不支持多音轨素材；替换的字幕译文会清空，需要再翻译；字幕列表没有右键菜单，只能在时间轴上用。
- **分开拖视频 / 音频**：之后再拖动视频片段时，不会避开同一条音频轨上分离出来的音频（两段可能叠在一起都出声；放下时会避开）；一个文件有好几条音轨时不能「分离音频」，「仅音频」只拖默认那条；预览没有入点 / 出点，拖进去的是整段素材。往媒体池「添加素材」加 WAV / MP3 时，它会自己占一条新音频轨、从 0 秒开始（以前就这样）。
- **API 设置窗口**：MOSS Pro 那页连不上 MOSI 时，结果几行被压扁、字看不全（原有问题）。
- **界面翻译**：新文字在 10 种界面语言都有译文，繁体中文按字转换；字幕工作台新面板在五种语言里真实窗口看过，其他新窗口只看了中文。

### What is new in this release (compared with 0.8.4)

This release comes from the version the developer uses every day and includes all changes from the one day since 0.8.4: Studio can re-transcribe just one range, ordinary subtitles have partial formatting and separate styles for the original and the translation, and media can be previewed first and then dragged onto tracks with picture and sound separate; the term library can hold symbols and the built-in libraries can be deleted; the beginner tutorial was redone; and two kinds of whole-recognition failure with MOSS Pro reported by users were fixed. Settings and recognition-result formats are unchanged, so older projects open as they are; **in projects that use partial formatting or layered styles, 0.8.4 and earlier cannot show that formatting** (see "Known limitations"). The minimum system for the Mac build changes from macOS 15 to **macOS 14**.

#### New

- **Re-transcribe just one range of subtitles.** If one range was recognized wrongly, you do not have to rerun the whole episode: in Studio set the in and out points with I / O, then right-click the timeline and choose "Re-transcribe this range only…". It opens the usual "Transcribe captions" window (same plan, models and term libraries), recognizes only the range from the in point to the out point and replaces the subtitles in that range; subtitles, styles, edits and speaker tracks outside the range are not touched, and one replacement is one undo step. When the in or out point falls in the middle of a subtitle, that whole subtitle is recognized again, and the window states the actual range; if the range contains subtitles you edited by hand, it asks before starting, and asks again if you edited more while recognition was running. When the option cannot be used, the reason is written after it (no in / out points set, shorter than 1 second, recognition running, media with several audio tracks, subtitle track locked).
- **Partial formatting for ordinary subtitles.** Above the subtitle edit box you can choose "Plain text" or "Markdown": `**粗体**` (bold), `*斜体*` (italic), `==重点==` (highlight), line breaks and partial color. This is display formatting only; the subtitle text and the word timing do not change; the original and the translation each have their own partial formatting.
- **Original / translation / whole group styled separately.** The Style panel offers "Original / Translated text / Whole group"; the translation can have its own font size and color, and for the position and alignment of bilingual subtitles you choose "Whole group" and then adjust. "Apply to" now defaults to "Selected": only the selected subtitles change, and the selection does not have to be contiguous (for example the 2nd and 5th subtitles); changing one item (for example font size) changes only that item, and one drag is one undo step. When a subtitle is split, the translation is divided by an estimate at its own word boundaries and marked as needing a check; merging back restores the original sentence's translation and formatting.
- **Double-click media in Studio to preview it first; drag picture and sound separately.** Double-click a file in the Media Pool on the "Media" page, and the subtitle list on the left is replaced by its preview (you can play it and drag the progress; the project pauses automatically; "Back to captions" returns). Under the preview, drag "Video + Audio / Video only / Audio only" onto a timeline track: while you drag, it shows which track and which place it will land on, and one click adds it at the playhead; rows in the Media Pool can also be dragged directly, and right-click lets you add only the video or only the audio. Right-click a video clip on the timeline and choose "Detach Audio": the picture and the sound become two clips that can be moved and deleted independently. Each drop and each detach is one undo step, and the project file format is unchanged.
- **Terms can contain symbols, and built-in libraries can be deleted.** Saving a term used to quietly strip symbols such as `《》（）·：` (`漂泊者·男` was saved as `漂泊者男`, `Re:Zero` as `ReZero`); now it is saved as you wrote it and the symbols are kept in the recognized subtitles too (a `漂泊者男` in the subtitles is changed back to `漂泊者·男`; where a symbol is at either end of the term, only the "Misheard spelling" you entered is replaced). The libraries that come with the app, such as Genshin Impact and Arknights, can be removed with "Delete library…" in "⋯" or in the list's right-click menu: the library no longer appears and is no longer used for recognition, the built-in content is not changed, and "New" → "Restore built-in libraries" puts it back.
- **Visual emphasis for library words and speaker-name templates.** A word in a library can also be given "Accent", which only changes how the subtitle looks and does no replacement; speaker names are read from a template, so a rename updates immediately and is not written into the subtitle text. In review mode, W / A go to the next subtitle and S / D to the previous one (typing in an input box is not affected).
- **The app checks for updates every time it opens and reminds you.** About 5 seconds after opening it checks once (if you reopen within 10 minutes, the last result is used), and when there is a new version the "New version available" window pops up by itself; it does not pop up while recognition is running, another window is open or you are in the beginner tutorial, and only once per launch. Untick "Check automatically and remind me when the app opens" in the pop-up or in "App Settings → About" and it stops popping up (the daily background check still runs as before and only marks the new version on the button).
- **MAI-Transcribe 2 can now be configured.** The MAI card in the Model workshop is now MAI-Transcribe 2 (OpenRouter · `microsoft/mai-transcribe-2`, about $0.10 / hour, character-level timestamps, speakers); click "Configure" and paste an OpenRouter key to use it; the transcription style and the proper names in your term library are really passed to MAI (without the library, "鸣潮、今汐、长离" come out as "明朝、金犀"; with it, all are right). In "Apply for and set up an API", the Qwen entry lets you choose the China site "Qianwen AI Platform" or the international site "Qwen Cloud"; the Simplified Chinese interface defaults to the China site.

#### Improved

- **Beginner tutorial redone.** The first step already asks you to choose "Cloud recognition / Local recognition" and the main language of the video, and recommends the model and timestamps by language (Chinese: FireRedASR2; other languages: Qwen3 alignment); the tutorial box fades in without flashing squares at the four corners; after the demo video is dropped in, it waits for Home to settle before showing the next step; once in Studio it teaches C (razor, for cutting), the B merge tool, Shift+Q / Shift+W ripple merge and T (new subtitle track).
- **"App Settings" is usable as soon as it opens.** Before, all eight categories were built every time and you could only start working after about 1.8 seconds; now only the current category is built, the other categories are built the first time you click on them (changed values are kept), and a window that has not been changed is reused next time: on a 1-hour project, the time until it is usable went from about 1.8 seconds to about 0.08 seconds.
- **Entering Studio the first time is faster, and going back to Home keeps the project.** The first entry builds Studio in steps and shows "Building the Subtitle Studio interface…" first, and you can go back to Home at any time; when you go back to Home, Studio is paused, and the project, undo history, selection and playhead position are all kept, so going back in carries straight on. Entering Studio no longer flashes a small window; the Ctrl+Shift+S keycap is no longer cut off.
- **When you drag the workspace divider sideways, the video keeps its proportions** instead of being squashed; fewer redundant redraws while dragging.
- **Clip suggestions (danmaku analysis)**: every suggestion has checkable subtitle / danmaku evidence; the card, the range preview, the manual start and end, and the list waiting to be generated all use the same range; after an old recording is deleted, the sources actually kept are used; browsing a video no longer jumps to the tools page, and when a project is reopened the tools page returns to the page it was on.
- **After connecting DeepSeek, AI enhancement in the term library's "Smart term building" works.** Before, DeepSeek used up the whole quota on thinking and returned empty content, yet the interface said "invalid API key"; now it goes through the same channel as AI line breaking, and when something goes wrong the message gives the real reason (key / balance / too many requests / cannot connect); a pasted-in table is read by column for the standard word, category and aliases.
- On Home, the "Recognition plan" menu also shows the chosen plan while models are still downloading; the text on Studio's new panels follows the interface language, and the drop-down in the partial-formatting toolbar is no longer covered by the buttons.

#### Fixed

- **When MOSI's content review blocked one part of a MOSS Pro task, the whole task failed** (reported by a user, `safety guardrail blocked`). Now a blocked part does not fail the task, and the other parts are delivered as usual; for the blocked part, by default the local main model already installed on this computer recognizes it, and it is marked in review; with no local model it is left empty and the app says so. To try MOSS Pro again, "Send to MOSI again in pieces…" first explains that you will be billed again and that passing is not guaranteed, and after you confirm, only the blocked part is cut into pieces of about 3 minutes and resubmitted. A blocked part is never resubmitted as it was.
- **When MOSS Pro reported that sentence times went beyond the submitted audio, the whole recognition failed, and retrying never helped** (reported by a user, an English singing stream in 0.8.4). Now an end that goes past is cut to the end of that audio; sentences whose time is outside the audio, whose start and end are reversed, or that have no time are dropped, and the rest produce subtitles as usual; the troubleshooting report says in which parts, and how many sentences were shortened and dropped. A task that failed in 0.8.4 just needs to be recognized again after the update; if MOSI still holds the result, it is fetched directly without uploading again.
- A deleted built-in library (for example 鹰角嘉年华) reappeared the next time the term library was opened.
- Numbers typed into the shadow panel, such as blur and angle, had no effect, and the angle dial did nothing when dragged; partial styles lost the original visual design (AI-designed shadow / motion); subtitle previews with a web theme took several seconds to appear; after converting between Simplified and Traditional Chinese, undo did not fully restore; the temporary files for playing the overlay kept piling up.

### Known limitations

- **No code signing.** Windows may show "Unknown publisher"; the Mac app is not notarized. Download only from this repository's Releases (or the GitCode mirror / gh-proxy links above) and check `SHA256SUMS.txt`; you do not need to, and should not, turn off antivirus or system security.

- **The Mac build is experimental**: the minimum system is now macOS 14 (checked on GitHub's macOS 14 and 15 virtual Macs, not on a physical Mac); hardware video encoding on macOS 14 is not verified, export uses software encoding; the new features in this release were not checked separately on Mac.

- **The Docker version is still 0.8.1** ([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)); this release does not update the Docker image.
- The other known limitations in the 0.8.4 and earlier release notes still apply.

### このバージョンの新しい点（0.8.4 との比較）

このバージョンは開発者が日常的に使っている版から作ったもので、0.8.4 以降 1 日分の変更をすべて含みます：字幕スタジオで 1 区間だけを認識し直せるようになり、通常の字幕に部分書式と、原文 / 訳文を分けたスタイルが加わり、素材を先にプレビューしてから映像と音声を別々にトラックへドラッグできるようになりました。用語集には記号を書けるようになり、内蔵辞書も削除できます。はじめてのチュートリアルを作り直し、ユーザーから報告された、MOSS Pro で認識全体が失敗する 2 つの問題も修正しました。設定と認識結果の形式は変わっていないので、古いプロジェクトもそのまま開けます。**部分書式やレイヤー別スタイルを使ったプロジェクトは、0.8.4 以前のバージョンで開いてもそれらの書式が表示されません**（「既知の制限」を参照）。Mac 版の最低要件は macOS 15 から **macOS 14** に変わりました。

#### 新機能

- **1 区間だけを認識し直せます。** ある区間の認識が間違っていても、全体をやり直す必要はありません。字幕スタジオで I / O を使ってイン点・アウト点を設定し、タイムラインで右クリックして「この範囲だけ認識し直す…」を選びます。通常の「字幕を認識」ウィンドウ（同じプラン、モデル、用語集）が開き、イン点からアウト点までの区間だけを認識して、その区間の字幕を置き換えます。区間外の字幕、スタイル、カット編集、話者トラックには手を加えず、1 回の置き換えが 1 回の「元に戻す」の単位です。イン点またはアウト点が字幕の途中にあるときは、その字幕全体をまとめて認識し直し、ウィンドウに実際の範囲を表示します。この区間に手で直した字幕があるときは開始前に確認し、認識の途中でさらに直したときにもう一度確認します。使えないときは、項目の後ろに理由が書かれます（イン・アウト点が未設定、1 秒未満、認識中、複数音声トラックの素材、字幕トラックがロック中）。
- **通常の字幕に部分書式。** 字幕の編集欄の上で「プレーンテキスト / Markdown」を選べます：`**粗体**`、`*斜体*`、`==重点==`、改行、部分的な色。表示上の書式だけで、字幕の本文と文字単位のタイミングは変わりません。原文と訳文にはそれぞれ独自の部分書式があります。
- **原文 / 訳文 / グループ全体を別々にスタイル設定。** スタイルパネルで「原文 / 翻訳文 / グループ全体」を選べ、訳文には独自の文字サイズや色を設定できます。二言語の位置と整列は「グループ全体」を選んでから調整します。スタイルの「適用先」の既定は「選択済み」になりました：選択した字幕だけを変更し、飛び飛びの複数選択（たとえば 2 件目と 5 件目）もできます。1 項目（たとえば文字サイズ）を変えるとその項目だけが変わり、1 回のドラッグが 1 回の「元に戻す」の単位です。字幕を分割するときは、訳文を語の区切りで推定して分け、「要確認」のしるしを付けます。結合し直すと、元の文の訳文と書式に戻ります。
- **字幕スタジオで素材をダブルクリックしてプレビュー、映像と音声を別々にドラッグ。** 「メディア」ページのメディアプールでファイルをダブルクリックすると、左側の字幕リストの場所がそのプレビューに切り替わります（再生やシークができ、プロジェクトは自動的に一時停止します。「字幕リストに戻る」で戻ります）。プレビューの下の「映像＋音声 / 映像のみ / 音声のみ」をタイムラインのトラックにドラッグすると、ドラッグ中にどのトラックのどの位置に置かれるかが表示され、クリックすると再生ヘッドの位置に追加されます。メディアプールの行も直接ドラッグでき、右クリックで映像だけ、または音声だけを追加できます。タイムライン上の映像クリップを右クリックして「音声を分離」を選ぶと、映像と音声が 2 つのクリップになり、それぞれ移動や削除ができます。ドロップや分離のたびに 1 回の「元に戻す」になり、プロジェクトファイルの形式は変わりません。
- **用語に記号を書けます。内蔵辞書は削除できます。** 以前は用語を保存するときに `《》（）·：` などの記号をこっそり削除していました（`漂泊者·男` が `漂泊者男`、`Re:Zero` が `ReZero` として保存）が、今は書いたとおりに保存し、認識された字幕にも残ります（字幕の `漂泊者男` は `漂泊者·男` に直ります。記号が両端にあるものは、入力した「聞き間違いの表記」だけを置き換えます）。原神、明日方舟などアプリに内蔵された辞書は、「⋯」または一覧の右クリックから「辞書を削除…」で削除できます：表示されなくなり、認識にも使われず、内蔵の内容自体は変更されません。「新規作成」→「内蔵辞書を復元」で元に戻せます。
- **用語ライブラリの視覚的アクセントと話者名テンプレート。** 用語ライブラリの語は、別に「アクセント」をオンにでき、字幕の見た目だけを変えて置換は行いません。話者名はテンプレートから読み取られ、名前を変えるとすぐ更新され、字幕本文には書き込まれません。レビューモードでは W / A で次の字幕、S / D で前の字幕へ移動します（入力欄での文字入力には影響しません）。
- **アプリを開くたびに更新を確認して通知します。** 起動の約 5 秒後に 1 回確認し（10 分以内に開き直したときは前回の結果を使います）、新しいバージョンがあれば自動で「新しいバージョンがあります」ウィンドウが出ます。認識中、別のウィンドウが開いているとき、はじめてのチュートリアルの途中では出さず、同じ起動で出るのは 1 回だけです。ウィンドウ内、または「アプリ設定 → このアプリについて」で「起動時に自動で確認して知らせる」をオフにすると出なくなります（従来どおり 1 日 1 回バックグラウンドで確認し、ボタンに新しいバージョンの表示だけが付きます）。
- **MAI-Transcribe 2 を設定できるようになりました。** モデルワークショップの MAI カードは MAI-Transcribe 2（OpenRouter · `microsoft/mai-transcribe-2`、約 $0.10 / 時間、文字単位のタイムスタンプ、話者）に変わり、「設定」を押して OpenRouter のキーを貼り付ければ使えます。書き起こしスタイルと用語集の固有名詞が実際に MAI に渡されるようになりました（用語集を渡さないと「鸣潮、今汐、长离」が「明朝、金犀」と書かれ、渡すとすべて正しくなります）。「API の申請と設定」の Qwen の項目では、中国サイト「千問AIプラットフォーム」と国際サイト「Qwen Cloud」を選べ、簡体字中国語の UI では中国サイトが既定です。

#### 改善

- **はじめてのチュートリアルを作り直しました。** 最初のステップで「クラウド認識 / ローカル認識」と動画の主な言語を選び、言語に応じてモデルとタイムスタンプを推奨します（中国語は FireRedASR2、その他の言語は Qwen3 アライメント）。ガイドの枠はフェードインで現れ、四隅に四角形がちらつくことはなくなりました。デモ動画を入れたあとはホームが落ち着くのを待ってから次のステップが出ます。字幕スタジオに入ってからは、C でのカット、B での結合ツール、Shift+Q / Shift+W でのリップル結合、T での字幕トラック新規作成を案内します。
- **「アプリ設定」が開いてすぐ使えます。** 以前は毎回 8 つのカテゴリすべてを作ってから、約 1.8 秒後にやっと操作できました。今は現在のカテゴリだけを作り、ほかのカテゴリは初めてクリックしたときに作ります（変更した値は保持されます）。変更していないウィンドウは次回そのまま再利用します：1 時間のプロジェクトで開いて使えるまでが約 1.8 秒 → 約 0.08 秒。
- **初めて字幕スタジオに入るのが速くなり、ホームに戻ってもプロジェクトが保持されます。** 初回は段階的に作り、まず「字幕スタジオの画面を作成しています…」と表示し、いつでもホームに戻れます。ホームに戻ると字幕スタジオは一時停止し、プロジェクト、元に戻す履歴、選択、再生位置はすべて保持され、再び入ればそのまま続きから使えます。字幕スタジオに入るときに小さなウィンドウが一瞬出ることもなくなり、ショートカットのキーキャップ Ctrl+Shift+S が途切れて表示されることもなくなりました。
- **ワークスペースの区切りを横にドラッグしても、映像の縦横比が保たれます。** つぶれなくなり、ドラッグ中の不要な再描画も減りました。
- **クリップ提案（弾幕分析）**：各提案に調べられる字幕 / 弾幕の根拠があり、カード、範囲プレビュー、手動の開始・終了、生成待ちリストが同じ範囲を使います。古い録画を削除したあとは、実際に残っている出所を使います。動画を閲覧してもツールページに飛ばず、プロジェクトを開き直すとツールページは元のページに戻ります。
- **用語集の「スマート用語生成」で、DeepSeek を接続した AI 強化が使えるようになりました**：以前は DeepSeek が先に思考して使用枠を使い切り、空の内容が返ってくるのに、画面は「API キーが無効」と表示していました。今は AI 文分割と同じ経路を使い、エラーのときは実際の原因（キー / 残高 / 頻度が高すぎる / 接続できない）を書きます。貼り付けた表は、列ごとに正式名称、分類、別名として読み取ります。
- ホームの「認識プラン」メニューは、モデルがダウンロード中でも選んだプランを表示します。字幕スタジオの新しいパネルの文字は UI 言語に合わせて切り替わり、部分書式ツールバーのドロップダウンがボタンに隠れなくなりました。

#### 修正

- **MOSS Pro で 1 区間が MOSI のコンテンツ審査にブロックされると、タスク全体が失敗する問題**（ユーザー報告、`safety guardrail blocked`）。今はブロックされた区間でタスクを失敗させず、残りの区間は通常どおり納品します。ブロックされた区間は、既定ではこの PC にインストール済みのローカルのメインモデルで認識を補い、レビューで印を付けます。ローカルモデルがなければ空のままにして説明を表示します。もう一度 MOSS Pro で試したいときは、「分けて MOSI に再送信…」で、再課金されることと通るかどうかは不確実であることを先に説明し、確認後にブロックされた区間だけを約 3 分に切って再送信します。ブロックされた区間をそのまま再送信することはありません。
- **MOSS Pro で「文区間の時刻が送信した音声の範囲を超える」と、認識全体が失敗し、何度やり直しても同じになる問題**（ユーザー報告、0.8.4 で英語の歌配信 1 本）。今は、末尾がはみ出した分はその音声の終わりに切り詰め、時刻が音声の外にあるもの、開始と終了が逆のもの、時刻がない文は取り除き、残りは通常どおり字幕にします。トラブルシューティングレポートには、どの区間で、何文を切り詰め、何文を取り除いたかが書かれます。0.8.4 で失敗したタスクは、更新後にもう一度認識すれば大丈夫です。MOSI に結果が残っていれば、再アップロードせずに直接取得します。
- 削除した内蔵辞書（たとえば鹰角嘉年华）が、次に用語集を開くとまた現れる問題。
- シャドウパネルに入力したぼかし、角度などの数値が反映されない問題、角度ダイヤルをドラッグしても反応しない問題。部分スタイルが元のビジュアルデザイン（AI デザインのシャドウ / モーション）を失う問題。ウェブテーマを適用した字幕のプレビューに数秒かかる問題。繁体字・簡体字の変換後に元に戻すと完全には復元されない問題。再生オーバーレイの一時ファイルが溜まり続ける問題。

#### 새 기능

- **한 구간의 자막만 다시 인식.** 어느 한 구간이 잘못 인식됐을 때 한 회 전체를 다시 돌릴 필요가 없습니다. 자막 스튜디오에서 I / O로 시작점과 끝점을 정하고, 타임라인에서 오른쪽 클릭 → "이 구간만 다시 인식…". 평소의 "자막 인식" 창(같은 구성, 모델, 용어집)이 열리고, 시작점부터 끝점까지만 인식해 그 구간의 자막을 바꿉니다. 구간 밖의 자막, 스타일, 편집, 화자 트랙은 건드리지 않으며, 한 번 바꾸는 것이 실행 취소 한 단계입니다. 시작점이나 끝점이 어떤 자막 한가운데에 있으면 그 자막 전체를 함께 다시 인식하며, 창에 실제 범위를 적어 줍니다. 이 구간에 직접 고친 자막이 있으면 시작하기 전에 먼저 묻고, 인식하는 도중에 또 고쳤으면 한 번 더 묻습니다. 쓸 수 없을 때는 옵션 뒤에 이유가 적힙니다(시작점 / 끝점 미설정, 1초 미만, 인식 중, 다중 오디오 트랙 소재, 자막 트랙 잠김).
- **일반 자막 부분 서식.** 자막 편집 칸 위에서 "일반 텍스트 / Markdown"를 고를 수 있습니다: `**粗体**`, `*斜体*`, `==重点==`, 줄바꿈, 부분 색. 표시 서식일 뿐이라 자막 본문과 글자 단위 타이밍은 바뀌지 않으며, 원문과 번역문이 각자 부분 서식을 가집니다.
- **원문 / 번역문 / 그룹 전체에 따로 스타일 지정.** 스타일 패널에서 "원문 / 번역문 / 그룹 전체"를 고를 수 있고, 번역문에 자신만의 글자 크기와 색을 줄 수 있습니다. 이중 언어의 위치와 정렬은 "그룹 전체"를 고른 뒤 조정하세요. 스타일의 "적용 대상" 기본값이 "선택됨"으로 바뀌었습니다: 선택한 자막만 바꾸며, 연속되지 않아도 여러 개를 선택할 수 있고(예: 2번째와 5번째), 한 항목(예: 글자 크기)을 바꾸면 그 항목만 바뀌고, 한 번 드래그가 실행 취소 한 단계입니다. 자막을 나눌 때 번역문은 단어 경계로 추정해 나누고 "확인 필요"로 표시하며, 다시 합치면 원래 문장의 번역문과 서식이 복원됩니다.
- **자막 스튜디오에서 미디어를 더블클릭하면 먼저 미리보기, 영상과 오디오는 따로 끌어다 놓기.** "미디어" 페이지의 미디어 풀에서 파일을 더블클릭하면 왼쪽 자막 목록 자리에 그 파일의 미리보기가 나타납니다(재생하고 진행 위치를 끌 수 있으며, 프로젝트는 자동으로 일시 정지됩니다. "자막 목록으로"를 누르면 돌아갑니다). 미리보기 아래의 "영상+오디오 / 영상만 / 오디오만"을 타임라인 트랙으로 끌어다 놓을 수 있고, 끄는 동안 어느 트랙의 어느 구간에 놓일지 표시되며, 한 번 클릭하면 재생 헤드 위치에 추가됩니다. 미디어 풀의 행도 바로 끌 수 있고, 오른쪽 클릭으로 영상만 또는 오디오만 추가할 수 있습니다. 타임라인의 영상 클립을 오른쪽 클릭 → "오디오 분리"를 누르면 영상과 오디오가 별개의 클립 둘이 되어 각각 옮기거나 삭제할 수 있습니다. 놓을 때마다, 분리할 때마다 실행 취소 한 단계이며, 프로젝트 파일 형식은 바뀌지 않았습니다.
- **용어에 기호를 쓸 수 있고, 기본 제공 용어집을 삭제할 수 있습니다.** 예전에는 용어를 저장할 때 `《》（）·：` 같은 기호를 조용히 지웠는데(`漂泊者·男`이 `漂泊者男`으로, `Re:Zero`가 `ReZero`로 저장됨), 이제는 쓴 그대로 저장하고 인식된 자막에서도 유지합니다(자막의 `漂泊者男`은 `漂泊者·男`으로 바뀌며, 기호가 앞뒤 끝에 있는 용어는 입력한 "잘못 들린 표기"로만 바꿉니다). 원신, 명일방주 같은 앱 기본 제공 용어집은 "⋯" 메뉴나 목록의 오른쪽 클릭 "용어집 삭제…"로 지울 수 있습니다: 더 이상 표시되지 않고 인식에도 쓰이지 않으며, 기본 제공 내용은 바뀌지 않습니다. "새로 만들기" → "기본 제공 용어집 복원"으로 다시 넣을 수 있습니다.
- **용어집 시각 강조와 화자 이름 템플릿.** 용어집의 용어에 따로 "강조"를 켤 수 있으며, 자막 모양만 바꾸고 치환은 하지 않습니다. 화자 이름은 템플릿에서 읽어 오므로 이름을 바꾸면 곧바로 갱신되고 자막 본문에는 쓰이지 않습니다. 검토 모드에서 W / A는 다음 자막으로, S / D는 이전 자막으로 이동합니다(입력 칸에 글자를 입력하는 데는 영향이 없음).
- **앱을 열 때마다 업데이트를 확인하고 알려 줍니다.** 연 지 약 5초 뒤에 한 번 확인하고(10분 안에 다시 열면 지난 결과를 씀), 새 버전이 있으면 "새 버전이 있습니다" 창이 자동으로 나타납니다. 인식 중이거나 다른 창이 열려 있거나 초보자 튜토리얼을 보는 중에는 먼저 띄우지 않으며, 한 번 연 동안에는 한 번만 띄웁니다. 창에서, 또는 "앱 설정 → 정보"에서 "앱을 열 때 자동으로 확인하고 알림"을 끄면 더 이상 띄우지 않습니다(전과 같이 하루에 한 번 백그라운드에서 확인하며, 버튼에만 새 버전을 표시).
- **MAI-Transcribe 2를 설정할 수 있습니다.** 모델 워크숍의 MAI 카드가 MAI-Transcribe 2(OpenRouter · `microsoft/mai-transcribe-2`, 시간당 약 $0.10, 글자 단위 타이밍, 화자)로 바뀌었고, "설정"을 눌러 OpenRouter Key를 붙여 넣으면 쓸 수 있습니다. 전사 스타일과 용어집 고유명사가 실제로 MAI에 전달됩니다(용어집을 주지 않으면 "鸣潮、今汐、长离"가 "明朝、金犀"로 적히지만, 주면 모두 맞음). "API 신청 및 설정"의 Qwen 항목에서는 중국 사이트 "첸원 AI 플랫폼"이나 국제 사이트 "Qwen Cloud"를 고를 수 있으며, 중국어(간체) 화면에서는 기본이 중국 사이트입니다.

#### 개선

- **초보자 튜토리얼 개편.** 첫 단계에서 바로 "클라우드 인식 / 로컬 인식"과 영상의 주요 언어를 고릅니다. 언어에 맞춰 모델과 타임스탬프를 추천합니다(중국어는 FireRedASR2, 다른 언어는 Qwen3 정렬). 안내 상자가 서서히 나타날 때 네 모서리에 네모가 깜빡이지 않으며, 데모 영상을 넣은 뒤 홈이 안정될 때까지 기다렸다가 다음 단계를 보여 줍니다. 자막 스튜디오에 들어간 뒤에는 C 자르기, B 병합 도구, Shift+Q / Shift+W 리플 병합, T 새 자막 트랙을 알려 줍니다.
- **"앱 설정"을 열자마자 쓸 수 있습니다.** 예전에는 매번 분류 여덟 개를 모두 만들어 약 1.8초 뒤에야 조작할 수 있었습니다. 이제는 현재 분류만 만들고, 다른 분류는 처음 눌렀을 때 만들며(바꾼 값은 모두 유지), 바꾸지 않은 창은 다음에 그대로 재사용합니다: 1시간짜리 프로젝트에서 열고 나서 쓸 수 있을 때까지 약 1.8초 → 약 0.08초.
- **처음 자막 스튜디오에 들어갈 때 더 빠르고, 홈으로 돌아가도 프로젝트가 유지됩니다.** 처음 들어갈 때는 단계별로 만들며 먼저 "자막 스튜디오 화면을 만드는 중…"이 표시되고 언제든 홈으로 돌아갈 수 있습니다. 홈으로 돌아가면 자막 스튜디오는 일시 정지되며 프로젝트, 실행 취소, 선택, 재생 위치가 모두 유지되어 다시 들어가면 그대로 이어서 쓸 수 있습니다. 들어갈 때 작은 창이 번쩍 나타나지 않으며, 단축키 키캡 Ctrl+Shift+S가 더 이상 잘리지 않습니다.
- **작업 영역 구분선을 가로로 끌 때 영상이 비율을 유지합니다.** 찌그러지지 않으며, 끄는 동안 불필요한 다시 그리기도 줄였습니다.
- **클립 제안(탄막 분석)**: 제안마다 확인할 수 있는 자막 / 탄막 근거가 있고, 카드, 범위 미리보기, 수동 시작·끝, 생성 목록이 같은 범위를 씁니다. 예전 방송 녹화본을 지운 뒤에는 실제로 남아 있는 소스를 사용합니다. 영상을 둘러볼 때 도구 페이지로 튀지 않으며, 프로젝트를 다시 열면 도구 페이지가 원래 보던 페이지로 돌아갑니다.
- **용어 라이브러리의 "스마트 용어 생성"에 DeepSeek을 연결하면 AI 강화를 쓸 수 있습니다**: 예전에는 DeepSeek이 먼저 생각하느라 토큰 한도를 다 써서 빈 내용이 돌아오는데도 화면에는 "API 키가 유효하지 않음"이라고 나왔습니다. 이제는 AI 줄 나누기와 같은 경로를 쓰며, 오류가 나면 실제 원인(키 / 잔액 / 너무 잦은 요청 / 연결 불가)대로 적습니다. 붙여 넣은 표는 열 기준으로 표준 용어, 분류, 별칭을 읽습니다.
- 홈의 "인식 구성" 메뉴가 모델을 아직 내려받는 중에도 고른 구성을 표시합니다. 자막 스튜디오의 새 패널 글자가 화면 언어를 따르고, 부분 서식 도구 모음의 드롭다운이 더 이상 버튼에 가려지지 않습니다.

#### 수정

- **MOSS Pro의 한 구간이 MOSI 콘텐츠 심사에 막히면 작업 전체가 실패하던 문제**(사용자 제보, `safety guardrail blocked`). 이제 막힌 구간 때문에 작업이 실패하지 않으며, 나머지 구간은 평소처럼 마무리됩니다. 막힌 구간은 기본적으로 이 컴퓨터에 설치된 로컬 주 모델로 보충 인식하고 검토 화면에 표시하며, 로컬 모델이 없으면 비워 두고 이유를 설명합니다. MOSS Pro로 다시 시도하려면 "나눠서 MOSI에 다시 보내기…"가 먼저 다시 과금되고 통과 여부는 확실하지 않다는 점을 설명하며, 확인하면 막힌 구간만 약 3분씩 나눠 다시 보냅니다. 막힌 구간은 원본 그대로 다시 제출하지 않습니다.
- **MOSS Pro가 "문장 구간 시간이 제출한 오디오를 벗어남" 오류를 내면 인식 전체가 실패하고 몇 번을 다시 해도 같던 문제**(사용자 제보, 0.8.4, 영어 노래 방송 한 회). 이제 끝이 넘친 부분은 그 오디오의 끝으로 잘라 내고, 시간이 오디오 밖이거나 시작과 끝이 뒤집혔거나 시간이 없는 문장은 빼고 나머지는 평소처럼 자막으로 만듭니다. 문제 해결 보고서에는 어느 구간에서 몇 문장을 줄이고 몇 문장을 뺐는지 적습니다. 0.8.4에서 실패한 작업은 업데이트 후 다시 인식하면 되며, MOSI에 결과가 남아 있으면 다시 올리지 않고 바로 가져옵니다.
- 삭제한 기본 제공 용어집(예: 鹰角嘉年华)이 다음에 용어 라이브러리를 열면 다시 나타나던 문제.
- 그림자 패널에 입력한 흐림, 각도 등의 값이 적용되지 않고 각도 다이얼을 끌어도 반응이 없던 문제; 부분 스타일이 원래의 시각 디자인(AI가 만든 그림자 / 모션)을 잃던 문제; 웹 테마를 쓴 자막의 미리보기가 몇 초씩 걸리던 문제; 간체/번체 변환 후 실행 취소가 완전히 복원되지 않던 문제; 오버레이 화면을 재생하는 데 쓰는 임시 파일이 계속 쌓이던 문제.

### 이전 버전에서 업데이트하기

- **0.8.2–0.8.4**: 메인 창 오른쪽 위 "업데이트 확인". 약 61 MB(프로그램 본체)만 내려받고, 나머지는 이미 설치된 것을 그대로 씁니다.
- **0.7.0–0.8.1**: 마찬가지로 "업데이트 확인". 이 버전들은 0.8.2에서 바뀐 FFmpeg, Python 실행 라이브러리, 오프라인 설치 패키지도 받아야 해서 모두 약 890 MB이며, Setup을 다시 내려받는 것과 비슷한 양입니다. **0.6.5**는 렌더러도 추가로 내려받습니다(합계 약 1.13 GB).
- 이번 버전의 업데이트 정보도 GitCode 국내 미러를 GitHub보다 앞에 둡니다. 설치된 0.6.5–0.8.2는 먼저 GitCode에서 내려받고(중국 본토에서는 GitHub보다 훨씬 빠름), GitCode에 연결되지 않으면 GitHub를 씁니다. 0.8.3, 0.8.4는 업데이트 확인 때 먼저 응답한 출처에서 내려받고, 한 출처가 계속 느리면 자동으로 다른 출처로 바꿔 이어받습니다.
- 끊긴 다운로드는 이어받습니다. 내려받은 뒤 검증하고, 프로젝트를 저장하고 종료에 동의한 다음에 교체합니다. 실패하면 원래 버전으로 돌아갑니다. 설정, 용어집, 프로젝트, 내려받은 모델과 실행 환경은 유지되어 다시 준비할 필요가 없습니다.
- **0.6.0 이하**: 2ByteASR를 닫고 0.8.5 Setup을 실행해 **그대로 덮어 설치하세요. 먼저 제거하지 마세요.**
- **Mac**: 아직 앱 안 업데이트가 없습니다. 이전 버전을 종료하고 새 DMG를 열어 App을 "응용 프로그램"으로 끌어 바꾸면 됩니다. 설정, 모델, 프로젝트는 App 밖의 사용자 폴더에 있습니다.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 "알 수 없는 게시자"가 표시될 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러, gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`를 확인하세요. 백신이나 시스템 보안을 끌 필요도 없고 꺼서도 안 됩니다.
- **부분 서식이나 레이어별 스타일을 쓴 프로젝트는 0.8.4와 그 이전 버전에서 열면 이 서식이 보이지 않습니다**(각 자막에 이미 있는 모양 필드에 저장되며, 자막 본문은 영향을 받지 않음). 다중 오디오 트랙 소재가 들어간 프로젝트는 여전히 0.8.4 이상에서만 열 수 있습니다.
- **한 구간만 다시 인식**: 다중 오디오 트랙 소재는 아직 지원하지 않습니다. 바뀐 자막의 번역문은 비워지므로 다시 번역해야 합니다. 자막 목록에는 오른쪽 클릭 메뉴가 없어 타임라인에서만 쓸 수 있습니다.
- **영상 / 오디오 따로 끌어다 놓기**: 그 뒤에 영상 클립을 끌 때는 같은 오디오 트랙에 분리해 둔 오디오를 피하지 않습니다(둘이 겹쳐 모두 소리가 날 수 있으며, 놓을 때는 피함). 파일 하나에 오디오 트랙이 여러 개면 "오디오 분리"를 쓸 수 없고, "오디오만"은 기본 트랙 하나만 끌어옵니다. 미리보기에는 시작점 / 끝점이 없어 끌어다 놓는 것은 소재 전체입니다. 미디어 풀의 "미디어 추가"로 WAV / MP3를 넣으면 새 오디오 트랙 하나를 차지하고 0초에서 시작합니다(예전부터 그랬음).
- **API 설정 창**: MOSS Pro 페이지에서 MOSI에 연결되지 않으면 결과 줄 몇 개가 눌려서 글자를 다 볼 수 없습니다(원래 있던 문제).
- **화면 번역**: 새 문구는 화면 언어 10가지 모두에 번역이 있으며, 번체 중국어는 글자 단위로 변환했습니다. 자막 스튜디오의 새 패널은 다섯 가지 언어에서 실제 창으로 확인했고, 다른 새 창은 중국어로만 확인했습니다.
- **Mac은 실험판**: 최소 시스템을 macOS 14로 바꿨습니다(GitHub의 macOS 14와 15 가상 Mac에서 확인, 실제 Mac에서는 확인하지 않음). macOS 14에서 하드웨어 영상 인코딩은 확인하지 않았고 내보내기는 소프트웨어 인코딩을 씁니다. 이번 버전의 새 기능은 Mac에서 따로 확인하지 않았습니다.
- **Claude**: Anthropic 공식 지원 지역에 중국 본토, 홍콩, 마카오는 없습니다.
- **Docker 버전은 아직 0.8.1입니다**([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)). 이번 버전에서는 Docker 이미지를 업데이트하지 않았습니다.
