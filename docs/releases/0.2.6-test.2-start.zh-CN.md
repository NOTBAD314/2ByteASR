# 首次使用与排错 · 0.2.6-test.2

## 安装与准备

只下载 `2ByteASR-Setup-0.2.6-test.2.exe`，同时下载 `SHA256SUMS.txt`。PowerShell 可用 `Get-FileHash .\2ByteASR-Setup-0.2.6-test.2.exe -Algorithm SHA256` 核对。

安装器提供位置选择。本版本使用冻结桌面程序，运行界面无需先手动搭建开发 Python／Git。模型工坊会按所选本地方案准备独立运行库和权重；包内工具与部分离线依赖不代表首次准备完全免网络。

启动后查看方案的未安装／待配置提示。需要本地模型时在模型工坊准备；使用云端角色时配置对应服务，关闭不需要的云端角色。SenseVoice 的 CPU 路径有本包短样本验证；MOSS 的本次验证使用 NVIDIA CUDA，不能把其 GPU 条件当作整个软件要求。

## 遇到问题

- **模型未就绪**：先看具体提示属于下载、依赖安装还是模型加载；记录错误和模型名称，不反复切换全部方案。
- **云端失败**：检查所选服务、模型、API Key 和额度。不要将 Key 放入反馈截图。
- **字幕不对**：在 Studio 对照视频与波形检查文字、断句、时间和说话人；术语参考并非保证纠错。
- **导出失败**：保留原工程，先试短区间，记录格式、范围和报错。没有完成提示时不要把目标文件视为有效结果。

本包尚未在无开发工具的干净 VM 验证，也未覆盖普通快捷方式、首次向导和只读安装树模型准备全流程。安装器未签名，不建议通过关闭系统保护解决来源提示。
