# 安装与首次使用

适用于 Windows x64，当前为 0.2.6-test.2 测试版。

## 下载安装

从 Release 附件下载 `2ByteASR-Setup-0.2.6-test.2.exe` 和 `SHA256SUMS.txt`。`Source code` 压缩包供查看源码，不是安装程序。

安装器未签名，Windows 可能显示来源或信誉提示。请确认下载来源，并在 PowerShell 中执行 `Get-FileHash .\2ByteASR-Setup-0.2.6-test.2.exe -Algorithm SHA256`，将结果与校验文件比较；不需要关闭系统保护。

运行安装器，选择安装位置。桌面界面无需事先安装开发用 Python 或 Git。

## 准备识别方案

在主页选择方案，只准备所需模型。安装包不包含模型权重，首次准备通常需要网络和额外磁盘空间，具体要求以模型工坊提示为准。不同模型的 CPU、显卡及运行库要求不同。

已有模型时先检查登记路径，不必重复下载。选择在线服务时，配置自己的 API Key 和模型；在线服务可能收费，不需要的在线复核可以关闭。

导入短素材开始识别，再进入 Studio 对照画面检查文字、时间和断句。重要工程请先备份。

## 遇到问题

- **模型或原工程突然不见**：先核对启动入口、模型路径和工程目录。不要清空数据、重装或用空工程覆盖旧文件。当前附件在自定义用户数据目录时，部分入口的工程路径解析可能不一致。
- **模型无法运行**：分别看权重、运行库和加载报错；目录存在不一定代表模型完整。
- **工程打不开视频**：工程文件和源媒体是分开的，请检查视频是否仍在原路径。
- **在线请求失败**：核对服务、模型、Key 和额度。反馈截图中不要包含 Key。
- **导出失败**：保留原工程，记录输出格式、范围和报错，先试短区间。

[反馈问题](https://github.com/NOTBAD314/2ByteASR/issues)时附版本号、复现步骤和截图即可。
