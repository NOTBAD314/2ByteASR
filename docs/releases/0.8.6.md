### 这一版有什么（相对 0.8.5）

这一版来自开发者日常使用的版本，0.8.5 之后一天的改动全部在内：贴上 YouTube 链接就能把视频和字幕下载进工程，自动字幕删掉 `[Music]` 这类标注、按词重排成整句；AI 清理改成一页清单，长工程不再失败；画中画双轨播放更顺；所有下拉列表统一；拖动窗口更跟手；AI 设置保存后马上生效；还修了回到工程库后残留黑色画面、大工程预览隔几秒顿一下、「AI 文字服务设置」右边被截断。设置和识别结果的格式没有变，旧工程可以直接打开。

#### 新增

- **链接下载视频与字幕。** 首页素材区和工作台工具栏都有「链接下载」：贴上 YouTube 视频链接，选画质（默认不超过 1080p 的 H.264，列出分辨率、帧率、编码和大小）、音轨和字幕。人工字幕、原语言自动字幕和自动翻译分开列出，原音语言明确时默认选原语言。也可以「仅视频」「仅音频」「仅字幕」。下载完视频和字幕直接放进当前工程（或新建工程），字幕马上能改；视频、字幕和来源一起放进去，一次撤销。下载可以暂停 / 继续、取消、重试，进度在工具栏下载按钮旁的小胶囊里；关掉下载窗口照样下载。有字幕时不用先装识别模型，也不会自动调用付费 AI。下载用随附的 yt-dlp 2026.10.21（官方版本，按锁定的 SHA-256 核对）。
- **工作台 Ctrl+V 快贴卡。** 在浏览器复制视频链接，回到字幕工作台按 Ctrl+V：右上角弹出小卡片，约 1 秒内先显示标题和封面，画质和字幕随后补齐，按回车就下载到播放头位置；完成后右下角提示可「定位到片段」「AI 精修」。剪贴板里不是视频链接、或正在文字框里打字时，Ctrl+V 照常粘贴。快捷键可以在「快捷键」设置里改。
- **YouTube 字幕自动整理。** 下载和导入时删掉 `[Music]`、`♪`、`>>` 这类标注（只有标注的行整行去掉）；英语（以及西、德、法、葡、意、俄语）的自动字幕按词重新断句：句末优先，不在 the / a / to 这类词后面断开，两行以内、一条不超过 7 秒，长停顿处一定断开。每个词的时间都保留，时间轴剃刀按词切，英文不会再按字母切开。下载目录里的 SRT 是整句，另存每个词带时间的 `.words.vtt`；原始字幕文件（JSON3 / VTT / SRT）原样保留。
- **AI 清理改成一页清单。** 上面选范围，点「开始整理」；左边「本地整理」删标注、按词严格重排断句（不用 AI、马上完成），右边「AI 校对」处理口癖、无意义重复、错字与术语、标点。下面一张清单列出每处修改和它的时间、类型（断句 / 删除 / 文字）：删的字划线、加的字下划线、新断句处画「｜」。可以按类型筛选、逐条勾掉不要的，「应用 N 处」整个只算一步撤销。

#### 改进

- **AI 清理不再因为工程太长而失败。** 以前选「全工程」会报「模型结构化输出达到长度上限，当前结果不完整」。现在整个范围分批进行（每批约 24 条），回答仍太长的那批自动拆小重试；进度显示「AI 第 x / y 批 · 已找到 n 处」，可以取消；某一批失败时，已经找到的修改照样能用。所有工程都在后台运行，不卡界面。
- **画中画双轨 1× 播放更顺。** 同一台 4K 60 Hz 电脑上，副画面从约 56 提到约 59.5 张不同画面 / 秒（主画面约 60），画面和声音的差 P95 在一帧（约 16.7 ms）以内；后台质检和进程检查不再让界面停顿，每次播放推进不再重复解析整个工程。
- **大工程预览不再隔几秒顿一下。** 一个 134 条字幕的真实工程，完整质检从约 30 秒降到约 0.5 秒（结果相同），并放到单独的后台进程。
- **下拉列表统一。** 程序里所有下拉列表都在框下方打开（下方连 3 行都放不下才往上），行高一致，最多显示 10 行，只有圆角、外面没有方框。
- **拖动窗口更跟手。** 标题栏拖动、最大化后拖出只还原一次、贴边分屏（Snap）和拖边缩放都交给 Windows 处理；普通窗口可以拖到任务栏后面，松手不弹回；不同缩放的多显示器之间拖动不跳位置。链接下载和 AI 清理窗口换成圆角标题栏。
- **AI 设置保存后马上生效。** 首页「AI 智能断句」的状态、下一次识别用的服务和模型立刻跟着变，不用重启软件；正在进行的任务继续用开始时的设置。

#### 修正

- **从工作台回到工程库后，原来视频的位置留着一块黑色画面。**
- **「AI 文字服务设置」展开「更多选项」后右边被截断**（0.8.5 用户回报）：服务框、Key 框、「保存设置」和「断句提示词」被切掉。现在窗口至少和表单一样宽，主窗口放不下时横向滚动；「协议」移到「模型」下面一行。
- 只开 AI 断句时，首页把 AI 显示成已关闭；改了服务后，隐藏的校对设置被旧值覆盖；清空 Key 后，旧的连接测试结果写回新设置。
- 窗口最大化或全屏时按 Ctrl+V，卡片跑到旁边的显示器上。

### 已经装过旧版本

- **0.8.2–0.8.5**：主界面右上角“检查更新”。下载约 305 MB：程序本身（约 58 MB）、多了 yt-dlp 的随附工具包（约 218 MB）和许可材料（约 29 MB），其余部分沿用已装的。
- **0.7.0–0.8.1**：同样用“检查更新”。这些版本还要补上 0.8.2 换过的 Python 运行库与离线安装包，共约 870 MB，和重新下载 Setup 差不多；**0.6.5** 还要多下载渲染器（共约 1.07 GB）。

- **0.6.0 及更早**：关闭兔白字幕，运行 0.8.6 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：还没有程序内更新。退出旧版，打开新的 DMG，把 App 拖进“应用程序”替换即可；设置、模型和工程存放在 App 以外的用户资料夹。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases（或上面的 GitCode 镜像、gh-proxy 链接）下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **链接下载**只支持 YouTube 单个视频（不支持播放列表、批量、需要登录的视频）；下载受 YouTube 与网络环境影响，在中国大陆需要能访问 YouTube。它的界面只有简体中文、繁體中文、英语和日语，其他界面语言显示英文。
- **字幕整理**：中文、日语、韩语自动字幕只删标注、不重排；选了双语译文时原文也不重排（保持与译文对应）。YouTube 英文自动字幕没有标点，个别地方断得别扭，可以在 AI 清理里勾「标点」再整理。
- **画中画双轨 2× 播放**副画面约 56.6 张 / 秒，还没到 60。
- **Mac 是实验版**：不随附 yt-dlp，第一次用链接下载时从 GitHub 下载（约 37 MB，核对 SHA-256 后才使用）；Mac 上的链接下载、AI 清理和这一版的其他新功能没有单独检查。最低 macOS 14（在 GitHub 的 macOS 14 与 15 虚拟 Mac 上检查过，没有实体 Mac）。
- **Claude**：Anthropic 官方支持的地区不含中国大陆、香港、澳门。
- **Docker 版仍是 0.8.1**（[v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)），这一版没有更新 Docker 镜像。
- 0.8.5 及更早发布说明里的其他已知限制不变。

#### 新機能

- **リンクから動画と字幕をダウンロード。** ホームの素材エリアと字幕スタジオのツールバーの両方に「リンクから取り込む」があります：YouTube 動画のリンクを貼り付け、画質（既定は 1080p 以下の H.264。解像度、フレームレート、コーデック、サイズを一覧表示）、音声トラック、字幕を選びます。手動字幕、原語の自動字幕、自動翻訳は分けて表示し、元の音声の言語がはっきりしているときは原語を既定で選びます。「動画のみ」「音声のみ」「字幕のみ」も選べます。ダウンロードが終わると動画と字幕はそのまま現在のプロジェクト（または新しいプロジェクト）に入り、字幕はすぐ編集できます。動画、字幕、出所はまとめて入り、1 回の「元に戻す」の単位です。ダウンロードは一時停止 / 再開、キャンセル、再試行ができ、進行状況はツールバーのダウンロードボタン横の小さなカプセルに表示されます。ダウンロード画面を閉じてもダウンロードは続きます。字幕があるときは先に認識モデルを入れる必要はなく、有料 AI を自動で呼び出すこともありません。ダウンロードには同梱の yt-dlp 2026.10.21（公式版、固定した SHA-256 で照合）を使います。
- **字幕スタジオで Ctrl+V のクイック貼り付けカード。** ブラウザーで動画のリンクをコピーし、字幕スタジオに戻って Ctrl+V を押すと、右上に小さなカードが出ます。約 1 秒以内にまずタイトルとサムネイルを表示し、画質と字幕はあとから補われます。Enter を押すと再生ヘッドの位置へダウンロードします。完了すると右下の通知から「クリップへ移動」「AI 校正」ができます。クリップボードの中身が動画のリンクでないとき、またはテキスト欄で入力中のときは、Ctrl+V は通常どおり貼り付けます。ショートカットは「ショートカット」設定で変更できます。
- **YouTube 字幕を自動で整理。** ダウンロード時と読み込み時に `[Music]`、`♪`、`>>` などの表記を削除し（表記だけの行は行ごと削除）、英語（およびスペイン語、ドイツ語、フランス語、ポルトガル語、イタリア語、ロシア語）の自動字幕は単語単位で区切り直します：文末を優先し、the / a / to のような語の後では区切らず、2 行以内・1 件 7 秒以内にし、長い間では必ず区切ります。各単語のタイミングは保持され、タイムラインのカッターは単語単位で切るので、英語が 1 文字ずつ切られることはなくなりました。ダウンロードフォルダーの SRT は文単位で、単語ごとのタイミング付きの `.words.vtt` も別に保存します。元の字幕ファイル（JSON3 / VTT / SRT）はそのまま残します。
- **AI クリーンアップを 1 ページの一覧に。** 上で範囲を選び、「整理を開始」を押します。左側の「ローカル整理」は表記の削除と単語単位の厳密な区切り直しを行い（AI を使わず、すぐ終わります）、右側の「AI 校正」は口癖、無意味な繰り返し、誤字と用語、句読点を扱います。下の一覧には、修正の一つ一つとその時刻、種類（文分割 / 削除 / 文字）が並びます：削除した文字には取り消し線、追加した文字には下線、新しい区切り位置には「｜」が付きます。種類で絞り込んだり、不要な修正を 1 件ずつ外したりでき、「N 件を適用」は全体で 1 回の「元に戻す」の単位です。

#### 改善

- **プロジェクトが長すぎて AI クリーンアップが失敗することはなくなりました。** 以前は「プロジェクト全体」を選ぶと「モデルの構造化出力が長さの上限に達したため、現在の結果は不完全です」と表示されました。今は範囲全体をバッチに分けて処理し（1 バッチ約 24 件）、回答がまだ長すぎるバッチは自動で小さく分けて再試行します。進行状況は「AI x / y バッチ · n 件」と表示され、キャンセルもできます。あるバッチが失敗しても、見つかった修正はそのまま使えます。どのプロジェクトでもバックグラウンドで実行し、画面が固まりません。
- **ピクチャー・イン・ピクチャーの 2 トラック 1× 再生がより滑らかに。** 同じ 4K 60 Hz の PC で、サブ画面は毎秒約 56 枚から約 59.5 枚の異なる画面に上がり（メイン画面は約 60 枚）、映像と音声のずれの P95 は 1 フレーム（約 16.7 ms）以内です。バックグラウンドの品質チェックとプロセスチェックで画面が止まることはなくなり、再生が進むたびにプロジェクト全体を解析し直すこともなくなりました。
- **大きなプロジェクトのプレビューが数秒ごとに引っかかることはなくなりました。** 字幕 134 件の実際のプロジェクトで、完全な品質チェックが約 30 秒から約 0.5 秒になり（結果は同じ）、別のバックグラウンドプロセスで実行するようにしました。
- **ドロップダウンリストを統一。** アプリ内のすべてのドロップダウンリストは枠の下に開き（下に 3 行も入らないときだけ上に開きます）、行の高さをそろえ、最大 10 行を表示し、角丸だけで外側の四角い枠はありません。
- **ウィンドウのドラッグがよりマウスに追従するように。** タイトルバーのドラッグ、最大化した状態からのドラッグ（復元は 1 回だけ）、端に寄せての分割（スナップ）、端のドラッグでのサイズ変更はすべて Windows に任せます。通常のウィンドウはタスクバーの後ろまでドラッグでき、離しても跳ね戻りません。拡大率の異なる複数のディスプレイ間でドラッグしても位置が飛びません。リンクからのダウンロード画面と AI クリーンアップ画面は角丸のタイトルバーになりました。
- **AI 設定は保存するとすぐ反映されます。** ホームの「AI自動文分割」の状態や、次の認識で使うサービスとモデルがすぐに切り替わり、アプリを再起動する必要はありません。実行中のタスクは開始時の設定をそのまま使います。

#### 修正

- **字幕スタジオからプロジェクトライブラリに戻ると、元の動画の位置に黒い画面が残る問題。**
- **「AI テキストサービス設定」で「その他のオプション」を開くと右側が切れる問題**（0.8.5 のユーザー報告）：サービス欄、Key 欄、「設定を保存」と「改行プロンプト」が切れていました。今はウィンドウを少なくともフォームと同じ幅にし、メインウィンドウに収まらないときは横にスクロールします。「プロトコル」は「モデル」の下の行に移しました。
- AI 文分割だけをオンにしたとき、ホームで AI がオフと表示される問題。サービスを変えたあと、隠れている校正設定が古い値で上書きされる問題。Key を消したあと、古い接続テストの結果が新しい設定に書き戻される問題。
- ウィンドウを最大化または全画面にしているときに Ctrl+V を押すと、カードが隣のディスプレイに出る問題。

### 既知の制限

- **コード署名はありません。** Windows では「不明な発行元」と表示されることがあり、Mac は Apple の公証を受けていません。このリポジトリの Releases（または上の GitCode ミラー、gh-proxy のリンク）からのみダウンロードし、`SHA256SUMS.txt` を確認してください。ウイルス対策やシステムのセキュリティをオフにする必要はなく、オフにすべきでもありません。
- **リンクからのダウンロード**は YouTube の単一の動画だけに対応しています（再生リスト、一括、ログインが必要な動画には非対応）。ダウンロードは YouTube とネットワーク環境の影響を受け、中国本土では YouTube にアクセスできる必要があります。この画面は中国語（簡体字）、中国語（繁体字）、英語、日本語のみで、ほかの UI 言語では英語で表示されます。
- **字幕の整理**：中国語・日本語・韓国語の自動字幕は表記を削除するだけで、区切り直しはしません。二言語の訳文を選んだときは原文も区切り直しません（訳文との対応を保つため）。YouTube の英語の自動字幕には句読点がないため、ところどころ不自然な位置で区切られます。AI クリーンアップで「句読点」にチェックを入れてから整理し直せます。
- **ピクチャー・イン・ピクチャーの 2 トラック 2× 再生**では、サブ画面は約 56.6 枚 / 秒で、まだ 60 に届いていません。
- **Mac 版は実験版**：yt-dlp は同梱しておらず、初めてリンクからのダウンロードを使うときに GitHub からダウンロードします（約 37 MB、SHA-256 を照合してから使用）。Mac でのリンクからのダウンロード、AI クリーンアップ、このバージョンのその他の新機能は個別に確認していません。最低要件は macOS 14 です（GitHub の macOS 14 と 15 の仮想 Mac で確認、実機では未確認）。

### 이번 버전의 새로운 점(0.8.5와 비교)

이번 버전은 개발자가 날마다 쓰는 버전에서 나왔으며, 0.8.5 이후 하루 동안의 변경을 모두 담았습니다. YouTube 링크를 붙여 넣기만 하면 영상과 자막을 프로젝트로 내려받을 수 있고, 자동 자막은 `[Music]` 같은 표기를 지우고 단어 단위로 온전한 문장으로 다시 나눕니다. AI 정리는 한 페이지 목록으로 바뀌어 긴 프로젝트에서도 더 이상 실패하지 않습니다. PIP(화면 속 화면) 2트랙 재생이 더 매끄러워졌고, 모든 드롭다운 목록을 통일했으며, 창을 끌 때 마우스를 더 잘 따라오고, AI 설정은 저장하면 바로 적용됩니다. 또 프로젝트 라이브러리로 돌아온 뒤 검은 화면이 남던 문제, 큰 프로젝트 미리보기가 몇 초마다 멈칫하던 문제, "AI 텍스트 서비스 설정" 오른쪽이 잘리던 문제를 고쳤습니다. 설정과 인식 결과 형식은 바뀌지 않았으므로 이전 프로젝트도 그대로 열 수 있습니다.

#### 새 기능

- **링크로 영상과 자막 내려받기.** 홈의 미디어 영역과 자막 스튜디오 도구 모음 모두에 "Import from link"가 있습니다. YouTube 영상 링크를 붙여 넣고 화질(기본은 1080p 이하의 H.264이며, 해상도, 프레임 속도, 코덱, 크기를 보여 줌), 오디오 트랙, 자막을 고릅니다. 수동 자막, 원어 자동 자막, 자동 번역은 따로 나열되며, 원음 언어가 분명하면 원어가 기본으로 선택됩니다. "영상만", "오디오만", "자막만"으로도 받을 수 있습니다. 다 받으면 영상과 자막이 곧바로 현재 프로젝트(또는 새 프로젝트)에 들어가고 자막은 바로 고칠 수 있습니다. 영상, 자막, 출처가 함께 들어가며 실행 취소 한 단계입니다. 다운로드는 일시 정지 / 계속, 취소, 다시 시도를 할 수 있고, 진행 상황은 도구 모음의 다운로드 버튼 옆 작은 캡슐에 표시됩니다. 다운로드 창을 닫아도 계속 내려받습니다. 자막이 있으면 인식 모델을 먼저 설치할 필요가 없고, 유료 AI를 자동으로 호출하지도 않습니다. 다운로드에는 함께 들어 있는 yt-dlp 2026.10.21(공식 버전, 고정된 SHA-256으로 대조)을 씁니다.
- **자막 스튜디오의 Ctrl+V 빠른 붙여넣기 카드.** 브라우저에서 영상 링크를 복사한 뒤 자막 스튜디오로 돌아와 Ctrl+V를 누르면 오른쪽 위에 작은 카드가 뜹니다. 약 1초 안에 제목과 썸네일이 먼저 보이고 화질과 자막은 이어서 채워지며, Enter를 누르면 재생 헤드 위치로 내려받습니다. 끝나면 오른쪽 아래 알림에서 "Go to clip", "AI proofreading"을 쓸 수 있습니다. 클립보드에 영상 링크가 없거나 텍스트 칸에 입력하는 중이면 Ctrl+V는 평소처럼 붙여 넣습니다. 단축키는 "단축키" 설정에서 바꿀 수 있습니다.
- **YouTube 자막 자동 정리.** 내려받을 때와 가져올 때 `[Music]`, `♪`, `>>` 같은 표기를 지우고(표기만 있는 줄은 줄째 삭제), 영어(와 스페인어, 독일어, 프랑스어, 포르투갈어, 이탈리아어, 러시아어) 자동 자막은 단어 단위로 다시 나눕니다. 문장 끝을 우선하고, the / a / to 같은 단어 뒤에서는 끊지 않으며, 두 줄 이내, 한 개에 7초 이하로 하고, 긴 쉼에서는 반드시 끊습니다. 단어마다 시간이 유지되고 타임라인 자르기 도구가 단어 단위로 자르므로, 영어가 더 이상 글자 단위로 잘리지 않습니다. 다운로드 폴더의 SRT는 온전한 문장이며, 단어마다 시간이 붙은 `.words.vtt`를 따로 저장합니다. 원래 자막 파일(JSON3 / VTT / SRT)은 그대로 남겨 둡니다.
- **AI 정리를 한 페이지 목록으로.** 위에서 범위를 고르고 "Start tidying"을 누릅니다. 왼쪽 "Local tidy"는 표기를 지우고 단어 단위로 엄격하게 다시 나누며(AI를 쓰지 않고 바로 끝남), 오른쪽 "AI 교정"은 말버릇, 의미 없는 반복, 오탈자와 용어, 문장 부호를 다룹니다. 아래 목록에는 수정 하나하나와 그 시간, 종류(줄 나누기 / 삭제 / 텍스트)가 나옵니다. 지운 글자에는 취소선, 더한 글자에는 밑줄이 그어지고, 새로 나눈 곳에는 "｜"가 표시됩니다. 종류별로 거르거나 필요 없는 수정을 하나씩 해제할 수 있고, "Apply N" 전체가 실행 취소 한 단계입니다.

#### 개선

- **프로젝트가 길어서 AI 정리가 실패하는 일이 없어졌습니다.** 예전에는 "전체 프로젝트"를 고르면 "모델의 구조화된 출력이 길이 상한에 도달해 현재 결과가 완전하지 않습니다"라는 오류가 났습니다. 이제 범위 전체를 묶음으로 나눠 처리하고(묶음당 약 24개), 답이 여전히 너무 긴 묶음은 자동으로 더 작게 나눠 다시 시도합니다. 진행 상황은 "AI batch x / y · n found"로 표시되며 취소할 수 있습니다. 어느 묶음이 실패해도 이미 찾은 수정은 그대로 쓸 수 있습니다. 모든 프로젝트에서 백그라운드로 실행되어 화면이 멈추지 않습니다.
- **PIP 2트랙 1× 재생이 더 매끄럽습니다.** 같은 4K 60 Hz 컴퓨터에서 보조 화면이 초당 약 56장에서 약 59.5장의 서로 다른 화면으로 늘었고(주 화면은 약 60장), 화면과 소리의 차이 P95가 한 프레임(약 16.7 ms) 이내입니다. 백그라운드 품질 검사와 프로세스 검사 때문에 화면이 멈추지 않으며, 재생이 진행될 때마다 프로젝트 전체를 다시 분석하지도 않습니다.
- **큰 프로젝트 미리보기가 몇 초마다 멈칫하지 않습니다.** 자막 134개짜리 실제 프로젝트에서 전체 품질 검사가 약 30초에서 약 0.5초로 줄었고(결과는 같음), 별도의 백그라운드 프로세스에서 실행합니다.
- **드롭다운 목록 통일.** 프로그램의 모든 드롭다운 목록이 칸 아래쪽으로 열리고(아래에 3줄도 들어가지 않을 때만 위로), 줄 높이가 같으며, 최대 10줄을 보여 주고, 모서리만 둥글며 바깥에 네모 테두리가 없습니다.
- **창을 끌 때 마우스를 더 잘 따라옵니다.** 제목 표시줄 끌기, 최대화 상태에서 끌어 내리기(복원은 한 번만), 가장자리에 붙여 화면 분할(스냅), 가장자리를 끌어 크기 조절을 모두 Windows에 맡깁니다. 일반 창은 작업 표시줄 뒤까지 끌 수 있고 놓아도 튕겨 돌아오지 않습니다. 배율이 다른 여러 모니터 사이에서 끌어도 위치가 튀지 않습니다. 링크 다운로드 창과 AI 정리 창은 둥근 모서리 제목 표시줄로 바뀌었습니다.
- **AI 설정은 저장하면 바로 적용됩니다.** 홈의 "AI 줄 나누기" 상태와 다음 인식에 쓰는 서비스와 모델이 즉시 바뀌어 앱을 다시 시작할 필요가 없습니다. 진행 중인 작업은 시작할 때의 설정을 계속 씁니다.

#### 수정

- **자막 스튜디오에서 프로젝트 라이브러리로 돌아오면 원래 영상 자리에 검은 화면이 남던 문제.**
- **"AI 텍스트 서비스 설정"에서 "추가 옵션"을 펼치면 오른쪽이 잘리던 문제**(0.8.5 사용자 제보): 서비스 칸, Key 칸, "설정 저장"과 "줄 나누기 프롬프트"가 잘렸습니다. 이제 창이 적어도 양식만큼 넓고, 메인 창에 다 들어가지 않으면 가로로 스크롤됩니다. "프로토콜"은 "모델" 아래 줄로 옮겼습니다.
- AI 줄 나누기만 켰을 때 홈에서 AI가 꺼진 것으로 표시되던 문제, 서비스를 바꾼 뒤 숨겨진 교정 설정이 이전 값으로 덮어쓰이던 문제, Key를 지운 뒤 이전 연결 테스트 결과가 새 설정에 다시 기록되던 문제.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 "알 수 없는 게시자"가 표시될 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러, gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`를 확인하세요. 백신이나 시스템 보안을 끌 필요도 없고 꺼서도 안 됩니다.
- **링크 다운로드**는 YouTube 단일 영상만 지원합니다(재생목록, 일괄 다운로드, 로그인이 필요한 영상은 지원하지 않음). 다운로드는 YouTube와 네트워크 환경의 영향을 받으며, 중국 본토에서는 YouTube에 접속할 수 있어야 합니다. 이 기능의 화면은 중국어(간체), 중국어(번체), 영어, 일본어만 있고, 다른 화면 언어에서는 영어로 표시됩니다.
