# 兔白字幕 2ByteASR 0.8.8

本版汇总0.8.7之后已进入日常的字幕编辑、校对、试听、时间轴、失败阶段恢复、导出与GIF素材修订。Windows x64安装包与macOS Apple Silicon DMG将分别验证后提供。

- 样式顶部应用范围持续控制预设、数值、画面拖动和缩放；原文、译文独立，整批一次撤销。
- 校对关闭口吃整理后排除待处理重复建议；规范词列表简化，行级选择始终可用，筛选范围批量处理和撤销保留。
- 重试失败项按真实阶段执行并显示进度，保留成功结果和手工编辑，拒绝切工程及过期输入写回。
- 优化时间轴及批量变换，保留已有多语言、SRT和翻译能力；修订试听、导出返回、窗口客户区和GIF预览及成片。
- 模型工坊准备运行环境支持国内镜像与文件校验；修订Mac下拉选项点击。

已知限制：冷缓存首次操作仍可能停顿，5000条单次批量提交约0.7–0.8秒；不能保证稳定60FPS。未找到历史所述第二项及独立断句错误的保存记录。一个旧trace测试在基线同样失败。macOS实测结果及安装说明在发布前补齐，不将Windows结果外推到Mac。没有Windows Authenticode或Apple公证；保留既有SHA-256与Ed25519发布签名机制。
