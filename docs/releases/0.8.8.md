## 主要变化

- **“应用到”持续生效。** 当前、已选、说话人和全部范围，共同控制预设、属性数值、滑块及画面拖动/缩放。原文、译文独立；空选择不悄悄退回单条。数值按绝对值、拖动按共同位移、控制框按倍率处理，整批一次撤销。
- **批量操作和时间轴减少重复工作。** 复用几何、字形及绘制缓存，合并无关刷新，保留直接输入反馈。修订播放头、滚动、缩略图和波形缓存的更新路径。
- **校对开关和批量选择完整衔接。** 关闭口吃整理后，相关待处理建议退出展示、计数和应用集合，异步结果也按当前设置过滤；正常词库纠错保留。规范词主行只显示词本身；行级复选框一直可见，初始不全选，筛选范围全选、批量采用/忽略及撤销继续可用。
- **失败项按实际阶段重试。** 完成页展示真实任务、进度与原因，按校对、断句或翻译处理必要部分，复用成功结果。修订旧编号在删词、拆分或合并后错绑的问题；保存成功才更新状态，拒绝切工程、另存为和过期输入的迟到写回。
- **试听、导出返回和GIF素材。** 试听支持缓存、暂停/继续与离页清队列；导出结束或取消后归还播放器，保留选择和视口。GIF按帧时长和透明度参与预览、编辑、保存和成片。窗口客户区与实际绘制区对齐。
- **Mac载入与模型准备。** 合入此前已验证的暂停预载定位修复，迟到画面不会使播放位置0秒却显示0.67秒，从而卡在“准备播放器”。保留Mac下拉框点击修订，以及模型工坊的国内镜像、续传和文件校验。

## 仍有限制

- 冷缓存首轮和大工程批量提交仍可能短暂停顿。日常留下的5000条夹具测量约0.7–0.8秒单次提交，不保证全程稳定60FPS；这次原视频缺失，没有重新宣称该实视频的性能数据。
- 本页列的是实际执行的检查，不表示全仓测试全绿。打开或离开工作台仍可能短暂露出上一画面，长时复杂多轨及实体音频听审未完整复测；更多既有边界保留在项目记录中。
- Mac仍是实验版；没有用户实体Mac的完整硬件矩阵或听审。虚拟机没有VideoToolbox，硬件编码探针失败；软件导出通过。云端、Keychain、MLX及MPS大型模型检查未在本次请求中执行，不把SenseVoice结果外推到全部模型。
- Windows安装包没有Authenticode签名，Mac没有Apple公证。只使用本仓库下载，并核对SHA256SUMS与发布者签名；不需要关闭系统安全设置。

## 源码、许可与校验

`2ByteASR-Source-0.8.8.zip`包含对应Windows构建输入、Mac构建脚本与固定原生清单；`2ByteASR-ThirdParty-Materials-0.8.8.zip`包含许可材料。固定第三方上游源码沿用[v0.6.5的2ByteASR-0.5.0-ThirdParty-Sources.zip](https://github.com/NOTBAD314/2ByteASR/releases/download/v0.6.5/2ByteASR-0.5.0-ThirdParty-Sources.zip)，SHA-256为`86ad952378273423a1dbbf16725d1b995cb3ff123d67706ca212cfbc5a06ab06`；libiconv固定源码及原签名随本版附上。模型不预装，下载后遵守各自许可。

自有代码GPL-3.0-only，Remotion/GSAP既有GPL第7节附加许可记录于本版附件；保留原贡献者和第三方声明。源码附件本身不替代第三方上游源码，各自范围见许可材料。

`SHA256SUMS.txt`检查完整性；`.sig`为同一发布者Ed25519密钥的签名，key id `21f1cb35659cfffd`。`update`与组件ZIP用于程序内更新，通常无需手动下载。
