### 这一版有什么（相对 0.8.2）

这一版来自开发者日常使用的版本，0.8.2 之后两天的改动全部在内，大多来自用户回报：识别出问题时软件能说出原因，Studio 拆分更准，大工程改字幕不再一顿一顿，非中文字幕不再拆得很碎，首页和 AI 设置更好懂。工程文件、设置、识别结果的格式都没有变，旧工程可以直接打开。

#### 新增

- **识别完成 / 失败页的「排查原因」。** 识别失败或结果有问题时，结果卡上直接写“可能原因”，点「查看原因与解决办法」打开排查窗口；成功的任务从「更多操作 → 排查原因…」打开，识别历史的详情里也有。软件先按内置的已知问题清单（目前约 80 条，涵盖素材、运行环境与模型、在线识别、字词时间、AI 断句与校对、保存等）在本机核对这次的任务报告，写出可能原因、把握程度、报告里的依据、怎么做，以及可以直接点的按钮（选择字幕时间轴模型、设置 AI 与 API Key、重试、恢复结果、检查更新等）。本机检查**不发送任何内容**。需要时点「让 AI 分析」，把精简、脱敏后的报告（隐藏密钥、用户名和文件夹路径，发送前可以展开查看）交给你配置的文字 AI（与 AI 断句 / 校对用同一个 Key）；「复制排查报告 / 保存为文件」可以直接发给开发者。
- **按文字位置拆分字幕。** 在时间轴双击字幕（或右键「按文字位置拆分…」），把光标放在两个字之间按 Ctrl+Enter。每个字间位置都有可靠度：能单独切的直接拆在声音的边界（两个字之间有停顿就拆在停顿中间）；在一个词里面的，给出最近的词边界；不可靠的，先重新对齐这条字幕再判断。时间轴每条字幕下面多一条细线，表示实测的说话范围（字幕条本身仍是为了好读而提前、留尾巴的显示时间）。「重新对齐字词时间」现在所有有对齐器的语言都能用。
- **拆分双语字幕时译文跟着拆。** 以前刀片拆开一条日语字幕后，整句中文挂在前半句下、后半句没有中文；现在原译文按内容比例和标点分给两半，两半都标“需更新”（不发 AI 请求；合并回去恢复原句）。刀片点在一个字的声音中间时，切点移到这个字后面的停顿或下一个字开口处。
- **时间轴上单击选中译文，按 E 直接改**（Enter 提交，可撤销）。
- **断句提示词可以自己改**：「AI 文字服务设置」→「更多选项」。
- **新的模型下载窗口。** 看得到进度、速度、来源和正在做的事，卡住时直接写怎么办；MFA 运行环境也逐个包显示进度。

#### 改进

- **英语、韩语、日语和西、德、法、葡、意、俄语字幕改成“一句一条、最多两行”。** 以前每条只按一行算，稍长的句子被拆成三四段，中文翻译跟着碎；现在一条最多两行，放得下的句子保持一整条，更长的才拆，AI 给的断点断在介词、冠词、否定词后面就不用。日语把同一个人、同一句话里被拆开的相邻短字幕合回去；日语 AI 断句提示词改写。中文不变。
- **首页更好懂。** 识别方案只留四项：本地识别、API 转写（云端 MOSS Pro + 本机字词时间）、日语、外语；「自定义」只在你自己换了模型时出现。「AI 智能断句」改成识别方案下面的第四张卡：没连上 AI（没 Key、没测过或测试失败）时，这张卡和「内容与术语」整块变成蓝灰色，术语库校对、联网补充核验和翻译锁住，写明连上 AI 才能用；你原来的选择不会被改掉，连上后原样恢复。「测试连接」通过会被记住（只存服务、模型和 Key 的指纹，不存 Key）。
- **「AI 文字服务设置」改成左右分栏。** 左边按步骤引导（看教程注册复制 Key → 贴到右边 → 测试连接），测试通过后变成“接好了”的卡片和 AI 能帮你做的四件事；右边是服务、API Key 和测试连接，同一时刻只有一个主按钮；模型、地址、断句提示词等收进「更多选项」。
- **新手教学合成一套**，分「做字幕」「改字幕」两章，会真的打开 AI 设置窗口带你选服务、贴 Key、测试连接；换一步更快（约 0.6 → 0.39 秒），打开工作台时不再闪一下。
- **Studio「识别字幕」窗口重做**：左边识别方案和三行模型（名字、支持的语言、是否就绪，点一行换模型），右边这次识别的词库、翻译和唯一的「识别并替换当前字幕」；说话人跟随主力转写。
- **大工程改字幕不再一顿一顿。** 改一条字幕只重建这一条的预览，选中、查找、打开、正式保存不再把整份工程过一遍，自动恢复文件第一次写整份、之后只写增量。本机 2090 条双语工程（62 MB）照用户的方式连续改字幕：界面卡住（0.25 秒以上）88 次 / 44.6 秒 → 6 次 / 4.9 秒，改一条字幕 154 → 54 ms，查找第二个字 1.19 → 0.07 秒，内存 1,265 → 962 MB。
- **播放更顺**：时间轴跟随播放不再每一帧整条重画（140 秒播放 4,528 → 8 次），每到字幕开头不再卡一下；播放中跳转少解码一次；说话人管理打开快一倍；暂停后不再每次都整理内存。
- **中文选 MFA / Qwen3 做字幕时间轴时，字幕终于有实测的字级时间**（以前对齐结果在合并时被丢掉、按字数均分）；MFA（实验）普通话逐字切分改用 MFA 词典，不再把辅音切到相邻的字上。
- **云端识别更快**：人声检测与上传同时进行，翻译两批同时发，两个对齐器同时跑，MFA 进程数按音频长度定。
- **工作台分隔条可以自由拖动，视频随拖动实时变化**；1080p 屏上上下分隔条的活动范围从 54 px 变成 317 px，小窗口里审核条不再压住候选卡。
- **默认字幕轨更少**：只给字幕最多的两位说话人各一条轨，其他人合成一条（「应用设置」可改成 1/2/3/5/8）。
- **程序内更新**：某个来源连得上但一直很慢时，自动从已下载的位置换到下一个来源续传；「检查更新失败」框同时给 GitHub 和 GitCode 发布页。
- **MFA 模型多了 ModelScope 来源**：大陆网络可以直接从 ModelScope 下载（0.8.2 只能从 Hugging Face 下）；中文分词模型下载慢时换来源续传。
- 识别历史的报告 JSON 可以“另存为…”（太大的报告不要粘贴进聊天软件）；「字幕简繁转换」移进「双语 / 翻译」菜单。

#### 修正

- **话少的长段让整份字幕在最后一步失败**（`字幕保真检查未通过`）：没有逐字时间、字很少的一段只能一字一条时，单独的“两”被当成数字 2，核对判定数字被改。现在数字和后面的字放进同一条，文字一个字都不改。
- **日语用 SenseVoice 识别整集时在“本地规则全文断句”失败**：相邻识别块共用的 0.5 秒让两段时间重叠、字幕顺序被打乱。现在增量识别和整段识别的重叠都从中间分开（已缓存的结果也一样）。打包程序里一块只有背景音、没认出字的片段不再让增量识别整个作废。
- **俄语等在“云端模型断句”整段失败**：对齐模型给出超出本句的单词时间时不用；万一某句仍切不出合格的字幕，只这一句保留整条并提示，任务不再失败。
- **打开工程时闪退**：最可能的原因是后台线程整理内存时删掉了窗口对象，现在只在界面线程整理（原因是推断，没有拿到原生崩溃记录）。**编辑字幕时点别处提交**会报错、卡住甚至闪退，已修正。
- 首页模型卡在 120% 缩放下名字叠到下一行；窗口宽度正好卡在两档之间时模型卡来回换档、程序直接退出。
- 开了“联网补充核验”、没开文字校对时，任务跑完才失败（`Text AI stage is disabled for this task: polish`）；现在跳过联网核验并写明原因。
- 主窗口几乎和屏幕一样高时，往下拖会弹回原处、来回抽动。
- Studio「识别字幕」展开高级配置后三行模型被压扁。

### 已经装过旧版本

- **0.8.2**：主界面右上角“检查更新”。只下载约 59 MB（程序本身），其余部分沿用已装的。
- **0.7.0–0.8.1**：同样用“检查更新”。这些版本还要补上 0.8.2 换过的随附 FFmpeg、Python 运行库与离线安装包，共约 890 MB，和重新下载 Setup 差不多；**0.6.5** 还要多下载渲染器（共约 1.13 GB）。

- 下载可以断点续传；下载后校验，等你保存工程并同意退出后才替换；失败会自动恢复原版本。设置、词库、工程、已下载的模型与运行环境都保留，不需要重新准备。
- **0.6.0 及更早**：关闭兔白字幕，运行 0.8.3 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：还没有程序内更新。退出旧版，打开新的 DMG，把 App 拖进“应用程序”替换即可；设置、模型和工程存放在 App 以外的用户资料夹。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases（或上面的 GitCode 镜像、gh-proxy 链接）下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **「排查原因」的清单只认识已经遇到过的问题**；新问题会写“没找到明确原因”，这时可以用「让 AI 分析」或把排查报告发给开发者。报告里没有记录程序版本，所以清单里“哪一版修好”只能按日期写。
- **进字幕工作台时偶尔闪退**（开发者 10-22 遇到两次，都在第一次建工作台页面时）没能复现，这一版只改了两处可疑的地方，没有确认修好。
- **大工程仍有残留的等待**：打开时的一致性检查约 0.3 秒，启动时建工作台页面约 2 秒；改默认样式、切换双语显示或说话人姓名版面仍会整份重建字幕预览（300 条以上在后台做，不卡界面，但新预览要等几秒）。
- **英语没有用 FireRedASR2 给字词时间**：中文以外的语言一律由 Qwen3 对齐器给时间。
- **日语**：只有词级切点，按文字位置拆分在日语里只能切在词边界。
- **首页识别方案卡上「FireRedASR2-AED」的名字**在 1700×1080、界面缩放 120% 时被裁掉半行。
- **界面翻译**：新窗口的文字在 10 种界面语言都有译文，繁体中文按字转换；英文以外的语言没有在真实窗口里看过。
- **MFA（实验）**：日语准确度一般；只支持 Windows。
- **已有工程不会自动套用新的断句和时间轴修正**，要重新识别（会沿用缓存）。
- **Mac 是实验版**：这一版的新功能没有在 Mac 上单独检查；MFA 只针对 Windows。
- **Claude**：Anthropic 官方支持的地区不含中国大陆、香港、澳门。

### What is new in this release (compared with 0.8.2)

This release comes from the version the developer uses every day and includes all changes from the two days since 0.8.2. Most of them come from user reports: when recognition goes wrong, the app can now tell you why; splitting in Studio is more accurate; editing subtitles in large projects no longer stutters; subtitles in languages other than Chinese are no longer chopped into tiny pieces; and Home and the AI settings are easier to understand. Project, settings and recognition-result formats are unchanged, so older projects open as they are.

#### New

- **"Troubleshoot" on the recognition finished / failed page.** When recognition fails or the result has problems, the result card says "Possible cause" right away; click "See cause and fix" to open the troubleshooting window. For a task that succeeded, open it from "More actions → Troubleshoot…"; it is also in the details in Recognition history. The app first checks this task's report on your computer against a built-in list of known problems (about 80 so far, covering media, the runtime and models, online recognition, word timing, AI line breaking and proofreading, saving and more). It then writes down the possible cause, how sure it is, the evidence from the report, what to do, and buttons you can click right there (choose a subtitle timeline model, set up AI and the API key, retry, recover results, check for updates, and more). The local check **sends nothing**. When you need more, click "Ask AI to analyze": it gives a shortened, redacted report (keys, user names and folder paths hidden; you can expand it and look before sending) to the text AI you configured (the same key as AI line breaking / proofreading). With "Copy troubleshooting report / Save as file" you can send the report straight to the developer.
- **Split subtitles at a text position.** Double-click a subtitle on the timeline (or right-click → "Split at a text position…"), put the cursor between two characters and press Ctrl+Enter. Every position between characters has a reliability rating: where it can be cut on its own, the split goes right on the boundary in the sound (when there is a pause between the two characters, in the middle of the pause); inside a word, you get the nearest word boundary; where it is unreliable, the subtitle is aligned again first and then checked. Each subtitle on the timeline now has a thin line under it that shows the measured speech range (the subtitle bar itself is still the display time, which starts a little early and keeps a tail so it is easier to read). "Re-align word timing" now works in every language that has an aligner.
- **Splitting a bilingual subtitle splits its translation too.** Before, after you cut a Japanese subtitle with the razor tool, the whole Chinese sentence stayed under the first half and the second half had no Chinese. Now the original translation is divided between the two halves by content proportion and punctuation, and both halves are marked "needs update" (no AI request is sent; merging them back restores the original sentence). When the razor lands in the middle of a character's sound, the cut point moves to the pause after that character or to where the next character starts.
- **Click a translation on the timeline to select it, then press E to edit it directly** (Enter commits; it can be undone).
- **You can edit the line-breaking prompt yourself**: "AI text service settings" → "More options".
- **A new model download window.** It shows progress, speed, source and what it is doing right now, and when something gets stuck it tells you what to do; the MFA runtime also shows progress package by package.

#### Improved

- **Subtitles in English, Korean, Japanese, Spanish, German, French, Portuguese, Italian and Russian are now "one sentence per subtitle, at most two lines".** Before, each subtitle was counted as a single line, so slightly longer sentences were split into three or four pieces, and the Chinese translation was chopped up with them. Now a subtitle can have up to two lines: a sentence that fits stays as one subtitle, only longer ones are split, and break points the AI suggests right after a preposition, an article or a negation are not used. In Japanese, short neighboring subtitles split from the same sentence of the same person are merged back; the Japanese AI line-breaking prompt was rewritten. Chinese is unchanged.
- **Home is easier to understand.** Only four recognition plans are left: "Local recognition", "API transcription" (MOSS Pro in the cloud + word timing on this computer), "Japanese" and "Other languages"; "Custom" appears only when you have changed models yourself. "AI smart segmentation" is now the fourth card below the recognition plans. When AI is not connected (no key, not tested, or the test failed), this card and the whole "Content & terms" area turn blue-gray, and term-library proofreading, additional web verification and translation are locked, with a note that they work only once AI is connected. Your earlier choices are not changed and come back as they were once AI is connected. A passed "Test connection" is remembered (only a fingerprint of the service, model and key is stored, never the key itself).
- **"AI text service settings" now has two columns.** The left side guides you step by step (watch the tutorial, sign up and copy the key → paste it on the right → test the connection); after the test passes, it turns into a "connected" card with the four things AI can do for you. The right side has the service, the API key and "Test connection", with only one main button at any time; the model, endpoint, line-breaking prompt and so on are tucked into "More options".
- **The beginner tutorials are merged into one**, with two chapters, "Make subtitles" and "Fix subtitles". It really opens the AI settings window and walks you through choosing a service, pasting the key and testing the connection. Moving to the next step is faster (about 0.6 → 0.39 s), and opening Studio no longer flashes.
- **The Studio "Transcribe captions" window was redone**: on the left, the recognition plan and three rows of models (name, supported languages, whether it is ready; click a row to change the model); on the right, the term libraries and translation for this recognition and a single "Transcribe and Replace Subtitles" button. Speakers follow the primary transcription.
- **Editing subtitles in large projects no longer stutters.** Changing one subtitle rebuilds the preview of that subtitle only; selecting, finding, opening and a regular save no longer go through the whole project; the auto-recovery file is written in full the first time and only the changes after that. On the developer's computer, editing subtitles one after another the way the user does in a 2090-subtitle bilingual project (62 MB): interface freezes (0.25 s or longer) went from 88 times / 44.6 s to 6 times / 4.9 s; changing one subtitle from 154 to 54 ms; typing the second character in Find from 1.19 to 0.07 s; memory from 1,265 to 962 MB.
- **Smoother playback**: while following playback, the timeline no longer redraws the whole strip on every frame (140 seconds of playback: 4,528 → 8 times), and it no longer hitches each time a subtitle starts; jumping during playback decodes one time fewer; Speaker Management opens twice as fast; memory is no longer tidied up every time you pause.
- **When you choose MFA / Qwen3 as the subtitle timeline for Chinese, subtitles finally get measured character-level timing** (before, the alignment results were dropped during merging and the time was split evenly by character count). MFA (experimental) now uses the MFA dictionary to split Mandarin character by character, and no longer cuts consonants onto the neighboring characters.
- **Faster cloud recognition**: voice detection and uploading run at the same time, translation sends two batches at once, the two aligners run at the same time, and the number of MFA processes depends on the length of the audio.
- **The dividers in Studio can be dragged freely, and the video changes live as you drag.** On a 1080p screen, the range of the divider between the top and bottom parts went from 54 px to 317 px, and in small windows the review bar no longer covers the candidate cards.
- **Fewer subtitle tracks by default**: only the two speakers with the most subtitles get a track each, and everyone else shares one track (you can change this to 1/2/3/5/8 in "App Settings").
- **In-app updates**: when a source connects but stays slow, the download switches to the next source automatically and continues from where it got to; the "Update check failed" box shows both the GitHub and the GitCode release pages.
- **MFA models gain a ModelScope source**: in mainland China you can download them directly from ModelScope (0.8.2 could only download them from Hugging Face); when the Chinese word-segmentation model downloads slowly, it switches source and resumes.
- The report JSON in Recognition history can now be saved with "Save As…" (do not paste very large reports into chat apps); "Subtitle Simplified/Traditional conversion" (字幕简繁转换) moved into the "Bilingual / Translation" (双语 / 翻译) menu.

#### Fixed

- **A long stretch with little speech made the whole subtitle file fail at the last step** (`字幕保真检查未通过`). When a stretch with no character timing and very few characters could only be split one character per subtitle, a lone "两" ("two") was taken as the number 2, and the check decided that a number had been changed. Now a number goes into the same subtitle as the character after it, and not a single character of the text is changed.
- **Recognizing a whole Japanese episode with SenseVoice failed at "Full-text line breaking with local rules".** The 0.5 seconds shared by neighboring recognition chunks made two segments overlap in time and mixed up the order of the subtitles. Now overlaps are split down the middle in both incremental and full recognition (cached results too). In the packaged app, a chunk that has only background sound and no recognized words no longer makes the whole incremental recognition invalid.
- **For Russian and some other languages, the whole "Cloud model line breaking" step failed.** Word timings from the alignment model that go beyond the current sentence are no longer used; if a sentence still cannot be cut into proper subtitles, only that sentence is kept as one subtitle with a notice, and the task no longer fails.
- **Crash when opening a project.** The most likely cause is that a background thread deleted window objects while tidying up memory; now this tidying happens only on the interface thread (the cause is inferred; no native crash record was obtained). **Committing an edit by clicking elsewhere while editing a subtitle** could show an error, freeze or even crash the app; this is fixed.
- On Home, model card names ran onto the next line at 120% zoom; when the window width sat exactly between two layout steps, the model cards switched back and forth and the app quit.
- With "Additional web verification" on and text proofreading off, the task failed only after it had run to the end (`Text AI stage is disabled for this task: polish`); now web verification is skipped and the reason is written down.
- When the main window was almost as tall as the screen, dragging it down made it snap back and jitter back and forth.
- In the Studio "Transcribe captions" window, the three model rows were squashed after you expanded the advanced settings.

### Known limitations

- **No code signing.** Windows may show "Unknown publisher"; the Mac app is not notarized. Download only from this repository's Releases (or the GitCode mirror / gh-proxy links above) and check `SHA256SUMS.txt`; you do not need to, and should not, turn off antivirus or system security.
- **The "Troubleshoot" list only knows problems that have been seen before.** For a new problem it says that no clear cause was found; then you can use "Ask AI to analyze" or send the troubleshooting report to the developer. The report does not record the app version, so in the list, "which version fixed it" can only be given as a date.
- **The app occasionally crashes when you open Studio** (the developer ran into it twice on 10-22, both times while the Studio page was being built for the first time). This could not be reproduced; this release only changes two suspicious places, and it is not confirmed fixed.
- **Large projects still have some waiting left**: the consistency check when a project opens takes about 0.3 s, and building the Studio page at startup about 2 s. Changing the default style, or switching the bilingual display or the speaker-name layout, still rebuilds the whole subtitle preview (with 300 subtitles or more this runs in the background and does not freeze the interface, but the new preview takes a few seconds).
- **English does not get word timing from FireRedASR2**: all languages other than Chinese get their timing from the Qwen3 aligner.
- **Japanese**: there are only word-level cut points, so in Japanese, splitting at a text position can only cut at word boundaries.
- **The name "FireRedASR2-AED" on the recognition plan card on Home** is cut off by half a line at 1700×1080 with 120% interface zoom.
- **Interface translations**: the text in the new windows is translated into all 10 interface languages, and Traditional Chinese is converted character by character; languages other than English have not been looked at in real windows.
- **MFA (experimental)**: Japanese accuracy is mediocre; Windows only.
- **Existing projects do not pick up the new line-breaking and timeline fixes automatically**; recognize them again (the cache is reused).
- **The Mac build is experimental**: the new features in this release were not checked separately on Mac; MFA is for Windows only.
- **Claude**: Anthropic's supported regions do not include mainland China, Hong Kong or Macau.
- **The Docker version is still 0.8.1** ([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)); this release does not update the Docker image.
- The other known limitations in the 0.8.2 and earlier release notes still apply.

### このバージョンの新しい点（0.8.2 との比較）

このバージョンは開発者が日常的に使っている版から作ったもので、0.8.2 以降 2 日間の変更をすべて含みます。その多くはユーザーからの報告によるものです：認識で問題が起きたときにアプリが原因を説明できるようになり、字幕スタジオでの分割がより正確になり、大きなプロジェクトで字幕を直してもカクカクしなくなり、中国語以外の字幕が細かく分かれすぎなくなり、ホームと AI 設定がわかりやすくなりました。プロジェクトファイル、設定、認識結果の形式は変わっていないので、古いプロジェクトもそのまま開けます。

#### 新機能

- **認識の完了／失敗ページに「原因を調べる」。** 認識が失敗したときや結果に問題があるときは、結果カードに「考えられる原因」が直接書かれ、「原因と対処法を見る」を押すと調査ウィンドウが開きます。成功したタスクでは「その他の操作 → 原因を調べる…」から開け、認識記録の詳細にもあります。アプリはまず内蔵の既知の問題リスト（現在約 80 項目。素材、実行環境とモデル、オンライン認識、文字・単語のタイミング、AI 文分割と校正、保存などを含みます）に照らして、今回のタスクのレポートをこの PC 上で確認し、考えられる原因、確からしさ、レポート内の根拠、対処方法と、そのまま押せるボタン（字幕タイムラインのモデルを選択、AI と API キーを設定、再試行、結果の復元、更新を確認など）を示します。この PC での確認では**何も送信しません**。必要なときは「AI で分析」を押すと、要点だけにまとめて個人情報を伏せたレポート（キー、ユーザー名、フォルダーのパスを隠します。送信前に展開して中身を確認できます）を、あなたが設定したテキスト AI（AI 文分割／校正と同じキー）に渡します。「トラブルシューティングレポートをコピー」／「ファイルに保存」で、そのまま開発者に送れます。
- **文字の位置で字幕を分割。** タイムラインで字幕をダブルクリック（または右クリックの「文字の位置で分割…」）し、2 つの文字の間にカーソルを置いて Ctrl+Enter を押します。文字と文字の間の位置ごとに信頼度があります：単独で切れる位置では、そのまま音の境目で分割します（2 つの文字の間に途切れがあれば、その途切れの真ん中で分割）。単語の途中にある位置では、いちばん近い単語の境目を示します。信頼できない位置では、まずこの字幕を再アラインしてから判断します。タイムラインでは各字幕の下に細い線が 1 本加わり、実測した発話の範囲を示します（字幕バー自体は、読みやすさのために少し早めに始まり、後ろに余裕を残した表示時間のままです）。「単語の時間を再アライン」は、アライナーがあるすべての言語で使えるようになりました。
- **二言語字幕を分割すると、訳文も一緒に分割。** 以前はカッターツールで日本語の字幕を分割すると、文全体の中国語訳が前半の下に付き、後半には中国語訳がありませんでした。今は元の訳文を内容の割合と句読点に従って 2 つに分け、両方に「要更新」の印を付けます（AI へのリクエストは送りません。結合し直すと元の文に戻ります）。カッターツールで 1 文字の音の途中をクリックしたときは、切る位置をその文字の後ろの途切れか、次の文字の話し始めに移します。
- **タイムラインで訳文をクリックして選び、E キーでそのまま編集**（Enter で確定、元に戻せます）。
- **文分割のプロンプトを自分で編集できます**：「AI テキストサービス設定」→「その他のオプション」。
- **新しいモデルのダウンロードウィンドウ。** 進捗、速度、ダウンロード元、いま何をしているかが見え、止まったときはどうすればよいかが直接書かれます。MFA の実行環境もパッケージごとに進捗を表示します。

#### 改善

- **英語、韓国語、日本語と、スペイン語・ドイツ語・フランス語・ポルトガル語・イタリア語・ロシア語の字幕を「1 文 1 件、最大 2 行」に変更。** 以前は 1 件を 1 行として計算していたため、少し長い文が 3〜4 つに分かれ、中国語訳も一緒に細切れになっていました。今は 1 件が最大 2 行で、収まる文は 1 件のまま保ち、それより長い文だけを分けます。AI が出した区切り位置が前置詞、冠詞、否定語の直後にある場合は使いません。日本語では、同じ人の同じ文なのに分かれてしまった隣り合う短い字幕を結合し直します。日本語の AI 文分割プロンプトも書き直しました。中国語は変わりません。
- **ホームがわかりやすくなりました。** 認識プランは「ローカル認識」「API転写」（クラウドの MOSS Pro + この PC での文字・単語のタイミング）「日本語」「外国語」の 4 つだけになり、「カスタム」は自分でモデルを変えたときだけ表示されます。「AI自動文分割」は認識プランの下の 4 枚目のカードになりました：AI につながっていない（キーがない、テストしていない、テストに失敗した）ときは、このカードと「コンテンツと用語」のブロック全体がブルーグレーになり、「用語集で校正」「追加のWeb検証」と翻訳がロックされ、AI に接続すると使えることが明記されます。元の選択は変更されず、接続すればそのまま戻ります。「接続テスト」に合格すると記憶されます（サービス、モデル、キーの指紋だけを保存し、キー自体は保存しません）。
- **「AI テキストサービス設定」を左右 2 列に変更。** 左側は手順に沿って案内し（チュートリアルを見ながら登録してキーをコピー → 右側に貼り付け → 接続テスト）、テストに合格すると「接続しました」のカードと、AI が手伝える 4 つのことの紹介に変わります。右側はサービス、API キー、接続テストで、メインのボタンは常に 1 つだけです。モデル、アドレス、文分割のプロンプトなどは「その他のオプション」にまとめました。
- **はじめてのチュートリアルを 1 つにまとめ**、「字幕を作る」「字幕を直す」の 2 章に分けました。実際に AI 設定ウィンドウを開いて、サービスの選択、キーの貼り付け、接続テストを案内します。次の手順への切り替えが速くなり（約 0.6 → 0.39 秒）、字幕スタジオを開くときに画面が一瞬ちらつかなくなりました。
- **字幕スタジオの「字幕を認識」ウィンドウを作り直しました**：左側に認識プランと 3 行のモデル（名前、対応言語、準備ができているか。行をクリックするとモデルを変更）、右側に今回の認識で使う用語辞書、翻訳と、ただ 1 つのボタン「認識して字幕を置き換え」があります。話者はメインの文字起こしに従います。
- **大きなプロジェクトで字幕を直しても、カクカクしなくなりました。** 字幕を 1 件直すと、その 1 件のプレビューだけを作り直します。選択、検索、開く、通常の保存でプロジェクト全体を処理し直さなくなり、自動復元ファイルは最初に全体を書き込み、その後は差分だけを書き込みます。開発者の PC で、2090 件の二言語プロジェクト（62 MB）をユーザーと同じやり方で続けて編集したところ：画面が止まる（0.25 秒以上）のが 88 回 / 44.6 秒 → 6 回 / 4.9 秒、字幕 1 件の修正が 154 → 54 ms、検索で 2 文字目を入力したときが 1.19 → 0.07 秒、メモリが 1,265 → 962 MB になりました。
- **再生がなめらかに**：再生に合わせてタイムラインが動くとき、毎フレーム全体を描き直さなくなり（140 秒の再生で 4,528 → 8 回）、字幕の始まりに来るたびに一瞬止まることもなくなりました。再生中のジャンプでデコードが 1 回減りました。「話者管理」が 2 倍速く開きます。一時停止のたびにメモリを整理することはなくなりました。
- **中国語で字幕タイムラインに MFA／Qwen3 を選んだとき、字幕にようやく実測した文字単位のタイミングが入るようになりました**（以前はアライメントの結果が結合の段階で捨てられ、文字数で均等に割り振られていました）。MFA（実験的）の標準中国語の 1 文字ずつの区切りには MFA の辞書を使うようになり、子音を隣の文字に切り分けてしまうことがなくなりました。
- **クラウド認識が速くなりました**：人の声の検出とアップロードを同時に行い、翻訳は 2 バッチを同時に送り、2 つのアライナーを同時に動かし、MFA のプロセス数は音声の長さで決めます。
- **字幕スタジオの区切り線を自由にドラッグでき、ドラッグに合わせて映像がリアルタイムに変わります**。1080p の画面では上下の区切り線を動かせる範囲が 54 px から 317 px になり、小さいウィンドウでもレビューバーが候補カードに重ならなくなりました。
- **既定の字幕トラックを減らしました**：字幕がいちばん多い 2 人の話者にだけそれぞれ 1 トラックを割り当て、ほかの人は 1 トラックにまとめます（「アプリ設定」で 1/2/3/5/8 に変更できます）。
- **アプリ内更新**：あるダウンロード元に接続はできてもずっと遅いときは、ダウンロード済みの位置から次のダウンロード元に自動で切り替えて続きを取得します。「更新の確認に失敗しました」のメッセージボックスには、GitHub と GitCode の両方のリリースページを載せます。
- **MFA のモデルに ModelScope のダウンロード元を追加**：中国本土のネットワークから ModelScope で直接ダウンロードできます（0.8.2 では Hugging Face からしかダウンロードできませんでした）。中国語の単語分割モデルのダウンロードが遅いときは、ダウンロード元を切り替えて続きを取得します。
- 認識記録のレポート JSON を「名前を付けて保存…」できるようになりました（大きすぎるレポートはチャットアプリに貼り付けないでください）。「字幕の簡体字・繁体字変換」（字幕简繁转换）は「バイリンガル / 翻訳」（双语 / 翻译）メニューに移りました。

#### 修正

- **発話の少ない長い区間のせいで、字幕全体が最後の段階で失敗する問題**（`字幕保真检查未通过`）。文字ごとのタイミングがなく、文字がとても少ない区間を 1 文字 1 件にするしかないとき、単独の「两」が数字の 2 と見なされ、照合で数字が書き換えられたと判定されていました。今は数字とその後ろの文字を同じ字幕に入れ、文字は 1 文字も変えません。
- **日本語を SenseVoice で 1 話まるごと認識すると「ローカル規則による全文の文分割」で失敗する問題**：隣り合う認識ブロックが共有する 0.5 秒のせいで 2 つの区間の時間が重なり、字幕の順番が乱れていました。今は増分認識でも区間全体の認識でも、重なりを真ん中で分けます（キャッシュ済みの結果も同様です）。パッケージ版のプログラムで、背景音だけで文字が認識されなかったブロックがあっても、増分認識全体が無効にならなくなりました。
- **ロシア語などで「クラウドモデルによる文分割」の段階全体が失敗する問題**：アライメントモデルがその文の範囲を超える単語のタイミングを返したときは、それを使わないようにしました。それでもある文から条件を満たす字幕を切り出せない場合は、その文だけを 1 件のまま残して知らせ、タスクは失敗しなくなりました。
- **プロジェクトを開くときにアプリが突然終了する問題**：最も可能性が高い原因は、バックグラウンドのスレッドがメモリを整理するときにウィンドウのオブジェクトを削除してしまうことで、今は UI のスレッドでのみ整理します（原因は推測で、ネイティブのクラッシュ記録は得られていません）。**字幕の編集中に別の場所をクリックして確定すると**、エラーが出る、固まる、さらにはアプリが突然終了することがありましたが、修正しました。
- ホームのモデルカードで、UI の拡大率 120% のとき名前が次の行に重なる問題。ウィンドウの幅がちょうど 2 つの段階の境目にあるとき、モデルカードの表示段階が行ったり来たりして、アプリがそのまま終了する問題。
- 「追加のWeb検証」をオンにして文章の校正をオフにしていると、タスクが最後まで進んでから失敗する問題（`Text AI stage is disabled for this task: polish`）。今は Web 検証をスキップし、その理由を表示します。
- メインウィンドウの高さが画面とほぼ同じとき、下にドラッグすると元の位置に跳ね返り、行ったり来たり小刻みに動く問題。
- 字幕スタジオの「字幕を認識」で詳細設定を開くと、3 行のモデルが押しつぶされる問題。

이번 버전은 개발자가 날마다 쓰는 버전에서 나왔으며, 0.8.2 이후 이틀 동안의 변경을 모두 담았습니다. 대부분은 사용자가 알려 준 내용입니다. 인식에 문제가 생기면 앱이 원인을 알려 주고, 자막 스튜디오의 자막 분할이 더 정확해졌으며, 큰 프로젝트에서 자막을 고칠 때 더 이상 뚝뚝 끊기지 않고, 중국어가 아닌 자막이 잘게 쪼개지지 않으며, 홈과 AI 설정이 더 알기 쉬워졌습니다. 프로젝트 파일, 설정, 인식 결과 형식은 바뀌지 않았으므로 이전 프로젝트도 그대로 열 수 있습니다.

#### 새 기능

- **인식 완료 / 실패 페이지의 "원인 찾기".** 인식이 실패하거나 결과에 문제가 있으면 결과 카드에 "가능한 원인"이 바로 적히고, "원인과 해결 방법 보기"를 누르면 원인 찾기 창이 열립니다. 성공한 작업은 "더 많은 작업 → 원인 찾기…"에서 열 수 있고, 인식 기록의 상세 정보에도 있습니다. 앱은 먼저 내장된 알려진 문제 목록(현재 약 80개. 소재, 실행 환경과 모델, 온라인 인식, 글자·단어 타이밍, AI 줄 나누기와 교정, 저장 등을 다룸)으로 이번 작업 보고서를 이 컴퓨터에서 대조하고, 가능한 원인, 확신 정도, 보고서 속 근거, 해결 방법, 그리고 바로 누를 수 있는 버튼(자막 타임라인 모델 선택, AI 및 API Key 설정, 다시 시도, 결과 복구, 업데이트 확인 등)을 적어 줍니다. 이 컴퓨터에서 하는 검사는 **아무것도 보내지 않습니다**. 필요하면 "AI에게 분석 맡기기"를 눌러, 줄이고 민감한 정보를 가린 보고서(키, 사용자 이름, 폴더 경로를 숨기며 보내기 전에 펼쳐 볼 수 있음)를 직접 설정한 텍스트 AI에 보냅니다(AI 줄 나누기 / 교정과 같은 키를 씀). "문제 해결 보고서 복사 / 파일로 저장"으로 만든 보고서는 그대로 개발자에게 보낼 수 있습니다.
- **텍스트 위치에서 자막 나누기.** 타임라인에서 자막을 더블클릭하고(또는 오른쪽 클릭 → "텍스트 위치에서 나누기…") 커서를 두 글자 사이에 둔 뒤 Ctrl+Enter를 누릅니다. 글자 사이의 위치마다 신뢰도가 매겨집니다. 따로 자를 수 있는 위치는 바로 소리의 경계에서 나누고(두 글자 사이에 쉬는 틈이 있으면 그 틈의 가운데에서 나눔), 한 단어 안이면 가장 가까운 단어 경계를 제시하며, 믿기 어려운 위치는 먼저 그 자막을 다시 정렬한 뒤 판단합니다. 타임라인의 자막마다 아래에 가는 선이 하나 더 생겼는데, 실제로 측정한 말소리 범위를 나타냅니다(자막 막대 자체는 여전히 읽기 편하도록 조금 일찍 나타나고 꼬리를 남기는 표시 시간입니다). "단어 타이밍 다시 정렬"은 이제 정렬기가 있는 모든 언어에서 쓸 수 있습니다.
- **이중 언어 자막을 나누면 번역문도 함께 나뉩니다.** 예전에는 자르기 도구로 일본어 자막 하나를 자르면 중국어 번역 전체가 앞쪽 아래에만 붙고 뒤쪽에는 중국어가 없었습니다. 이제는 원래 번역문을 내용 비율과 문장 부호에 따라 두 쪽에 나누어 주고, 두 쪽 모두 "업데이트 필요"로 표시합니다(AI 요청은 보내지 않음. 다시 병합하면 원래 문장으로 돌아옴). 자르기 도구로 한 글자의 소리 중간을 클릭하면, 자르는 위치가 그 글자 뒤의 쉬는 틈이나 다음 글자가 시작되는 곳으로 옮겨집니다.
- **타임라인에서 번역문을 한 번 클릭해 선택하고 E를 누르면 바로 고칠 수 있습니다**(Enter로 확정, 실행 취소 가능).
- **줄 나누기 프롬프트를 직접 고칠 수 있습니다**: "AI 텍스트 서비스 설정" → "추가 옵션".
- **새 모델 다운로드 창.** 진행률, 속도, 출처와 지금 하고 있는 일이 보이고, 멈추면 어떻게 하면 되는지 바로 적어 줍니다. MFA 실행 환경도 패키지마다 진행률을 표시합니다.

#### 개선

- **영어, 한국어, 일본어와 스페인어·독일어·프랑스어·포르투갈어·이탈리아어·러시아어 자막이 "한 문장에 자막 하나, 최대 두 줄"로 바뀌었습니다.** 예전에는 자막 하나를 한 줄로만 계산해서 조금 긴 문장도 서너 조각으로 나뉘었고, 중국어 번역도 따라서 조각났습니다. 이제 자막 하나는 최대 두 줄이며, 들어가는 문장은 한 자막으로 두고 더 긴 문장만 나눕니다. AI가 준 나누는 위치가 전치사, 관사, 부정어 바로 뒤라면 쓰지 않습니다. 일본어는 같은 사람의 같은 문장에서 쪼개진 이웃한 짧은 자막을 다시 합치고, 일본어 AI 줄 나누기 프롬프트를 새로 썼습니다. 중국어는 바뀌지 않습니다.
- **홈이 더 알기 쉬워졌습니다.** 인식 구성은 네 가지만 남았습니다: 로컬 인식, API 전사(클라우드 MOSS Pro + 이 컴퓨터의 글자·단어 타이밍), 일본어, 외국어. "사용자 지정"은 직접 모델을 바꿨을 때만 나타납니다. "AI 줄 나누기"는 인식 구성 아래의 네 번째 카드가 되었습니다. AI에 연결되지 않았을 때(키가 없거나, 테스트하지 않았거나, 테스트에 실패한 경우) 이 카드와 "콘텐츠 및 용어" 전체가 청회색으로 바뀌고, 용어집 교정, 추가 웹 검증, 번역이 잠기며, AI를 연결해야 쓸 수 있다고 적어 줍니다. 원래 고른 설정은 바뀌지 않으며, 연결하면 그대로 돌아옵니다. "연결 테스트"를 통과한 사실은 기억됩니다(서비스, 모델, 키의 지문만 저장하고 키는 저장하지 않음).
- **"AI 텍스트 서비스 설정"이 왼쪽·오른쪽 두 칸으로 바뀌었습니다.** 왼쪽은 단계별로 안내하고(튜토리얼을 보며 가입해 키 복사 → 오른쪽에 붙여 넣기 → 연결 테스트), 테스트를 통과하면 "연결 완료" 카드와 AI가 도와줄 수 있는 네 가지 일로 바뀝니다. 오른쪽에는 서비스, API 키, 연결 테스트가 있고, 한 번에 주 버튼은 하나만 있습니다. 모델, 주소, 줄 나누기 프롬프트 등은 "추가 옵션" 안으로 들어갔습니다.
- **초보자 튜토리얼을 하나로 합쳤습니다.** "자막 만들기"와 "자막 고치기" 두 장으로 나뉘며, 실제로 AI 설정 창을 열어 서비스 고르기, 키 붙여 넣기, 연결 테스트를 함께 진행합니다. 다음 단계로 넘어가는 시간이 줄었고(약 0.6 → 0.39초), 자막 스튜디오를 열 때 화면이 한 번 번쩍이지 않습니다.
- **자막 스튜디오의 "자막 인식" 창을 새로 만들었습니다**: 왼쪽에는 인식 구성과 모델 세 줄(이름, 지원 언어, 준비 여부. 한 줄을 누르면 모델을 바꿈), 오른쪽에는 이번 인식의 용어집, 번역과 하나뿐인 "인식 후 현재 자막 바꾸기"가 있습니다. 화자는 주 전사를 따라갑니다.
- **큰 프로젝트에서 자막을 고칠 때 더 이상 뚝뚝 끊기지 않습니다.** 자막 하나를 고치면 그 자막의 미리보기만 다시 만들고, 선택, 찾기, 열기, 정식 저장 때 프로젝트 전체를 훑지 않으며, 자동 복구 파일은 처음에만 전체를 쓰고 그 뒤로는 바뀐 부분만 씁니다. 개발자 컴퓨터에서 자막 2090개짜리 이중 언어 프로젝트(62 MB)를 사용자가 하던 방식대로 이어서 고쳤을 때: 화면 멈춤(0.25초 이상) 88번 / 44.6초 → 6번 / 4.9초, 자막 하나 고치기 154 → 54 ms, 찾기에서 두 번째 글자 입력 1.19 → 0.07초, 메모리 1,265 → 962 MB.
- **재생이 더 매끄러워졌습니다**: 타임라인이 재생을 따라갈 때 더 이상 프레임마다 전체를 다시 그리지 않고(140초 재생에서 4,528 → 8번), 자막이 시작될 때마다 멈칫하지 않습니다. 재생 중 이동할 때 디코딩을 한 번 덜 하고, "화자 관리"가 두 배 빨리 열리며, 일시 정지할 때마다 메모리를 정리하지 않습니다.
- **중국어에서 자막 타임라인으로 MFA / Qwen3를 고르면 이제야 자막에 실제로 측정한 글자 단위 타이밍이 들어갑니다**(예전에는 정렬 결과가 병합 과정에서 버려지고 글자 수로 똑같이 나눴음). MFA(실험)의 표준 중국어 글자별 분할은 MFA 사전을 쓰도록 바꿔, 자음을 옆 글자에 잘라 붙이지 않습니다.
- **클라우드 인식이 더 빨라졌습니다**: 음성 감지와 업로드를 동시에 하고, 번역은 두 배치를 동시에 보내며, 두 정렬기를 동시에 돌리고, MFA 프로세스 수는 오디오 길이에 따라 정합니다.
- **자막 스튜디오의 구분선을 자유롭게 드래그할 수 있고, 드래그하는 동안 영상도 실시간으로 바뀝니다**. 1080p 화면에서 위아래 구분선이 움직일 수 있는 범위가 54 px에서 317 px로 늘었고, 작은 창에서 검토 막대가 후보 카드를 가리지 않습니다.
- **기본 자막 트랙이 줄었습니다**: 자막이 가장 많은 화자 두 명에게만 트랙을 하나씩 주고, 나머지는 한 트랙으로 합칩니다("앱 설정"에서 1/2/3/5/8로 바꿀 수 있음).
- **앱 안 업데이트**: 어떤 출처에 연결은 되지만 계속 아주 느리면, 이미 내려받은 위치부터 다음 출처로 자동으로 바꿔 이어받습니다. "업데이트 확인 실패" 창에는 GitHub와 GitCode 출시 페이지를 함께 보여 줍니다.
- **MFA 모델에 ModelScope 출처가 추가되었습니다**: 중국 본토 네트워크에서도 ModelScope에서 바로 내려받을 수 있습니다(0.8.2는 Hugging Face에서만 가능). 중국어 단어 분할 모델은 다운로드가 느리면 출처를 바꿔 이어받습니다.
- 인식 기록의 보고서 JSON을 "다른 이름으로 저장…"할 수 있습니다(너무 큰 보고서는 채팅 앱에 붙여 넣지 마세요). "자막 간체/번체 변환"은 "이중 언어 / 번역" 메뉴로 옮겼습니다.

#### 수정

- **말이 적은 긴 구간 때문에 자막 전체가 마지막 단계에서 실패하던 문제**(`字幕保真检查未通过`): 글자별 타이밍이 없고 글자가 아주 적은 구간을 한 글자에 자막 하나로밖에 나눌 수 없을 때, 따로 떨어진 "两"(중국어로 '둘')이 숫자 2로 취급되어, 대조 과정에서 숫자가 바뀌었다고 판정했습니다. 이제 숫자와 그 뒤의 글자를 같은 자막에 넣으며, 글자는 하나도 바꾸지 않습니다.
- **일본어를 SenseVoice로 한 회 전체 인식할 때 "로컬 규칙 전체 줄 나누기"에서 실패하던 문제**: 이웃한 인식 블록이 함께 쓰는 0.5초 때문에 두 구간의 시간이 겹치고 자막 순서가 뒤섞였습니다. 이제 증분 인식과 전체 구간 인식 모두 겹친 부분을 가운데에서 나눕니다(이미 캐시된 결과도 마찬가지). 패키징된 앱에서 배경음만 있고 글자를 하나도 인식하지 못한 블록 때문에 증분 인식 전체가 무효가 되는 일도 없어졌습니다.
- **러시아어 등이 "클라우드 모델 줄 나누기"에서 통째로 실패하던 문제**: 정렬 모델이 그 문장 범위를 벗어나는 단어 시간을 주면 쓰지 않습니다. 그래도 어떤 문장을 알맞은 자막으로 나누지 못하면 그 문장만 자막 하나로 남기고 알려 주며, 작업은 더 이상 실패하지 않습니다.
- **프로젝트를 열 때 앱이 갑자기 꺼지던 문제**: 가장 가능성이 높은 원인은 백그라운드 스레드가 메모리를 정리하면서 창 객체를 지운 것이라, 이제 화면(UI) 스레드에서만 정리합니다(원인은 추정이며, 네이티브 충돌 기록은 얻지 못했습니다). **자막을 편집하다가 다른 곳을 클릭해 확정하면** 오류가 나거나 멈추거나 심지어 앱이 꺼지던 문제도 고쳤습니다.
- 홈의 모델 카드에서 120% 배율일 때 이름이 다음 줄과 겹치던 문제, 창 너비가 딱 두 단계 사이에 걸리면 모델 카드가 두 배치를 오가다 앱이 그대로 종료되던 문제.
- "추가 웹 검증"을 켜고 텍스트 교정은 끈 상태에서 작업이 끝까지 돈 뒤에야 실패하던 문제(`Text AI stage is disabled for this task: polish`). 이제 웹 검증을 건너뛰고 그 이유를 적어 둡니다.
- 메인 창 높이가 화면과 거의 같을 때 아래로 드래그하면 원래 자리로 튕겨 돌아가며 왔다 갔다 떨리던 문제.
- 자막 스튜디오 "자막 인식" 창에서 고급 설정을 펼치면 모델 세 줄이 납작하게 눌리던 문제.

### 이전 버전에서 업데이트하기

- **0.8.2**: 메인 창 오른쪽 위 "업데이트 확인". 약 59 MB(프로그램 본체)만 내려받고, 나머지는 이미 설치된 것을 그대로 씁니다.
- **0.7.0–0.8.1**: 마찬가지로 "업데이트 확인". 이 버전들은 0.8.2에서 바뀐 FFmpeg, Python 실행 라이브러리, 오프라인 설치 패키지도 받아야 해서 모두 약 890 MB이며, Setup을 다시 내려받는 것과 비슷한 양입니다. **0.6.5**는 렌더러도 추가로 내려받습니다(합계 약 1.13 GB).
- 이번 버전의 업데이트 정보는 GitCode 국내 미러를 GitHub보다 앞에 둡니다. 설치된 0.6.5–0.8.2는 먼저 GitCode에서 내려받고(중국 본토에서는 GitHub보다 훨씬 빠름), GitCode에 연결되지 않으면 GitHub를 씁니다.
- 끊긴 다운로드는 이어받습니다. 내려받은 뒤 검증하고, 프로젝트를 저장하고 종료에 동의한 다음에 교체합니다. 실패하면 원래 버전으로 돌아갑니다. 설정, 용어집, 프로젝트, 내려받은 모델과 실행 환경은 유지되어 다시 준비할 필요가 없습니다.
- **0.6.0 이하**: 2ByteASR를 닫고 0.8.3 Setup을 실행해 **그대로 덮어 설치하세요. 먼저 제거하지 마세요.**
- **Mac**: 아직 앱 안 업데이트가 없습니다. 이전 버전을 종료하고 새 DMG를 열어 App을 "응용 프로그램"으로 끌어 바꾸면 됩니다. 설정, 모델, 프로젝트는 App 밖의 사용자 폴더에 있습니다.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서 "알 수 없는 게시자"가 표시될 수 있고, Mac은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases(또는 위의 GitCode 미러, gh-proxy 링크)에서만 내려받고 `SHA256SUMS.txt`를 확인하세요. 백신이나 시스템 보안을 끌 필요도 없고 꺼서도 안 됩니다.
- **"원인 찾기"의 목록은 이미 겪어 본 문제만 알아봅니다.** 새로운 문제에는 "뚜렷한 원인을 찾지 못함"이라고 적으니, 이럴 때는 "AI에게 분석 맡기기"를 쓰거나 문제 해결 보고서를 개발자에게 보내 주세요. 보고서에 프로그램 버전이 기록되지 않아서, 목록의 "어느 버전에서 고쳤는지"는 날짜로만 적을 수 있습니다.
- **자막 스튜디오에 들어갈 때 가끔 앱이 꺼지는 문제**(개발자가 10-22에 두 번 겪었고, 두 번 모두 자막 스튜디오 페이지를 처음 만들 때였음)는 재현하지 못했습니다. 이번 버전에서는 의심스러운 곳 두 군데만 고쳤고, 고쳐졌는지는 확인하지 못했습니다.
- **큰 프로젝트에는 아직 기다림이 남아 있습니다**: 열 때의 일관성 검사가 약 0.3초, 시작할 때 자막 스튜디오 페이지를 만드는 데 약 2초 걸립니다. 기본 스타일을 바꾸거나 이중 언어 표시나 화자 이름 배치를 바꾸면 여전히 자막 미리보기 전체를 다시 만듭니다(300개 이상이면 백그라운드에서 해서 화면이 멈추지는 않지만, 새 미리보기가 나오기까지 몇 초 걸림).
- **영어는 FireRedASR2로 글자·단어 타이밍을 매기지 않습니다**: 중국어 외의 언어는 모두 Qwen3 정렬기가 타이밍을 매깁니다.
- **일본어**: 단어 단위의 자르는 위치만 있어서, 일본어에서는 텍스트 위치에서 나누기를 해도 단어 경계에서만 자를 수 있습니다.
- **홈 인식 구성 카드의 "FireRedASR2-AED" 이름**이 1700×1080, 화면 배율 120%에서 반 줄 잘립니다.
- **화면 번역**: 새 창의 문구는 화면 언어 10가지 모두에 번역이 있으며, 번체 중국어는 글자 단위로 변환했습니다. 영어 외의 언어는 실제 창에서 보지 않았습니다.
- **MFA(실험)**: 일본어 정확도는 보통 수준입니다. Windows만 지원합니다.
- **기존 프로젝트에는 새 줄 나누기와 타임라인 수정이 자동으로 적용되지 않습니다.** 다시 인식하세요(캐시를 그대로 씀).
- **Mac은 실험판**: 이번 버전의 새 기능은 Mac에서 따로 확인하지 않았습니다. MFA는 Windows만 대상입니다.
- **Claude**: Anthropic 공식 지원 지역에 중국 본토, 홍콩, 마카오는 없습니다.
- **Docker 버전은 아직 0.8.1입니다**([v0.8.1-docker.1](https://github.com/NOTBAD314/2ByteASR/releases/tag/v0.8.1-docker.1)). 이번 버전에서는 Docker 이미지를 업데이트하지 않았습니다.
