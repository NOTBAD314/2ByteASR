# Mac 实机简短检查单

2026-10-23 优先目标：M3 Max / macOS 14.4.1 的原生 arm64 候选；目前没有该环境，尚未实测。先记录候选 SHA-256、完整系统版本、硬件／程序架构与是否 Rosetta。另测 13 / 12 时应使用该系统支持的机型，不能改版本字符串代替。[当前矩阵](macos-compatibility.zh-TW.md)。

这些项目需要真人或适用实机，Windows 控件和虚拟 runner 不能代替。先看[实际自动验证状态](macos-validation.zh-CN.md)，使用自建临时工程。

- Finder/Dock 打开，移到“应用程序”后重开，确认模型、配置和工程保留。
- 中文/日文输入法、复制粘贴、保存、撤销重做；编辑文字时 Q/W/E 不切时间轴。
- 中文/日文路径、拖入媒体、Retina/缩放及下次启动窗口恢复。
- Studio 播放/暂停、seek、倍速、结束重播和离开工程；听到一份音频，字幕和画面连贯同步。
- 基础字幕/特效叠加层在预览、移动/缩放和短成片中一致。
- 无AI密钥冷准备 SenseVoice、取消/重试、断网复用校验模型。
- 有MPS/VideoToolbox时分别验真实模型/硬件，记录时长、耗时、设备、内存和输出差异。
- 短样本通过后再尝试长任务，不推广短样本或CI设备结论。
