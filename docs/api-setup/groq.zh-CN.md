## 它在兔白里做什么

- 用于语音识别，可以当“主力转写”，也可以当“复核”来源。
- 兔白先在本机找出有人声的片段，切成短块：当主力时每块 10 秒以内，当复核时 25 秒以内。每块转成 16 kHz 单声道 WAV 上传，默认 4 块同时进行。
- 兔白向 Groq 要的是“带句段时间”的结果，**没有**要逐词时间。所以字幕时间精确到句段；需要按字剪辑时，请在模型工坊配一个本地字幕时间轴（对齐）模型。
- 每次上传还会附一段文字提示，帮助拼对专有名词：当前字幕场景、素材文件名，以及你在词库里确认过的专名（最多 64 个）。
- 某一块失败时，兔白会自动等一会儿再试，最后再把失败的块逐个补一遍。仍失败的部分会提示“约 N 秒素材无字幕，可重跑识别补齐”。

## 从未注册开始

1. 打开 <https://console.groq.com/>，注册并登录。可用哪些注册方式（邮箱、第三方账号等）：需要登录才能看到，待核实。
2. 打开 API Key 页面 <https://console.groq.com/keys>，点 **Create API Key**。官方说明：只有团队的 owner 或 developer 角色能创建和管理 Key。之后要不要命名、完整 Key 是否只显示一次：需要登录才能看到，待核实。建议建好后立刻复制。
3. 不填付款方式就是免费档，可以直接用，但限额较低。要更高限额，在 Settings → Billing 填付款方式升级到 Developer 档（官方：信用卡、美国银行账户或 SEPA 借记账户）。
4. 打开兔白的「申请与设置 API」，在左侧“语音识别（生成字幕）”下选 **Groq Whisper**。打开方式任选一种：
   - 首页右上角“说明”菜单 →“申请与设置 API…”
   - 模型工坊 →“在线 API”页 →“Groq Whisper API”卡片上的设置按钮
   - 首页识别方案卡片上的“配置 API”
5. 把 Key 贴进“API Key”，点“免费检查（不上传音频）”。
6. 想确认真的能识别，再点“试识别一小段…”（见下文，会产生极少费用）。
7. 点“保存”；要马上用它做主力转写，点“保存并用于识别”。

这一页目前没有“① 在官网创建 API Key [打开网页]”那一排提示，请用上面表格里的链接打开官网。

## 测试时会看到什么

**免费检查（不上传音频）**：兔白用你的 Key 读取 Groq 的模型列表，不上传音频、不收费。全部正常时：

| 结果行 | 显示 |
| --- | --- |
| 设置格式 | ✓ 格式正确（地址 api.groq.com）。这一步只在本机检查，没有联系服务商。 |
| 服务可以连线 | ✓ 通过 |
| 认证成功（API Key 有效） | ✓ 通过 |
| 指定模型可用 | ✓ 通过（模型列表里有 `whisper-large-v3-turbo`） |
| 实际短音频识别、回传时间戳、回传说话人 | — 尚未检查 |

**试识别一小段…**：先弹出确认，写明会上传到 `api.groq.com`、可能产生费用。选“上传自带测试音频”（兔白自带约 6 秒英文合成语音，不含你的素材）或“选择我的音频…”（60 秒以内）。自带音频按最少 10 秒计费，约 $0.0001。成功时：

| 结果行 | 显示 | 说明 |
| --- | --- | --- |
| 实际短音频识别 | ✓ 识别出 N 段文字。 | 真的能用了 |
| 回传时间戳 | ? 只有句段起止时间，没有逐字时间…… | 正常结果，不是失败 |
| 回传说话人 | — 这次结果没有说话人标签…… | Groq 不分说话人 |

## 常见失败与下一步

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 设置格式 ✗“还没有填写 API Key”或“API Key 里有空格或换行” | 没贴上，或多复制了空格 | 回 Key 页面重新复制那一串字符 |
| 服务可以连线 ✗“连不上服务：……” | 电脑网络到不了 `api.groq.com` | 换一个能打开 console.groq.com 的网络再检查；连不上就改用国内服务（如讯飞、阿里云百炼） |
| 认证成功 ✗ HTTP 401 | Key 填错，或已在控制台删除 | 在 Key 页面新建一把，重新贴入 |
| 认证成功 ✗ HTTP 403 | 账户权限不允许（官方：权限不足） | 确认你在这个团队里是 owner 或 developer，或用自己团队建的 Key |
| 指定模型可用 ✗“模型列表里没有 whisper-large-v3-turbo” | 模型被改名或下架；或在进阶设置里改错了模型 | 对照官方模型页，在“进阶设置…”的“API 模型”改成列表里有的语音模型 |
| 试识别或正式识别报 HTTP 429，而且等了好几分钟 | 免费档每分钟 / 每天的请求数或音频秒数用完 | 兔白已自动等待重试过。到 <https://console.groq.com/settings/limits> 看限额；隔一段时间再跑，或绑付款方式升级 Developer 档 |
| 识别完成，但提示“N 个短块最终失败（约 X 秒素材无字幕，可重跑识别补齐）” | 部分短块被限流或网络中断 | 稍后再识别一次 |
| “没有成功返回任何短块。请检查 API Key、余额和网络。” | 所有短块都失败 | 先点“免费检查”，看哪一行 ✗，按上面对应的行处理 |
| HTTP 500 / 502 / 503 / 498 | Groq 服务端忙或故障 | 稍后再试；官方说服务端错误不计费 |

## 隐私与费用

- **传到哪里**：`api.groq.com`（Groq，境外）。
- **传什么**：有人声的音频短块（16 kHz 单声道 WAV，不含画面），加一段文字提示（字幕场景、素材文件名、词库里确认过的专名）。
- **密钥**：只保存在本机。Windows 用 DPAPI 加密；macOS 存在“钥匙串”，钥匙串不可用时只在本次运行期间保存在内存，绝不存明文。不写进工程、日志或导出文件。
- **费用**（Groq 模型页，2026-10-14 核对）：`whisper-large-v3-turbo` $0.04 / 小时音频，`whisper-large-v3` $0.111 / 小时。每次请求最少按 10 秒计；兔白每块不超过 10 秒（主力），所以大约按“块数 × 10 秒”计费，例如切出 300 块约 3000 秒，约 $0.03。免费档的额度以你账户的 Limits 页为准，官方可以随时调整。

## 进阶（一般使用者可跳过）

- 兔白每块发送 `POST …/audio/transcriptions`（multipart），字段：`model`、`file`（chunk.wav）、`prompt`（最多 900 字）、`response_format=verbose_json`。不发送 `timestamp_granularities[]`，官方默认值是 `segment`，所以只有句段时间。服务商回 400 时，兔白改用 `response_format=json` 重试一次，这时没有句段时间，整块只有一个起止时间。
- 重试：429、5xx 和网络错误每块最多 6 次，等待 1.5 秒起倍增、最长 20 秒，会遵守 `retry-after`；之后对失败块逐个补扫最多 4 轮。
- 免费检查调用的是 `GET https://api.groq.com/openai/v1/models`。
- 官方说 `prompt` 限 224 tokens。兔白的提示可能更长，超长时 Groq 会怎样，官方未写明，兔白未实测。
- 两份官方页面的限额数字不一致：速率限制页写 Developer 档 Whisper 每分钟 20 次请求、每小时 7.2K 音频秒；模型页写每分钟 300～400 次、每小时 200K～400K 音频秒。以账户 Limits 页为准。
