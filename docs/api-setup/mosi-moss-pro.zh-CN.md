# 申请与设置 MOSS-Transcribe-Diarize Pro 云端（MOSI 平台）

最后核对：2026-10-14。来源见文末。标“待核实”的地方需要登录 MOSI 控制台才能确认，教程里不写看不到的按钮名称。

## 一眼看懂

| 项目 | 内容 |
| --- | --- |
| 在兔白里做什么 | 云端多人转写：上传本次音频，返回文字、每句起止时间和说话人（S01、S02…） |
| 需要什么 | **只要一把 API Key**。兔白直接上传本地音频，不需要 OSS、公网网址或自己的服务器 |
| 显卡 / 本地模型 | 都不需要（Mac、没有独显的 Windows 都能用） |
| 时间精度 | 只有句段时间，**没有逐字时间**；要按字剪辑，再装本地对齐模型（见下文） |
| 费用 | ¥2.00 / 小时音频（40 积分 / 小时），按实际用量计费；失败任务是否计费官方未写明（MOSI 价格页，2026-10-14 核对；以积分账单为准） |
| 和本地 MOSS 的关系 | 两个独立引擎：设置、密钥、识别记录互不影响 |

## 跟着做

1. **注册并登录**：打开 <https://platform.mosi.cn/>。是否需要实名认证：官方文档没写（**待核实**）。
2. **确认有积分**：价格见 <https://platform.mosi.cn/app/pricing/>；充值入口在登录后的控制台（**待核实**）。想先试试可以用在线体验 <https://platform.mosi.cn/app/playground/>。
3. **创建 API Key**：打开 <https://platform.mosi.cn/app/api-keys/> 新建一个 Key，**立刻复制**（官方：完整密钥只显示一次）。
4. **贴到兔白**：首页右上角“说明”→“申请与设置 API…”→ 左侧选“MOSS-Transcribe-Diarize Pro 云端”。上方步骤卡里的“打开网页”就是第 1、3 步的页面。把 Key 贴进“API Key”。
5. **检查**：点“免费检查（不上传音频）”。想确认真的能识别，再点“试识别一小段…”（会先问你，约 6 秒，约 ¥0.003）。
6. 点“**保存并用于识别**”。

## 兔白里的每一栏

| 栏位 | 填什么 | 从哪里来 | 已预填？ |
| --- | --- | --- | --- |
| 模型 | `moss-transcribe-diarize-pro` | — | 已预选 |
| API Key | 一串以 `sk-` 开头的字符 | MOSI 的 API Key 页面 | 否 |
| 服务地址（灰色，按“修改”才能改） | `https://api.mosi.cn/v1` | 官方文档 | **已预填，不用改** |

地址不用你判断：官方网站 `https://platform.mosi.cn/`（登录用）、API Host `api.mosi.cn`、Base URL `https://api.mosi.cn/v1`、完整请求 Endpoint `https://api.mosi.cn/v1/audio/transcriptions`。贴成哪一种都会换算成同一个 Base URL，不会出现 `/v1/v1`。

## 常见失败与下一步

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 认证失败（HTTP 401/403） | 复制不完整、Key 已删除、账号没有该模型权限 | 回 API Key 页面重新创建并复制；再做一次免费检查 |
| 积分不足（HTTP 402） | 余额不足 | 充值后重试；已保存的任务编号不受影响 |
| 请求太频繁（HTTP 429） | 频率或并发限制 | 等几分钟再试；兔白不会因此重复提交 |
| 连不上 | 网络、代理、公司防火墙 | 检查网络；确认能打开 api.mosi.cn |
| “无法确认是否受理” | 上传途中断网 | 先到 MOSI 控制台看有没有这次任务和扣费；确定要重来，在完成页按“重试失败项”并确认重新提交 |
| 任务失败（FAILED） | 服务端执行失败 | 到控制台看积分账单是否扣费（官方未写明）；在完成页按“重试失败项”并确认重新提交 |

## 识别时会发生什么

- 兔白把本次识别范围转成 16 kHz 单声道 WAV（只有声音，不含画面），以异步任务上传到 `api.mosi.cn`，再定时查询结果。
- 任务编号立刻保存在本机。断网后重新识别，兔白先查询原任务，**不会**自动重新上传收费。
- 取消：MOSI 文档没有取消接口。兔白里取消只停止本机等待，云端任务可能仍会完成并计费，界面会如实提示。
- 超过 60 分钟（官方单次上限）：自动分段，每段在目标切点前后 4 分钟内找最安静的一秒切开（游戏音乐不断也会选相对最安静处），每段都低于 60 分钟。各段的 S01、S02 只在该段内有效，兔白**不会**假定不同段的 S01 是同一人，会标为“待确认”。
- 术语库：最多把 20 个、每个不超过 30 字的规范词作为“热词提示”发送，保持原大小写与数字；超出的不发送并记录。热词只是提示，不保证一定识别正确；识别后的词库校对照常进行。
- 想要逐字时间：在模型工坊“字幕时间轴”页安装 Qwen3 对齐模型（Windows 可用 CPU，Apple Silicon 用 MLX 版）。它在本机运行、不上传，只给 MOSS Pro 的文字配上字词时间；对不上的句子标为“估算”。没装时，工作台如实显示“缺少字级对齐”，不会把平均切开的字当成实测。

## 隐私与费用

- 会上传：本次识别范围的音频。不会上传：画面、工程、其他素材、本机路径。
- API Key 只存在本机：Windows 用系统 DPAPI 加密；Mac 用钥匙串，钥匙串不可用时只保留到退出程序，不改成明文。不写进工程、日志或导出文件。
- 兔白本身免费，但 MOSI 是第三方付费服务，按其价格和账单计费。
