## 它在兔白里做什么

- **AI 断句**：把识别出的整段文字切成适合看的字幕句子（“全文断句使用 AI”）。
- **字幕校对**：修正错别字、专有名词、标点（“字幕校对使用 AI”）。
- **翻译**：日语任务识别后翻成中文，以及字幕工作室里的“翻译 / 生成双语字幕”。翻译用的是“字幕校对模型”那一套设置。
- 同一套设置也用于术语整理、字幕工作室的“AI 设计”等辅助功能。

## 从未注册开始

1. 打开 <https://console.x.ai/>，点 “Create an account” 注册。可用哪些注册方式：需要登录流程里才能看到，待核实。
2. **充值**：官方入门页原意是“在 console.x.ai 注册账户，然后充值 credits 才能开始使用 API”。在控制台哪里充值、最低金额、付款方式：需要登录才能看到，待核实。
3. **创建 API Key**：打开 <https://console.x.ai/team/default/api-keys> 创建 Key 并复制。按钮名称、完整 Key 是否只显示一次：需要登录才能看到，待核实。建议一创建就复制下来。
4. 打开兔白的「AI 智能断句设置」，任选一种方式：
   - 首页“AI 智能断句”卡片上的“设置 AI”按钮（或直接点这张卡片）
   - 模型工坊 →“AI 模型 / 智能断句”
   - 「申请与设置 API」里这篇教程下方的“去填写这家服务的密钥”（打开后仍要在“AI 服务”里自己选 xAI）
5. 在“AI 服务”下拉里选 **xAI API**（新安装时默认选的是“Grok Account”，那是另一种方式，记得改）。
6. 把 Key 贴进“API 密钥”，点“测试连接”。
7. 看到“连接测试通过”后，点对话框右下角“保存设置”。

**一张卡片还是两张**：对话框上方的开关“同一云端模型负责字幕校对与全文断句（推荐）”默认打开，这时只有一张卡片，标题是“统一校对与断句模型”。关掉后会出现“字幕校对模型”和“全文断句模型”两张卡片，各自选服务、各自填密钥。

## 测试时会看到什么

**测试连接**：兔白用这张卡片上的服务、模型、地址和密钥（刚贴进去还没保存的密钥也会用）发一句很短的固定文字，要求模型只回一小段 JSON，最多等 45 秒。会产生极少量费用。

- 成功时状态行显示：`连接测试通过 · 中文 JSON 字段正确 · 兼容 JSON／本地校验 · 1.23s`（最后是用时）。如果卡片上选的服务和上次保存的不同，后面还会加“尚未保存：点击保存后 AI 设计才会使用此 Provider”。
- 首页 AI 卡片下方会显示“连接正常”；失败显示“连接失败”；还没测过显示“尚未测试连接”。
- 失败时状态行显示服务商的错误，例如 `HTTP 401：……`，对照下表处理。

**刷新模型**：读取你账户能用的模型列表（不让模型生成文字）。成功显示“已发现 N 个模型 · 可搜索选择或手动输入”。填完密钥、离开输入框时也会自动读一次。

## 常见失败与下一步

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| “当前模型（xai）缺少 API 密钥……” | 还没贴密钥 | 把 Key 贴进“API 密钥”再测 |
| `HTTP 401` | 官方：没有带授权信息，或授权令牌无效 | 到 API Keys 页面新建一个 Key，重新贴入 |
| `HTTP 403` | 官方：请团队管理员给你权限 | 请团队管理员开权限，或用自己团队建的 Key |
| `HTTP 404` | 地址或模型名不对 | Base URL 改回 `https://api.x.ai/v1`，“模型”改回 `grok-4.7` 或点“刷新模型”选 |
| `HTTP 400` 或 `HTTP 422` | 请求内容格式不被接受 | 先把模型、Base URL、协议都改回预填值再测 |
| `HTTP 429` | 官方：请求太频繁、达到限速 | 等一会儿再试；少开几个同时跑的任务；限速会随累计消费自动提高 |
| 余额用完时的报错 | 官方错误码页没有写 credits 用完会显示什么，兔白未实测 | 到控制台查看 credits 余额并充值 |
| 连不上（超时、无法连接） | 网络到不了 `api.x.ai` | 换一个能打开 console.x.ai 的网络再试；不行就改用 DeepSeek、阿里云百炼等其他服务 |
| 任务完成页写“原文回退 N 批” | 任务中这些批次的 AI 请求失败，兔白保留了原文 | 按上表查原因，处理后重新识别；只差少量字幕时，可在字幕工作室“字幕列表”上方点“AI 校对”看修改建议 |

## 隐私与费用

- **传到哪里**：`api.x.ai`（境外）。
- **传什么**：字幕文字，以及你填写的游戏 / 内容名称和术语提示。**不发送音频**。字幕工作室的“AI 设计”在模型支持看图时，可能附带画面截图或字幕效果预览图。
- **密钥**：只保存在本机。Windows 用 DPAPI 加密；macOS 存在“钥匙串”，钥匙串不可用时只保留到退出软件，绝不存明文。不写进工程、日志或导出文件。
- **费用**（官方模型页，2026-10-14 核对，单位：美元 / 百万 token）：

| 模型 | 单次请求的提示长度 | 输入 | 缓存输入 | 输出 | 上下文 |
| --- | --- | --- | --- | --- | --- |
| `grok-4.7`（预填） | 不到 200k / 200k 及以上 | 2.00 / 4.00 | 0.50 / 1.00 | 6.00 / 12.00 | 500k |
| `grok-4.3` | 不到 200k / 200k 及以上 | 1.25 / 2.50 | 0.20 / 0.40 | 2.50 / 5.00 | 1M |

官方：提示长度达到门槛时，这次请求的全部 token 都按较高价格计费。一段视频要花多少取决于字幕字数和重试次数，兔白没有固定数字。价格以官方页面为准。

## 进阶（一般使用者可跳过）

- 兔白发送 `POST https://api.x.ai/v1/chat/completions`，带 `Authorization: Bearer <密钥>`；需要按 JSON 回答时附 `response_format: {"type": "json_object"}`。测试连接的内容是一句要求回 `{"ok":true,"text":"兔白字幕"}` 的提示，最多 80 个输出 token。
- “刷新模型”调用 `GET https://api.x.ai/v1/models`，再尝试用 `GET https://api.x.ai/v1/language-models` 补充模型信息。
- 官方模型页说明：`<模型名>` 指向最新稳定版，`<模型名>-latest` 指向最新版本。兔白旧版本预填过 `grok-4-latest`，官方模型页没有单独列出它。
- 本机没有保存密钥时，兔白也会读取环境变量 `XAI_API_KEY`；已保存的密钥优先。
