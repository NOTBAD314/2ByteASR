## 它在兔白裡做什麼

- **AI 斷句**：把識別出的整段文字切成適合看的字幕句子（“全文斷句使用 AI”）。
- **字幕校對**：修正錯別字、專有名詞、標點（“字幕校對使用 AI”）。
- **翻譯**：日語任務識別後翻成中文，以及字幕工作室裡的“翻譯 / 生成雙語字幕”。翻譯用的是“字幕校對模型”那一套設定。
- 同一套設定也用於術語整理、字幕工作室的“AI 設計”等輔助功能。

## 從未註冊開始

1. 開啟 <https://console.x.ai/>，點 “Create an account” 註冊。可用哪些註冊方式：需要登入流程裡才能看到，待核實。
2. **充值**：官方入門頁原意是“在 console.x.ai 註冊賬戶，然後充值 credits 才能開始使用 API”。在控制台哪裡充值、最低金額、付款方式：需要登入才能看到，待核實。
3. **建立 API Key**：開啟 <https://console.x.ai/team/default/api-keys> 建立 Key 並複製。按鈕名稱、完整 Key 是否只顯示一次：需要登入才能看到，待核實。建議一建立就複製下來。
4. 開啟兔白的「AI 智慧斷句設定」，任選一種方式：
   - 首頁“AI 智慧斷句”卡片上的“設定 AI”按鈕（或直接點這張卡片）
   - 模型工坊 →“AI 模型 / 智慧斷句”
   - 「申請與設定 API」裡這篇教程下方的“去填寫這家服務的金鑰”（開啟後仍要在“AI 服務”裡自己選 xAI）
5. 在“AI 服務”下拉里選 **xAI API**（新安裝時預設選的是“Grok Account”，那是另一種方式，記得改）。
6. 把 Key 貼進“API 金鑰”，點“測試連線”。
7. 看到“連線測試通過”後，點對話方塊右下角“儲存設定”。

**一張卡片還是兩張**：對話方塊上方的開關“同一雲端模型負責字幕校對與全文斷句（推薦）”預設開啟，這時只有一張卡片，標題是“統一校對與斷句模型”。關掉後會出現“字幕校對模型”和“全文斷句模型”兩張卡片，各自選服務、各自填金鑰。

## 測試時會看到什麼

**測試連線**：兔白用這張卡片上的服務、模型、地址和金鑰（剛貼進去還沒儲存的金鑰也會用）發一句很短的固定文字，要求模型只回一小段 JSON，最多等 45 秒。會產生極少量費用。

- 成功時狀態行顯示：`連線測試通過 · 中文 JSON 欄位正確 · 相容 JSON／本地校驗 · 1.23s`（最後是用時）。如果卡片上選的服務和上次儲存的不同，後面還會加“尚未儲存：點選儲存後 AI 設計才會使用此 Provider”。
- 首頁 AI 卡片下方會顯示“連線正常”；失敗顯示“連線失敗”；還沒測過顯示“尚未測試連線”。
- 失敗時狀態行顯示服務商的錯誤，例如 `HTTP 401：……`，對照下表處理。

**重新整理模型**：讀取你賬戶能用的模型列表（不讓模型生成文字）。成功顯示“已發現 N 個模型 · 可搜尋選擇或手動輸入”。填完金鑰、離開輸入框時也會自動讀一次。

## 常見失敗與下一步

| 現象 | 可能原因 | 下一步 |
| --- | --- | --- |
| “當前模型（xai）缺少 API 金鑰……” | 還沒貼金鑰 | 把 Key 貼進“API 金鑰”再測 |
| `HTTP 401` | 官方：沒有帶授權資訊，或授權令牌無效 | 到 API Keys 頁面新建一個 Key，重新貼入 |
| `HTTP 403` | 官方：請團隊管理員給你許可權 | 請團隊管理員開許可權，或用自己團隊建的 Key |
| `HTTP 404` | 地址或模型名不對 | Base URL 改回 `https://api.x.ai/v1`，“模型”改回 `grok-4.7` 或點“重新整理模型”選 |
| `HTTP 400` 或 `HTTP 422` | 請求內容格式不被接受 | 先把模型、Base URL、協議都改回預填值再測 |
| `HTTP 429` | 官方：請求太頻繁、達到限速 | 等一會兒再試；少開幾個同時跑的任務；限速會隨累計消費自動提高 |
| 餘額用完時的報錯 | 官方錯誤碼頁沒有寫 credits 用完會顯示什麼，兔白未實測 | 到控制台檢視 credits 餘額並充值 |
| 連不上（超時、無法連線） | 網路到不了 `api.x.ai` | 換一個能開啟 console.x.ai 的網路再試；不行就改用 DeepSeek、阿里雲百鍊等其他服務 |
| 任務完成頁寫“原文回退 N 批” | 任務中這些批次的 AI 請求失敗，兔白保留了原文 | 按上表查原因，處理後重新識別；只差少量字幕時，可在字幕工作室“字幕列表”上方點“AI 校對”看修改建議 |

## 隱私與費用

- **傳到哪裡**：`api.x.ai`（境外）。
- **傳什麼**：字幕文字，以及你填寫的遊戲 / 內容名稱和術語提示。**不傳送音訊**。字幕工作室的“AI 設計”在模型支援看圖時，可能附帶畫面截圖或字幕效果預覽圖。
- **金鑰**：只儲存在本機。Windows 用 DPAPI 加密；macOS 存在“鑰匙串”，鑰匙串不可用時只保留到退出軟體，絕不存明文。不寫進工程、日誌或匯出檔案。
- **費用**（官方模型頁，2026-10-14 核對，單位：美元 / 百萬 token）：

| 模型 | 單次請求的提示長度 | 輸入 | 快取輸入 | 輸出 | 上下文 |
| --- | --- | --- | --- | --- | --- |
| `grok-4.7`（預填） | 不到 200k / 200k 及以上 | 2.00 / 4.00 | 0.50 / 1.00 | 6.00 / 12.00 | 500k |
| `grok-4.3` | 不到 200k / 200k 及以上 | 1.25 / 2.50 | 0.20 / 0.40 | 2.50 / 5.00 | 1M |

官方：提示長度達到門檻時，這次請求的全部 token 都按較高價格計費。一段影片要花多少取決於字幕字數和重試次數，兔白沒有固定數字。價格以官方頁面為準。

## 進階（一般使用者可跳過）

- 兔白髮送 `POST https://api.x.ai/v1/chat/completions`，帶 `Authorization: Bearer <金鑰>`；需要按 JSON 回答時附 `response_format: {"type": "json_object"}`。測試連線的內容是一句要求回 `{"ok":true,"text":"兔白字幕"}` 的提示，最多 80 個輸出 token。
- “重新整理模型”呼叫 `GET https://api.x.ai/v1/models`，再嘗試用 `GET https://api.x.ai/v1/language-models` 補充模型資訊。
- 官方模型頁說明：`<模型名>` 指向最新穩定版，`<模型名>-latest` 指向最新版本。兔白舊版本預填過 `grok-4-latest`，官方模型頁沒有單獨列出它。
- 本機沒有儲存金鑰時，兔白也會讀取環境變數 `XAI_API_KEY`；已儲存的金鑰優先。
