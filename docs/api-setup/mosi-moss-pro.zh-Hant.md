## 跟著做

1. **註冊並登入**：開啟 <https://platform.mosi.cn/>。是否需要實名認證：官方文件沒寫（**待核實**）。
2. **確認有積分**：價格見 <https://platform.mosi.cn/app/pricing/>；充值入口在登入後的控制台（**待核實**）。想先試試可以用線上體驗 <https://platform.mosi.cn/app/playground/>。
3. **建立 API Key**：開啟 <https://platform.mosi.cn/app/api-keys/> 新建一個 Key，**立刻複製**（官方：完整金鑰只顯示一次）。
4. **貼到兔白**：首頁右上角“說明”→“申請與設定 API…”→ 左側選“MOSS-Transcribe-Diarize Pro 雲端”。上方步驟卡里的“開啟網頁”就是第 1、3 步的頁面。把 Key 貼進“API Key”。
5. **檢查**：點“免費檢查（不上傳音訊）”。想確認真的能識別，再點“試識別一小段…”（會先問你，約 6 秒，約 ¥0.003）。
6. 點“**儲存並用於識別**”。

## 常見失敗與下一步

| 現象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 認證失敗（HTTP 401/403） | 複製不完整、Key 已刪除、賬號沒有該模型許可權 | 回 API Key 頁面重新建立並複製；再做一次免費檢查 |
| 積分不足（HTTP 402） | 餘額不足 | 充值後重試；已儲存的任務編號不受影響 |
| 請求太頻繁（HTTP 429） | 頻率或併發限制 | 等幾分鐘再試；兔白不會因此重複提交 |
| 連不上 | 網路、代理、公司防火牆 | 檢查網路；確認能開啟 api.mosi.cn |
| “無法確認是否受理” | 上傳途中斷網 | 先到 MOSI 控制台看有沒有這次任務和扣費；確定要重來，在完成頁按“重試失敗項”並確認重新提交 |
| 任務失敗（FAILED） | 服務端執行失敗 | 到控制台看積分賬單是否扣費（官方未寫明）；在完成頁按“重試失敗項”並確認重新提交 |

## 識別時會發生什麼

- 兔白把本次識別範圍轉成 16 kHz 單聲道 WAV（只有聲音，不含畫面），以非同步任務上傳到 `api.mosi.cn`，再定時查詢結果。
- 任務編號立刻儲存在本機。斷網後重新識別，兔白先查詢原任務，**不會**自動重新上傳收費。
- 取消：MOSI 文件沒有取消介面。兔白裡取消只停止本機等待，雲端任務可能仍會完成並計費，介面會如實提示。
- 超過 60 分鐘（官方單次上限）：自動分段，每段在目標切點前後 4 分鐘內找最安靜的一秒切開（遊戲音樂不斷也會選相對最安靜處），每段都低於 60 分鐘。各段的 S01、S02 只在該段內有效，兔白**不會**假定不同段的 S01 是同一人，會標為“待確認”。
- 術語庫：最多把 20 個、每個不超過 30 字的規範詞作為“熱詞提示”傳送，保持原大小寫與數字；超出的不傳送並記錄。熱詞只是提示，不保證一定識別正確；識別後的詞庫校對照常進行。
- 想要逐字時間：在模型工坊“字幕時間軸”頁安裝 Qwen3 對齊模型（Windows 可用 CPU，Apple Silicon 用 MLX 版）。它在本機執行、不上傳，只給 MOSS Pro 的文字配上字詞時間；對不上的句子標為“估算”。沒裝時，工作台如實顯示“缺少字級對齊”，不會把平均切開的字當成實測。

## 隱私與費用

- 會上傳：本次識別範圍的音訊。不會上傳：畫面、工程、其他素材、本機路徑。
- API Key 只存在本機：Windows 用系統 DPAPI 加密；Mac 用鑰匙串，鑰匙串不可用時只保留到退出程式，不改成明文。不寫進工程、日誌或匯出檔案。
- 兔白本身免費，但 MOSI 是第三方付費服務，按其價格和賬單計費。
