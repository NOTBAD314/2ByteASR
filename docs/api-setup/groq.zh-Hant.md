## 它在兔白裡做什麼

- 用於語音識別，可以當“主力轉寫”，也可以當“複核”來源。
- 兔白先在本機找出有人聲的片段，切成短塊：當主力時每塊 10 秒以內，當複核時 25 秒以內。每塊轉成 16 kHz 單聲道 WAV 上傳，預設 4 塊同時進行。
- 兔白向 Groq 要的是“帶句段時間”的結果，**沒有**要逐詞時間。所以字幕時間精確到句段；需要按字剪輯時，請在模型工坊配一個本地字幕時間軸（對齊）模型。
- 每次上傳還會附一段文字提示，幫助拼對專有名詞：當前字幕場景、素材檔名，以及你在詞庫裡確認過的專名（最多 64 個）。
- 某一塊失敗時，兔白會自動等一會兒再試，最後再把失敗的塊逐個補一遍。仍失敗的部分會提示“約 N 秒素材無字幕，可重跑識別補齊”。

## 從未註冊開始

1. 開啟 <https://console.groq.com/>，註冊並登入。可用哪些註冊方式（郵箱、第三方賬號等）：需要登入才能看到，待核實。
2. 開啟 API Key 頁面 <https://console.groq.com/keys>，點 **Create API Key**。官方說明：只有團隊的 owner 或 developer 角色能建立和管理 Key。之後要不要命名、完整 Key 是否只顯示一次：需要登入才能看到，待核實。建議建好後立刻複製。
3. 不填付款方式就是免費檔，可以直接用，但限額較低。要更高限額，在 Settings → Billing 填付款方式升級到 Developer 檔（官方：信用卡、美國銀行賬戶或 SEPA 借記賬戶）。
4. 開啟兔白的「申請與設定 API」，在左側“語音識別（生成字幕）”下選 **Groq Whisper**。開啟方式任選一種：
   - 首頁右上角“說明”選單 →“申請與設定 API…”
   - 模型工坊 →“線上 API”頁 →“Groq Whisper API”卡片上的設定按鈕
   - 首頁識別方案卡片上的“配置 API”
5. 把 Key 貼進“API Key”，點“免費檢查（不上傳音訊）”。
6. 想確認真的能識別，再點“試識別一小段…”（見下文，會產生極少費用）。
7. 點“儲存”；要馬上用它做主力轉寫，點“儲存並用於識別”。

這一頁目前沒有“① 在官網建立 API Key [開啟網頁]”那一排提示，請用上面表格裡的連結開啟官網。

**免費檢查（不上傳音訊）**：兔白用你的 Key 讀取 Groq 的模型列表，不上傳音訊、不收費。全部正常時：

| 結果行 | 顯示 |
| --- | --- |
| 設定格式 | ✓ 格式正確（地址 api.groq.com）。這一步只在本機檢查，沒有聯絡服務商。 |
| 服務可以連線 | ✓ 通過 |

**試識別一小段…**：先彈出確認，寫明會上傳到 `api.groq.com`、可能產生費用。選“上傳自帶測試音訊”（兔白自帶約 6 秒英文合成語音，不含你的素材）或“選擇我的音訊…”（60 秒以內）。自帶音訊按最少 10 秒計費，約 $0.0001。成功時：

| 結果行 | 顯示 | 說明 |
| --- | --- | --- |
| 實際短音訊識別 | ✓ 識別出 N 段文字。 | 真的能用了 |
| 回傳時間戳 | ? 只有句段起止時間，沒有逐字時間…… | 正常結果，不是失敗 |
| 回傳說話人 | — 這次結果沒有說話人標籤…… | Groq 不分說話人 |

## 常見失敗與下一步

| 現象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 設定格式 ✗“還沒有填寫 API Key”或“API Key 裡有空格或換行” | 沒貼上，或多複製了空格 | 回 Key 頁面重新複製那一串字元 |
| 服務可以連線 ✗“連不上服務：……” | 電腦網路到不了 `api.groq.com` | 換一個能開啟 console.groq.com 的網路再檢查；連不上就改用國內服務（如訊飛、阿里雲百鍊） |
| 認證成功 ✗ HTTP 401 | Key 填錯，或已在控制台刪除 | 在 Key 頁面新建一把，重新貼入 |
| 認證成功 ✗ HTTP 403 | 賬戶許可權不允許（官方：許可權不足） | 確認你在這個團隊裡是 owner 或 developer，或用自己團隊建的 Key |
| 指定模型可用 ✗“模型列表裡沒有 whisper-large-v3-turbo” | 模型被改名或下架；或在進階設定裡改錯了模型 | 對照官方模型頁，在“進階設定…”的“API 模型”改成列表裡有的語音模型 |
| 試識別或正式識別報 HTTP 429，而且等了好幾分鐘 | 免費檔每分鐘 / 每天的請求數或音訊秒數用完 | 兔白已自動等待重試過。到 <https://console.groq.com/settings/limits> 看限額；隔一段時間再跑，或綁付款方式升級 Developer 檔 |
| 識別完成，但提示“N 個短塊最終失敗（約 X 秒素材無字幕，可重跑識別補齊）” | 部分短塊被限流或網路中斷 | 稍後再識別一次 |
| “沒有成功返回任何短塊。請檢查 API Key、餘額和網路。” | 所有短塊都失敗 | 先點“免費檢查”，看哪一行 ✗，按上面對應的行處理 |
| HTTP 500 / 502 / 503 / 498 | Groq 服務端忙或故障 | 稍後再試；官方說服務端錯誤不計費 |

## 隱私與費用

- **傳到哪裡**：`api.groq.com`（Groq，境外）。
- **傳什麼**：有人聲的音訊短塊（16 kHz 單聲道 WAV，不含畫面），加一段文字提示（字幕場景、素材檔名、詞庫裡確認過的專名）。
- **金鑰**：只儲存在本機。Windows 用 DPAPI 加密；macOS 存在“鑰匙串”，鑰匙串不可用時只在本次執行期間儲存在記憶體，絕不存明文。不寫進工程、日誌或匯出檔案。
- **費用**（Groq 模型頁，2026-10-14 核對）：`whisper-large-v3-turbo` $0.04 / 小時音訊，`whisper-large-v3` $0.111 / 小時。每次請求最少按 10 秒計；兔白每塊不超過 10 秒（主力），所以大約按“塊數 × 10 秒”計費，例如切出 300 塊約 3000 秒，約 $0.03。免費檔的額度以你賬戶的 Limits 頁為準，官方可以隨時調整。

## 進階（一般使用者可跳過）

- 兔白每塊傳送 `POST …/audio/transcriptions`（multipart），欄位：`model`、`file`（chunk.wav）、`prompt`（最多 900 字）、`response_format=verbose_json`。不傳送 `timestamp_granularities[]`，官方預設值是 `segment`，所以只有句段時間。服務商回 400 時，兔白改用 `response_format=json` 重試一次，這時沒有句段時間，整塊只有一個起止時間。
- 重試：429、5xx 和網路錯誤每塊最多 6 次，等待 1.5 秒起倍增、最長 20 秒，會遵守 `retry-after`；之後對失敗塊逐個補掃最多 4 輪。
- 免費檢查呼叫的是 `GET https://api.groq.com/openai/v1/models`。
- 官方說 `prompt` 限 224 tokens。兔白的提示可能更長，超長時 Groq 會怎樣，官方未寫明，兔白未實測。
- 兩份官方頁面的限額數字不一致：速率限制頁寫 Developer 檔 Whisper 每分鐘 20 次請求、每小時 7.2K 音訊秒；模型頁寫每分鐘 300～400 次、每小時 200K～400K 音訊秒。以賬戶 Limits 頁為準。
