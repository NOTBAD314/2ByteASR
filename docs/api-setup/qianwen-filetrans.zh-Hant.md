# 申請與設定 千問AI平台（Qwen 官方中國站）· 錄音檔案識別

最後核對：2026-10-25。來源見文末。千問AI平台是 Qwen 官方 API 的中國站，和國際站 Qwen Cloud 是同一套介面、同一批模型；兔白所在電腦沒有千問AI平台賬號，真實服務尚未驗證。2026-10-28 起音訊預設交給服務商臨時空間，不用建 OSS（臨時上傳的官方說明當天重新核對）。

## 一眼看懂

| 專案 | 內容 |
| --- | --- |
| 在兔白裡做什麼 | 雲端識別長錄音（單個檔案 ≤12 小時、≤2 GB），不需要顯示卡或本地模型。服務在北京，大陸網路直接可用 |
| 兩個模型（同一把 Key） | **Qwen-Audio-3.1-ASR-Flash**（推薦）：字/詞級時間 + 說話人（官方建議 2 小時內），支援熱詞與上下文。**Qwen3-ASR-Flash**：字/詞級時間，不分說話人，不支援熱詞 |
| 需要什麼 | 千問AI平台賬號 + 按量付費 API Key（`sk-ws-` 開頭）。**不用建 OSS** |
| 音訊怎麼交給服務商 | 這個介面只收“服務端讀得到的音訊網址”（官方：公網可訪問的檔案 URL，單次 1 個）。兔白預設先把本次音訊傳到千問AI平台提供的免費臨時空間（48 小時後失效），再把 `oss://` 臨時地址交給服務商識別。單個檔案的大小上限按模型不同，超過會在上傳時報錯 |
| 想自己保管音訊 | 可以改選“我自己的阿里雲 OSS 私有儲存”（見“可選：改用自己的 OSS”）：音訊放進你的私有 Bucket，用限時簽名連結交給服務商，取得結果後刪除 |
| 費用 | 按音訊用量計費，以千問AI平台賬單為準；新使用者註冊有體驗額度（哪些模型可用以控制台為準）。單價見官方定價頁。用自己的 OSS 時另有很少的儲存與流量費用 |

> **關於服務商臨時空間**：官方寫明臨時地址 48 小時有效，上傳憑證介面每個賬號每個模型限 100 QPS，並說“請勿用於生產環境”。它不適合的是伺服器那種高併發、批次的生產處理；兔白每個識別任務只上傳一個檔案、上傳後馬上提交。經常大量識別、想自己保管音訊，或者臨時空間上傳一直失敗，可以改用自己的 OSS。

### 中國站還是國際站

在“申請與設定 API…”裡選“千問AI平台 錄音檔案識別”或“Qwen Cloud 錄音檔案識別”都是同一項，視窗頂部有“中國站（千問AI平台）/ 國際站（Qwen Cloud）”切換。簡體中文介面預設中國站；已經儲存過地址的，按儲存的地址顯示。

| 入口 | 能不能給兔白識別字幕 |
| --- | --- |
| 千問 App / 網頁聊天 | **不能**。聊天登入只用於聊天，沒有給第三方軟體的授權方式 |
| **千問AI平台（本頁，platform.qianwenai.com）** | **能**。服務在北京，用按量付費 API Key，不需要 Workspace ID |
| Qwen Cloud（國際站，home.qwencloud.com） | 能，在同一視窗切到“國際站”。服務在新加坡，Key 與千問AI平台**不能互換** |
| 阿里雲百鍊 | 能，見“阿里雲百鍊 · 錄音檔案識別”。Key 與千問AI平台**不能互換** |

## 跟著做

1. **註冊並登入**：<https://platform.qianwenai.com/home> → 右上角“登录”，用手機號或阿里雲賬號登入。
2. **認證與充值**：新使用者註冊即有體驗額度；體驗額度用完後，要先完成實名認證並充值才能繼續呼叫（官方錯誤碼說明）。賬單頁：<https://platform.qianwenai.com/home/billing/overview>。控制台裡有“免費額度用完即停”開關：開著時免費額度用完會直接停止，不扣錢。
3. **建立 API Key**：<https://platform.qianwenai.com/home/api-keys> → “创建 API Key” → 填描述（例如“兔白字幕”）→ 生成，**立刻複製**（官方：完整 Key 只在建立時顯示一次）。按量付費 Key 是 `sk-ws-` 開頭（早期建立的是 `sk-` 開頭）。**不要用 Token Plan 訂閱 Key（`sk-sp-` 開頭）**，它不能做錄音檔案識別。
4. **貼到兔白**：首頁右上角“說明”→“申請與設定 API…”→ 右上角“換一家”選“千問AI平台 錄音檔案識別”，確認頂部選的是“中國站（千問AI平台）”。視窗一步一頁：註冊登入 › 充值 › 建立 Key › 貼上檢查，每一步的按鈕直接開啟對應頁面。
5. **檢查**：點“免費檢查”（不上傳音訊）；想確認真的能識別，再點“試識別一小段…”。
6. 點“**儲存並用於識別**”。

### 可選：改用自己的 OSS

想自己保管音訊、經常大量識別，或者臨時空間上傳一直失敗時再做，只做一次：

- 已經為“阿里雲百鍊 · 錄音檔案識別”設定過 OSS 的，**直接共用**。
- 沒有的話，在阿里雲 OSS 控制台 <https://oss.console.aliyun.com/> 建私有 Bucket。地域建議選華北2 北京（`cn-beijing`），離服務近。
- 建只管 `asr-temp/` 目錄的 RAM 子使用者與 AccessKey（<https://ram.console.aliyun.com/>）、加最小許可權策略與生命週期清理，步驟和許可權策略與百鍊教程“第四部分”完全相同。
- 在“貼上檢查”頁把“音訊交給服務商的方式”改成“我自己的阿里雲 OSS 私有儲存”：視窗多出“建 OSS”一步和 OSS 幾欄，填好後再點“檢查 OSS（上傳很小的測試檔案後刪除）”。

## 常見失敗與下一步

| 現象 | 原因 | 下一步 |
| --- | --- | --- |
| 服務商不認這把 API Key | 複製不完整、多了空格、Key 已刪除，或用了 Qwen Cloud（國際站）/ 百鍊的 Key | 回 API Key 頁面重新建立並複製；用國際站的 Key 就把視窗頂部切到“國際站” |
| 這是 Token Plan 訂閱專用的 Key | `sk-sp-` 開頭 | 在同一頁面建立按量付費 Key |
| 賬戶還沒完成認證或充值 | 新使用者體驗額度用完 | 在控制台完成實名認證並充值 |
| 免費額度已用完，且開著“免費額度用完即停” | 官方說明：開著這個開關時免費額度用完即停止 | 要繼續付費使用就關掉該開關；不想付費就停在這裡 |
| 賬戶欠費或餘額不足 | `Arrearage` | 到賬單頁充值 |
| 請求太頻繁 | `Throttling` | 稍等再試 |
| 音訊上傳方式 ✗（臨時上傳憑證被拒、上傳到臨時空間失敗） | Key 或模型不對、網路中斷 | 先確認前幾項都 ✓，檢查網路後再試；一直失敗可以改用自己的 OSS |
| 音訊上傳方式 ✗“OSS 設定不完整” | 填了 Bucket，但 AccessKey 沒儲存 | 補全 AccessKey；或把“音訊交給服務商的方式”改回“服務商臨時空間” |
| 服務端沒能讀取音訊 | 簽名連結讀不到（Bucket 白名單）或臨時地址已過期 | 用自己的 OSS 時先“檢查 OSS”；再在完成頁重試（會重新上傳） |
| 連不上 maas.qianwenaiapi.com | 網路或代理 | 檢查網路或代理設定 |

## 識別時會發生什麼

- 預設：音訊（16 kHz 單聲道 WAV，只有聲音）→ 向服務商申請這個模型的臨時上傳憑證 → 上傳到服務商臨時空間 → 用 `oss://` 臨時地址提交非同步任務 → **立即儲存任務編號** → 定時查詢 → 下載結果 → 寫入工程。臨時空間裡的音訊 48 小時後由服務商清理；上傳後超過約 40 小時還沒提交的會重新上傳。
- 選了自己的 OSS：音訊 → 你的 OSS → 限時簽名連結 → 提交 → 儲存任務編號 → 查詢 → 下載結果 → 寫入工程 → 刪除 OSS 臨時音訊。
- 斷網後重新識別：先查詢原任務，**不會**自動重新提交、不會重複收費。只有排隊中（PENDING）的任務能在雲端取消；已在執行的任務，按“取消”只停止本機等待，服務端仍可能完成並計費，兔白會如實顯示。
- 服務端返回的多字詞（如“阿里雲”）作為一個實測單位儲存，剃刀不會在詞中間按估算時間切。

## 隱私與費用

- 會上傳：本次識別範圍的音訊（預設到服務商臨時空間，48 小時後清理；選了自己的 OSS 時先到你的 OSS）。不會上傳：畫面、工程、其他素材。
- API Key、AccessKey 只存本機（Windows DPAPI 加密；Mac 鑰匙串，不可用時只留本次會話、不寫明文）。
- 兔白本身免費；千問AI平台是第三方付費服務，臨時空間官方說明是免費的；用自己的 OSS 時 OSS 另計費。
