## 它在兔白裡做什麼

- 用於語音識別，可以當“主力轉寫”，也可以當“複核”來源。
- 官方規定一次會話的音訊不超過 60 秒。兔白把**整段音訊（包括沒人說話的部分）**切成不超過約 55 秒的塊，儘量切在安靜處，逐塊傳送；每塊是一次獨立的會話。
- 訊飛只回文字。官方返回表把時間欄位標為保留欄位，兔白不拿它們當逐字時間，所以每塊只有一個起止時間。需要像樣的字幕時間軸，請在模型工坊配一個本地字幕時間軸（對齊）模型。
- 兔白目前不會把詞庫或熱詞傳給訊飛（官方支援熱詞，兔白沒有接）。
- 官方說 V2.0 從“準確轉寫”轉向“流暢成文”，口語裡的重複、語氣詞可能被整理掉。
- 某一塊失敗時，這次識別會停下，已完成的塊會保留；再次識別時只補沒完成的塊，不會重複收已完成部分。

6. 開啟兔白的「申請與設定 API」，在左側“語音識別（生成字幕）”下選 **訊飛 Spark-ASR 2.0**。開啟方式任選一種：

## 常見失敗與下一步

訊飛的錯誤碼說明見官方錯誤碼查詢頁（動態載入，本次沒讀到）。下表的錯誤碼含義取自訊飛“語音聽寫（流式版）”文件的錯誤碼錶，V2.0 文件沒有單獨列出，以訊飛實際返回為準。

| 現象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 設定格式 ✗“還缺 AppID / APIKey / APISecret” | 有一欄沒填；或再次開啟頁面後 AppID、APISecret 是空的 | 把三項都重新貼一次 |
| 試識別失敗，顯示 HTTP 401（連線被拒） | APIKey 或 APISecret 填錯，或三項不是同一個應用的 | 回到同一個應用的服務頁，把三項重新複製 |
| 試識別失敗，顯示 HTTP 403 | 電腦時間和標準時間相差太多（官方：簽名時間偏差不能超過 300 秒） | 在 Windows 的“日期和時間”設定裡同步時間，再試 |
| “Spark業務錯誤 11200：……” | 沒有許可權：沒領免費額度、額度用完或已過期 | 回產品頁領取或購買；確認實名認證已通過 |
| “Spark業務錯誤 10005：……”或“10313：……” | AppID 不對或為空，或沒開通這個服務 | 核對 AppID 是否來自同一個應用，並確認已在產品頁開通 |
| “Spark業務錯誤 11201：……” | 當天呼叫次數超過上限 | 隔天再跑，或聯絡訊飛商務提高上限 |
| “Spark會話達到有界等待時間”“Spark 提前結束……”或連不上 | 網路中斷或太慢 | 檢查網路後再次識別；已完成的塊會保留，只補沒完成的 |
| 其他“Spark業務錯誤 程式碼：說明” | 訊飛返回的業務錯誤 | 記下程式碼，到官方錯誤碼頁查詢，或在控制台提交工單 |

## 隱私與費用

- **傳到哪裡**：`iat.cn-huabei-1.xf-yun.com`（訊飛開放平台）。
- **傳什麼**：本次識別的整段音訊（16 kHz 單聲道，不含畫面），按約 55 秒一塊即時傳送。沒有附加檔名或詞庫。
- **金鑰**：AppID、APIKey、APISecret 三項都只儲存在本機。Windows 用 DPAPI 加密；macOS 存在“鑰匙串”，鑰匙串不可用時只在本次執行期間儲存在記憶體，絕不存明文。不寫進工程、日誌或匯出檔案。
- **費用**：按訊飛的免費額度或套餐扣除。一塊約 55 秒就是一次會話，例如 10 分鐘影片約 11 次會話。訊飛是按呼叫次數還是按時長計費、單價多少，本次沒能從官方頁面讀到（待核實），以控制台顯示為準。免費額度不是永久的，規則可能調整。

## 進階（一般使用者可跳過）

- 鑑權：兔白按官方文件用 APISecret 對 `host`、`date`、請求行做 HMAC-SHA256 簽名，拼進連線地址；APISecret 本身不傳送。
- 傳送引數：`domain=spark_asr_v2`、`language=zh_cn`、`accent=mandarin`、`dwa=wpgs`（動態修正）、`vinfo=1`、`fa_nbest=true`、`bos=60000`、`eos=60000`；音訊為 16 kHz、16 bit、單聲道 PCM，每 40 毫秒一幀。
- 訊飛回傳的 `bg`、`ed`、`wb`、`we` 等時間欄位，兔白只存作診斷證據，不當作字幕時間。
- 免費檢查不聯絡訊飛；“試識別一小段…”走的是正式識別相同的程式路徑。
