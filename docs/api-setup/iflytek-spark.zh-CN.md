## 它在兔白里做什么

- 用于语音识别，可以当“主力转写”，也可以当“复核”来源。
- 官方规定一次会话的音频不超过 60 秒。兔白把**整段音频（包括没人说话的部分）**切成不超过约 55 秒的块，尽量切在安静处，逐块发送；每块是一次独立的会话。
- 讯飞只回文字。官方返回表把时间字段标为保留字段，兔白不拿它们当逐字时间，所以每块只有一个起止时间。需要像样的字幕时间轴，请在模型工坊配一个本地字幕时间轴（对齐）模型。
- 兔白目前不会把词库或热词传给讯飞（官方支持热词，兔白没有接）。
- 官方说 V2.0 从“准确转写”转向“流畅成文”，口语里的重复、语气词可能被整理掉。
- 某一块失败时，这次识别会停下，已完成的块会保留；再次识别时只补没完成的块，不会重复收已完成部分。

## 从未注册开始

1. 打开讯飞开放平台注册登录。官方快速指引：可用微信扫码或手机号快捷登录，也可在注册页注册完整账号。
2. 完成个人实名认证。官方：未实名的普通用户不能购买服务、不能参加福利活动；免费礼包写明“完成个人实名认证的新用户”才能领。认证方式和所需材料：需要登录才能看到，待核实。企业用户不能再改做个人认证，选认证主体时要想清楚。
3. 打开产品页 <https://www.xfyun.cn/services/spark_asr_zh_en_v2.0>，领取免费额度或购买套餐。官方接口文档要求先做这一步再测试。按钮名称和额度数量：需要登录才能看到，待核实。
4. 打开控制台“我的应用” <https://console.xfyun.cn/app/myapp>，创建一个应用（官方：填应用名称等信息后提交；新版控制台一个应用可以管理所有接口）。
5. 进入这个应用的“语音听写大模型（中英）V2.0”服务页，复制 **AppID、APIKey、APISecret** 三项（官方：APIKey 和 APISecret 都是 32 位字符串）。三项必须来自同一个应用。页面具体位置：需要登录才能看到，待核实。
6. 打开兔白的「申请与设置 API」，在左侧“语音识别（生成字幕）”下选 **讯飞 Spark-ASR 2.0**。打开方式任选一种：
   - 首页右上角“说明”菜单 →“申请与设置 API…”
   - 模型工坊 →“在线 API”页 →“Spark-ASR-2.0”卡片上的设置按钮
   - 首页识别方案卡片上的“配置 API”
7. 三项分别贴进对应的栏，点“免费检查（不上传音频）”，再点“试识别一小段…”确认真的能用。
8. 点“保存”；要马上用它做主力转写，点“保存并用于识别”。

这一页目前没有“① 在官网创建 API Key [打开网页]”那一排提示，请用上面表格里的链接打开官网。

## 常见失败与下一步

讯飞的错误码说明见官方错误码查询页（动态载入，本次没读到）。下表的错误码含义取自讯飞“语音听写（流式版）”文档的错误码表，V2.0 文档没有单独列出，以讯飞实际返回为准。

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 设置格式 ✗“还缺 AppID / APIKey / APISecret” | 有一栏没填；或再次打开页面后 AppID、APISecret 是空的 | 把三项都重新贴一次 |
| 试识别失败，显示 HTTP 401（连线被拒） | APIKey 或 APISecret 填错，或三项不是同一个应用的 | 回到同一个应用的服务页，把三项重新复制 |
| 试识别失败，显示 HTTP 403 | 电脑时间和标准时间相差太多（官方：签名时间偏差不能超过 300 秒） | 在 Windows 的“日期和时间”设置里同步时间，再试 |
| “Spark业务错误 11200：……” | 没有权限：没领免费额度、额度用完或已过期 | 回产品页领取或购买；确认实名认证已通过 |
| “Spark业务错误 10005：……”或“10313：……” | AppID 不对或为空，或没开通这个服务 | 核对 AppID 是否来自同一个应用，并确认已在产品页开通 |
| “Spark业务错误 11201：……” | 当天调用次数超过上限 | 隔天再跑，或联系讯飞商务提高上限 |
| “Spark会话达到有界等待时间”“Spark 提前结束……”或连不上 | 网络中断或太慢 | 检查网络后再次识别；已完成的块会保留，只补没完成的 |
| 其他“Spark业务错误 代码：说明” | 讯飞返回的业务错误 | 记下代码，到官方错误码页查询，或在控制台提交工单 |

## 隐私与费用

- **传到哪里**：`iat.cn-huabei-1.xf-yun.com`（讯飞开放平台）。
- **传什么**：本次识别的整段音频（16 kHz 单声道，不含画面），按约 55 秒一块实时发送。没有附加文件名或词库。
- **密钥**：AppID、APIKey、APISecret 三项都只保存在本机。Windows 用 DPAPI 加密；macOS 存在“钥匙串”，钥匙串不可用时只在本次运行期间保存在内存，绝不存明文。不写进工程、日志或导出文件。
- **费用**：按讯飞的免费额度或套餐扣除。一块约 55 秒就是一次会话，例如 10 分钟视频约 11 次会话。讯飞是按调用次数还是按时长计费、单价多少，本次没能从官方页面读到（待核实），以控制台显示为准。免费额度不是永久的，规则可能调整。

## 进阶（一般使用者可跳过）

- 鉴权：兔白按官方文档用 APISecret 对 `host`、`date`、请求行做 HMAC-SHA256 签名，拼进连接地址；APISecret 本身不发送。
- 发送参数：`domain=spark_asr_v2`、`language=zh_cn`、`accent=mandarin`、`dwa=wpgs`（动态修正）、`vinfo=1`、`fa_nbest=true`、`bos=60000`、`eos=60000`；音频为 16 kHz、16 bit、单声道 PCM，每 40 毫秒一帧。
- 讯飞回传的 `bg`、`ed`、`wb`、`we` 等时间字段，兔白只存作诊断证据，不当作字幕时间。
- 免费检查不联系讯飞；“试识别一小段…”走的是正式识别相同的程序路径。
